# Manual do Whisk3D UI

O **Whisk3D UI** é a biblioteca de interface do Whisk3D: botões, abas, menus suspensos, cartões de propriedades, texto e ícones, desenhados sobre o Whisk3D Core. O editor é feito com ela. Este manual é para quem programa em C ou C++ e quer usá-la para a interface do seu jogo ou programa. Rascunho para revisão.

A página do projeto: **[Whisk3D UI](https://leoncini.com.ar/proyecto.php?id=whisk3d-ui&lang=pt)**. O código está em **[Whisk3D-UI](https://github.com/Dante-Leoncini/Whisk3D-UI)**, no GitHub, com licença MIT.
