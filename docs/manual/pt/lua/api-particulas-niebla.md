# Partículas, névoa e visibilidade

| Função | O que faz |
|---|---|
| `emit(obj [, n])`, `setEmitting(obj, bool)` | Uma rajada de partículas, ou ligar/desligar um emissor. |
| `getFog(obj)`, `setFog(obj, density [, r, g, b, inicio, fin])` | Ler e mudar a névoa. |
| `setSector`, `visCell`, `setVisAnchor`, `setVisCurveT`, `setBatch` | Controle avançado de quais partes do nível são desenhadas. |
