# Cenas e cinemáticas

| Função | O que faz |
|---|---|
| `changeScene(name [, restart])` | Passa para outra cena (menu, nível 2…) no fim do quadro. |
| `playScene(name [, "funcion"])` | Reproduz uma cena 3D como cinemática com o jogo em pausa; ao terminar, chama essa função. |
| `stopScene3D()`, `scenePlaying()` | Interrompe a cinemática / diz qual está sendo vista. |
| `draw3D([on])` | Desliga ou liga todo o 3D (por exemplo, atrás de um menu opaco). |
