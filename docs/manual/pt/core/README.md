# Manual do Whisk3D Core

O **Whisk3D Core** é a camada de abstração sobre a qual o Whisk3D é feito: uma única forma de pedir as coisas (desenhar, tocar sons, ler arquivos, receber as teclas) e uma implementação diferente para cada sistema. Este manual é para quem programa em C ou C++ e quer fazer um jogo diretamente sobre o Core. Rascunho para revisão.

A página do projeto, com exemplos que rodam no navegador: **[Whisk3D Core](https://leoncini.com.ar/proyecto.php?id=whisk3d-core&lang=pt)**. O código está em **[Whisk3D-Core](https://github.com/Dante-Leoncini/Whisk3D-Core)**, no GitHub, com licença MIT.
