# Navegação na Viewport 3D

## Com mouse (PC)

| Função | Descrição | Como usar |
|---|---|---|
| Orbitar | Gira a vista ao redor do ponto pivô. | Botão do meio + arrastar, ou <kbd>Alt</kbd> + botão esquerdo + arrastar. |
| Deslocar (pan) | Move a vista para o lado. | <kbd>Shift</kbd> + botão do meio, ou <kbd>Alt+Shift</kbd> + botão esquerdo + arrastar. |
| Zoom | Aproxima ou afasta. | Roda do mouse. |
| Selecionar | Escolhe o que está sob o ponteiro (decide ao soltar). | Clique esquerdo; <kbd>Shift</kbd>+clique adiciona ou remove. |
| Seleção por caixa | Arrastar sobre o fundo marca um retângulo. | Arrastar com o botão esquerdo, ou <kbd>B</kbd>. |
| Menu de contexto | Abre o menu do modo no ponteiro (durante um transform, cancela-o). | Clique direito. |
| Travar órbita | O que orbitava passa a deslocar: a vista fica como um tabuleiro 2D. | Menu Vista → Travar Órbita. |
| Mover a câmera com a vista | Olhando pela câmera ativa, navegar move a câmera: é assim que se ajusta a tomada. | Clique no cadeado (embaixo, na vista da câmera), ou Menu Vista → Mover a câmera com a vista. |

## Com teclado

| Função | Descrição | Atalho |
|---|---|---|
| Vista frontal / traseira | Olha de frente ou de trás. | <kbd>Num1</kbd> / <kbd>Ctrl+Num1</kbd> |
| Vista direita / esquerda | Olha de lado. | <kbd>Num3</kbd> / <kbd>Ctrl+Num3</kbd> |
| Vista superior / inferior | Olha de cima ou de baixo. | <kbd>Num7</kbd> / <kbd>Ctrl+Num7</kbd> |
| Perspectiva / Ortográfica | Alterna entre as duas projeções. | <kbd>Num5</kbd> |
| Girar a vista | Gira a vista 15° sobre o seu eixo. | <kbd>Num4</kbd> / <kbd>Num6</kbd> |
| Vista da câmera | Olha através da câmera ativa (de novo: sai). | <kbd>Num0</kbd> |
| Definir câmera ativa | O objeto ativo passa a ser a câmera ativa. | <kbd>Ctrl+Num0</kbd> |
| Enquadrar seleção | Centraliza a vista no que está selecionado e ajusta o zoom. | <kbd>Num.</kbd> (ponto do teclado numérico) |
| Vista local | Mostra só o que está selecionado e o enquadra; de novo, restaura tudo. | <kbd>/</kbd> |
| Importar modelo | Abre o explorador para importar OBJ, FBX, glTF ou GLB (só no PC). | <kbd>Num9</kbd> |

## Com os dedos (Android, Web touch)

| Função | Descrição | Gesto |
|---|---|---|
| Orbitar | Gira a vista. | Arrastar um dedo. |
| Zoom e deslocar | Fazer pinça aproxima ou afasta; mover os dois dedos juntos desloca. | Dois dedos. |
| Selecionar | Escolhe o que está sob o dedo. | Tocar e levantar sem mover. |
| Enquadrar seleção | Igual a <kbd>Num.</kbd>. | Toque duplo com dois dedos. |
| Modificadores de toque | Botões Shift e Ctrl da barra inferior: ficam ligados (verde) para adicionar à seleção ou escolher caminhos. | Tocar em Shift / Ctrl. |
| Vista (navegar) | No Modo Edição e nos modos de pintura, o dedo navega em vez de selecionar ou pintar. | Botão em forma de monitor da barra inferior. |

## Com o teclado do Nokia N95

| Função | Tecla |
|---|---|
| Orbitar | Setas (manter pressionadas) |
| Zoom / Enquadrar seleção | <kbd>0</kbd> + cima/baixo / <kbd>0</kbd> sozinho |
| Deslocar | <kbd>\*</kbd> + setas |
| Vistas (frontal, lateral, superior) / Perspectiva-Ortográfica | <kbd>#</kbd> + setas / <kbd>#</kbd> sozinho |
| Mover / Rotacionar / Escalar (durante o transform: eixo X / Y / Z) | <kbd>1</kbd> / <kbd>2</kbd> / <kbd>3</kbd> |
| Confirmar / Cancelar | OK (centro) / <kbd>C</kbd> |
| Excluir (sem nada para cancelar) / Desfazer e Refazer | <kbd>C</kbd> / <kbd>C</kbd> + esquerda ou direita |
| Mudar o sombreamento | <kbd>6</kbd> |
| Extrudar (Modo Edição) | <kbd>7</kbd> |
| Loop Cut (Modo Edição) / vista da câmera (fora da edição) | <kbd>8</kbd> |
| Travar órbita | <kbd>9</kbd> |
| Mover a câmera com a vista (olhando pela câmera) | Tecla de seleção esquerda → menu Vista |
| Percorrer a seleção / adicionar, remover, tudo ou nada | Lápis / Lápis + setas |
| Barra de menus / cursor virtual | Tecla de seleção esquerda / direita |
| Mudar de viewport, redimensionar, maximizar | Tecla verde (sozinha, + setas, + OK) |
| Modo jogo em tela cheia | Tecla verde + <kbd>0</kbd> (de novo: a imagem cobre a tela toda; de novo: volta). Sem a UI, sem a borda da câmera nem a área escura em volta (só ficam faixas pretas se a câmera declarar um aspecto diferente do da tela, até a segunda vez), e as setas não fazem pan: vê-se o jogo tal como é |

O N95 também aceita mouse e teclado Bluetooth. Para digitar texto, usa-se o T9.
