# サウンド

**Sound**オブジェクトは、シーンに置いたオーディオです。音楽、効果音、機械の音などです。3D Viewportではスピーカーとして表示されます。音楽のようにどこでも同じように鳴らすことも、置いた位置から、近いほど大きく鳴らすこともできます。このページはサウンドのプロパティのリファレンスです。オブジェクトの追加と移動のしかたは、チュートリアル[Object Mode](../tutoriales/modo-objeto.md)で説明しています。

新しいSoundオブジェクトは、オーディオがない状態（**None**）で始まります。ファイルはSoundカードで選びます。

![Soundタブ全体。追加したばかりのサウンドで、ファイルはNoneです](../tutoriales/img/objeto-sonido-propiedades.webp)

## サウンドを選んだ状態で作る

- ![PC](../tutoriales/img/icono-pc.svg) [Library](outliner.md#libraryビュー)からサウンドを3D Viewportにドラッグすると、落とした位置に、そのサウンドを持つSoundオブジェクトが作成されます。
- ![PC](../tutoriales/img/icono-pc.svg) サウンドファイル（たとえば`.wav`）を3D Viewportにドロップすると、プロジェクトに追加され、その位置にオブジェクトが作成されます。

## タブ

| タブ | 内容 |
|---|---|
| Object | 位置、名前、表示。すべてのオブジェクトと同じです。[3Dメッシュ](objeto-malla.md#objectタブ)を参照してください。非表示のサウンドは鳴りません。コレクションを非表示にすると、その中のサウンドも鳴らなくなります。 |
| Sound | 下のカードです。 |
| Constraints | [コンストレイント](restricciones.md)を参照してください。 |
| Scripts | オブジェクトのLuaスクリプトです。ゲームの中でサウンドを鳴らしたり止めたりできます。[Whisk3DのLua](../lua/README.md)を参照してください。 |

## Soundカード

| プロパティ | 働き |
|---|---|
| Sound | 鳴らすファイルと、その長さです。メニューには、プロジェクトのサウンド、**None**、そしてディスクからサウンドをプロジェクトに読み込む**Load sound from the file browser...**が並びます。 |
| Active | チェックを外すと鳴りません。削除せずにオフにしたいときに使います。 |
| Volume ◆ | 音の大きさです。1でファイルの音量、0で無音、2で2倍です。 |
| Pitch ◆ | 高く、または低くします。1が元の高さです。2では1オクターブ高く2倍の速さで、0.5では1オクターブ低く半分の速さで鳴ります。そのため、Pitchを変えると長さも変わります。 |
| Reverb ◆ | このサウンドをどれだけリバーブの残響に送るかです。0でまったく送らず、1ですべて送ります。洞窟、教会、廊下のような感じが出ます。 |
| Pan | どちら側で鳴るかです。-1で左、0で中央、1で右。Positional (3D)がオフのときだけ使います。オンのときは、位置によって左右が決まります。 |
| Start time | シーンの何秒目から鳴り始めるかです。 |
| Trim start | ファイルの先頭を何秒切り取るかです。 |
| Trim end | ファイルの末尾を何秒切り取るかです。 |
| Loop forever | 2つの切り取りの間に残った部分を、途切れなく繰り返し続けます。BGMや、途切れない環境音に使います。 |
| Positional (3D) | オブジェクトの位置から鳴ります。下の説明を参照してください。 |
| Full volume radius | Positional (3D)のときのみ：この距離（メートル）までは、最大の音量で鳴ります。 |
| Audible range | Positional (3D)のときのみ：この距離（メートル）から先では、聞こえなくなります。 |

## 時間は秒単位

サウンドの時間は、フレームではなく**秒**で測ります。そのため、シーンを毎秒30フレームから60フレームに変えても、サウンドは同じ瞬間に合ったままで、何も調整し直す必要はありません。

[Timeline](linea-de-tiempo.md#サウンド)では、選択した各サウンドに**ストリップ**があり、どこから鳴り始めてどれだけ続くかを表しています。ストリップをドラッグすると**Start time**が変わり、端のどちらかをつかむと切り取りが変わります。TimelineのPlayで鳴り、停止すると止まります。

ゲームでは、サウンドは出現したときに鳴り始めます（たとえば、プレハブの一部である爆発の音）。そこに**Start time**の値が加わります。

## Positional (3D)

チェックを入れないと、サウンドは音楽のように、どこにあっても同じように聞こえます。チェックを入れると、聞き手から見て**置いた位置から**聞こえます。

- 近いほど大きく聞こえます。**Full volume radius**までは最大の音量で鳴り、そこから**Audible range**で消えるまで小さくなっていきます。
- 右にあれば右から、左にあれば左から聞こえます。
- 後ろにあると、小さく、より中央寄りに聞こえます。

聞き手は、ゲームではアクティブなカメラ、エディターではアクティブな3D Viewport（カメラから見ているときはそのカメラ）です。サウンドを選択すると、3D Viewportに2つの球が描画されます。最大音量の半径の球と、聞こえる範囲の球です。

## 例

| サウンド | 作り方 |
|---|---|
| BGM | Positional (3D)をオフにして、Loop foreverをオンにします。 |
| 滝 | Positional (3D)とLoop foreverをオンにし、Full volume radiusを小さく、Audible rangeを大きくします。遠くから聞こえ始め、近づくにつれて大きくなります。 |
| アニメーションの4秒目に鳴る打撃音 | Start timeを4にするか、Timelineでストリップをそこまで動かします。30 FPSならフレーム121です。フレーム1が0秒目だからです。 |
| 最後にフェードアウトする音楽 | Volume（◆）にキーフレームを打ちます。終わりの少し前に1、終わりに0です。 |
