# Array

**Array**モディファイアーは、メッシュのコピーを、1つ前のコピーから少しずつずらして列状に並べます。柵の支柱、階段の段、廊下の柱、鎖の輪など、繰り返すものなら何にでも使えます。パーツを1つだけモデリングすれば、残りはArrayが作ります。パーツを変更すると、すべてのコピーが変わります。

![Modifiersタブ全体。立方体にArrayモディファイアーが付いています](../tutoriales/img/modificador-array.webp)

## 追加のしかた

1. メッシュを選択します。
2. Propertiesで**Modifiers**タブ（スパナのアイコン）を開きます。
3. **Add**をタップして、**Array**を選びます。

リストには**Array**として表示され、その下にパラメーターのカードが開きます。ほかのモディファイアーと同じく、メッシュを壊しません。オフにしたり、**Move Up**と**Move Down**で順番を変えたり、**Remove**で外したり、**Apply Modifier**でベイクしたりできます。

## パラメーター

| パラメーター | 働き |
|---|---|
| Display in Viewport | オフにすると、コピーは計算されません。ビューにもレンダリングにも表示されません。 |
| Display in Edit Mode | オフにすると、編集中は元のパーツだけが表示されます。 |
| Count | 元のパーツを含めた、パーツの合計数です（初期値は2）。1にすると元のパーツだけになります。 |
| Relative Offset | パーツの**サイズ**に応じて各コピーをずらします。初期状態ではオンで、Factor Xは1です。各コピーは前のコピーにぴったり接し、すき間も重なりもできません。 |
| Factor X / Y / Z | 各コピーをその軸方向に、自分のサイズの何倍ずらすかです。1 = 接する、2 = パーツ1つ分のすき間ができる、0.5 = 半分重なる。Objectタブと同じく、Yは奥行き、Zは高さです。Relative Offsetがオンのときだけ表示されます。 |
| Constant Offset | パーツのサイズに関係なく、各コピーを一定の距離だけずらします。初期状態ではオフです。2つのオフセットが両方オンのときは、合計されます。 |
| Distance X / Y / Z | 各コピーを各軸方向にずらす距離（メートル）です。Constant Offsetがオンのときだけ表示されます。 |
| Object Offset | シーンのオブジェクト（Emptyがいちばん便利です）を使って、各コピーを1つ前のコピーより少しずつ多く移動、回転、拡大縮小します。下の説明を参照してください。**None**のときは使われません。 |
| Merge | あるコピーと次のコピーの間で接している頂点を結合して、1つのサーフェスにします。手すりが、ばらばらの区間ではなく1本につながります。初期状態ではオフです。 |
| Merge Distance | 2つの頂点がどれだけ近ければ結合されるかです（初期値は0.001 m）。Mergeがオンのときだけ表示されます。 |
| Apply Modifier | コピーをメッシュにベイクします。下の注を参照してください。 |

## 例

- **柵：** 支柱（細くて背の高いCube）で、Countを10、Factor Xを3にします。支柱10本が、支柱2本分の間隔をあけて並びます。
- **階段：** 段（平たいCube）で、Factor Xを0、Factor Yを1、Factor Zを1にします。各段が、前の段より1段分奥に、1段分高くなります。

## Object Offset

オブジェクトを選ぶと、各コピーは、そのオブジェクトが**メッシュに対してどれだけ移動、回転、拡大縮小しているか**を繰り返し、それを積み重ねていきます。2つ目のコピーは1回分、3つ目は2回分、というように続きます。

- Emptyがメッシュと同じ位置にあり、垂直軸のまわりに30°回転している場合、各コピーは前のコピーより30°ずつ多く回転します。コピーが12個で1周します。
- さらに少し上にあれば、各コピーは少しずつ高くなります。らせん階段になります。
- 0.9に拡大縮小されていれば、各コピーは前のコピーより少しずつ小さくなります。内側へ巻いていくらせんになります。

Emptyがメッシュと同じ位置にあるとき、コピーはメッシュの原点を中心に回転します。コピーがその場で回転するのではなく円形に並ぶようにするには、Edit Modeでパーツを原点から離し、Relative Offsetをオフにします。オブジェクトを移動・回転すると、コピーはすぐに更新されます。

## 順番が大切

Relative Offsetは、上のモディファイアーから**渡されたままの**メッシュを測ります。上に[Mirror](modificador-espejo.md)があれば、鏡映されたあとのオブジェクトを測ります。下に[Subdivision Surface](modificador-subdivision.md)があると、Mergeで結合したコピーは1つのパーツとして滑らかになります。Mergeを使わないと、各コピーが別々に滑らかになります。

> [!NOTE]
> ArrayでApply Modifierを使うと、Arrayだけでなく、リストにあるオンのモディファイアーが**すべて**（ビューの値で）ベイクされ、リストは空になります。オフになっていたモディファイアーや、[Armature](modificador-esqueleto.md)のようにジオメトリを生成しないモディファイアーも消えます。元に戻すことができます。
