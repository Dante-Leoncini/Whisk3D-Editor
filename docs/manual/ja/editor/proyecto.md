# プロジェクト（.w3d）とファイル

| 機能 | 説明 | 場所 |
|---|---|---|
| Open project | .w3dを開きます（システムからダブルクリックでも開けます）。 | Properties → File/Render → File |
| Save / Save As | カードに設定したフォルダーと名前で保存します。Save Asでは別の名前を指定します。名前が空の場合、欄が赤くなります。 | Fileカード、<kbd>Ctrl+S</kbd> |
| Save Version | 保存したうえで、番号付きのコピー（`proyecto_v03.w3d`）も残します。 | Fileカード |
| Extract assets | 中身をすべてフォルダーにコピーします（コピーを変更してもプロジェクトは変わりません）。 | Fileカード |
| Meshes as text | メッシュをバイナリではなく、読めるテキストとして保存します。 | Fileカード |
| Imports | OBJ、FBX、glTF、GLB、および.w3duiインターフェース。インポートしたものはプロジェクト内にコピーされます（重複はしません）。 | 3D Viewport → Add → Imports |
| Export | 選択したオブジェクトをOBJ、glTF、GLBで書き出します（モディファイアーとトランスフォームの有無を選べます）。 | Properties → Export |
| 未保存の変更 | 編集して保存していないもの（スクリプト、ペイントしたテクスチャ）には`*`が付きます。プロジェクトを閉じるときや別のプロジェクトを開くときは、失われる内容が一覧で表示されます。 | 自動 |
| リソースを中に置くか外に置くか | 外部リソースはコピーされません。パスが保存され、見つからない場合は警告が出ます。 | Resourceカード。IDEとUV Editorの「Save inside / outside the .w3d」 |

保存中にファイルが中途半端な状態になることはありません。まず一時的なコピーを書き込み、そのあとで名前を変更します。

## ブラウザーで（Web版）

ブラウザーでは、ページが自分でPCのファイルを読んだり書いたりすることはできません。そのため、Web版では次のようになります。

- **Open project**、**Imports**、テクスチャの選択では、ブラウザーのファイル選択画面が開きます。**Choose file**ボタンの付いた案内が表示されます。OBJの場合は、.obj、その.mtl、テクスチャをまとめて選びます。glTFの場合は、.gltfとその.binを選びます。
- **Save**（<kbd>Ctrl+S</kbd>）、**Save As**、**Save Version**、**Extract assets**は、ファイルをブラウザーのダウンロードフォルダーにダウンロードします。**Export**（OBJは.mtlとテクスチャが一緒にダウンロードされます）、レンダー、UVマップ、外部に保存するペイントしたテクスチャ、外部スクリプトも同じです。
- エディターが保存先のフォルダーを求めるときも、ファイル選択画面は開かず、ファイルがそのままダウンロードされます。
- ページが複数のファイルをダウンロードしてよいかをブラウザーが尋ねてきたら、許可してください。許可しないと、最初のファイルしかダウンロードされません。
- 開いたものはページのメモリーの中にあります。ページを再読み込みすると、ダウンロードしていないものはすべて失われます。
