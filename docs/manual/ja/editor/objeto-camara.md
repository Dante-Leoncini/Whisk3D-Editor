# カメラ

**カメラ**は、シーンに置いた視点です。**アクティブなカメラ**は、ゲームとレンダリングに使われるカメラです。このカメラに映るものが、プレイ中に見えるもので、画像や動画に出力されるものです。このページはカメラのプロパティのリファレンスです。オブジェクトの追加と移動のしかたは、チュートリアル[Object Mode](../tutoriales/modo-objeto.md)で説明しています。

![Cameraタブ全体](../tutoriales/img/objeto-camara-propiedades.webp)

## タブ

| タブ | 内容 |
|---|---|
| Object | 位置、回転、名前、表示。すべてのオブジェクトと同じです。[3Dメッシュ](objeto-malla.md#objectタブ)を参照してください。 |
| Camera | カメラのレンズです。下のカードです。 |
| Constraints | [コンストレイント](restricciones.md)を参照してください。 |
| Scripts | オブジェクトのLuaスクリプトです。[Whisk3DのLua](../lua/README.md)を参照してください。 |

## Cameraカード

| プロパティ | 働き |
|---|---|
| Orthographic | 遠近感をなくします。遠くのものが小さくならず、平行な線が集まりません。[透視投影と平行投影](../tutoriales/navegacion.md#透視投影と平行投影)を参照してください。 |
| FOV ◆ | 視野角です（上下方向、度単位）。小さくすると望遠レンズのようになり、写る範囲が狭く、近くに見えます。大きくすると広角レンズになり、写る範囲が広く、遠近感が強調されます。初期値は45です。 |
| Near ◆ | 描画する最小距離です。カメラにこれより近いものは描画されません。初期値は0.01です。 |
| Far ◆ | 描画する最大距離です。これより遠いものは描画されません。初期値は1000です。 |
| Depth of field | ぼかしをオンにします。ピントの距離にあるものはくっきりと、それ以外はぼけて写ります。描画するのはレイトレーシングです。Post Processingでも同じピントを使えます。 |
| F-stop | 本物のカメラと同じく、どれだけぼかすかです。数値が小さいほど強くぼけます。 |
| Focus distance ◆ | 何メートル先にピントを合わせるかです。カメラに描かれる線と十字が、その位置を示します。 |
| Focus object | ピントが自動で追いかけるオブジェクトです。どこにあっても追従します。オブジェクトを選ぶと、Focus distanceは表示されなくなります。**None**にすると、手で設定する距離に戻ります。 |
| Target | アクティブなカメラが常に向くオブジェクトです。オブジェクトが動くと、カメラは回転して追いかけます。**None**にすると、回転させた方向を向いたままになります。 |

F-stop、Focus distance、Focus objectは、Depth of fieldにチェックを入れると表示されます。

### NearとFarを変更するとき

カメラのすぐ近くにある壁やキャラクターが切れて見えるときは、**Near**を下げます。大きなステージの奥が消えるときは、**Far**を上げます。範囲は必要以上に広げないほうがよいでしょう。NearとFarの差が大きいと、すぐ近くにある面同士がちらつくことがあります。特にNokia N95で起こります。

NearとFarはアニメーションできます。たとえば、カメラが上昇してステージが広く見えるようになるときに、描画の限界を遠ざけるのに使えます。

### キャラクターを追うカメラ

ショットに合わせて、2つの方法があります。

- **カメラはその場にとどまり、回転する：** キャラクターを**Target**に設定します。キャラクターが走っても、アクティブなカメラはショットの中央にとらえ続けます。通り過ぎるのを見送る人のような動きです。
- **カメラがキャラクターと一緒に移動する：** TargetはNoneのままにして、キャラクターをソースにした**Child Of**コンストレイントを追加し、**Location**だけにチェックを入れます。同じ距離、同じ角度でついていき、キャラクターが向きを変えても回転しません（[Child Of](restricciones.md#child-of)を参照）。

## アクティブなカメラを選ぶ

シーンにはカメラをいくつも置けますが、アクティブなカメラは1つだけです。切り替える方法：

| | 選び方 |
|---|---|
| ![PC](../tutoriales/img/icono-pc.svg) PC | カメラを選択して<kbd>Ctrl</kbd> + <kbd>Num 0</kbd> |
| メニュー | View → Cameras → Set Active Object as Camera |
| Properties | Animationタブ → **Active camera**カード |

Active cameraカードでは、ひし形で**カメラカット**を作れます。あるフレームで、カメラから別のカメラに切り替えるものです。[Timeline](linea-de-tiempo.md)を参照してください。

アクティブなカメラから見て、ナビゲーションでショットを調整する方法は、ナビゲーションのチュートリアルの[アクティブなカメラ](../tutoriales/navegacion.md#アクティブなカメラ)を参照してください。
