# コンストレイント

**コンストレイント**（英語で*constraint*）は、オブジェクトに別のオブジェクトの何かを取り込ませます。位置や回転を写したり、常にカメラの方を向かせたり、子のように追従させたりします。手でアニメーションしなくても、ものが自動で収まるようにするのに使います。キャラクターの下についていく影、いつも正面を向いている平面の木、手にくっついた剣などです。このページでは、それぞれのコンストレイントとそのすべてのパラメーターを説明します。オブジェクトの追加と移動のしかたは、チュートリアル[Object Mode](../tutoriales/modo-objeto.md)で説明しています。

## 場所

Properties → **Constraints**タブにあります。メッシュ、カメラ、ライト、アーマチュア、サウンド、エンプティなど、どの3Dオブジェクトにもあります。インターフェースの2D要素にはありません。

それぞれを見る前に、すべてに共通する3つのことです。

- **オブジェクトの数値は変わりません。** コンストレイントは、描画するときに上から適用されます。ObjectタブのTransformカードには、オブジェクト自身の位置と回転が表示されたままで、コンストレイントをオフにしたり削除したりすると、オブジェクトは正確にその位置に戻ります。
- **ビューごとに計算されます。** カメラに依存するもの（Billboard、またはソースが**View**のもの）は、描画しているカメラを使います。3D Viewportを2つ開いていると、それぞれが自分の視点からの結果を表示します。ゲームでは、アクティブなカメラを使います。
- **どこでも同じように動きます。** エディターでも、ビルドしたゲームでも、AndroidでもNokia N95でも同じです。

## Constraintsカード

| プロパティ | 働き |
|---|---|
| リスト | オブジェクトのコンストレイントです。選んだものが、下のカードに表示されます。 |
| Add | 4つの種類のメニューです：**Copy Location**、**Copy Rotation**、**Billboard**、**Child Of**。 |
| Remove | 選んだコンストレイントを削除します。 |
| Move Up / Move Down | 順番を変えます（2つ以上あるときに表示されます）。 |

**順番**は重要です。上から下へ適用され、それぞれが上のコンストレイントが残したものに対して働きます。2つが同じものを変更する場合は、下にあるほうが優先されます。

## すべてに共通する項目

下には、選んだコンストレイントのカードが、その名前をタイトルにして表示されます。次の3行は、どの種類にもあります。

| プロパティ | 働き |
|---|---|
| Enabled | コンストレイントを削除せずにオン・オフします。あり・なしでどうなるかを比べるのに使えます。 |
| Show in Edit Mode | オフ（初期設定）のときは、オブジェクトの頂点を編集している間、コンストレイントは適用されません。メッシュは本当の位置に表示され、そこで編集できます。オンにすると、Edit Modeでも適用されます。 |
| Influence | どれだけ効かせるかです（0〜100 %）。100では完全に適用され、0では何もしません。その間では、オブジェクトは単独のときの位置と、コンストレイントが動かす位置の間に来ます（50なら中間）。 |

**Show in Edit Mode**が初期状態でオフなのは意図的です。カメラを追って回転する木や、別の場所へ逃げていくメッシュを編集するのは、とてもやりにくいからです。

## Copy Location

![Constraintsタブ全体。立方体にCopy Locationコンストレイントが付いています](../tutoriales/img/restricciones-copiar-posicion.webp)

別のオブジェクトの**位置をコピー**します。オブジェクトは、選んだ軸について、ソースとまったく同じ位置に来ます。

| プロパティ | 働き |
|---|---|
| Source | どこからコピーするかです。**None**、**View**（描画しているカメラ）、またはシーンの任意のオブジェクト（自分自身と、自分の下にぶら下がっているものを除く）。 |
| Copy X, Copy Y, Copy Z | どの軸をコピーするかです。軸はTransformカードと同じで、Zが高さです。チェックを外した軸は、オブジェクト自身の値のままです。 |

位置をそのままコピーするので、距離は残りません。3つの軸すべてをコピーすると、オブジェクトはソースに重なります。ずらしたいときは、追従させたくない軸のチェックを外すか、Edit Modeでメッシュをずらします（距離を保ったまま何かを追いかけるには、[Child Of](#child-of)を参照してください）。

カードに表示される警告：

- 「No source: this constraint does nothing.」ソースがNoneのときに表示されます。ソースのオブジェクトを削除したときにも表示され、ボタンは自動でNoneになります。
- 「No axes: this constraint does nothing.」3つの軸すべてのチェックが外れているときに表示されます。

**例：**

- **キャラクターの下の丸い影：** 暗いしみを描いた平面で、Copy XとCopy Yにチェックを入れ、Copy Zはチェックを外します。床の上のどこでもキャラクターの下についていき、キャラクターがジャンプしても影は地面に残ります。
- **決してたどり着けない空：** 空を描いた大きな球で、ソースを**View**にします。空は常にカメラを中心にしているので、どれだけ歩いても端にはたどり着きません。
- **キャラクターについていくライト：** キャラクターをソースにしたライトで、Copy XとCopy Yだけにします。ライト自身の高さのまま、上からついていきます。

## Copy Rotation

![Constraintsタブ全体。立方体にCopy Rotationコンストレイントが付いています](../tutoriales/img/restricciones-copiar-rotacion.webp)

別のオブジェクトの**回転をコピー**します。オブジェクトは、その場から動かずに、ソースと同じように回転します。

| プロパティ | 働き |
|---|---|
| Source | どこからコピーするかです。**None**、**View**（描画しているカメラ）、またはシーンのオブジェクト（自分自身と、自分の下にぶら下がっているものを除く）。 |
| Copy X, Copy Y, Copy Z | どの回転をコピーするかです。軸はTransformカードの回転と同じです。3つすべてなら、オブジェクトはソースとまったく同じ向きになります。1つか2つなら、その角度だけをコピーし、残りはオブジェクト自身の値のままです。 |

Copy Locationと同じ警告（「No source…」と「No axes…」）があります。Influenceが中間の値のとき、回転は常に最短の経路をたどります。

**例：**

- **バーの天井扇風機：** 1台の羽根の回転だけをアニメーションし、ほかの扇風機の羽根はその回転をコピーします。どれもまっすぐ吊り下がっているので、3つの軸すべてにチェックを入れれば十分です。全部の速さを変えたいときは、1台のアニメーションを変えます。
- **一人称視点で画面に貼りついたもの**（ゲームの手と武器、宇宙船のコックピット）：同じオブジェクトに、Copy LocationとCopy Rotationの2つのコンストレイントを付け、どちらもソースを**View**にします。オブジェクトはカメラの行く所へ行き、カメラと一緒に回転します。メッシュはEdit Modeでずらして、前方、下、右に来るようにします。

## Billboard

![Constraintsタブ全体。立方体にBillboardコンストレイントが付いています](../tutoriales/img/restricciones-billboard.webp)

オブジェクトを**カメラの方に向けます**。自動で回転して、画面に正面を向けます。ソースはありません。常に描画しているカメラです。

| プロパティ | 働き |
|---|---|
| Mode | **Upright (does not tilt)**：振り返る人のように横方向にだけ回転し、常にまっすぐ立ったままです。**Face the camera**：さらに、カメラが上や下にあるときは、傾いてカメラの方を向きます。 |

ビルボードは、カメラのある点ではなく、画面の**平面**に合わせて向きをそろえます。ビューにあるビルボードはすべて、画面と平行になります。

Influenceが100のときは、回転はビルボードが決め、Transformカードの回転は使われません。平面が横向きになってしまうときは、Edit Modeで回転させます（Show in Edit Modeは初期状態でオフなので、そこではコンストレイントなしで表示されます）。

カードの警告：「With influence between 0 and 100 the billboard can flip 180 degrees when it crosses the camera. Use 100% to avoid it.」これは、回転していく向きと混ぜ合わせる方法によるものです。この反転が気になるときは、100 %を使います。

**例：**

- **低コストの木：** 木の写真（透明度付き）を貼った平面で、ModeをUpright (does not tilt)にします。どこから見ても1本の木に見えますが、平面は1枚だけです。Nokia N95で森を埋めるのに最適です。
- **煙、火花、ランプの輝き、背景の太陽：** テクスチャを貼った平面で、ModeをFace the cameraにします。上から見ても正面を向いて見えます。
- **頭の上のキャラクター名の看板や体力バー：** Face the cameraにして、キャラクターについていくように、キャラクターにペアレントします。

## Child Of

![Constraintsタブ全体。立方体にChild Ofコンストレイントが付いています](../tutoriales/img/restricciones-child-of.webp)

オブジェクトを、別のオブジェクトや、アーマチュアの**ボーン**の**子**のようにふるまわせます。Outlinerでは別の所にぶら下がっていてもかまいません。ソースが移動、回転、拡大縮小すると、くっついているかのようについていきます。

| プロパティ | 働き |
|---|---|
| Source | 親の役をするオブジェクトです。**None**、またはシーンのオブジェクト（自分自身と、自分の下にぶら下がっているものを除く）。ここにはViewの選択肢はありません。 |
| Bone | ソースがアーマチュアのときだけ：ぶら下がるボーンです。**None**ではアーマチュア全体についていきます。 |
| Location | ソースの移動についていくかどうかです。 |
| Rotation | ソースが回転したときに回転するかどうかです。 |
| Scale | ソースと一緒に大きく、または小さくなるかどうかです。 |
| Set Inverse | オブジェクトをコンストレイントの前にあった位置に置いたまま、その時点からソースについていくようにします。 |
| Clear Inverse | オブジェクトの位置を、ソースから測り直します。Locationが0, 0, 0なら、ちょうどソース（またはボーンの根元）の位置に来ます。 |

ソースを削除すると、ほかのコンストレイントと同じく「No source: this constraint does nothing.」という警告が表示されます。

### インバースを設定するか、クリアするか

ソースを選ぶと、オブジェクトが跳びます。位置がソースから測られるようになるからです。作業のしかたは2つあります。

- **先に配置してから設定する：** オブジェクトを置きたい位置（たとえば、剣を手の中）に置き、ソースとボーンを選んで、**Set Inverse**をタップします。置いた位置に戻り、そこからソースについていきます。
- **クリアして数値を入力する：** **Clear Inverse**を使うと、オブジェクトのTransformカードが、ソースからの距離になります。正確な数値がわかっているときに便利です。Locationを0, 0, 0にすると、ちょうどボーンの位置に来ます。

コンストレイントは、インバースがクリアされた状態で作られます。ソースを選んだときに跳ぶのはそのためです。

### Child OfのInfluence

0ではオブジェクトの本当の親（Outlinerでの親）に従い、100ではソースに従います。そのため、剣をOutlinerではキャラクターの子にしておき（キャラクターを別の場所へ動かしたときに一緒に動くように）、さらに手へのChild Ofを付けることができます。剣は二重に動くことなく手についていきます。

**例：**

- **Leonの手にある武器：** LeonのアーマチュアをソースにしてBoneに右手のボーンを指定したChild Ofで、武器を手の中に合わせてからSet Inverseをタップします。変形しないオブジェクトなら、アーマチュアでメッシュを変形するよりずっと軽く、Nokia N95では違いがはっきりわかります。
- **帽子やメガネ：** 同じように、頭のボーンを使います。
- **回転せずについていくカメラ：** Locationだけにチェックを入れます。カメラは同じ距離でキャラクターと一緒に動きますが、キャラクターが振り向いても回りません。
- **動く台の上のオブジェクト：** 台へのChild Ofで、LocationとRotationにチェックを入れます。Outlinerでの位置を変えずに、台と一緒に移動します。

## 使い分け

| オブジェクトを… | コンストレイント |
|---|---|
| 別のオブジェクトやカメラのある位置へ行かせる | Copy Location |
| 別のオブジェクトやカメラと同じように回転させる | Copy Rotation |
| 常にカメラの方に向ける | Billboard |
| 距離を保ったまま、別のオブジェクトやボーンについていかせる | Child Of |

2つのオブジェクトが互いにコピーし合う（AがBを、BがAをコピーする）場合、Whisk3Dはフリーズしないように循環を断ち切り、[Console](consola.md)に警告を出します。2つのうち一方は、自分自身の位置のままになります。解決するには、2つのコンストレイントのどちらかを外します。
