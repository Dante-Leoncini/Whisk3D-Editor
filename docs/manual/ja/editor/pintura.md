# ペイントモード

> [!NOTE]
> 3つのペイントモードは**3Dメッシュ専用**です。カメラ、ライト、アーマチュア、カーブ、2D要素では表示されません。ペイント中はクリックしても選択が変わりません。別のオブジェクトにペイントするには、Outlinerで選択します。

## 3つに共通する機能

| 機能 | 説明 | 使い方 |
|---|---|---|
| ペイント | 見えている表向きの面だけに塗ります（X-Rayでは裏側の面にも塗ります）。1回のストロークが、取り消しの1ステップになります。 | クリックしてドラッグ |
| Radius | ブラシのサイズ（ピクセル単位）です。変更すると、ビューの中央に実際の大きさの円が表示されます。 | ツールバーの上にあるドラッグ式のバー |
| Value | ブラシの強さです。 | ドラッグ式のバー |
| Falloff | ブラシの縁のぼかし方です。独自のカーブを描くこともできます。 | Falloffボタン |
| View（タッチ） | オン：指でビューを操作します。オフ：指でペイントします。 | モニターの形のボタン |

## Weight Paint

各頂点にボーンがどれだけ影響するかをペイントします（青 = 影響なし、赤 = 最大）。これによって、メッシュがアーマチュアに合わせてきれいに変形します。

| 機能 | 説明 |
|---|---|
| Brush mode | Add（+）、Subtract（−）、Set（=、正確な値にします）。 |
| Vertex Group | ペイントするグループ（ボーン）です。グループを追加することもできます。グループがない場合は、最初のストロークで1つ作成されます。 |
| Markers | 頂点ごとに小さな四角を表示します。ブラシはそれらにだけ作用します。 |
| Selected only | 選択していない部分を保護します（暗く表示されます）。 |

## Vertex Paint

**3Dメッシュ**の頂点に色を塗ります（画像や2D要素には使えません。それにはTexture Paintを使います）。とても軽く、N95で色を付けるときにおすすめの方法です。

| 機能 | 説明 |
|---|---|
| Color | カラーピッカーを開きます（RGB、HSV、16進数、またはパレットのインデックス）。 |
| Per-Vertex / Per-Corner | Per-Vertexでは色が面の間で共有され、Per-Cornerでは面ごとに別の色を持てます（境界がくっきりします）。 |
| Color Layers | カラーレイヤーを選択または作成します。 |
| Markers / Selected only | Weight Paintと同じです。 |

## Texture Paint

3Dオブジェクトの上に直接ペイントし、そのストロークがテクスチャに書き込まれます。

| 機能 | 説明 |
|---|---|
| 自動テクスチャ | メッシュにテクスチャがない場合、最初のストロークで自動的に作成されます：専用のマテリアル、自動UV、マテリアルの色で塗られた1024×1024（N95では256×256）の画像。 |
| Color、Falloff、Radius、Value | ほかのモードと同じです。 |
| Save Texture | ペイントは保存するまでメモリ上にあります。保存していない変更があると、フロッピーディスクのアイコンが緑になります。オプション：Save、Save As…、Save inside the .w3d、Save outside the .w3d… |
