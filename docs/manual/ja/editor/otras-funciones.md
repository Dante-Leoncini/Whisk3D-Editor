# 3D Viewportのその他の機能

| 機能 | 説明 | 使い方 |
|---|---|---|
| Camera View | アクティブなカメラから、レンダリングサイズの枠付きで見ます。この中では、ホイールまたはピンチで、カメラを動かさずに確認用のズームができます。 | <kbd>Num0</kbd> |
| Local View | 選択したものとその子だけを表示します（親は描かれません：メッシュを選んでも、そのアーマチュアのボーンは表示されません）。左上に **Local View** と表示されます。もう一度押すと元に戻ります。 | <kbd>/</kbd> |
| 3D Cursor | 新しいオブジェクトが作成される位置で、ピボットとしても使えます。Snapメニュー（<kbd>Shift+S</kbd>）で配置します。 | <kbd>Shift+S</kbd> |
| Ray Tracing | ソフトシャドウ、透明、反射（マテリアルのラフネスとメタリック）、ノーマルマップ、スポットライトを備えたリアルなレンダリングです。Properties → Renderで有効にし、Render Previewで表示します。**GPU**（Vulkan：NVIDIA、AMD、Intel。ドライバーが対応していればRTX/RDNA2/Arcのレイトレーシングコアを使用）またはCPUでトレースします。**Only the final image**で途中経過を隠せます。 マテリアルの **Transmission**（0〜1）はどれだけがガラスかを表します：光は **IOR** で曲がって通り抜け（1 = なし、1.33 水、1.5 ガラス）、**Roughness** があればすりガラスのようになります。アルファで透明な部分はまっすぐ通ります（transmission 0では、以前と同じくIORが透明部分を曲げます）。[自作シェーダー](shaders.md#レイトレーシングとの関係)を参照。**Transparency layers** はレイが通過する透明面の数の上限（超えると黒）。コースティクスはシミュレートしません。 **New noise each image**（既定でオン）は画像ごとにノイズを変えるので、アニメーションでノイズが画面に貼り付きません。 | Properties → Render → Ray Tracing、Device |
| デノイザーとアップスケーリング | **デノイザー**は少ないパスのノイズを除去します：Vulkan対応の全GPUで**GPU (A-Trous)**（リアルタイム）、**Open Image Denoise**（CPU）、**OptiX**（NVIDIA）。**アップスケーリング**（x2、x3、x4）はビュー解像度の一部でトレースし、ノイズを除去して拡大します：フレームレートが上がります。すべてオプションで、そのマシンにないものは表示されません。 **Upscaler** で拡大の方法を選べます：Linear、または **FSR 1**（AMD、オープン）：エッジがよりシャープになり、どのグラフィックカードでも動きます（CPU 処理）。 | Properties → Render → Denoiser、Upscaling |
| モーションベクターとモーションブラー | **Motion vectors** は追加の画像（`_vectores`）を保存します。各ピクセルが前のフレームから画面上でどれだけ動いたかを表します（赤 = X、緑 = Y。128 = 静止、1 段階 = 半ピクセル）。各頂点を動きの色で塗る普通の OpenGL パスなので、OpenGL ES 1.1 でも動きます。**Motion blur** はそのベクターを使い、CPU で動きの方向に画像をぼかします。**Shutter**（0〜1）はフレームのうちカメラが開いている割合です（0.5 = 定番の 180°）。 | Properties → Render → Motion vectors、Motion blur |
| レイトレースのモーションブラー | **Ray Tracing** がオンのとき、**Ray traced motion blur** は各パスをシャッターの別の瞬間でトレースします（Render Image と Render Animation）。動くメッシュとカメラを隣のフレームの間で補間します。本物のブラー（影、反射、動く物の後ろ）です。コピーが見えないよう十分なパス数にしてください。**Shutter**（0.01〜1、既定 0.5）と **Position**：**Center of frame**、**Start of frame**、**End of frame**。ベクターによるブラーの代わりになります。 | Properties → Render → Ray traced motion blur |
| カメラの被写界深度 | 各カメラに **Depth of field** があります：**F-stop**（本物のレンズと同じく、小さいほどボケる）、**Focus distance**（m、キーフレームのひし形でアニメーション可能）、**Focus object**（ピントがそのオブジェクトに自動で合う）。カメラのオレンジの線と十字がピントの合う面を示します。**Ray Tracing** はレンズから本物のボケを作ります（カメラから見たとき）。ポストプロセスの **Depth of field** も同じピントと同じ F-stop を使えます。チェックを入れるとすぐにオプションが表示されます。 | Properties → Camera → Depth of field |
| ポストプロセス | **Render** の下のカードで、モディファイアのスタックと同じように、エフェクトを **Add** し、並べ替え（**Move Up** / **Move Down**）、**Remove** できます。それぞれに設定があります。**Film grain**（強さ、サイズ、カラー）、深度を使う **Depth of field**（くっきりした範囲。**Use camera focus** をオンにするとアクティブなカメラのピントと F-stop を使い、そのカメラの被写界深度がオフなら何もボカしません。オフのときはピントの距離とボケを手で指定）、モーションパスを使う **Motion blur**（シャッター）。これらはカメラのエフェクトです。**Rendered** ビューでは **アクティブなカメラから見ているときだけ**、しかも **その枠の内側だけ** に表示され（フルスクリーンのゲームモードでは画面全体）、レンダー画像にも入ります。ゲームのリアルタイム向け：OpenGL ES 2.0 と Vulkan ではすべて GPU で処理し（深度・法線・モーション・Solid ビューも）、OpenGL ES 1.1（N95）と PC 標準の OpenGL では CPU で処理し、カードにその旨が表示されます（PC では **Settings → Graphics → OpenGL ES 2.0** または **Vulkan** にすると GPU で処理されます）。レイトレースのブラーや被写界深度とは独立していて、片方でも両方でも使えます。 | Properties → Render → Post Processing |
| グラフィックス | エディタは同じプログラムに3つのバックエンドを持ちます：**OpenGL**（固定パイプライン、古いGPUでも動作）、**OpenGL ES 2.0**（シェーダー）、**Vulkan**。選択は再起動後に有効になり、そのマシンでVulkanが動かなければOpenGLのままです。 | Properties → Settings → Graphics |
| ゲームモード | 「Game」アニメーションを再生（Play）すると、クリックとキー入力がゲームに送られます。<kbd>Esc</kbd>で一時停止します。 | バーのPlay / Stopボタン |
