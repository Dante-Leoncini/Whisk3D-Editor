# Screw

**Screw**モディファイアーは、断面を軸のまわりに回転させ、回転したあとにできるサーフェスを作ります。旋盤のようなものです。花瓶、グラス、瓶のシルエットを半分だけ描くと、Screwがそれをオブジェクト全体に変えます。さらに、回転しながら断面が上がっていくと、ネジ山やバネができます。

![Modifiersタブ全体。立方体にScrewモディファイアーが付いています](../tutoriales/img/modificador-tornillo.webp)

## 追加のしかた

1. 断面のあるメッシュを選択します。
2. Propertiesで**Modifiers**タブ（スパナのアイコン）を開きます。
3. **Add**をタップして、**Screw**を選びます。

リストには内部名の**Screw**で表示され、その下にパラメーターのカードが開きます。ほかのモディファイアーと同じく、メッシュを壊しません。断面はそのまま残り、結果を見ながら編集できます。オフにしたり、**Move Up**と**Move Down**で順番を変えたり、**Remove**で外したり、**Apply Modifier**でベイクしたりできます。

## 断面

断面は線です。辺でつながった頂点で、面はありません。回転の軸はメッシュの**原点**を通るので、各頂点から原点までの距離が、その高さでのオブジェクトの半径になります。描き方の一例です。

1. **Add → Mesh → Vertex**で、原点に単独の頂点が作られ、そのままEdit Modeに入ります。
2. 正面から見ます（[3D Viewportのナビゲーション](../tutoriales/navegacion.md#正面側面上からのビュー)を参照）。
3. **Extrude Vertices**（Meshメニュー → Vertex）で、次の頂点を横へ伸ばして底を作り、続けて上へ伸ばして側面を作ります。1点ずつ進めます。

軸の上にある頂点は、オブジェクトを閉じます。最初の頂点は原点にあり、花瓶の底の中心になります。

## パラメーター

| パラメーター | 働き |
|---|---|
| Display in Viewport | オフにすると、回転しません。ビューでもレンダリングでも、断面だけが表示されます。 |
| Display in Edit Mode | オフにすると、断面の編集中は線だけが表示されます。 |
| Angle | 最初のステップから最後のステップまでに、断面を何度回転させるかです（初期値は360、つまり1周）。180にすると半分のオブジェクトになります。負の値では逆向きに回転します。360を超えることもでき、1080なら3周します。 |
| Screw | 回転の始めから終わりまでに、断面が軸に沿って何メートル上がるかです。0なら旋盤（花瓶、グラス、瓶）で、それ以外の値ならネジ山やバネになります。 |
| Axis | どの軸のまわりに回転するか：X、Y、Z。初期値は垂直の**Z**です。正面のビューで描いた断面は、テーブルの上の花瓶のように立った形になります。 |
| Steps Viewport | ビューで、回転に沿って断面のコピーをいくつ作るかです。2から512まで（初期値は16）。ステップが多いほど丸くなり、重くなります。 |
| Render | **Render Image**や**Render Animation**のときに使うステップ数です（初期値は32）。 |
| Stretch U | 回転方向にUV座標を作ります。テクスチャがラベルのようにオブジェクトを包みます。 |
| Stretch V | 断面に沿って、上から下までUV座標を作ります。両方オフのときはUVがありません。 |
| Smooth | 生成されるサーフェスをスムーズシェーディングにします。角ばらず、丸く見えます。初期状態ではオンです。 |
| Merge | 同じ位置に重なる頂点を結合します。軸に触れている断面の頂点（底や、口を閉じた瓶の口）と、1周が閉じる継ぎ目です。初期状態ではオンです。 |
| Flip Normals | 面の向きを反転します。オブジェクトが裏返しに見える、暗い、内側から見ているように見える、といったときに使います。 |
| Apply Modifier | **Steps Viewport**の値で、結果をメッシュにベイクします。下の注を参照してください。 |

1周が継ぎ目なしで自動的に閉じるのは、Angleが360でScrewが0のときだけです。それ以外の角度や、断面が上がっていく場合は、始めと終わりが開いたままになります。

## 例

- **花瓶：** シルエット半分の断面で、Angleを360、Screwを0、ステップを16から32にします。
- **ネジ山：** 軸から離した短い断面で、Angleを1080、Screwを3にします。1周ごとに1メートルずつ上がる3周になります。らせんが角ばらないように、ステップを増やしてください。

![Nokia](../tutoriales/img/icono-nokia.svg) Nokia N95では、ステップが1つ増えるごとに、描画する断面のコピーが1つ増えます。モデリング中はSteps Viewportを少なくして、多いステップはRenderに回してください。

> [!NOTE]
> ScrewでApply Modifierを使うと、これだけでなく、リストにあるオンのモディファイアーが**すべて**ベイクされ、リストは空になります。オフになっていたモディファイアーや、[Armature](modificador-esqueleto.md)のようにジオメトリを生成しないモディファイアーも消えます。元に戻すことができます。
