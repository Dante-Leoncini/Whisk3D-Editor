# Properties

> [!NOTE]
> ![Nokia](../tutoriales/img/icono-nokia.svg) Nokia N95はマウスとキーボード（Bluetooth）に対応しています。このページのNokiaの説明は、マウスやキーボードを使わずに、電話のキーだけで操作する方法です。

**Properties**は、**アクティブなオブジェクト**（最後に選択したオブジェクト）のデータを表示するビューポートです：位置、名前、マテリアル、ライトの色、メッシュのモディファイアーなど。**タブ**に分かれていて、各タブには値の行が並んだ**カード**があります。ここで変更したことは、ほとんどがすぐに3D Viewportに反映されます。

「[ビューポート](interfaz.md#アクティブなビューポート)」で説明したとおり、キー入力はアクティブなビューポート（緑の枠があるビューポート）に送られます。

![Nokia](../tutoriales/img/icono-nokia.svg) Nokia N95では、Propertiesは3D Viewportの右にあります。緑の**通話キー** ![](../tutoriales/img/tecla-verde.svg) でPropertiesをアクティブなビューポートにします。戻ってきたときは、前回いた行のままです。

## タブ

タブは、Propertiesのメニューバーにあるアイコンです。タブごとに、カードのグループが表示されます。

タブは**アクティブなオブジェクトによって変わります**：オブジェクトの種類ごとに、必要なタブだけが表示されます。メッシュにはMaterial、3D Mesh、Modifiersがあり、ライトにはマテリアルの代わりにLightタブ、カメラにはCameraタブがあります。

| タブ | 表示されるとき |
|---|---|
| File / Render（フロッピーディスク） | 常に表示されます。何も選択していなくても表示されます。 |
| Object | どの3Dオブジェクトでも：位置、回転、スケール、名前、表示。 |
| オブジェクトの種類のタブ | メッシュならMaterial、ライトならLight、カメラならCamera、というように種類ごとに変わります。アイコンも種類に合わせて変わります。 |
| 3D MeshとModifiers | メッシュのときだけ。 |
| Transform | Edit Modeのメッシュのときだけ。 |
| Constraints | どの3Dオブジェクトでも。 |
| Scripts | どのオブジェクトでも。 |
| Animation | 常に表示されます。 |

種類のタブは同じ場所にとどまります：メッシュのマテリアルを見ているときにライトを選択すると、Lightタブに移ります。見ていたタブが新しいオブジェクトにない場合（ライトを選択したときのModifiersなど）は、PropertiesはObjectタブに戻ります。

![立方体を選択しているとき、Propertiesにはメッシュのタブが表示され、マテリアルのタブが開いています。ライトを選択するとタブが変わり、マテリアルのタブがライトのタブになります。カメラを選択すると、カメラのタブになります](../tutoriales/img/propiedades-pestanas.webp)

| | タブの切り替え方 |
|---|---|
| ![PC](../tutoriales/img/icono-pc.svg) PC | タブをクリックします。全部が収まらない場合は、バーの上でホイールを回します。 |
| ![Android](../tutoriales/img/icono-android.svg) タッチスクリーン | タブをタップします。全部が収まらない場合は、バーを横にドラッグします。 |
| ![Nokia](../tutoriales/img/icono-nokia.svg) Nokia N95 | **上**の方向キーで最初のカードのタイトルまで上がり、もう一度押します：現在のタブが緑になります。**左**と**右**でタブを切り替え、**下**でカードに戻ります。最初のタブで左を押すと、隅のボタンのメニューが開きます。 |

## カード

**カード**は、各タブにある枠です：タイトルとその行でできています。タイトルの矢印は、カードが開いているか折りたたまれているかを示します。使わないカードを折りたたむと、使うカードにすぐ手が届きます。

![立方体のObjectタブで、Transformカードをタイトルから折りたたむと、下のカードが上がってきます。もう一度タイトルを押すと展開されます](../tutoriales/img/propiedades-tarjetas.webp)

| | 折りたたみと展開の方法 |
|---|---|
| ![PC](../tutoriales/img/icono-pc.svg) PC | タイトルをクリックします。 |
| ![Android](../tutoriales/img/icono-android.svg) タッチスクリーン | タイトルをタップします。 |
| ![Nokia](../tutoriales/img/icono-nokia.svg) Nokia N95 | タイトルの上で<kbd>OK</kbd>。**左**の方向キーを押すと、カードのどの行からでもカードを折りたたみます。タイトルの上で**右**を押すと展開します。 |

カードがビューポートに収まらない場合は、パネルがスクロールします：PCではマウスホイールで、タッチスクリーンでは指を上下にドラッグします。Nokiaでは、パネルが選択中の行に自動でついていきます。

### キーで移動する

![Nokia](../tutoriales/img/icono-nokia.svg) Nokia N95には**選択中の行**があります：その名前は緑で、値は白い枠で表示されます。**上**と**下**で行から行へ、カードから次のカードへ移動し、<kbd>OK</kbd>でその行を使います：数値を編集する、チェックボックスをオン・オフする、ドロップダウンを開く。編集中は枠が緑になります。

![PC](../tutoriales/img/icono-pc.svg) PCでは、マウスがPropertiesの上にあるとき、矢印キーと<kbd>Enter</kbd>で同じことができ、<kbd>Esc</kbd>で編集中の内容をキャンセルします。

## 数値

ほとんどの行は**数値**です：左に名前、右に値があります。たとえば、TransformカードのLocation、Rotation、Scaleです。数値は**入力**することも、**ドラッグ**することもできます。数値ごとに変化の速さが決まっていて、上限・下限があるものもあります：ライトのGL Lightは0〜7です。

### 数値を入力する

![PC](../tutoriales/img/icono-pc.svg) マウスを動かさずに数値をクリックします：値が選択状態になり、入力した内容で置き換わります。<kbd>Enter</kbd>で適用し、<kbd>Esc</kbd>で元のままにします。ほかの場所をクリックしても適用されます。

![立方体のLocation Xをクリックすると、値が選択状態になります。2と入力してEnterを押すと、立方体がX方向に2メートル移動します](../tutoriales/img/propiedades-numero-raton.webp)

![Android](../tutoriales/img/icono-android.svg) 数値をタップすると、画面の下にWhisk3Dの**テンキー**が開き、行の名前と値が表示されます。数字、小数点、削除用の**DEL**、カーソルを動かす矢印があります。**OK**で値を適用し、**X**でキャンセルします。テンキーの外をタップしても適用されます。

![Android](../tutoriales/img/icono-android.svg) テンキーでは**計算**もできます：<kbd>+</kbd>、<kbd>-</kbd>、<kbd>\*</kbd>、<kbd>/</kbd>とかっこを使って`2*3`や`1.5+0.25`と入力し、OKをタップすると結果が入ります。<kbd>-</kbd>は負の数の入力にも使います。

![立方体のLocation Xをタップすると、下にテンキーが開きます。2*3と入力してOKを押すと、値が6になり、立方体が移動します](../tutoriales/img/propiedades-numero-dedo.webp)

![Nokia](../tutoriales/img/icono-nokia.svg) 方向キーでその行まで行き、<kbd>OK</kbd>を押します：値が選択状態になり、電話のキーで数字を入力できるようになります（Propertiesのバーに**123**と表示されます）。最初に入力した数字で、元の値が置き換わります。<kbd>\*</kbd>は小数点、<kbd>C</kbd>で削除、**左**と**右**でカーソルを移動、<kbd>OK</kbd>で適用、**左ソフトキー**でキャンセルします。

![Nokia N95：緑キーでPropertiesに移り、下の方向キーでLocation Xまで行き、OKで値が選択状態になります。2と入力してOKを押すと、立方体が移動します](../tutoriales/img/propiedades-nokia.webp)

### 数値をドラッグする

![PC](../tutoriales/img/icono-pc.svg) 数値の上でクリックしたまま、マウスを横に動かします：右へ動かすと値が増え、左へ動かすと減ります。ポインターがビューポートの端に届くと反対側から現れるので、そのままドラッグを続けられます。ボタンを離すと、その値で確定します。

![Location Xの上でクリックしたまま、マウスを右へ左へ動かすと、数値と一緒に立方体が動きます](../tutoriales/img/propiedades-arrastrar-raton.webp)

![Android](../tutoriales/img/icono-android.svg) 数値の上に（名前の上ではなく）指を置き、横にドラッグします。上下にドラッグすると、値は変わらずにパネルがスクロールします。

![Location Xに置いた指を右へ左へドラッグすると、数値と一緒に立方体が動きます](../tutoriales/img/propiedades-arrastrar-dedo.webp)

## ドロップダウン

**ドロップダウン**は、選ばれているオプションを表示するボタンです。たとえば、ライトの**Type**（Point、Sun、Spot）や、回転の**Mode**です。押すとオプションの一覧が開き、現在のオプションは緑で表示されます。別のものを選ぶと、一覧は閉じます。

![ライトを選択した状態で、LightカードのTypeドロップダウンを開くと、Pointが緑で表示されています。そこでSunを選びます](../tutoriales/img/propiedades-desplegable.webp)

| | 開き方と選び方 |
|---|---|
| ![PC](../tutoriales/img/icono-pc.svg) PC | ボタンをクリックし、続けてオプションをクリックします。 |
| ![Android](../tutoriales/img/icono-android.svg) タッチスクリーン | ボタンをタップし、続けてオプションをタップします。 |
| ![Nokia](../tutoriales/img/icono-nokia.svg) Nokia N95 | <kbd>OK</kbd>で開き、**上**と**下**でオプションを移動し、<kbd>OK</kbd>で選びます。<kbd>C</kbd>で何も変えずに閉じます。 |

## チェックボックス

**チェックボックス**はオン・オフを切り替えます：チェックありは「はい」、空は「いいえ」です。行の右側にあります。たとえば、マテリアルの**Lighting**：オフにすると、オブジェクトはライトの影響を受けず、自分の色でフラットに表示されます。行（チェックボックスでも名前でも）をクリックまたはタップすると切り替わります。Nokiaでは<kbd>OK</kbd>です。

![立方体のマテリアルでLightingをオフにすると、立方体はライトなしで白くフラットに表示されます。もう一度オンにすると、また照らされて見えます](../tutoriales/img/propiedades-casilla.webp)

## テキスト

**テキストフィールド**には、名前やパスが入ります。たとえば、Transformカードの最後にあるオブジェクトの**Name**です。押すと、テキストの末尾にカーソルが表示されます。新しい名前はOutlinerにも表示されます。

![立方体のNameを編集します：消して、Boxと入力し、確定するとOutlinerに新しい名前が表示されます](../tutoriales/img/propiedades-texto.webp)

- ![PC](../tutoriales/img/icono-pc.svg) **PCでは：** フィールドをクリックして入力します。<kbd>Enter</kbd>（またはほかの場所をクリック）で確定し、<kbd>Esc</kbd>で元のテキストに戻ります。
- ![Android](../tutoriales/img/icono-android.svg) **タッチスクリーンでは：** タップすると、ñも入力できるWhisk3Dのキーボードが開きます。**Aa**で大文字、**123**で数字と記号に切り替え、**DEL**で削除、**OK**で確定します。Web版では、電話のキーボードが開きます。
- ![Nokia](../tutoriales/img/icono-nokia.svg) **Nokia N95では：** <kbd>OK</kbd>を押し、メッセージを打つときと同じように電話のキーで入力します：キーを何回か押すと、そのキーの文字が順に出ます。<kbd>#</kbd>でAbc、abc、ABCを切り替え、長押しで123になります（Propertiesのバーにモードが表示されます）。<kbd>0</kbd>はスペース、<kbd>1</kbd>は句読点で、<kbd>\*</kbd>でさらに多くの記号が開きます。<kbd>C</kbd>で削除、**左**と**右**でカーソルを移動、<kbd>OK</kbd>で確定、**左ソフトキー**でキャンセルします。

## 色

**色**の行には、右側に色の付いた小さな四角があります。たとえば、ライトのカードの**Diffuse**、**Ambient**、**Specular**です。押すと**カラーピッカー**が開きます：

- **円**で色相と彩度を選び、隣のバーで明度（どれだけ明るいか）を選びます。
- **RGB**、**HSV**、**Hex**のタブでは、色を数値で表示します：Red、Green、Blue。Hue、Saturation、Value。または16進数のコード（`#FF8800`）で、CopyとPasteがあります。
- **Alpha**は透明度です。
- **OK**で色を確定し、**Cancel**で元の色に戻ります。

動かしている間も色が変わるので、確定する前にシーンで確認できます。ピッカーの外をクリックまたはタップしても閉じ、その色のままになります。

![ライトを選択した状態でDiffuseをクリックすると、カラーピッカーが開きます：色の円、明度のバー、RGB、HSV、Hexのモード](../tutoriales/img/propiedades-color.webp)

![PC](../tutoriales/img/icono-pc.svg) ![Android](../tutoriales/img/icono-android.svg) マウスまたは指で、円とバーの中をドラッグします。数値は、Propertiesと同じように横にドラッグします。

![Nokia](../tutoriales/img/icono-nokia.svg) Nokia N95では、**上**と**下**で、円、バー、タブ、数値の行、OK / Cancelを順に移動します。数値の行では、**左**と**右**で値を変えます（押したままにすると、だんだん速くなります）。円の上で<kbd>OK</kbd>を押すと編集に入ります：**左**と**右**で色相を回し、**上**と**下**で彩度を変え、<kbd>OK</kbd>で抜けます。バーも同じように、上と下で編集します。<kbd>C</kbd>でピッカーを閉じ、元の色に戻ります。

## リスト

カードの中には**リスト**を持つものがあります：メッシュのモディファイアー、パーツ、UVマップなど。選んだ項目が強調表示され、その下にあるものは、その項目のデータを表示したり、その項目に対して働いたりします。リストの下には**ボタン**の行があります。

**Move Up**と**Move Down**で、選んだ項目の位置を変えます。順番は大切です：モディファイアーは上から下へ順に適用され、メッシュのパーツはその順番で描画されます。この2つのボタンは、リストに2つ以上の項目があるときに表示されます。

![モディファイアーが2つある立方体のModifiersタブ：選んだモディファイアーはリストの下にあり、Move Upで上に移ります](../tutoriales/img/propiedades-lista.webp)

| | リストの使い方 |
|---|---|
| ![PC](../tutoriales/img/icono-pc.svg) PC | クリックで選びます。全部が収まらない場合は、リストの上でホイールを回します。 |
| ![Android](../tutoriales/img/icono-android.svg) タッチスクリーン | タップで選びます。全部が収まらない場合は、リストの上で指を上下にドラッグします。 |
| ![Nokia](../tutoriales/img/icono-nokia.svg) Nokia N95 | リストの上で<kbd>OK</kbd>を押し、**上**と**下**で選び、<kbd>OK</kbd>で抜けます。ボタンの行では、**左**と**右**でボタンからボタンへ移り（枠でどのボタンかがわかります）、<kbd>OK</kbd>で押します。 |

## ひし形：プロパティをアニメーションする

アニメーションできるプロパティの右側には**ひし形**があります。ひし形がないものはアニメーションできません。ひし形をクリックまたはタップすると**キーフレーム**が打たれます：Timelineの現在のフレームに、そのプロパティの値が記録されます。いくつかのフレームにキーフレームがあると、アニメーションを再生したときにプロパティが自動で変わります。

ひし形の色は、**現在のフレームでの**プロパティの状態を示します：

| ひし形 | 意味 | クリックすると |
|---|---|---|
| グレー | プロパティはアニメーションしていません。 | 今の値で最初のキーフレームを打ちます。 |
| 薄い緑 | アニメーションしていますが、このフレームにはキーフレームがありません。 | 今の値でキーフレームを打ちます。 |
| 緑 | このフレームにキーフレームがあります。 | キーフレームを削除します。 |

値を変えても、ひし形の色は変わりません：キーフレームを打つまで、新しい値はアニメーションに記録されません。その前にフレームを変えると、プロパティはアニメーションの値に戻ります。すでにキーフレームがあるフレーム（緑のひし形）で新しい値を記録するには、2回クリックします：1回目でキーフレームを削除し、2回目で今の値でもう一度打ちます。

![立方体のLocation X：ひし形はグレーです。クリックすると緑になります。Timelineで別のフレームに移ると薄い緑になります。値を変えてもひし形は薄いままで、クリックすると緑になります](../tutoriales/img/propiedades-rombo.webp)

![Nokia](../tutoriales/img/icono-nokia.svg) Nokia N95では、行にいるときに**右**の方向キーでひし形に移り（白い枠で示されます）、<kbd>OK</kbd>でキーフレームを打つか削除し、**左**で値に戻ります。

Animationタブの**Active camera**カードでは、アニメーションの各瞬間にどのカメラを使うかを選びます：シーンのカットです。このひし形にはもう1色、**明るい緑**があります：選んだカメラが、このフレームでアニメーションが指定しているカメラと違う、つまりまだ記録していない変更があるという意味です。クリックすると、現在のフレームにカットを記録します。

アニメーションには、あとで専用のチュートリアルがあります。

すべてのタブとそのカードは、マニュアルの[Properties](propiedades.md)にあります。「[ビューポート](interfaz.md)」に戻る。

## 各タブの内容

| タブ | 内容 |
|---|---|
| File / Render（フロッピーディスク） | **File**：Open project、Save、Save As、Save Version、Extract assets。**Render**：出力先、サイズ、追加のレンダーパス、背景、**Ray Tracing**（レイ数、サンプル数、パス数）、Render ImageとRender Animation。**Game**：プラットフォーム（Windows、Symbian、Linux .deb、AppImage、WebGL、Android、Android 2.3）、ウィンドウ、画面の向き、アイコン、物理、サウンド、音量、**Resolution**（ゲームが描画する画面の割合。Android 2.3ではシステムが引き伸ばすので、そうした電話では描画するピクセルを減らすとフレームレートが上がります）、Build game（adbで電話を接続していれば、インストールして起動します）。**Export**：OBJ、glTF、GLB、STL（三角形のみ。3Dプリントや、CADプログラムに渡すためのもの）。**Settings**：言語、アンチエイリアス、グラフィックス、スキン、ログ、スケール、**Keyboard Shortcuts…**、Save Changes。 |
| Object | 位置、回転（オイラー角、クォータニオン、軸と角度）、スケール、名前、表示、レンダリング。オブジェクトのアニメーションとパレット。 |
| Contextual | 種類によって変わります：メッシュのパーツと**マテリアル**（テクスチャ、ライティング、頂点カラー、透明、反射、ノーマルマップ、ブレンド、深度、テクスチャレイヤー、**Advanced: custom shader**（[自作シェーダー](shaders.md)を参照）。レイトレーシングではRoughness、Metallic、Transmission、IOR）、ライト、カメラ、フォグ、パーティクル、物理、ヒットボックス、アーマチュアとボーン、2D要素、プレハブ、ルーチン。 |
| 3D Mesh | 使用しているメッシュ（と、それを共有している数）、UVマップ、カラーレイヤー、頂点グループ、UVグループ。Libraryでリソースを選んでいる場合は、そのデータと場所（.w3dの中か外か）。 |
| Modifiers | [モディファイアー](objeto-malla.md#modifiersタブ)を参照してください。 |
| Transform | Edit Modeのみ：選択範囲とそのUVの中心を表示し、編集できます。 |
| Armature 2D | メッシュの2Dアーマチュアと2Dボーン。 |
| Constraints | Copy Location、Copy Rotation、Billboard（カメラの方を向く）、Child Of。 |
| Scripts | オブジェクトのLuaスクリプトとそのプロパティ（[Luaのドキュメント](../lua/README.md)を参照）。 |
| Animation | アクティブなアニメーション、ブレンドレイヤー（Mix）、選択したキーフレームの正確な値、カメラのカット。 |

## ルーチン

ルーチンは、Propertiesで組み立てる描画ステップのリストです（移動、回転、テクスチャの設定、メッシュの描画、別のルーチンの呼び出し、Call Lua…）。N95でいちばん高速に描画できる方法です。

| 機能 | 説明 | ショートカット |
|---|---|---|
| Add / Remove（ステップ） | テーマ別にまとめられたステップを追加する、または選択したステップを削除します。 | ボタン。<kbd>X</kbd>または<kbd>Delete</kbd>で削除 |
| Grab step | 方向キーでステップを並べ替えます。<kbd>Enter</kbd>で確定します。 | <kbd>G</kbd> |
| Insert Keyframe | ステップの値を、現在のフレームでアニメーションに記録します。 | <kbd>I</kbd> |
| Repeat | リストを続けて何回実行するか（Routine loop）。1 = 通常のルーチン。 | Repeatフィールド |
| Render mode / Use | シェーディングモードごとに別のリストを使う、またはすべてで同じリストを使います。 | ドロップダウン |
