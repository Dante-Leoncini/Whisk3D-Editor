# 移動・回転・拡大縮小

Object Mode、Edit Mode、Pose、ボーンの編集で、同じように動作します。

| 機能 | 説明 | ショートカット |
|---|---|---|
| Move（平行移動） | 選択したものがポインターに追従します。 | <kbd>G</kbd> |
| Rotate | ピボットを中心に回転します。もう一度<kbd>R</kbd>を押すと、自由回転（トラックボール）と軸まわりの回転（オービタル）が切り替わります。 | <kbd>R</kbd> |
| Scale | ピボットを基準に拡大・縮小します。 | <kbd>S</kbd> |
| 軸に制限 | トランスフォーム中に使います。もう一度押すと、Global → Local → View → 制限なし、の順に切り替わります。 | <kbd>X</kbd> / <kbd>Y</kbd> / <kbd>Z</kbd> |
| 平面に制限 | その軸を除外します（残りの2軸で動かします）。 | <kbd>Shift+X</kbd> / <kbd>Shift+Y</kbd> / <kbd>Shift+Z</kbd> |
| 正確な値 | 数値または計算式（`2*3`、`(1+0.5)/2`）を入力します。<kbd>-</kbd>で符号を反転し、<kbd>Backspace</kbd>で削除します。 | 数字キー |
| Confirm | 操作を確定します。 | 左クリック、<kbd>Enter</kbd>、緑のチェックマーク |
| Cancel | すべてが元の状態に戻ります。 | <kbd>Esc</kbd>、右クリック、赤い×印 |
| 細かいステップ | 少しずつ移動、回転、拡大縮小します。 | 方向キー |

操作中は、上部バーに実行中の内容が表示されます（例：「Move X: 1.5 along global X」）。タッチ操作では、このバーをタップするとテンキーが開きます。

## ギズモ

ギズモは、Object ModeとEdit Modeでピボットの位置に表示されます（Overlays → Gizmoでオン・オフします）。

| 機能 | 説明 |
|---|---|
| 移動ギズモ | 矢印 = 1つの軸、四角 = 1つの平面、中央の円 = 自由移動。 |
| 回転ギズモ | 軸ごとに色付きの半円があり、白いリングでビューに正対した回転、内側で自由回転をします。 |
| 拡大縮小ギズモ | 軸ごとに四角い先端があり、中央の円で均等に拡大縮小します。 |
| ギズモの切り替え | ギズモをドラッグせずにマウスでクリックするか指でタップすると、Move → Rotate → Scale → Moveの順に切り替わります。PC、ブラウザー、タッチスクリーンのどれでも同じように動作します。 |

## 直前の操作を調整

（Object ModeまたはEdit Modeで）移動、回転、拡大縮小を行うと、左下に実行した内容のパネルが表示されます：X、Y、Zの値（または角度）、Orientation、Proportional Editingとそのオプション。値を変更すると、新しい値で操作がやり直されます。**Cancel**で操作を取り消し、**Accept**でそのまま確定します。パネルの外をクリックしても確定します。パネルが開いている間は、3D Viewportのツールバーが隠れます。

パネルの枠が緑なのは、フォーカスのあるウィンドウだからです。画面の高さの半分に収まらない場合はその高さまで縮小され、指でドラッグして（オプションには触れずに）、ホイールで、または方向キーでスクロールできます。キーボードや電話のキーでは、方向キーで行を移動し、<kbd>OK</kbd> / <kbd>Enter</kbd>でパネルを閉じずに値を編集します。**Accept**、<kbd>Esc</kbd>、<kbd>Delete</kbd>（N95では<kbd>C</kbd>）は変更を残したままパネルを閉じ、**Cancel**だけが変更を取り消します。

## ツールバー

Undo、Redo、最近使った操作、Proportional Editingのボタンがあります。トランスフォーム中は、チェックマーク（確定）、×印（キャンセル）、Orientation、X / Y / Z軸（2つの軸がオン = 平面）が表示されます。タッチ操作では、押し出しのあとに**Repeat**が表示され、確定してもう一度押し出します。
