# Boolean

**Boolean**モディファイアーは、メッシュを別のメッシュと組み合わせます。もう一方の体積を引いたり、足したり、共通する部分だけを残したりします。手でモデリングすると手間のかかるものに使えます。壁の窓の穴、カップのくぼみ、溝、2つのパーツを1つに融合したものなどです。

![Modifiersタブ全体。立方体にBooleanモディファイアーが付いています](../tutoriales/img/modificador-booleano.webp)

## 追加のしかた

1. 変更するメッシュ（たとえば壁）を選択します。
2. Propertiesで**Modifiers**タブ（スパナのアイコン）を開きます。
3. **Add**をタップして、**Boolean**を選びます。

リストには内部名の**Boolean**で表示され、その下にパラメーターのカードが開きます。ほかのモディファイアーと同じく、メッシュを壊しません。壁はその下で元のままなので、モディファイアーを外せば穴は消えます。オフにしたり、**Move Up**と**Move Down**で順番を変えたり、**Remove**で外したり、**Apply Modifier**でベイクしたりできます。

## パラメーター

| パラメーター | 働き |
|---|---|
| Display in Viewport | オフにすると、演算は行われません。ビューでもレンダリングでも、元のメッシュが表示されます。 |
| Display in Edit Mode | オフにすると、編集中は演算をしていないメッシュが表示されます。 |
| Intersect | 両方のメッシュの内側に同時に入っている部分だけを残します。 |
| Union | 2つを1つのサーフェスにまとめ、内側に残った面を取り除きます。 |
| Difference | このメッシュから、もう一方のメッシュの体積を引きます。穴を開けるのはこれです。初期状態で選ばれています。 |
| Object | もう一方のメッシュ、つまり**カッター**です。**None**のときは何もしません。リストにはシーンのすべてのオブジェクトが表示されますが、使えるのはメッシュだけです。 |
| Apply Modifier | 結果をメッシュにベイクします。下の注を参照してください。 |

選んでいる演算は緑で表示されます。

## 例：壁に窓を開ける

1. **Cube**を追加し、拡大縮小して壁にします。幅が広く、背が高く、薄くします。
2. もう1つ**Cube**（丸い窓なら**Cylinder**）を追加し、窓を開けたい位置に、壁を端から端まで貫くように置きます。
3. 壁を選択して**Boolean**を追加し、**Difference**のままにして、**Object**でカッターを選びます。
4. カッターを隠します（[Object Mode](modo-objeto.md)のHide / Show、またはObjectタブの**Visible**のチェックを外します）。穴が残ります。

隠したカッターも切り続けます。カッターを動かすには、もう一度表示するか、Outlinerで選択します。

## 知っておくとよいこと

- 両方のメッシュは、サーフェスに穴のない**閉じた**メッシュである必要があります。そうでないと、Booleanは何が内側で何が外側かを判断できません。
- カッターを移動、回転、拡大縮小、編集すると、切り口がすぐに更新されます。結果を見ながら窓の位置を調整できます。
- 切断に関係しない面は元のままです。四角形は四角形のままです。切断された面は、三角形ではなく多角形になります。そのため、適用したあとも編集しやすいメッシュのままです。
- カッターによってできる面（たとえば窓の内側の縁）には、メッシュの最初のマテリアルが使われます。
- UVと頂点カラーは保持されます。切断された所では補間されます。
- 同じ平面上にある部分は1つにまとまりません。接して置いた2つの箱をUnionすると、上面がいくつかの断片に分かれたままになります。

![Nokia](../tutoriales/img/icono-nokia.svg) Nokia N95では、カッターを動かしたり編集したりするたびに切断が再計算されます。大きなメッシュでは、カッターの位置を決めたらモディファイアーを適用し、切断済みのメッシュで作業を続けてください。

> [!NOTE]
> BooleanでApply Modifierを使うと、これだけでなく、リストにあるオンのモディファイアーが**すべて**ベイクされ、リストは空になります。オフになっていたモディファイアーや、[Armature](modificador-esqueleto.md)のようにジオメトリを生成しないモディファイアーも消えます。元に戻すことができます。カッターは削除されず、普通のオブジェクトとして残ります。
