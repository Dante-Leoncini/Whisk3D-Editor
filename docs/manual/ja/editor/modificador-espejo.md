# Mirror

**Mirror**モディファイアーは、メッシュを平面の反対側に鏡映します。左右対称のものすべてに使えます。キャラクター、顔、車などの半分をモデリングすると、残りの半分が鏡映されて自動で現れます。作業中に片側で変更したことは、反対側にも繰り返されます。

![Modifiersタブ全体。立方体にMirrorモディファイアーが付いています](../tutoriales/img/modificador-espejo.webp)

## 追加のしかた

1. メッシュを選択します。
2. Propertiesで**Modifiers**タブ（スパナのアイコン）を開きます。このタブは、アクティブなオブジェクトがメッシュのときだけ表示されます。
3. **Add**をタップして、**Mirror**を選びます。

Modifiersカードのリストには内部名の**Mirror**で表示され、その下にパラメーターのカードが開きます。

モディファイアーはメッシュを壊しません。元のメッシュはそのまま残り、それを編集し続けます。表示されるのは結果です。いつでもオフにしたり、**Move Up**と**Move Down**（2つ以上あるときに表示されます）でリスト内の順番を変えたり、**Remove**で外したり、**Apply Modifier**でメッシュにベイクしたりできます。

## パラメーター

| パラメーター | 働き |
|---|---|
| Display in Viewport | オフにすると、鏡映は計算されません。ビューにもレンダリングにも表示されません。あり・なしを比べるのに使えます。 |
| Display in Edit Mode | オフにすると、メッシュの編集中は元の半分だけが表示されます。Object Modeに戻ると鏡映が表示されます。 |
| Mirror X | 左右に鏡映します。初期状態ではオンです。キャラクターや車に使うのはこれです。 |
| Mirror Y | 前後に鏡映します。 |
| Mirror Z | 上下に鏡映します。 |
| Mirror Object | **None**のときは、鏡の平面がメッシュの原点を通ります。別のオブジェクト（たとえばEmpty）を選ぶと、平面はそのオブジェクトの原点を通り、そのオブジェクトと一緒に回転します。スケールは関係しません。そのオブジェクトを移動・回転すると、鏡映はすぐに更新されます。 |
| Merge | 継ぎ目を結合します。平面のすぐ近くにある頂点が平面に吸着し、2つの半分で共有されます。こうすると中央に線が残らず、スムーズシェーディングが切れ目なく反対側へつながります。半球が完全な球に見えます。初期状態ではオンです。 |
| Merge Distance | 頂点が結合されるには、平面にどれだけ近い必要があるかです（初期値は0.001 m）。継ぎ目が開いたままなら少し上げ、結合したくない頂点がくっつくなら下げます。Clippingの許容範囲にもなります。 |
| Clipping | Edit Modeで頂点を動かすとき、平面の反対側へ行かないようにします。平面に達した頂点はそこに吸着し、平面の上を滑るだけになります。中央の頂点が離れないので、継ぎ目がうっかり開くことがありません。初期状態ではオンです。 |
| Apply Modifier | 鏡映をメッシュにベイクします。2つの半分が本物の頂点になり、モディファイアーはリストから外れます。四角形の面は四角形のままです。元に戻すことができます。 |

複数の軸をオンにすると、それぞれの鏡映は前の鏡映の結果に対して行われます。XとYをオンにすると、オブジェクトの4分の1をモデリングするだけで、4つの部分ができます。

## 順番が大切

モディファイアーは上から下へ適用されます。それぞれが、前のモディファイアーが残したものに対して働きます。Mirrorはほとんどの場合、いちばん上に置きます。

- **Mirrorを[Subdivision Surface](modificador-subdivision.md)より上に置く：** 先にモデル全体ができてから、全体がまとめて滑らかになるので、中央に跡が残りません。逆にすると、半分ずつ別々に滑らかになり、つなぎ目に折り目ができます。
- **Mirrorを[Array](modificador-array.md)より上に置く：** Arrayは完成したオブジェクトをコピーし、Relative Offsetにはオブジェクト全体のサイズが使われます。

MirrorでApply Modifierを使うと、リストのどこにあっても、ベイクされるのはMirrorだけです。ほかのモディファイアーはそのまま残ります。

## ヒント

- 鏡の平面はメッシュの原点を通るので、原点をモデルの中心に置いて作業します。中央に来る頂点は、平面のちょうど上に置きます。
- モデリングしやすいように、正面から平行投影で見ます（[3D Viewportのナビゲーション](../tutoriales/navegacion.md#正面側面上からのビュー)を参照）。Mirror Xの平面が、中央の縦線になります。
- モデルが完成したあと、それぞれの半分を別々に手直ししたいときは、Mirrorを適用します。たとえば、キャラクターを完全な左右対称でなくしたいときです。
