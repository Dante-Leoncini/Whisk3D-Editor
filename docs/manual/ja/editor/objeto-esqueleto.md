# アーマチュア

**アーマチュア**は**ボーン**でできたオブジェクトで、キャラクターや曲がるものをアニメーションするのに使います。ボーンが動くと、メッシュが変形しながらついてきます。何百もの頂点を動かす代わりに、ボーンを2本ほど回転させるだけで腕をアニメーションできます。このページはアーマチュアのプロパティのリファレンスです。オブジェクトの追加と移動のしかたは、チュートリアル[Object Mode](../tutoriales/modo-objeto.md)で説明しています。

Add → Armatureで、ボーンが1本だけのアーマチュアが作成され、そこにボーンを追加していけます。3D Viewportでは、各ボーンはすべての上に青い線で描画されるので、メッシュの中にあっても見えます。

![Armatureタブ全体。Leonのアーマチュアのアニメーションとボーンが表示されています](../tutoriales/img/objeto-esqueleto-propiedades.webp)

## レストとポーズ

各ボーンには2つの状態があります。

- **レスト：** アーマチュアを組み立てたときに置いた位置です。メッシュが変形していない姿勢です（たとえば、腕を広げたキャラクター）。
- **ポーズ：** アニメーションのあるフレームでの状態です。腕を上げている、頭を回している、などです。ポーズを付けてもレストは変わらないので、いつでもレストに戻れます。

## モード

アーマチュアには3つのモードがあり、3D Viewportの**Mode**メニューで選びます。

| モード | 用途 |
|---|---|
| Object Mode | ほかのオブジェクトと同じように、アーマチュア全体を移動、回転、拡大縮小します。 |
| Edit Mode | アーマチュアを組み立てます。先端からボーンを作り、動かし、ペアレントします。レストが変わります。 |
| Pose Mode | ポーズ付けとアニメーション：ボーンを回転させ、キーフレームを保存します。 |

![PC](../tutoriales/img/icono-pc.svg) <kbd>Tab</kbd>でObject ModeとPose Modeを切り替えます（Edit ModeからはPose Modeに移ります）。

各モードのツールとショートカットは、マニュアルの[アーマチュア](esqueletos.md)にあります。

## タブ

| タブ | 内容 |
|---|---|
| Object | アーマチュア全体の位置、回転、スケール、名前、表示。すべてのオブジェクトと同じです。[3Dメッシュ](objeto-malla.md#objectタブ)を参照してください。 |
| Armature | アニメーションとボーン：下の2つのカードです。 |
| Constraints | [コンストレイント](restricciones.md)を参照してください。 |
| Scripts | オブジェクトのLuaスクリプトです。[Whisk3DのLua](../lua/README.md)を参照してください。 |

## Armatureタブ

### Animation

アーマチュアのアニメーション（**クリップ**）です。歩く、走る、跳ぶ、などです。各クリップは、ボーンのポーズを時間に沿って保存します。

| プロパティ | 働き |
|---|---|
| リスト | アーマチュアのクリップです。選んだクリップが編集され、再生されます。 |
| New Animation | ボーンがレストの状態の、空のクリップを作成します。 |
| Duplicate | 選んだクリップをコピーします。元のクリップに手を加えずにバリエーションを作れます（クリップがあるときに表示されます）。 |
| Rename | クリップの名前を変えます。同じアーマチュアの中で同じ名前は使えません。 |
| Delete / Move Up / Move Down | クリップを削除する、またはリストの中で移動します。 |

アニメーションのしかた：[Timeline](linea-de-tiempo.md)。

### Bones

アーマチュアのボーンのリストです。1本選ぶと、カードにそのデータが表示されます。

| プロパティ | 働き |
|---|---|
| Name | ボーンの名前です。変更すると、アーマチュアのメッシュにあるそのボーンの頂点グループの名前も変わるので、メッシュは変わらずついてきます。 |
| Parent | どのボーンにぶら下がっているかです（ルートなら**None**）。親を動かすと子も動きます。輪ができないように、メニューにはそのボーン自身と、その下にぶら下がっているボーンは表示されません。 |
| Connected | 親があるときだけ表示されます。チェックを入れると、ボーンの根元が親の先端に結合され、一方を動かすともう一方も動きます。離れているボーンでチェックを入れると、ボーンが移動してくっつきます。チェックを外すと、子のままですが根元は離れます（点線が表示されます）。 |
| Pos X, Y, Z | 現在のポーズでのボーンの位置です。親から測ります。 |
| Rot X, Y, Z | 現在のポーズでの回転の量です（度）。 |
| Scale X, Y, Z | 現在のポーズでのサイズです。1が元のサイズです。 |

Pos、Rot、Scaleは**ポーズ**を編集し、すぐに反映されますが、キーフレームを挿入する（Pose ModeでInsert Keyframe）までは、アニメーションに保存されません。

## メッシュをアーマチュアに追従させる

メッシュをボーンで変形させるには、2つのものが必要です。

1. メッシュの**Armatureモディファイアー**（Properties → Modifiersタブ → Add → Armature）で、**Target**にアーマチュアを選んだもの。[Armature（モディファイアー）](modificador-esqueleto.md)を参照してください。
2. ボーンの名前を付けた**頂点グループ**（Properties → 3D Meshタブ → [Vertex Groups](objeto-malla.md#vertex-groups)）。各グループは、そのボーンがどの頂点をどれだけ動かすかを表します。ウェイトは[Weight Paint](pintura.md#weight-paint)でペイントします。

手に持った剣や帽子のような変形しないオブジェクトには、どちらも必要ありません。アーマチュアをソースにし、手や頭のボーンを指定した[Child Of](restricciones.md#child-of)コンストレイントがあれば十分です。メッシュを変形するよりずっと軽く、Nokia N95では違いがはっきりわかります。

## キャラクターを読み込む

Add → Imports → glTFまたはGLBで、組み立て済みのキャラクターを一度に読み込めます。たとえば、Leonの場合：

- **メッシュ**。アーマチュアの子になります。
- **アーマチュア**。ファイル名の末尾に`_rig`が付いた名前になります。
- **頂点グループ**。メッシュを動かすボーンごとに1つで、ファイルに入っていたウェイトが付いています。
- **アニメーション**。Animationカードのクリップになります。
- アニメーションが入っている場合は、メッシュに**Armatureモディファイアー**がすでに付いていて、そのアーマチュアを指しています。

リストからクリップを選び、TimelineでPlayを押すと、キャラクターが動きます。
