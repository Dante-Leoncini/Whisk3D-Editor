# エンプティ

**Empty**は、メッシュを持たないオブジェクトです。レンダリングでもゲームでも表示されません。基準点として使います。子としてぶら下げたほかのオブジェクトを回転・拡大縮小するためのピボット、カメラやコンストレイントを向ける場所、アニメーション用のコントロールなどです。**Add → Empty**で、3Dカーソルの位置に追加します。オブジェクトの追加と移動のしかたは、チュートリアル[Object Mode](../tutoriales/modo-objeto.md)で説明しています。

3D Viewportでは線で描画されます。新しいEmptyは**床に寝かせた円**で、見つけやすく、つかみやすい形です。描画の形、サイズ、回転はEmptyのカードで変更できます。これは**見た目だけ**の設定で、オブジェクト自体も、そのトランスフォームも、子も変わりません。

![6つのEmpty：十字、床に寝かせた正方形、立方体、床に寝かせた円、3つの輪の球、Xで90度回転して立てた円](../tutoriales/img/objeto-vacio-formas.webp)

## タブ

| タブ | 内容 |
|---|---|
| Object | 位置、回転、スケール、名前、表示。すべてのオブジェクトと同じです。[3Dメッシュ](objeto-malla.md#objectタブ)を参照してください。Emptyを拡大縮小すると、子も拡大縮小されます。 |
| Empty（十字） | 下のカードです。 |
| Constraints | [コンストレイント](restricciones.md)を参照してください。 |
| Scripts | オブジェクトのLuaスクリプトです。[Whisk3DのLua](../lua/README.md)を参照してください。 |

## Emptyカード

| プロパティ | 働き |
|---|---|
| Shape | 描画のしかたです。それぞれにアイコンがあります：**Cross**（3つの軸）、**Square**、**Cube**、**Circle**、**Sphere**（軸ごとに1つ、3つの円）。正方形と円は、床に寝た状態で作られます。小さな画面（Nokia N95、PSP、3DS、Dreamcast）では、円と球は半分の本数の線で描画されます。そうした画面では違いがわからず、描画の負荷が減ります。 |
| Size | 描画の端から端までの大きさです（メートル）。1で1メートルです。 |
| Rotation X, Y, Z | 描画を回転させます（度）。たとえば、円の**X**を90にすると立ちます。 |

どれもオブジェクトを移動・回転させるものではありません。Emptyは同じ位置にあり、子にも影響しません。設定はプロジェクトと一緒に保存されます。

## 用途

- **ピボット：** Emptyの子になったオブジェクトは、Emptyを中心に回転・拡大縮小します。たとえば、ボールの下端に置いたEmptyにボールをペアレントしておくと、Emptyを拡大縮小したときに、ボールが床に押しつぶされます。
- **シーンの整理：** Emptyにぶら下げた複数のオブジェクトは、Emptyを動かすだけでまとめて動きます。
- **ターゲット：** [コンストレイント](restricciones.md)はEmptyを向くことができます。たとえば、カメラがEmptyを見続けるようにできます。
