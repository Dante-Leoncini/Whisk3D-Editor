# ライト

**ライト**はシーンを照らします。Lightingがオンのマテリアルは、届くライトに応じて明るく、または暗く見えます。このページはライトのプロパティのリファレンスです。オブジェクトの追加と移動のしかたは、チュートリアル[Object Mode](../tutoriales/modo-objeto.md)で説明しています。

![Lightタブ全体。Pointライトを選んでいます](../tutoriales/img/objeto-luz-propiedades.webp)

## 3つの種類

| 種類 | 照らし方 | 用途 |
|---|---|---|
| **Point** | 電球のように、1点からあらゆる方向へ照らします。 | ランプ、ろうそく、たき火、オブジェクトの輝き。 |
| **Sun** | すべて同じ方向から来る平行な光線で照らします。重要なのは向きで、位置は関係ありません。 | 屋外の昼の光。 |
| **Spot** | 懐中電灯のように、円錐状に照らします。 | 懐中電灯、車のヘッドライト、ステージのスポットライト。 |

Add → LightでPointライトが作成されます。Add → SunとAdd → Spotでは、ほかの2つを直接作成できます。種類はあとから**Type**プロパティで変更できます。

SunとSpotは、オブジェクトを回転させて向きを決めます。Sunは常に、照らす方向へ床まで届く線を描画します。ライトを選択すると、Spotはその円錐を、Pointは**Distance**の大きさの球を表示します。

## タブ

| タブ | 内容 |
|---|---|
| Object | 位置、回転、名前、表示。すべてのオブジェクトと同じです。[3Dメッシュ](objeto-malla.md#objectタブ)を参照してください。 |
| Light | 下のカードです。 |
| Constraints | [コンストレイント](restricciones.md)を参照してください。 |
| Scripts | オブジェクトのLuaスクリプトです。[Whisk3DのLua](../lua/README.md)を参照してください。 |

## Lightカード

| プロパティ | 働き |
|---|---|
| Ignore order | チェックを入れると（初期設定）、Outlinerのどこにあっても、ライトはシーン全体を照らします。チェックを外すと、Outlinerでライトより**あと**に描画されるものだけを照らします。特定のものを特定のライトで照らしたいときに使います。 |
| Type | Point、Sun、Spot。 |
| GL Light ◆ | OpenGLの8つのライトのどれを使うかです（0から7）。[8個を超えるライト](#8個を超えるライト)を参照してください。 |
| Diffuse ◆ | ライトの色です。 |
| Intensity ◆ | どれだけ強く照らすかです。1で色そのまま、それより大きいとさらに強くなります。 |
| Ambient ◆ | どこにでも均一に届く光で、ライトの方を向いていない面にも届きます。初期値は黒（アンビエントなし）です。影が真っ黒にならないように、少し上げてください。 |
| Specular ◆ | ライトがマテリアルに作るハイライトの色です。初期値は黒（ハイライトなし）です。 |
| Att Constant、Att Linear、Att Quadratic ◆ | **減衰**、つまり距離によってライトがどう弱まるかです。Constantはどこでも均一に弱め、Linearは離れるにつれて少しずつ弱め、Quadraticは遠くでずっと速く弱めます。Sunにはありません。 |
| Spot Cutoff ◆ | Spotのみ：円錐の開き具合です。中心から縁までの角度（度）で、45なら円錐は全体で90°開きます。 |
| Spot Exponent ◆ | Spotのみ：円錐の中で光がどう分布するかです。0では均一に照らし、値を上げると中心に集まり、縁が暗くなります。 |
| Distance | レイトレーシングで、PointライトやSpotがどこまで照らすかです（メートル）。描画される円錐の長さでもあります。0は無制限です。Sunにはありません。 |
| Radius | レイトレーシング用：ランプの大きさです。0では縁のくっきりした硬い影に、大きくすると縁の柔らかい影になります。Sunでは度単位です。 |
| Rays | レイトレーシング用：このライトが出す影のレイの数です。レイが多いほど柔らかい影がきれいになりますが、遅くなります。0にするとFile / Renderタブの値を使います。 |

### Distanceと減衰

どちらもライトがどこまで届くかを変えますが、働きは同じではありません。

- **減衰**は、3D Viewportでも、ゲームでも、レイトレーシングでも常に働きます。ライトは距離とともに弱まっていきますが、完全に切れることはありません。
- **Distance**はレイトレーシングでの打ち切りです。ライトはちょうどその距離でゼロになるように滑らかに弱まり、その先は照らしません。OpenGLでは打ち切られず、減衰だけが働きます。球や円錐がどこで終わるかを示すので、目安としても使えます。

## 8個を超えるライト

OpenGLは**同時に8個まで**のライトを描画します。0から7の番号が付いていて、これが**GL Light**プロパティです。シーンにはそれよりずっと多くのライトを置けますが、8個を超えると、新しいライトは前のライトのどれかと番号を共有します。一方、レイトレーシングはすべてのライトを使います。

**Ignore order**のチェックを外すと、番号を意図的に使い回せます。GL Lightが0のライトは、Outlinerでそれよりあとに描画されるものを照らし、その下にある同じGL Light 0の別のライトが、そこから先の分を引き継ぎます。こうすると、長いステージでも8個を超えずに、エリアごとに違うライトを使えます。

## 例

| シーン | 作り方 |
|---|---|
| 昼の屋外 | Sunを1つ置き、Diffuseをほんの少し黄色にします。影が真っ黒にならないように、水色のAmbientを少し加えます。 |
| ランプのある部屋 | ランプの位置にPointを置き、壁に向かって弱まるようにAtt Linearを少し高くします。レイトレーシング用に、Distanceを部屋の大きさにします。 |
| 懐中電灯 | Spot Cutoffを小さく、Spot Exponentを高くしたSpotを、[Child Of](restricciones.md#child-of)コンストレイントでキャラクターの手に付けます。 |
| ちらつくライト | Intensity（◆）にキーフレームを打ち、値を上げ下げします。 |
