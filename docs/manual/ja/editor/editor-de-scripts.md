# Script Editor（IDE）

Luaスクリプトと[自作シェーダー](shaders.md)（`.glsl`）用のテキストエディターで、行番号、シンタックスハイライト、インデントガイドを備え、ñやアクセント記号にも対応しています。フォーカスがある間は、文字キーは入力に使われます（エディターのショートカットは働きません）。Androidでは、テキストをタップするとキーボードが開きます。N95ではT9で入力します。

| 機能 | 説明 | ショートカット |
|---|---|---|
| Script | 編集するプロジェクト内の.luaを選びます。またはLoad .lua…（外部ファイル）。 | Scriptメニュー |
| Save | スクリプトを保存します。.w3dの中にある場合は、プロジェクトも保存します。 | <kbd>Ctrl+S</kbd>またはFile → Save |
| Save As… | 別の名前で、プロジェクトの中または外の、好きなフォルダーに保存します。 | File |
| Save inside the .w3d | スクリプトが外部にある場合のみ：プロジェクトに取り込みます。 | File |
| Save outside the .w3d… | スクリプトが内部にある場合のみ：ファイルとして外に出します。オブジェクトはそのファイルを使うようになります。 | File |
| Refresh | ディスク上のファイルをそのまま読み込みます（別のエディターで編集した内容）。エディターに未保存の変更がある場合は、破棄する前に確認します（<kbd>Ctrl+Z</kbd>で元に戻せます）。ゲームの実行中は、そのスクリプトを使うオブジェクトをその場で再読み込みします。 | ボタン |
| シェーダー（.glsl） | マテリアル（**Shader** 行の小さなボタン）、Library、またはセレクターから開きます。GLSLとして色分けされます。名前の横に **Compile** が表示されます：書いている内容をコンパイルします（マテリアルが使っていれば、保存してそのマテリアルをコンパイルします）。シェーダーを保存すると、それを使うすべてのマテリアルでコンパイルされ、成功したか、エラーとその行番号が表示されます。 | <kbd>Ctrl+S</kbd> |
| 保存時の保護 | 開いたあとで外部ファイルが外部で変更されていた場合、Saveは上書きする前に確認します。ゲームの実行中は、Saveでスクリプトもその場で再読み込みされます。 | 自動 |
| インデント（Tab） | <kbd>Tab</kbd>は次の4の倍数の位置まで埋めます。複数行を選択しているときは1段インデントし、<kbd>Shift+Tab</kbd>で1段戻します。縦線が各インデントレベルを示し、カーソルがあるブロックの線は明るく表示されます。 | <kbd>Tab</kbd> / <kbd>Shift+Tab</kbd> |
| Editメニュー | Undo、Redo、Cut、Copy、Paste、Find…、Replace… | Editボタン |
| Selectメニュー | Select All。 | Selectボタン |
| Undo / Redo | スクリプトのテキストに対して働きます（シーンには影響しません）。 | <kbd>Ctrl+Z</kbd> / <kbd>Ctrl+Y</kbd>または<kbd>Ctrl+Shift+Z</kbd> |
| Find / Replace | 右上にパネルが開きます：検索するテキスト、一致した数（「3 of 7」）、Match case、Whole word、Previous / Next。Replaceでは置換後のテキストと、ReplaceとReplace all（取り消しは1ステップ）。一致した箇所はコード内で強調表示されます。パネルはエディターをふさがないので、ポインターをスクリプトの上に置けば、そのまま入力を続けられます。Closeまたは<kbd>Esc</kbd>で閉じます。 | <kbd>Ctrl+F</kbd> / <kbd>Ctrl+H</kbd> |
| Copy / Cut / Paste | システムのクリップボードを使います。 | <kbd>Ctrl+C</kbd> / <kbd>Ctrl+X</kbd> / <kbd>Ctrl+V</kbd> |
| Select All / Undo | Undoはテキストに対して働き、シーンには影響しません。 | <kbd>Ctrl+A</kbd> / <kbd>Ctrl+Z</kbd> |
| 指で選択 | ダブルタップで単語、トリプルタップで行全体を選択します。選択すると両端に2つのハンドル（緑の円）が表示され、ドラッグして範囲を調整できます。 | タップ |
| ルーペ（タッチ） | コードの上で指を少し止めると、指の上に拡大した行とカーソルが表示されます。ドラッグするとカーソルが指についていき、離した位置に置かれます。 | 長押し |
| N95での選択 | 方向キーでカーソルを動かします。Pencilキーを押したままにすると、方向キーでカーソルの位置から選択できます。Pencilキーを押している間は下にバーが表示され、左ソフトキーで**コピー**、右ソフトキーで**ペースト**します。 | Pencilキー + 方向キー / ソフトキー |
| テキスト内の移動 | 方向キー、Home、End、PageUp、PageDown（<kbd>Shift</kbd>と一緒に押すと選択します）。<kbd>Ctrl+Home</kbd> / <kbd>Ctrl+End</kbd>で先頭または末尾に移動します。 | キーボード |
