# Armature

**Armature**モディファイアーは、メッシュをアーマチュアのボーンに追従させます。アーマチュアにポーズを付けたりアニメーションさせたりすると、メッシュも一緒に曲がります。止まったモデルを、歩いたり、跳んだり、手を振ったりするキャラクターに変えるのがこのモディファイアーです。

![Leonのメッシュの、Modifiersタブ全体。Armatureモディファイアーが付いています](../tutoriales/img/modificador-esqueleto.webp)

## 追加のしかた

1. メッシュを選択します。
2. Propertiesで**Modifiers**タブ（スパナのアイコン）を開きます。
3. **Add**をタップして、**Armature**を選びます。

リストには内部名の**Armature**で表示され、その下にパラメーターのカードが開きます。ほかのモディファイアーと同じく、メッシュを壊しません。レストポーズはそのまま残ります。オフにしたり、**Remove**で外したり、**Apply Modifier**でベイクしたりできます。

アーマチュア付きのFBXやglTFを読み込むと、このモディファイアーはすでに付いていて、そのアーマチュアを指しています。

## パラメーター

| パラメーター | 働き |
|---|---|
| Display in Viewport | オフにすると、メッシュは変形せず、レストポーズのままになります。 |
| Display in Edit Mode | オフにすると、頂点の編集中はメッシュがレストポーズのままになり、変形しません。 |
| Target | メッシュを動かすアーマチュアです。リストには、シーンのアーマチュアだけが表示されます。**None**のときは変形しません。 |
| Optimize Vertex Groups | 各頂点に、いちばん大きく動かしていたボーン1本だけを、ウェイト1で残します。中間のウェイトが失われるので、確認を求めます。 |
| Apply Modifier | 現在のフレームのポーズをメッシュにベイクし、モディファイアーを外します。メッシュはそのポーズで固定されます。アーマチュアには手を加えません。元に戻すことができます。 |

## メッシュはどのボーンが動かすかをどう知るか

**頂点グループ**を使います。各グループは**ボーンと同じ名前**を持ち、そのボーンがどの頂点をどれだけ動かすかを表します。これが**ウェイト**で、0（まったく動かさない）から1（完全に動かす）までです。1つの頂点が複数のグループに入ることもできます。ひじでは、半分を上腕に、半分を前腕に入れると、滑らかに曲がります。

グループは**3D Mesh**タブの**Vertex Groups**カードにあります。

| ボタン | 働き |
|---|---|
| Add Vertex Group / Rename | グループを作成し、名前を付けます。名前はボーンの名前と1文字ずつ同じにする必要があります。 |
| Assign / Remove | Edit Modeで、選択した頂点をグループに入れる（ウェイト1）か、グループから外します。 |
| Select / Deselect | グループにどの頂点が入っているかを表示します。 |

肩やひざの移り変わりのような細かいウェイトには、[Weight Paint](pintura.md#weight-paint)を使います。選んだグループのウェイトを、青（まったく動かさない）から赤（完全に動かす）までペイントします。

## 手順

1. アーマチュアを作り（**Add → Armature**）、ボーンをモデルの中に配置します（[アーマチュア](esqueletos.md)を参照）。
2. メッシュに**Armature**モディファイアーを追加し、**Target**でそのアーマチュアを選びます。
3. ボーンごとに同じ名前のグループを作り、ウェイトを割り当てるか、ペイントします。
4. アーマチュアを選択し、**Pose Mode**に切り替えて、ボーンを動かします。メッシュがついてきます。

## 知っておくとよいこと

- Armatureがリストのどこにあっても、結果は変わりません。ほかのモディファイアーと一緒には計算されず、描画するときに毎フレーム、メッシュを変形します。
- 変形するのは元のメッシュです。ジオメトリを生成するほかのモディファイアー（[Mirror](modificador-espejo.md)、[Array](modificador-array.md)、[Subdivision Surface](modificador-subdivision.md)、[Screw](modificador-screw.md)、[Boolean](modificador-booleano.md)）がオンになっていると、表示されるのは生成されたメッシュで、それはボーンに追従しません。アニメーションする前に、それらを適用してください。
- それらのモディファイアーのどれか（Mirrorを除く）を適用すると、リスト全体が空になり、Armatureも消えます。頂点グループは残るので、もう一度Armatureを追加して、Targetを選び直してください。

![Nokia](../tutoriales/img/icono-nokia.svg) Nokia N95では、毎フレームのメッシュの変形に負荷がかかり、各頂点に影響するボーンが多いほど重くなります。**Optimize Vertex Groups**を使うと頂点ごとにボーンが1本だけになり、スキニングがずっと速くなります。その代わり、関節の曲がり方が硬くなります。ウェイトが仕上がってから、最後に行ってください。
