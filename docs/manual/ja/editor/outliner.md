# Outliner

シーン内にあるすべてのものの一覧で、プロジェクトのリソースライブラリーでもあります。Androidでは表示されません（3D ViewportとPropertiesで作業します）。

## Viewメニュー（目）

| 機能 | 説明 |
|---|---|
| Scene / Library / Libraries | 一覧に表示するもの：シーンのツリー、プロジェクトのすべてのリソース、またはリンクした別の.w3dのリソース（読み取り専用）。 |
| Constructor / Routines | Constructorルーチン（開始時に一度だけ実行されるもの）と、そのほかのルーチンの表示・非表示を切り替えます。 |
| Visibility icons / Render icons | 目とカメラの列の表示・非表示を切り替えます。 |
| Grid | Libraryで、リストの代わりにサムネイルを表示します。 |
| Link .w3d… / Unlink | 別のプロジェクトをライブラリーとして使う、またはそのリンクを解除します。 |

## Sceneビュー

| 機能 | 説明 | 使い方 |
|---|---|---|
| Select | オブジェクトを選択します。<kbd>Shift</kbd>+クリックで範囲を選択し、<kbd>Ctrl</kbd>+クリックで追加または解除します。 | クリック |
| 展開 / 折りたたみ | 子の表示・非表示を切り替えます。 | 矢印。<kbd>Left</kbd> / <kbd>Right</kbd> |
| Visible / Renderable | 目のアイコンでオブジェクトを隠します（アニメーションできます）。カメラのアイコンでレンダリングから除外します。 | 目 / カメラのアイコンをクリック |
| 並べ替えとペアレント | 別の行の前、後ろ、または上（子として）にドロップします。 | 行をドラッグ |
| Move (reorder) | キーボードで：上/下で並べ替え、左で親から外し、右で直前の行の下に入れ、<kbd>Enter</kbd>で確定します。 | <kbd>G</kbd> |
| Rename | 行がテキスト欄になります。 | ダブルクリックまたは<kbd>F2</kbd> |
| Duplicate / Duplicate Linked | 3D Viewportと同じです。 | <kbd>Shift+D</kbd> / <kbd>Alt+D</kbd> |
| Hide / Show | 表示・非表示を切り替えます。 | <kbd>H</kbd> |
| Delete | 確認のうえ削除します。 | <kbd>X</kbd>または<kbd>Delete</kbd> |
| Create / Unpack Prefab | Objectメニューから行います。 | 右クリック |
| Show active | アクティブなオブジェクトまでリストをスクロールします。 | <kbd>Num.</kbd> |
| リストのスクロール | ホイール、またはドラッグ（指でも可能）。 | ホイール / ドラッグ |

## Libraryビュー

| 機能 | 説明 |
|---|---|
| リソース | メッシュ、マテリアル、テクスチャ、アニメーション、プレハブ、シーン、サウンド、スクリプト、[シェーダー](shaders.md)、フォント、動画が、フォルダーに分かれて表示されます。3D Viewportのメッシュの上にドラッグしたマテリアルやシェーダーは、ドロップする前からポインターの下のパーツに表示されます。緑のチェックマーク = 使用中、赤い×印 = 孤立、`*` = 未保存。 |
| Filter / List or Grid | 1種類だけを表示します。サムネイルを表示します。 |
| リソースのドラッグ | フォルダーへ（移動します）、3D Viewportへ（メッシュ = 新しいオブジェクト、マテリアルまたはテクスチャ = ドロップした先に割り当て、プレハブ = インスタンス）、またはPropertiesのドロップダウンへ。 |
| New Folder / Move to Folder | 整理します（フォルダーは並べるためだけのものです）。 |
| Duplicate Resource / Select Users / Purge Orphans | コピーする、何が使っているかを調べる、何にも使われていないものを削除する。 |
| Inside the .w3d / External | Properties（Resourceカード）から行います：リソースをプロジェクトの中または外に移します。 |

## シーン、ゲーム、プレハブ

シーン名が書かれたボタン（Outlinerと3D Viewportにあります）には、プロジェクトのシーン、ゲーム、プレハブが一覧表示されます。そこから新しく作成したり、開始シーンを選んだり、シーンをゲームに変換したり（またはその逆）できます。
