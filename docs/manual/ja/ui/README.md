# Whisk3D UIマニュアル

**Whisk3D UI**は、Whisk3Dのインターフェースのライブラリです：ボタン、タブ、ドロップダウンメニュー、プロパティのカード、テキスト、アイコンを、Whisk3D Coreの上に描画します。エディターはこのライブラリで作られています。このマニュアルは、CまたはC++でプログラミングをしていて、自分のゲームやプログラムのインターフェースにこのライブラリを使いたい人のためのものです。レビュー用の草稿です。

プロジェクトのページ：**[Whisk3D UI](https://leoncini.com.ar/proyecto.php?id=whisk3d-ui&lang=ja)**。コードはGitHubの**[Whisk3D-UI](https://github.com/Dante-Leoncini/Whisk3D-UI)**にあり、MITライセンスです。
