# Outliner

> [!NOTE]
> ![Nokia](img/icono-nokia.svg) Nokia N95はマウスとキーボード（Bluetooth）に対応しています。このページのNokiaの説明は、マウスやキーボードを使わずに、電話のキーだけで操作する方法です。

**Outliner**は、シーンにあるものすべての一覧です。オブジェクト、カメラ、ライト、コレクションが並びます。[ビューポート](viewports.md)で見たビューポートの1つで、PCでは右上にあります。ここでは、オブジェクトを選択したり、隠したり、並べ替えたり、別のオブジェクトの中に入れたり、名前を変えたりできます。

Outlinerで選択したものは3D Viewportでも選択され、その逆も同じです。最後に選択したものが**アクティブなオブジェクト**で、Propertiesに表示されるのはこのオブジェクトです。

![Android](img/icono-android.svg) **Androidでは**、Outlinerは最初は画面にありません。その場所は3D ViewportとPropertiesに使われています。使うときは、[種類を変える](viewports.md#種類を変える)のように、隅のボタンでビューポートの1つをOutlinerに変えます（またはビューポートを分割します）。Outlinerがなくても作業はできます。オブジェクトは3D Viewportでタップして選択でき、Propertiesには名前と、**Visible**と**Renderable**のチェックボックスがあります。

![Nokia](img/icono-nokia.svg) **Nokia N95では**、Outlinerは最初は画面にありません。ビューポートが2つしか入らないからです。シーンを整理する間は、PropertiesをOutlinerに変えます。**左ソフトキー**でタブに入り、左の方向キーで隅のボタンのメニューまで行き、そこでOutlinerを選びます。元に戻すときは、Outlinerで左ソフトキーを押すと、すぐにそのメニューが開きます。**緑キー** ![](img/tecla-verde.svg) でOutlinerをアクティブなビューポートにします。このあとのN95の説明は、すべてOutlinerに緑の枠がある状態での操作です。

## 各行に表示されるもの

各行が1つのオブジェクトです。**矢印**で、中にあるものを折りたたんだり展開したりします。**アイコン**は種類（メッシュ、カメラ、ライト、コレクション…）を表します。その次が**名前**で、アクティブなら緑、選択されていれば少し暗い緑で表示されます。右端には**目**と**カメラ**があります。別のオブジェクトの中にあるオブジェクトは、少し右にずれて、その下にぶら下がるように表示されます。薄く表示されている行は、隠れているオブジェクトです。

新しいプロジェクトでは、いちばん上に画面を準備するルーチン**Constructor**があり、その下に、カメラ、ライト、立方体が入った**Collection**があります。コレクションは、整理するためのフォルダーです。

| ![Nokia](img/icono-nokia.svg) Nokia N95 | 上下の方向キーで前または次の行に移ります。リストは自動でスクロールして、その行についていきます。 |
| メニュー | Select → Select All、Deselect All、Invert Selection |

## 折りたたみと展開

中にほかのオブジェクトがあるときは、矢印でそれを表示したり隠したりします。使っていないものを折りたたむと、リストが短くなります。

| | 折りたたみと展開のしかた |
|---|---|
| ![PC](img/icono-pc.svg) PC | 矢印を1回クリックします。マウスがOutlinerの上にあるときは、キーボードの右矢印キーでアクティブなオブジェクトを展開し、左矢印キーで折りたたみます。すでに折りたたまれている場合は、左で外側のオブジェクトに移って、それを折りたたみます。 |
| ![Android](img/icono-android.svg) タッチスクリーン | 矢印を1回タップします。 |
| ![Nokia](img/icono-nokia.svg) Nokia N95 | 右でアクティブなオブジェクトを展開し、左で折りたたみます。すでに折りたたまれている場合は、左で外側のオブジェクトに移って、それを折りたたみます。 |

![Collectionの矢印をクリックすると、Camera、Light、Cubeが隠れ、もう一度クリックするとまた表示されます](img/outliner-plegar-raton.webp)

## 隠す：目とカメラ

- **目**は、3D Viewportでオブジェクトを表示したり隠したりします。隠したオブジェクトは、レンダーにも出ません。中にほかのオブジェクトがある場合は、それらも一緒に隠れて、行が薄く表示されます。
- **カメラ**は、**レンダー**に出すかどうかを決めます。オフにすると、作業中はオブジェクトが見えたままですが、レンダーした画像や動画には出ません。

これらに触れても、選択は変わりません。

| | 目 | カメラ |
|---|---|---|
| ![PC](img/icono-pc.svg) PC | 目をクリック。アクティブなオブジェクトなら<kbd>H</kbd>（マウスをOutlinerの上に置いて） | カメラをクリック |
| ![Android](img/icono-android.svg) タッチスクリーン | 目を1回タップ | カメラを1回タップ |
| ![Nokia](img/icono-nokia.svg) Nokia N95 | <kbd>2</kbd>（アクティブなオブジェクトの目） | <kbd>3</kbd>（アクティブなオブジェクトのカメラ） |
| メニュー | Element → Hide/Show（アクティブなオブジェクト） | — |

![Cubeの目をクリックすると目が閉じて、立方体が3D Viewportから消えます。もう一度クリックすると、また表示されます。Cubeのカメラをクリックするとオフになりますが、立方体は見えたままです](img/outliner-ocultar-raton.webp)

どちらもPropertiesのTransformカードにもあります：**Visible**と**Renderable**です。ひし形があるのでアニメーションでき、たとえば動画のある瞬間に何かを登場させるのに使えます。

## 並べ替えとペアレント

リストの順番は変えられます。また、オブジェクトを別のオブジェクトの**中に**入れることもできます。入れたオブジェクトはその**子**になり、親が移動、回転、拡大縮小すると、子も一緒に動きます。[Object Mode](modo-objeto.md#outlinerシーンのオブジェクト)で**ペアレント**と呼んでいたものです。オブジェクトのシーン内の位置は変わりません。変わるのはリストの中だけです。

![PC](img/icono-pc.svg) **マウスで：** 行をつかんでドラッグします。別の行の上端または下端に来ると**緑の線**が表示され、離すと、オブジェクトはその行の前または後ろに、同じ階層で置かれます。別の行の中央に来るとその行が強調され、離すと、オブジェクトはその行の**中に**入ります。最後の行より下で離すと、それまで入っていたものすべての外に出ます。リストの上端や下端の近くでは、リストが自動でスクロールするので、長いリストでもどの行にでも届きます。

![Lightの行をCameraの上までドラッグすると、緑の線で先頭に置かれます。次にCameraをCubeの行の中央で離すと、その中に入り、右にずれて表示されます](img/outliner-mover-raton.webp)

![Android](img/icono-android.svg) **指で：** 電話が振動するまで、行の上に指を1秒動かさずに置きます。これで行をつかんだ状態になります。あとはマウスと同じようにドラッグして離します。動かさずに離すと、オブジェクトのメニューが開きます。待たずに指をドラッグすると、リストがスクロールします。

![Nokia](img/icono-nokia.svg) **Nokia N95では：** 方向キーで行を選び、<kbd>1</kbd>を押します。行が緑になり、方向キーで行を動かせるようになります。

- ![Nokia](img/icono-nokia.svg) **上**と**下**で、同じ階層の行の間で上下に動かします。
- ![Nokia](img/icono-nokia.svg) **右**で、すぐ上にある同じ階層の行の中に入れます。
- ![Nokia](img/icono-nokia.svg) **左**で、入っているオブジェクトの外に出します。そのオブジェクトの後ろに、同じ階層で置かれます。
- ![Nokia](img/icono-nokia.svg) もう一度<kbd>1</kbd>（または<kbd>OK</kbd>）を押すと、その位置で確定します。<kbd>C</kbd>でキャンセルすると、元の位置に戻ります。

![Nokia](img/icono-nokia.svg) 動かした結果は、<kbd>C</kbd> + 左でまとめて元に戻せます。これは、たとえばライトを、それが照らすオブジェクトより前に置くときに使います。

![Outlinerがアクティブな状態のNokia N95。1でLightの行が緑になり、上の方向キーでCameraの上に移り、1でそこに確定します。2で立方体が3D Viewportから消えてまた現れ、3でその行のカメラがオフになります](img/outliner-nokia.webp)

## アクティブなオブジェクトを見つけて画面に収める

大きなシーンではリストが長くなります。3D Viewportで何かを選択してもリストは動かないので、その行が見えない位置にあることがあります。リストでその行を見つけたり、3D Viewportでそのオブジェクトを見たり（[選択したものを画面に収める](navegacion.md#選択したものを画面に収める)のように**画面に収める**）するには：

| | Outlinerで | 3D Viewportで |
|---|---|---|
| ![PC](img/icono-pc.svg) PC | マウスをOutlinerの上に置いて<kbd>Num .</kbd>（**Show active**）。選択したものが中央に来るまでリストがスクロールします。折りたたまれたものの中にある場合は行がないので、先に展開してください。 | マウスを3D Viewportの上に置いて<kbd>Num .</kbd> |
| ![Android](img/icono-android.svg) タッチスクリーン | 指でリストをドラッグします | 3D Viewportの上で2本指でダブルタップ |
| ![Nokia](img/icono-nokia.svg) Nokia N95 | 方向キーで選んだ行に、リストが自動でついていきます | <kbd>0</kbd>を1回押します（アクティブなビューポートがOutlinerでも使えます） |
| メニュー | — | 3D ViewportのバーでView → Frame Selected |

![数十個のオブジェクトがあるシーン。3D Viewportで1つを選択しても、Outlinerにはその行が見えません。マウスをOutlinerの上に置いてNum .を押すと、リストがスクロールして、緑の行が中央に来ます](img/outliner-activo-raton.webp)

## 名前を変える

| | 名前の変え方 |
|---|---|
| ![PC](img/icono-pc.svg) PC | 名前をダブルクリックするか、アクティブなオブジェクトなら<kbd>F2</kbd>を押します。行がテキストフィールドになります。新しい名前を入力して、<kbd>Enter</kbd>か外側のクリックで確定します。<kbd>Esc</kbd>で元のままになります。 |
| ![Android](img/icono-android.svg) タッチスクリーン | 名前をダブルタップします。画面のキーボードが開きます。 |
| ![Nokia](img/icono-nokia.svg) Nokia N95 | 左ソフトキーでバーに入り、右の方向キーでElement → Renameまで行きます。T9で入力し、<kbd>OK</kbd>で確定します。 |
| メニュー | Element → Rename |

![Cubeの名前をダブルクリックするとフィールドになり、Boxと入力してEnterで確定します。次にLightを選択してF2を押し、Lampと入力してEnterを押します](img/outliner-renombrar-raton.webp)

同じシーンの2つのオブジェクトに同じ名前は付けられません。その名前がすでに使われている場合は、Whisk3Dが番号を付けて知らせます。スクリプトがそのオブジェクトの名前を使っていた場合は、自動で更新されます。

## 複製と削除

| | 複製 | 削除 |
|---|---|---|
| ![PC](img/icono-pc.svg) PC | <kbd>Shift</kbd> + <kbd>D</kbd>。Duplicate Linkedは<kbd>Alt</kbd> + <kbd>D</kbd> | <kbd>X</kbd>または<kbd>Delete</kbd> |
| ![Nokia](img/icono-nokia.svg) Nokia N95 | Element → Duplicate | <kbd>C</kbd> |
| メニュー | Element → DuplicateまたはDuplicate Linked | Element → Delete |

Outlinerから複製すると、コピーは元のオブジェクトにぴったり重なって置かれ、3D Viewportのようにマウスにはついてきません。あとで動かしてください。削除には確認があり、どちらの操作も元に戻せます。

## Library

プロジェクトの**リソース**（メッシュ、マテリアル、テクスチャ、アニメーション、サウンド、スクリプト、プレハブ…）はOutlinerにはありません。専用のビューポート**Library**があり、隅のボタンで選びます。フォルダーに分けてサムネイルを表示し、どのリソースが使われていて、どれが使われていないかを示します。リソースは3D Viewportにドラッグできます。メッシュならオブジェクトが作られ、マテリアルならその下にあるものに割り当てられます。[Libraryビュー](outliner.md#libraryビュー)で説明しています。Outlinerのそのほかの機能は、[マニュアル](outliner.md)と[ショートカット](../editor/atajos.md#outliner)にあります。

## Libraryビュー

| 機能 | 説明 |
|---|---|
| リソース | メッシュ、マテリアル、テクスチャ、アニメーション、プレハブ、シーン、サウンド、スクリプト、[シェーダー](../editor/shaders.md)、フォント、動画が、フォルダーに分かれて表示されます。3D Viewportのメッシュの上にドラッグしたマテリアルやシェーダーは、ドロップする前からポインターの下のパーツに表示されます。緑のチェックマーク = 使用中、赤い×印 = 孤立、`*` = 未保存。 |
| Filter / List or Grid | 1種類だけを表示します。サムネイルを表示します。 |
| リソースのドラッグ | フォルダーへ（移動します）、3D Viewportへ（メッシュ = 新しいオブジェクト、マテリアルまたはテクスチャ = ドロップした先に割り当て、プレハブ = インスタンス）、またはPropertiesのドロップダウンへ。 |
| New Folder / Move to Folder | 整理します（フォルダーは並べるためだけのものです）。 |
| Duplicate Resource / Select Users / Purge Orphans | コピーする、何が使っているかを調べる、何にも使われていないものを削除する。 |
| Inside the .w3d / External | Properties（Resourceカード）から行います：リソースをプロジェクトの中または外に移します。 |

## シーン、ゲーム、プレハブ

シーン名が書かれたボタン（Outlinerと3D Viewportにあります）には、プロジェクトのシーン、ゲーム、プレハブが一覧表示されます。そこから新しく作成したり、開始シーンを選んだり、シーンをゲームに変換したり（またはその逆）できます。
