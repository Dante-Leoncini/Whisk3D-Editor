# 3D Viewportのナビゲーション

> [!NOTE]
> ![Nokia](img/icono-nokia.svg) Nokia N95はマウスとキーボード（Bluetooth）に対応しています。このチュートリアルのNokiaの説明は、マウスやキーボードを使わずに、電話のキーだけで操作する方法です。

このチュートリアルでは、3D Viewportでのナビゲーションの方法を説明します。ナビゲーションとは、視点を動かすことです。シーンのまわりを回ったり、横にずれたり、近づいたり離れたりします。

ナビゲーションを覚えることは大切です。3Dモデルやアニメーションを快適にすばやく作るには、シーンの中を移動して、作業しやすい位置に視点を置けるようになる必要があります。

[前のチュートリアル](viewports.md#アクティブなビューポート)で説明したとおり、このあとのコマンドを使うには、3D Viewportがアクティブなビューポート（緑の枠があるビューポート）になっている必要があります。

いちばんよく使うのは、**オービット**、**平行移動**、**ズーム**の3つです。どれも、マウスでも、タッチスクリーンで指を使っても、Nokia N95のキーパッドでも操作できます。PCの動画では、右下のマウスの図で、押しているボタンが緑で表示されます。

## オービット

オービットは、シーンのまわりでビューを回すことです。テーブルのまわりを歩いて、上にあるものをあらゆる方向から見るような感じです。

![PC](img/icono-pc.svg) **マウスで：** **中ボタン**（ホイールを押し込むと押せます）を押したままドラッグします。トラックパッドや、中ボタンのないマウスでは、<kbd>Alt</kbd>を押したまま**プライマリクリック**（左ボタン）でドラッグします。

![3D Viewportの上にあるマウスポインター。中ボタンを押したままドラッグすると、ビューが立方体のまわりを回ります](img/navegacion-orbitar-raton.webp)

![Android](img/icono-android.svg) **指で：** 3D Viewportの上で指を1本ドラッグします。背景の上から始めてください。ギズモ（オブジェクトの色付きの矢印）の上に指を置くと、ギズモを動かしてしまいます。

![3D Viewportの背景の上で指を1本ドラッグすると、ビューが立方体のまわりを回ります](img/navegacion-orbitar-dedo.webp)

![Nokia](img/icono-nokia.svg) **Nokia N95では：** **方向キー**を押したままにします。押している間、ビューがその方向に回ります。

![縦向きのNokia N95。右、左、上、下の方向キーを押したままにすると、ビューが立方体のまわりを回ります](img/navegacion-orbitar-nokia.webp)

## 平行移動

平行移動（*パン*）は、ビューを回さずに、横や上下にずらすことです。

![PC](img/icono-pc.svg) **マウスで：** <kbd>Shift</kbd>を押したまま、**中ボタン**でドラッグします。トラックパッドでは、<kbd>Alt</kbd> + <kbd>Shift</kbd>を押したまま、プライマリクリックでドラッグします。

![Shiftと中ボタンを押したままポインターが円を描くと、ビューもそれに合わせて平行移動します](img/navegacion-panear-raton.webp)

![Android](img/icono-android.svg) **指で：** **2本の指**を置いて、同じ方向に一緒に動かします。

![2本の指が一緒に円を描くように動き、ビューが平行移動します](img/navegacion-panear-dedo.webp)

![Nokia](img/icono-nokia.svg) **Nokia N95では：** <kbd>\*</kbd>キーを押したまま、方向キーを使います。

![アスタリスクキーを押したままのNokia N95。方向キーを押すたびに、ビューがその方向に平行移動します](img/navegacion-panear-nokia.webp)

## ズーム

ズームは、近づいたり離れたりする操作です。1回で進む量は距離に合わせて変わります。小さいものの近くではゆっくり、遠くからは速く進むので、シーン全体を見るときにも、1つの頂点を見るときにも同じように使えます。

![PC](img/icono-pc.svg) **マウスで：** **ホイール**を回します。前に回すと近づき、後ろに回すと離れます。トラックパッドでは、2本の指を上下にスライドします。

![立方体の上にあるマウスポインター。ホイールを前に回すとビューが近づき、後ろに回すと離れます](img/navegacion-zoom-raton.webp)

![Android](img/icono-android.svg) **指で：** ピンチします。指を広げると近づき、閉じると離れます。

![2本の指を広げるとビューが立方体に近づき、閉じると離れます](img/navegacion-zoom-dedo.webp)

![Nokia](img/icono-nokia.svg) **Nokia N95では：** <kbd>0</kbd>を押したまま、**上**の方向キーで近づき、**下**の方向キーで離れます。

![0を押したままのNokia N95。上でビューが立方体に近づき、下で離れます](img/navegacion-zoom-nokia.webp)

## 選択したものを画面に収める

どこを見ているかわからなくなったときや、特定のものを作業したいときは、それを**画面に収めます**。ビューが選択したものを中心にして、ちょうど収まるようにズームを合わせます。そのあとは、オービットするとそれを中心に回ります。

| | 画面に収める方法 |
|---|---|
| ![PC](img/icono-pc.svg) PC | <kbd>Num .</kbd>（テンキーのピリオド） |
| ![Nokia](img/icono-nokia.svg) Nokia N95 | 方向キーを使わずに<kbd>0</kbd>を1回押します（方向キーと一緒に押したままにするとズームです） |
| ![Android](img/icono-android.svg) タッチスクリーン | 2本指でダブルタップ |
| メニュー | View → Frame Selected |

![ビューが遠く、ずれていて、立方体が隅に小さく見えています。Num .を押すと、立方体が中央に来てビューいっぱいに表示されます](img/navegacion-encuadrar.webp)

![Nokia N95。0を1回押すと、隅に小さく見えていた立方体が中央に来て、画面に収まります](img/navegacion-encuadrar-nokia.webp)

### Edit Modeでは

[Edit Mode](../editor/modo-edicion.md)では、メッシュの選択した部分を画面に収めます。オブジェクト全体ではなく、選んだ頂点、辺、面です。大きなモデルの細部を作業するときに便利です。その部分を選択して画面に収め、そのまわりをオービットします。

![Edit Modeの球体で、6つの面が選択されています（緑）。Num .を押すとビューが近づき、それらの面が画面いっぱいに表示されます](img/navegacion-encuadrar-edicion.webp)

## ローカルビュー

シーンにたくさんのものがあると、1つのものを作業するのは大変です。手前のものが邪魔になり、オービットすると間に入ってきます。**ローカルビュー**では、選択したもの（1つまたは複数のオブジェクト）だけを表示して、画面に収めます。ほかのものは、シーンから削除されたり隠されたりするわけではありません。このビューポートで見えなくなるだけです。左上に「Local View」と表示されます。

元に戻すには、同じ操作をもう一度します。すべてが再び表示され、ビューも前の状態に戻ります。

| | 入り方と出方 |
|---|---|
| ![PC](img/icono-pc.svg) PC | <kbd>/</kbd> |
| ![Nokia](img/icono-nokia.svg) ![Android](img/icono-android.svg) Nokia N95とタッチスクリーン | Viewメニュー → Local View |

![箱、球、円柱、円錐でいっぱいのシーンで、円錐が1つ選択されています。/を押すと円錐だけが画面に収まって残り、もう一度/を押すとすべてが戻ります](img/navegacion-vista-local.webp)

## 正面、側面、上からのビュー

オービットを手で合わせなくても、シーンをある方向からまっすぐ見られます。

| ビュー | ![PC](img/icono-pc.svg) PC | メニュー |
|---|---|---|
| 正面 / 背面 | <kbd>Num 1</kbd> / <kbd>Ctrl</kbd> + <kbd>Num 1</kbd> | View → Viewpoint → Front / Back |
| 右 / 左 | <kbd>Num 3</kbd> / <kbd>Ctrl</kbd> + <kbd>Num 3</kbd> | View → Viewpoint → Right / Left |
| 上 / 下 | <kbd>Num 7</kbd> / <kbd>Ctrl</kbd> + <kbd>Num 7</kbd> | View → Viewpoint → Top / Bottom |

![PC](img/icono-pc.svg) <kbd>Ctrl</kbd>を押しながら使うと、それぞれ反対側からのビューになります。

![ものでいっぱいのシーンを、正面、右、上から見たところ。Ctrlを使うと、それぞれ反対側から見たところになります](img/navegacion-vistas.webp)

![Nokia](img/icono-nokia.svg) **Nokia N95では：** <kbd>#</kbd>キーを押したまま、方向キーを押します。左右の方向キーで、ビューがシーンのまわりを90°ずつ回ります。上で上からのビューになり、下で側面からのビューに戻ります。もう一度下を押すと、下からのビューになります。自由にオービットしていた場合、最初の方向キーは、ビューをいちばん近い方向にまっすぐ合わせるだけです。

![シャープキーを押したままのNokia N95。右の方向キーでビューが90度ずつ回り、上で上からのビューになり、下で元に戻ります](img/navegacion-vistas-nokia.webp)

## 透視投影と平行投影

3D Viewportには、シーンを表示する方法が2つあります。

- **透視投影：** 目やカメラで見たときと同じ見え方です。遠くのものほど小さく見え、平行な線（道路の両端や、動画の箱の列）は地平線上の1点、**消失点**に集まります。奥行きのある、実際の見え方です。
- **平行投影：** 遠近感がありません。近くても遠くても、すべてが同じ大きさのままで、平行な線はけっして交わりません。建築の図面や製図のような見え方です。

平行投影は、正確にモデリングするのに向いています。距離にだまされずに、ものをそろえたり、大きさを比べたり、測ったりできます。正面、側面、上からのビューと組み合わせると、図面の上で作業しているようになります。透視投影は、仕上がりを確かめるのに向いています。

| | 切り替え方 |
|---|---|
| ![PC](img/icono-pc.svg) PC | <kbd>Num 5</kbd> |
| ![Nokia](img/icono-nokia.svg) Nokia N95 | 方向キーを使わずに<kbd>#</kbd>を1回押します |
| メニュー | View → Perspective/Ortho |

![同じ箱が2列に並んでいます。透視投影では奥の箱が小さく見えます。Num 5で平行投影にすると、すべて同じ大きさになります](img/navegacion-perspectiva.webp)

![Nokia N95。シャープキーを1回押すと、箱の列が透視投影から平行投影に変わり、また元に戻ります](img/navegacion-perspectiva-nokia.webp)

## オービットをロックする

**オービットをロック**すると、ビューが回らなくなります。オービットだった操作が平行移動になり、机の上で紙をすべらせるような動きになります。家の間取り図や機械部品のように、2Dの図面として描くモデルを快適に作業するのに最適です。上から平行投影で見れば、図面が傾くことなく、図面全体を自由に移動できます。

| | ロックと解除の方法 |
|---|---|
| ![PC](img/icono-pc.svg) PC | Viewメニュー → Lock Orbit |
| ![Android](img/icono-android.svg) タッチスクリーン | Viewメニュー → Lock Orbit |
| ![Nokia](img/icono-nokia.svg) Nokia N95 | <kbd>9</kbd> |

ロックや解除をすると通知が表示され、ロック中はメニューのLock Orbitが緑で表示されます。

![上から見た家の間取り図。View → Lock Orbitを選び、中ボタンでドラッグすると、図面が回らずに平行移動します](img/navegacion-bloquear-orbita-raton.webp)

![上から見た家の間取り図。View → Lock Orbitをタップし、指でドラッグすると、図面が回らずに平行移動します](img/navegacion-bloquear-orbita-dedo.webp)

![家の間取り図を表示したNokia N95。9でオービットをロックすると、方向キーで図面が回らずに平行移動します](img/navegacion-bloquear-orbita-nokia.webp)

## アクティブなカメラ

シーンにはカメラを何台も置けますが、**アクティブなカメラ**は1台だけです。ゲームとレンダーに使われるカメラです。ゲームをプレイしたときに見えるものも、画像や動画をレンダーしたときに出力されるものも、このカメラから見たものです。ナビゲーションに使うビューは作業用で、ゲームにもレンダーにも出てきません。

アクティブなカメラから見るには：

| | 入り方と出方 |
|---|---|
| ![PC](img/icono-pc.svg) PC | <kbd>Num 0</kbd> |
| ![Nokia](img/icono-nokia.svg) Nokia N95 | <kbd>8</kbd>（Edit Mode以外で。Edit Modeでは8はLoop Cutです） |
| メニュー | View → Cameras → Active Camera |

![Num 0を押すと、3D Viewportがカメラから見たビューになり、レンダーに出る範囲の枠が表示されます。もう一度Num 0を押すと元に戻ります](img/navegacion-camara.webp)

![Nokia N95。8を押すとビューがアクティブなカメラに切り替わり、もう一度8を押すと元に戻ります](img/navegacion-camara-nokia.webp)

四角形はフレームで、その内側にあるものが出力されます。下の中央には**鍵**があります。

- **開いている**（最初の状態）：ズームと平行移動は、フレームを確かめるために近づくだけで、カメラは動きません。オービットするとカメラのビューから抜けて、カメラがあった位置からナビゲーションを続けます。
- **閉じている**：オービット、平行移動、ズームで**カメラ**が動きます。こうしてショットを調整します。

### カメラをビューにロックする

鍵を閉じると、アクティブなカメラがビューにロックされます。いつものナビゲーションと同じようにオービット、平行移動、ズームができ、カメラも一緒に動きます。カメラを思いどおりの位置に置くには、これがいちばん楽な方法です。カメラから見て、ロックし、狙いどおりのショットになるまでナビゲーションします。

| | ロックと解除の方法 |
|---|---|
| ![PC](img/icono-pc.svg) PC | 鍵をクリックします |
| ![Android](img/icono-android.svg) タッチスクリーン | 鍵をタップします |
| ![Nokia](img/icono-nokia.svg) Nokia N95 | 左ソフトキーでメニューバーを開き（[前のチュートリアル](viewports.md#バーが収まらないとき)と同じ）、そこでView → Lock the camera to the viewを選びます |
| メニュー | View → Lock the camera to the view |

![Num 0でビューがカメラに切り替わります。鍵をクリックして閉じ、オービットしてホイールを回すと、立方体がフレームに収まるまでカメラが動きます](img/navegacion-camara-bloquear-raton.webp)

![カメラから見た状態で鍵をタップして閉じ、指でドラッグすると、立方体がフレームに収まるまでカメラが動きます](img/navegacion-camara-bloquear-dedo.webp)

![Nokia N95。8でカメラに切り替え、左ソフトキーでViewメニューを開いてLock the camera to the viewを選びます。方向キーと0で、立方体がフレームに収まるまでカメラを動かします](img/navegacion-camara-bloquear-nokia.webp)

別のカメラをアクティブなカメラにするには、そのカメラを選択して<kbd>Ctrl</kbd> + <kbd>Num 0</kbd>を押します（またはView → Cameras → Set Active Object as Camera）。
