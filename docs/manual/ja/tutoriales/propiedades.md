# Properties

> [!NOTE]
> ![Nokia](img/icono-nokia.svg) Nokia N95はマウスとキーボード（Bluetooth）に対応しています。このページのNokiaの説明は、マウスやキーボードを使わずに、電話のキーだけで操作する方法です。

**Properties**は、**アクティブなオブジェクト**（最後に選択したもの）のデータを表示するビューポートです。位置、名前、マテリアル、ライトの色、メッシュのモディファイアーなどがあります。**タブ**に分かれていて、各タブには、値の行が並んだ**カード**があります。ここで変えたことは、ほとんどすぐに3D Viewportに反映されます。

[ビューポート](viewports.md#アクティブなビューポート)で説明したとおり、キーの入力は、緑の枠があるアクティブなビューポートが受け取ります。

![Nokia](img/icono-nokia.svg) Nokia N95では、Propertiesは3D Viewportの右にあります。**緑キー** ![](img/tecla-verde.svg) でアクティブなビューポートにします。戻ってきたときは、前にいた行のままです。

## タブ

タブは、Propertiesのメニューバーにあるアイコンです。それぞれのタブに、カードのグループが表示されます。

タブは**アクティブなオブジェクトによって変わります**。オブジェクトの種類ごとに、必要なタブだけが表示されます。メッシュにはMaterial、3D Mesh、Modifiersがあります。ライトではマテリアルの場所にLightタブがあり、カメラではCameraタブがあります。

| タブ | 表示されるとき |
|---|---|
| File / Render（フロッピーディスク） | いつも。何も選択していなくても表示されます。 |
| Object | どの3Dオブジェクトでも：位置、回転、スケール、名前、表示。 |
| オブジェクトの種類のタブ | メッシュではMaterial、ライトではLight、カメラではCamera、というように種類ごとに変わります。アイコンも種類によって変わります。 |
| 3D MeshとModifiers | メッシュのときだけ。 |
| Transform | Edit Modeのメッシュのときだけ。 |
| Constraints | どの3Dオブジェクトでも。 |
| Scripts | どのオブジェクトでも。 |
| Animation | いつも。 |

種類のタブは同じ位置にあります。メッシュのマテリアルを見ているときにライトを選ぶと、Lightタブに移ります。見ていたタブが新しいオブジェクトにない場合（ライトを選んだときのModifiersなど）は、PropertiesはObjectタブに戻ります。

![立方体を選択すると、Propertiesにはメッシュのタブが表示され、マテリアルのタブが開いています。ライトを選ぶとタブが変わり、マテリアルのタブがライトのタブになります。カメラを選ぶと、カメラのタブになります](img/propiedades-pestanas.webp)

| | タブの切り替え方 |
|---|---|
| ![PC](img/icono-pc.svg) PC | タブを1回クリックします。全部が入りきらないときは、バーの上でホイールを回します。 |
| ![Android](img/icono-android.svg) タッチスクリーン | タブを1回タップします。全部が入りきらないときは、バーを横にドラッグします。 |
| ![Nokia](img/icono-nokia.svg) Nokia N95 | **上**の方向キーで最初のカードのタイトルまで上がり、もう1回押します。今のタブが緑になります。**左**と**右**でタブを切り替え、**下**でカードに戻ります。最初のタブでは、左で隅のボタンのメニューが開きます。 |

## カード

**カード**は、各タブの中にある枠で、タイトルと行でできています。タイトルの矢印で、カードが開いているか折りたたまれているかがわかります。使わないカードを折りたたんでおくと、使うカードが扱いやすくなります。

![立方体のObjectタブで、Transformカードをタイトルで折りたたむと、下のカードが上がってきます。もう一度タイトルを押すと展開します](img/propiedades-tarjetas.webp)

| | 折りたたみと展開のしかた |
|---|---|
| ![PC](img/icono-pc.svg) PC | タイトルを1回クリックします。 |
| ![Android](img/icono-android.svg) タッチスクリーン | タイトルを1回タップします。 |
| ![Nokia](img/icono-nokia.svg) Nokia N95 | タイトルの上で<kbd>OK</kbd>。**左**の方向キーで、カードのどの行からでもカードを折りたたみ、タイトルの上で**右**を押すと展開します。 |

カードがビューポートに入りきらないときは、パネルをスクロールします。PCではマウスのホイールで、タッチスクリーンでは指を上下にドラッグします。Nokiaでは、パネルが選んだ行に自動でついていきます。

### キーで移動する

![Nokia](img/icono-nokia.svg) Nokia N95には**選択中の行**があります。名前が緑で、値が白い枠で表示されます。**上**と**下**で行から行へ、カードから次のカードへ移り、<kbd>OK</kbd>でその行を使います。数値を編集する、チェックボックスをオンにする、ドロップダウンを開く、などです。編集中は枠が緑になります。

![PC](img/icono-pc.svg) PCでは、マウスをPropertiesの上に置くと、矢印キーと<kbd>Enter</kbd>で同じことができ、<kbd>Esc</kbd>で編集中の内容をキャンセルします。

## 数値

ほとんどの行は**数値**です。左に名前、右に値があります。TransformカードのLocation、Rotation、Scaleなどです。数値は**入力**することも、**ドラッグ**することもできます。数値ごとに変化の速さがあり、上限があるものもあります。ライトのGL Lightは0から7までです。

### 数値を入力する

![PC](img/icono-pc.svg) マウスを動かさずに数値を1回クリックします。値が選択された状態になり、入力した内容で置き換わります。<kbd>Enter</kbd>で適用し、<kbd>Esc</kbd>で元のままにします。ほかの場所をクリックしても適用されます。

![立方体のLocation Xをクリックすると値が選択されます。2と入力してEnterを押すと、立方体がXの2メートルの位置に移ります](img/propiedades-numero-raton.webp)

![Android](img/icono-android.svg) 数値を1回タップすると、下にWhisk3Dの**テンキー**が開き、行の名前と値が表示されます。数字、小数点、削除用の**DEL**、カーソルを動かす矢印があります。**OK**で値を適用し、**X**でキャンセルします。テンキーの外をタップしても適用されます。

![Android](img/icono-android.svg) テンキーでは**計算**もできます。<kbd>+</kbd>、<kbd>-</kbd>、<kbd>\*</kbd>、<kbd>/</kbd>とかっこを使って`2*3`や`1.5+0.25`のように入力し、OKをタップすると、その結果が入ります。<kbd>-</kbd>は負の数を入力するのにも使います。

![立方体のLocation Xをタップすると、下にテンキーが開きます。2*3と入力してOKを押すと値が6になり、立方体が移動します](img/propiedades-numero-dedo.webp)

![Nokia](img/icono-nokia.svg) 方向キーでその行まで行き、<kbd>OK</kbd>を押します。値が選択された状態になり、電話のキーで数字を入力できます（Propertiesのバーに**123**と表示されます）。最初に入力した数字で、元の値が置き換わります。<kbd>\*</kbd>が小数点で、<kbd>C</kbd>で削除し、**左**と**右**でカーソルを動かし、<kbd>OK</kbd>で適用し、**左ソフトキー**でキャンセルします。

![Nokia N95。緑キーでPropertiesに移り、下の方向キーでLocation Xまで行き、OKで値が選択されます。2と入力してOKを押すと、立方体が移動します](img/propiedades-nokia.webp)

### 数値をドラッグする

![PC](img/icono-pc.svg) 数値の上でクリックしたまま、マウスを横に動かします。右に動かすと値が上がり、左に動かすと下がります。ポインターがビューポートの端に着くと反対側から現れるので、そのままドラッグを続けられます。離すと、その値になります。

![Location Xの上でクリックしたまま、マウスを右と左に動かすと、数値に合わせて立方体が動きます](img/propiedades-arrastrar-raton.webp)

![Android](img/icono-android.svg) 指を数値の上（名前の上ではなく）に置いて、横にドラッグします。上下にドラッグすると、値は変わらずにパネルがスクロールします。

![Location Xの上に置いた指を右と左にドラッグすると、数値に合わせて立方体が動きます](img/propiedades-arrastrar-dedo.webp)

## ドロップダウン

**ドロップダウン**は、選ばれているオプションを表示するボタンです。ライトの**Type**（Point、Sun、Spot）や、回転の**Mode**などがあります。操作するとオプションの一覧が開き、今のオプションが緑で表示されます。別のものを選ぶと、一覧が閉じます。

![ライトを選択した状態で、LightカードのTypeのドロップダウンを開くと、Pointが緑で表示されています。そこでSunを選びます](img/propiedades-desplegable.webp)

| | 開き方と選び方 |
|---|---|
| ![PC](img/icono-pc.svg) PC | ボタンをクリックし、オプションをクリックします。 |
| ![Android](img/icono-android.svg) タッチスクリーン | ボタンをタップし、オプションをタップします。 |
| ![Nokia](img/icono-nokia.svg) Nokia N95 | <kbd>OK</kbd>で開き、**上**と**下**でオプションを移動し、<kbd>OK</kbd>で選びます。<kbd>C</kbd>で何も変えずに閉じます。 |

## チェックボックス

**チェックボックス**はオンとオフを切り替えます。チェックが入っていればオン、空ならオフです。行の右側にあり、たとえばマテリアルの**Lighting**です。オフにすると、オブジェクトはライトの影響を受けず、自分の色のまま平らに見えます。行（チェックボックスか名前）をクリックまたはタップすると切り替わり、Nokiaでは<kbd>OK</kbd>で切り替えます。

![立方体のマテリアルでLightingをオフにすると、立方体はライトなしで白く平らに見えます。もう一度オンにすると、また照らされて見えます](img/propiedades-casilla.webp)

## テキスト

**テキストフィールド**には、名前やパスが入ります。たとえば、Transformカードのいちばん下にあるオブジェクトの**Name**です。操作すると、テキストの最後にカーソルが表示されます。新しい名前はOutlinerにも表示されます。

![立方体のNameを編集します。消してBoxと入力し、確定すると、Outlinerに新しい名前が表示されます](img/propiedades-texto.webp)

- ![PC](img/icono-pc.svg) **PCでは：** フィールドをクリックして入力します。<kbd>Enter</kbd>（またはほかの場所をクリック）で確定し、<kbd>Esc</kbd>で前のテキストに戻ります。
- ![Android](img/icono-android.svg) **タッチスクリーンでは：** タップすると、ñも入力できるWhisk3Dのキーボードが開きます。**Aa**で大文字に、**123**で数字と記号に切り替わり、**DEL**で削除し、**OK**で確定します。Web版では電話のキーボードが開きます。
- ![Nokia](img/icono-nokia.svg) **Nokia N95では：** <kbd>OK</kbd>を押し、メッセージを書くときと同じように電話のキーで入力します。各キーを何回か押すと、そのキーの文字が順に出ます。<kbd>#</kbd>でAbc、abc、ABCが切り替わり、長押しで123になります（Propertiesのバーにモードが表示されます）。<kbd>0</kbd>がスペース、<kbd>1</kbd>が句読点で、<kbd>\*</kbd>でほかの記号が開きます。<kbd>C</kbd>で削除し、**左**と**右**でカーソルを動かし、<kbd>OK</kbd>で確定し、**左ソフトキー**でキャンセルします。

## 色

**色**の行には、右側に色の小さな四角が表示されます。ライトのカードの**Diffuse**、**Ambient**、**Specular**などです。操作すると**カラーピッカー**が開きます。

- **円**で色相と彩度を、その横のバーで明度（どれだけ明るいか）を選びます。
- **RGB**、**HSV**、**Hex**のタブで、色を数値で表示します。RGBではRed、Green、Blue、HSVではHue、Saturation、Value、Hexでは16進数のコード（`#FF8800`）で、CopyとPasteもあります。
- **Alpha**は透明度です。
- **OK**でその色に決まり、**Cancel**で前の色に戻ります。

色は動かしている間も変わるので、確定する前にシーンで確かめられます。ピッカーの外をクリックまたはタップしても、その色のまま閉じます。

![ライトを選択した状態でDiffuseをクリックすると、カラーピッカーが開きます。色の円、明度のバー、RGB、HSV、Hexのモードがあります](img/propiedades-color.webp)

![PC](img/icono-pc.svg) ![Android](img/icono-android.svg) マウスでも指でも、円やバーの中でドラッグします。数値は、Propertiesと同じように横にドラッグします。

![Nokia](img/icono-nokia.svg) Nokia N95では、**上**と**下**で、円、バー、タブ、数値の行、OK / Cancelを順に移動します。数値の行では、**左**と**右**で値を変えます（押し続けると、だんだん速くなります）。円の上で<kbd>OK</kbd>を押すと編集に入り、**左**と**右**で色相を回し、**上**と**下**で彩度を変え、<kbd>OK</kbd>で抜けます。バーも同じように、上と下で編集します。<kbd>C</kbd>でピッカーを閉じ、前の色に戻ります。

## リスト

カードによっては**リスト**があります。メッシュのモディファイアー、パーツ、UVマップなどです。選んだ項目が強調され、その下にあるものが、その項目のデータを表示したり、その項目に対して働いたりします。リストの下には**ボタン**の行があります。

**Move Up**と**Move Down**で、選んだ項目の位置を変えます。順番には意味があります。モディファイアーは上から順に適用され、メッシュのパーツはその順に描画されます。この2つのボタンは、リストに2つ以上の項目があるときに表示されます。

![モディファイアーが2つある立方体のModifiersタブ。選んだ項目はリストの下にあり、Move Upで上に移ります](img/propiedades-lista.webp)

| | リストの使い方 |
|---|---|
| ![PC](img/icono-pc.svg) PC | クリックで選びます。全部が入りきらないときは、リストの上でホイールを回します。 |
| ![Android](img/icono-android.svg) タッチスクリーン | タップで選びます。全部が入りきらないときは、リストの上で指を上下にドラッグします。 |
| ![Nokia](img/icono-nokia.svg) Nokia N95 | リストの上で<kbd>OK</kbd>を押し、**上**と**下**で選び、<kbd>OK</kbd>で抜けます。ボタンの行では、**左**と**右**でボタンからボタンへ移り（枠でどれかがわかります）、<kbd>OK</kbd>で押します。 |

## ひし形：プロパティをアニメーションする

アニメーションできるプロパティの右側には**ひし形**があります。ひし形がないプロパティは、アニメーションできません。ひし形をクリックまたはタップすると**キーフレーム**が入ります。そのプロパティの値を、Timelineの現在のフレームに保存します。いくつかのフレームにキーフレームがあると、アニメーションを再生したときにプロパティが自動で変わります。

ひし形の色で、**現在のフレームでの**プロパティの状態がわかります。

| ひし形 | 意味 | クリックすると |
|---|---|---|
| 灰色 | プロパティはアニメーションされていません。 | 今の値で、最初のキーフレームを入れます。 |
| 薄い緑 | アニメーションされていますが、このフレームにはキーフレームがありません。 | 今の値でキーフレームを入れます。 |
| 緑 | このフレームにキーフレームがあります。 | キーフレームを削除します。 |

値を変えても、ひし形の色は変わりません。新しい値はキーフレームを入れるまでアニメーションに残らず、その前にフレームを変えると、プロパティはアニメーションの値に戻ります。すでにキーフレームがあるフレーム（緑のひし形）で新しい値を保存するには、2回クリックします。1回目でキーフレームが削除され、2回目で今の値のキーフレームがまた入ります。

![立方体のLocation X。ひし形は灰色で、クリックすると緑になります。Timelineの別のフレームでは薄い緑になります。値を変えてもひし形は薄いままで、クリックすると緑になります](img/propiedades-rombo.webp)

![Nokia](img/icono-nokia.svg) Nokia N95では、その行にいる状態で**右**の方向キーを押すとひし形に移り（白い枠で示されます）、<kbd>OK</kbd>でキーフレームを入れたり削除したりし、**左**で値に戻ります。

Animationタブの**Active Camera**カードでは、アニメーションの各瞬間にどのカメラを使うかを選びます。シーンのカットです。このひし形にはもう1つ色があり、**さらに明るい緑**は、選んだカメラがこのフレームでアニメーションが示すカメラと違う、つまりまだ保存されていない変更があることを表します。クリックすると、現在のフレームにカットを保存します。

アニメーションについては、あとで専用のチュートリアルがあります。

すべてのタブとカードは、マニュアルの[Properties](propiedades.md)にあります。[ビューポート](viewports.md)に戻る。

## 各タブの内容

| タブ | 内容 |
|---|---|
| File / Render（フロッピーディスク） | **File**：Open project、Save、Save As、Save version、Extract assets。**Render**：出力先、サイズ、追加のレンダーパス、背景、**Ray Tracing**（レイ数、サンプル数、パス数）、Render ImageとRender Animation。**Game**：プラットフォーム（Windows、Symbian、Linux .deb、AppImage、WebGL、Android、Android 2.3）、ウィンドウ、画面の向き、アイコン、物理、サウンド、音量、**Resolution**（ゲームが描画する画面の割合。Android 2.3ではシステムが引き伸ばすので、そうした電話では描画するピクセルを減らすとフレーム数が増えます）、Build game（adbで電話をつないでいると、インストールして起動します）。**Export**：OBJ、glTF、GLB、STL（三角形だけで、3Dプリント用やCADのプログラムに渡すためのもの）。**Settings**：言語、アンチエイリアス、グラフィックス、スキン、ログ、スケール、**Keyboard Shortcuts...**、Save Changes。 |
| Object | 位置、回転（オイラー角、クォータニオン、軸と角度）、スケール、名前、表示、レンダリング。オブジェクトのアニメーションとパレット。 |
| Contextual | 種類によって変わります：メッシュのパーツと**マテリアル**（テクスチャ、ライティング、頂点カラー、透明、反射、ノーマルマップ、ブレンド、深度、テクスチャレイヤー、**Advanced: custom shader**（[自作シェーダー](../editor/shaders.md)を参照）。レイトレーシングではRoughness、Metallic、Transmission、IOR）、ライト、カメラ、フォグ、パーティクル、物理、ヒットボックス、アーマチュアとボーン、2D要素、プレハブ、ルーチン。 |
| 3D Mesh | 使用しているメッシュ（と、それを共有している数）、UVマップ、カラーレイヤー、頂点グループ、UVグループ。Libraryでリソースを選んでいる場合は、そのデータと場所（.w3dの中か外か）。 |
| Modifiers | [Modifiers](../editor/objeto-malla.md#modifiersタブ)を参照してください。 |
| Transform | Edit Modeのみ：選択範囲とそのUVの中心を表示し、編集できます。 |
| Armature 2D | メッシュの2Dアーマチュアと2Dボーン。 |
| Constraints | Copy Location、Copy Rotation、Billboard（カメラの方を向く）、Child Of。 |
| Scripts | オブジェクトのLuaスクリプトとそのプロパティ（[Luaのドキュメント](../lua/README.md)を参照）。 |
| Animation | アクティブなアニメーション、ブレンドレイヤー（Mix）、選択したキーフレームの正確な値、カメラのカット。 |

## ルーチン

ルーチンは、Propertiesで組み立てる描画ステップのリストです（移動、回転、テクスチャの設定、メッシュの描画、別のルーチンの呼び出し、Call Lua…）。N95でいちばん高速に描画できる方法です。

| 機能 | 説明 | ショートカット |
|---|---|---|
| Add / Remove（ステップ） | テーマ別にまとめられたステップを追加する、または選択したステップを削除します。 | ボタン。<kbd>X</kbd>または<kbd>Delete</kbd>で削除 |
| Grab step | 方向キーでステップを並べ替えます。<kbd>Enter</kbd>で確定します。 | <kbd>G</kbd> |
| Insert Keyframe | ステップの値を、現在のフレームでアニメーションに記録します。 | <kbd>I</kbd> |
| Repeat | リストを続けて何回実行するか（Routine loop）。1 = 通常のルーチン。 | Repeatフィールド |
| Render mode / Use | シェーディングモードごとに別のリストを使う、またはすべてで同じリストを使います。 | ドロップダウン |
