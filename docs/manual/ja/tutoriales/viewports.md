# ビューポート

> [!NOTE]
> Nokia N95はマウスとキーボード（Bluetooth）に対応しています。このチュートリアルのNokiaの説明は、マウスやキーボードを使わずに、電話のキーだけで操作する方法です。

Whisk3Dのウィンドウは**ビューポート**に分かれています。ビューポートはパネルで、それぞれにエディター（3D Viewport、Outliner、Properties…）が入っています。ビューポートは分割したり、サイズを変えたり、それぞれに何を表示するかを選んだりできます。マウスでも、タッチスクリーンで指を使っても、Nokiaのキーパッドでも、同じように操作できます。

これは、プログラムを初めて起動したときの画面です。

![起動直後の Whisk3D：立方体、カメラ、ライトがある 3D Viewport、右に Outliner と Properties、下に Timeline](img/inicio.webp)

## アクティブなビューポート

マウスの下にあるビューポートが**アクティブなビューポート**で、緑の枠で示されます。キーボードのコマンドやコントローラー、そのほかの周辺機器の入力は、このビューポートが受け取ります。マウスをビューポートからビューポートへ動かすと、緑の枠がついてきます。

![マウスポインターが3D Viewport、Outliner、Properties、Timelineの上を通り、そのたびに下にあるビューポートが緑の枠で示されます](img/viewports-activo.webp)

**Nokia N95では：** 緑の**通話キー** ![](img/tecla-verde.svg) を1回押すごとに、次のビューポートに移ります。N95の画面には、左に3D Viewport、右にPropertiesの2つが入ります。

![左に3D Viewport、右にPropertiesがあるNokia N95。緑キーを押すたびに、緑の枠がもう一方のビューポートに移ります](img/viewports-activo-nokia.webp)

## メニューバーと隅のボタン

どのビューポートにも、上部に**メニューバー**（画像の緑の部分）があり、そのエディターのメニューとボタンが並んでいます。左上にはいつも**隅のボタン**（オレンジの部分）があります。ビューポートを切り替えたり変更したりするボタンです。

![Whisk3Dの4つのビューポート。それぞれのメニューバーが緑で、隅のボタンがオレンジで強調されています](img/viewports-barras.webp)

## サイズを変える

隅のボタンを（指またはマウスで）**押したまま**ドラッグすると、サイズを変えられます。そのビューポートの左端と上端が動き、隣のビューポートもそれに合わせて変わります。ドラッグせずに**1回タップ**すると、ビューポートのオプションが入ったドロップダウンメニューが開きます。この例では、右下のビューポートのボタンを円を描くようにドラッグしていて、3つのビューポートのサイズが変わります。

![指で右下のビューポートの隅のボタンを円を描くようにドラッグすると、3つのビューポートのサイズが変わります](img/viewports-arrastrar.webp)

**Nokiaでは：** 緑の**通話キー** ![](img/tecla-verde.svg) を押したまま、方向キーを押します。アクティブなビューポート（緑の枠があるもの）の境界がその方向に動き、ビューポートが大きく、または小さくなります。方向キーを使わずに緑キーだけを押すと、次のビューポートに移ります。

![緑キーを押したままのNokia N95。右の方向キーで3D Viewportが大きくなり、左の方向キーで小さくなって、元の大きさに戻ります](img/viewports-tamano-nokia.webp)

## ビューポートのオプション

隅のボタンをタップすると、このメニューが開きます。

![指が3D Viewportの隅のボタンまで動いてタップすると、メニューが開きます。上にビューポートの種類があり、線の下にExpand、Split in Columns、Split in Rows、Maximizeがあります](img/viewports-menu.webp)

上にあるのは**ビューポートの種類**です。1つ選ぶと、ビューポートがそのエディターに変わります。線の下には、ビューポートに対してできる操作があります。

| オプション | 内容 |
|---|---|
| Expand | ビューポートが隣のビューポートの場所も使うようになり、隣のビューポートは閉じます（隣が分割されている場合は、そのグループ全体が閉じます）。 |
| Split in Columns | 左右に並ぶ2つに分けます。 |
| Split in Rows | 上下に並ぶ2つに分けます。 |
| Maximize | ウィンドウ全体に拡大します。最大化している間、メニューには**Minimize**しかありません。これを選ぶと元の位置に戻ります。 |

## バーが収まらないとき

ビューポートの幅が狭いと、バー全体が収まりません。3D Viewportの下にあるツールバーも同じです。残りの部分を見るには：

- **指で**：バーを横にドラッグします。
- **マウスで**：バーの上でクリックしたままドラッグするか、バーの上で**ホイール**を回します。
- **キーボードで**：PCでは<kbd>M</kbd>、Nokiaでは**左ソフトキー**で、アクティブなビューポートのバーに入ります。左右の矢印キーでバーの上を移動し、各メニューはそこに来ると開きます。上下の矢印キーでメニューの中を移動し、OK（PCでは<kbd>Enter</kbd>）で選びます。バーは、今いる場所が見えるように自動でスクロールします。

![指でOutlinerのバーを横にドラッグすると、収まっていなかったボタンが現れます](img/viewports-barra-dedo.webp)

![Outlinerのバーの上にあるマウスポインター。ホイールを回すとバーがスクロールします](img/viewports-barra-rueda.webp)

Nokia N95では、左ソフトキーでバーに入り、方向キーでバーの上を移動します。

![Nokia N95のインターフェース。左ソフトキーでモードのメニューが開き、右の方向キーでバーのメニューを順に移動します。バーは自動でスクロールします](img/viewports-barra-nokia.webp)

## ビューポートの種類

| ビューポート | 用途 |
|---|---|
| [3D Viewport](../editor/vista-3d.md) | シーンを表示して編集する場所です。モデリング、オブジェクトの移動、ペイント、ポーズ付け、アニメーションを行います。 |
| [Outliner](../editor/outliner.md) | シーンにあるものすべての一覧です。 |
| [Library](../editor/outliner.md#libraryビュー) | プロジェクトのリソースです。メッシュ、マテリアル、テクスチャ、アニメーション、サウンド、スクリプトなどがあります。 |
| [Properties](../editor/propiedades.md) | アクティブなオブジェクトのデータを、タブに分けて表示します。 |
| [UV Editor](../editor/editor-uv.md) | テクスチャがメッシュにどう貼られるかを扱います。 |
| [Timeline](../editor/linea-de-tiempo.md) | アニメーションです。キーフレームとカーブを扱います。 |
| [2D Editor](../editor/editor-2d.md) | ゲームのインターフェース、HUD、2Dゲームを作ります。 |
| [Console](../editor/consola.md) | エンジンのログです。エラー、警告、情報が表示されます。 |
| [IDE](../editor/editor-de-scripts.md) | Luaスクリプトとシェーダーのエディターです。 |

それぞれのビューポートについて、今後もっと詳しいチュートリアルを用意します。それまでは、[Whisk3Dマニュアル](../editor/README.md)でそれぞれを説明しています。

Whisk3Dは今も成長しています。今後、新しいビューポートが加わったり、今あるビューポートが変わったりすることがあります。どれも同じように、上にバー、隅にボタンがある形で使えます。
