# ドアをアニメーションさせる

前のチュートリアル[ドアノブをモデリングする](modelar-picaporte.md)で作った、ドアノブ付きのドアから始めます。ドアの原点は蝶番にあり、レバーの原点はレバーが回る位置にあって、レバーはドアの子になっています。これを本物のドアのようにアニメーションさせます。まずドアノブが下がり、下がりきってから初めてドアが開き始め、最後にドアノブが元の位置に戻ります。

その途中で、次のことを学びます。

- **キーフレーム**を入れる。キーフレームとは、あるフレームでのオブジェクトのポーズです
- 思いどおりになっているキーフレームを**複製**する
- アニメーションの**タイミング**を調整し、**1秒あたりのフレーム数**を選ぶ
- **カーブエディター**を使う。カーブとは何か、クリックとツールバーでどう変えるか

## 1. ドアノブ

**キーフレーム**は、あるフレームでオブジェクトがどうなっているか（位置、回転、スケール）を保存します。キーフレームが2つあれば、その間のフレームはすべてプログラムが計算します。これがアニメーションです。

1. **レバー**をクリックして選択します。**Timeline**でフレーム**1**に移動します。ドアノブは上がった状態です。
2. マウスを3D Viewportの上に置いて<kbd>I</kbd>を押し、**Rotation Only**を選びます。Timelineのフレーム1にひし形が現れます。
3. フレーム**9**に移動し（Timelineの数字をクリック）、ドアノブを下げます：<kbd>R</kbd> <kbd>Y</kbd> `-34` <kbd>Enter</kbd>。前のチュートリアルで設定した原点を中心に回ります。
4. もう一度<kbd>I</kbd> → **Rotation Only**。フレーム9にもひし形が現れます。

![レバーをクリック。フレーム1でIとRotation Only。フレーム9でR Y -34でドアノブを下げ、IとRotation Only](img/animar-picaporte-raton.webp)

![Android](img/icono-android.svg) タッチスクリーンでは：キーフレームは、3D Viewportのメニューバーのひし形のボタンで入れます（**Animation → Insert Keyframe → Rotation Only**）。フレームはTimelineの数字をタップして変えます。ドアノブは、ツールバーの**Rotate** **Y** `-34`で下げます。数値は上のバーのテンキーで入力します。

![Nokia](img/icono-nokia.svg) Nokia N95では：<kbd>2</kbd>（回転）、<kbd>2</kbd>（Y軸）、鉛筆キー + `-34`、<kbd>OK</kbd>。キーフレームは**Animation → Insert Keyframe → Rotation Only**で入れます。

## 2. キーフレームを複製する

ドアが開く間はドアノブが下がったままで、最後に上に戻る必要があります。この2つのポーズはもうあるので、もう一度回す必要はありません。

1. Timelineでフレーム**9**のひし形（下がった状態）をクリックし、<kbd>Shift</kbd> + <kbd>D</kbd>を押して、コピーをフレーム**26**まで動かしてクリックします。9から26まで、ドアノブは下がったままになります。
2. フレーム**1**のひし形（上がった状態）をクリックし、<kbd>Shift</kbd> + <kbd>D</kbd>で、コピーを**33**に置きます。ドアノブが上に戻ります。

ポインターではなく、コピーのひし形を見てください。マウスの1フレーム右に出ます。コピーがほかのキーフレームの上を通っても何も起きません。ちょうどその上で離したときだけ、そのキーフレームを**置き換えます**。

![フレーム9のひし形を26に、1のひし形を33に複製します。Playで、ドアノブが下がり、下がったままになり、また戻ります](img/animar-duplicar-raton.webp)

![Android](img/icono-android.svg) ![Nokia](img/icono-nokia.svg) タッチスクリーンとN95（仮想マウスで）では、複製する代わりにコピーして貼り付けます。フレーム9のキーフレームをタップし、Timelineの**Key**メニュー（ひし形のボタン）で**Copy**を選びます。数字をタップしてフレーム26に移動し、**Key → Paste**を選びます。1から33も同じようにします。

## 3. ドア

1. **ドア**をクリックして、ドアだけを選択します。フレーム**11**に移動して、<kbd>I</kbd> → **Rotation Only**。ここまでドアは閉じています。ドアノブが下がりきったフレーム11から、初めて開き始めます。
2. フレーム**26**に移動してドアを開き（<kbd>R</kbd> <kbd>Z</kbd> `-80` <kbd>Enter</kbd>）、もう一度<kbd>I</kbd> → **Rotation Only**。

**Play**（<kbd>Space</kbd>、またはTimelineの▶ボタン）で再生します。ドアノブが下がり、ドアが開き、ドアノブが上に戻ります。その間、ドアノブはドアの子なので、ドアと一緒に動きます。

![ドアをクリック。フレーム11でIとRotation Only。26でR Z -80とI、Rotation Only。Playで、ドアノブが下がり、ドアが開き、ドアノブが戻ります](img/animar-puerta-raton.webp)

![Android](img/icono-android.svg) タッチスクリーンでは：**Rotate** **Z** `-80`と、**Animation → Insert Keyframe → Rotation Only**。

![Nokia](img/icono-nokia.svg) Nokia N95では：<kbd>2</kbd>、<kbd>3</kbd>（Z軸）、鉛筆キー + `-80`、<kbd>OK</kbd>。そして**Animation → Insert Keyframe → Rotation Only**。

## 4. タイミング

動きが速すぎたり、遅すぎたりしますか？ その場合はキーフレームを動かします。

- <kbd>G</kbd>で、選択したキーフレームを時間の方向に動かします（たとえば、ドアノブが戻るキーフレームを33から36に）。
- <kbd>S</kbd>で拡大縮小します。すべてを選択して`2`にすると、アニメーションの長さが2倍になります。

アニメーションはフレーム**50**で終わるようにします。Timelineの**時計**で、**End**に`50`と入力して<kbd>Enter</kbd>を押します。

### 1秒あたりのフレーム数

アニメーションの時間は**フレーム**で数えます。1秒に何フレーム入るかは**FPS**（*frames per second*：1秒あたりのフレーム数）で決まります。FPSは同じ**時計**の**FPS**で変えます。FPSはアニメーションごとに設定でき、シーンのアニメーションとそれぞれのクリップを別々のFPSにできます。

Whisk3Dの最初の設定は**30**です。ドアの50フレームは、1.5秒より少し長くなります。

![Timelineの時計を開いたところ。Frame、Start、End、FPSがあり、FPSが強調されています](img/animar-reloj.webp)

| FPS | 用途 |
|---|---|
| **24** | 映画。アニメーションがより映画らしい雰囲気になります。レンダーする場合は、フレーム数もずっと少なくて済みます。1分は、24では1440フレーム、30では1800フレームです。 |
| **30**または**60** | テレビシリーズやゲーム。 |

60でアニメーションを作る必要はありません。ゲームでは、エンジンが間のフレームを自動で計算します。30で作ったアニメーションでも60の画面でなめらかに見え、メモリも少なくて済みます。

FPSはアニメーションを作る**前に**選びましょう。キーフレームは同じフレームにとどまるので、あとからFPSを上げるとアニメーションが速くなり、下げると遅くなります。

## 5. カーブ

Timelineを**カーブエディター**に切り替えます（**View → Curves**）。そこでは、アニメーションする値の1つ1つが**カーブ**になっていて、オブジェクトが各瞬間にどの位置、回転、スケールにあるかを表します。左右の方向が**時間**、上下の方向が**値**です。

**Rotation Only**は3つの軸を保存しますが、ドアノブもドアも1つの軸でしか回りません。ほかの2つのカーブは、何もしない平らな線です。これを削除します。その行を選択して<kbd>X</kbd>を押します。変化するカーブだけが残り、作業しやすくなります。

### カーブの形

カーブが**直線**なら、オブジェクトはいつも同じ速さで動きます。急に動き出し、急に止まります。**ロボットのような**感じです。ときにはそれが欲しいこともありますが、現実の世界でそのように動くものはほとんどありません。ものは動き出すときに**加速**し、着くときに**減速**します。

左から右へ**同じ時間**で動く、6つのボールを見てください。それぞれ別のカーブを使っています。各ボールの横にはそのカーブがあり、ボールと一緒に点が進みます。

![フレーム1から40まで動く6つのボール。それぞれの横にカーブの図があります。Linearはいつも同じ速さ。加速して減速するボールは、ゆっくり動き出してゆっくり着きます。加速して急に止まるボールは、全速力で着きます。速く飛び出すボールは、だんだん減速します。Bounceのボールは、着いて跳ね返り、止まります。Elasticのボールは、行きすぎて戻り、揺れてから止まります](img/animar-curvas.webp)

| カーブ | 動き方 | 用途 |
|---|---|---|
| **Linear** | いつも同じ速さ。 | 機械、ベルトコンベヤー、ロボットのような動き。 |
| **加速して減速**（Ease In and Out） | ゆっくり動き出し、途中は速く、ゆっくり着きます。 | ほとんどすべて：歩く人、ドア、カメラ。 |
| **加速して急停止**（Ease In） | ゆっくり動き出し、全速力で着きます。 | 落ちてぶつかるもの、止まる位置まで下がるドアノブ。 |
| **速く飛び出して減速**（Ease Out） | 全速力で動き出し、少しずつ減速します。 | 投げたもの、ひとりでに閉まる引き出し。 |
| **Bounce** | 着いてから、終点で何回か跳ね返って止まります。 | 落ちて弾むもの、閉まるふた。 |
| **Elastic** | 行きすぎて戻り、ばねのように揺れてから止まります。 | ばね、アンテナ、画面に軽やかに現れるもの。 |

カーブを使うと、アニメーションが**自然に**見えます。

### ツールバー

キーフレームまたは区間を選択していると、Timelineのツールバーで、1クリックでそのカーブを変えられます。

- **Interpolation Mode：** **Constant**、**Linear**、**Bezier**。次に計算で作るカーブが、なめらかなものから急なものの順に並び（**Sinusoidal**、**Quadratic**、**Cubic**、**Quartic**、**Quintic**、**Exponential**、**Circular**）、最後に効果のあるカーブ（**Back (overshoot)**、**Bounce**、**Elastic**）があります。
- **Handle Type：** **Bezier**カーブのハンドルの形を決めます。
- **Easing Type：** 計算で作るカーブで、効果をどこにかけるか：**Automatic**、**Ease In**、**Ease Out**、**Ease In and Out**。

キーボードでは、<kbd>E</kbd>で**Interpolation Mode**が、<kbd>Ctrl</kbd> + <kbd>E</kbd>で**Easing Type**が開きます。

![マウスをTimelineのツールバーの各ボタンの上に動かすと、その名前が表示されます](img/animar-barra-curvas.webp)

### ドアノブ：ガチャン！

本物のドアノブは、下げると勢いがついて、止まる位置でガチャン！と急に止まります。手を離すと、ばねで上がり、上でまた急に止まります。どちらも**加速して急停止**です。

1. **レバー**を選択した状態で、カーブエディターで、残ったカーブの行をクリックします。Timelineにそのカーブ全体が収まります。
2. フレーム1から9の間の、カーブが下がる区間をクリックします。線をクリックすると、その区間が選択されます。
3. ツールバーで**Quadratic**を選びます。Easing Typeが**Automatic**のときは**Ease In**になり、加速して急停止します。
4. 26から33の間の、戻る区間も同じようにします。

![カーブエディターのレバー。動かない行をXで削除し、残った行をクリックして画面に収めます。下がる区間をクリックしてQuadratic、戻る区間をクリックしてQuadratic。Playで、ドアノブが加速して急に止まります](img/animar-picaporte-curva-raton.webp)

![Android](img/icono-android.svg) ![Nokia](img/icono-nokia.svg) タッチスクリーンとN95では：区間をタップ（または仮想マウスでクリック）し、**Quadratic**をタップします。ツールバーは同じです。

### ドア

ドアは、いつものカーブ**Bezier**のままでうまくいきます。**加速して減速**するカーブです。押すと勢いがつき、だんだん減速して開いた状態で止まります。何も変える必要はありません。

次のチュートリアル[ボールを弾ませる](pelota.md)では、カーブを使ってボールに重さを与えます。アニメーションのもう1つの原則、伸ばしとつぶしも一緒に使います。
