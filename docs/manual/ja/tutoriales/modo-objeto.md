# Object Mode

**Object Mode**では、オブジェクト全体を扱います。選択、移動、回転、拡大縮小、追加、削除をしたり、オブジェクトを別のオブジェクトの中に入れたりします。Whisk3Dを起動したときのモードで、3D Viewportの左上のボタンにそう表示されています。メッシュの形（頂点、辺、面）を変えるにはEdit Modeを使います。Edit Modeには専用のチュートリアルがあります。

## オブジェクトとは

シーンにあるものはすべて**オブジェクト**です。プロジェクトを始めたときにある立方体も、カメラも、ライトも、キャラクターもそうです。どのオブジェクトにも、次のものがあります。

- **名前**。Outlinerに表示されます。
- **トランスフォーム**。どこにあるか（位置）、どう回っているか（回転）、どの大きさか（スケール）です。
- **プロパティ**。種類によって違います。ライトには色と強さ、カメラにはレンズ、メッシュにはマテリアルがあります。

オブジェクトにはたくさんの種類がありますが、選択、移動、回転、拡大縮小のしかたはどれも同じです。

|---|---|---|
| **Cut** | 選択したものを、あとで貼り付けられるように保存して、シーンから取り除きます。 | <kbd>Ctrl</kbd> + <kbd>X</kbd> |
| **Copy** | 選択したものを子も含めてコピーし、あとで貼り付けられるように保存します。このシーンにも、別のプロジェクトにも、開いている別のWhisk3Dのウィンドウにも貼り付けられます。 | <kbd>Ctrl</kbd> + <kbd>C</kbd> |

## 移動、回転、拡大縮小

オブジェクトの基本操作は、**移動**、**回転**、**拡大縮小**の3つです。どれも、ギズモ、キーボード、またはタッチスクリーンではツールバーのコマンドで行えます。うまくいかなかったときは、**Undo**（PCでは<kbd>Ctrl</kbd> + <kbd>Z</kbd>）で元に戻せます。

### ギズモ

**ギズモ**は、選択したオブジェクトの上に表示される色付きの矢印です。色はそれぞれ軸を表します。**赤**がX、**緑**がY、**青**が上向きのZです。

ギズモには、操作ごとに1つずつ、3つのモードがあります。**ギズモをドラッグせずに1回クリックすると、次のモードに切り替わります**。MoveからRotateへ、RotateからScaleへ、ScaleからまたMoveへ、の順です。

![PC](img/icono-pc.svg) マウスでギズモを1回クリックすると、モードが切り替わります。

![Leonの上のギズモ。クリックするたびに、移動の矢印から回転の半円、拡大縮小の四角い先端に変わり、また矢印に戻ります](img/objeto-gizmo-modos-raton.webp)

![Android](img/icono-android.svg) ギズモを1回タップすると、モードが切り替わります。

![指でタップするたびに、ギズモが移動から回転、拡大縮小に変わり、また移動に戻ります](img/objeto-gizmo-modos-dedo.webp)

使うときは、ギズモの一部をつかんでドラッグします。離すと操作が確定します。

| モード | つかむところ | 動作 |
|---|---|---|
| Move | 矢印 | その軸の方向にだけ動かします。 |
| Move | 小さな四角 | 平面の上で動かします。青い四角では、高さを変えずにXとYの方向に動かします。 |
| Move | 中央の円 | ポインターについて自由に動かします。 |
| Rotate | 色付きの半円 | その軸のまわりに回します。 |
| Rotate | 白いリング | ビューに正対した向きで回します。 |
| Scale | 四角い先端 | その軸の方向に伸ばしたり縮めたりします。 |
| Scale | 中央の円 | 3つの軸すべてで均等に拡大・縮小します。 |

![PC](img/icono-pc.svg) マウスで：ギズモの一部をクリックしてドラッグします。

![赤い矢印でLeonが動いて戻ります。1回クリックするとギズモが回転に切り替わり、青い半円でLeonが回ります。もう1回クリックすると拡大縮小に切り替わり、青い先端でLeonが縦に伸び、Ctrl+Zで元に戻ります](img/objeto-gizmo-raton.webp)

![Android](img/icono-android.svg) 指で：ギズモの一部に指を置いてドラッグします。背景に指を置くと、ビューがオービットします。

![指で赤い矢印をドラッグすると、LeonがXの方向に動きます。次に、回転モードで青い半円をドラッグすると、Leonが回ります](img/objeto-gizmo-dedo.webp)

![Nokia](img/icono-nokia.svg) Nokia N95では、ギズモは最初はオフになっています。移動、回転、拡大縮小は、下で説明するようにキーで行います。Bluetoothのマウスで使いたい場合は、Overlays → Gizmoでオンにできます。

### キーボードやコマンドで

キーボードなら、何かにポインターを合わせる必要はありません。キーを押すと、確定するまでオブジェクトがマウス（電話では方向キー）についてきます。

| | 移動 | 回転 | 拡大縮小 | 1つの軸だけ | 確定 | キャンセル |
|---|---|---|---|---|---|---|
| ![PC](img/icono-pc.svg) PC | <kbd>G</kbd> | <kbd>R</kbd> | <kbd>S</kbd> | <kbd>X</kbd> / <kbd>Y</kbd> / <kbd>Z</kbd> | クリックまたは<kbd>Enter</kbd> | <kbd>Esc</kbd>または右クリック |
| ![Nokia](img/icono-nokia.svg) Nokia N95 | <kbd>1</kbd> | <kbd>2</kbd> | <kbd>3</kbd> | <kbd>1</kbd> / <kbd>2</kbd> / <kbd>3</kbd> | <kbd>OK</kbd>（方向キーの中央） | <kbd>C</kbd> |

![PC](img/icono-pc.svg) <kbd>G</kbd>を押してマウスを動かすと、オブジェクトがついてきます。<kbd>X</kbd>を押すとXの方向にだけ動き、もう一度<kbd>X</kbd>を押すとGlobalからLocalに切り替わります。回転も同じです。<kbd>R</kbd>のあとに<kbd>Z</kbd>を押すと、垂直なZ軸のまわりに回ります。軸を指定しないと、ビューに正対した向きで回ります。数値を入力することもできます。<kbd>G</kbd>、<kbd>X</kbd>、<kbd>2</kbd>、<kbd>Enter</kbd>で、Xの方向に2メートル動きます。

![GでLeonがマウスについてきて、Xで赤い軸に固定され、クリックでその位置に確定します。RとZでその軸のまわりに回り、Sで大きくなります。どれもクリックで確定します](img/objeto-teclas-raton.webp)

![Nokia](img/icono-nokia.svg) Nokia N95では：<kbd>1</kbd>で移動、<kbd>2</kbd>で回転、<kbd>3</kbd>で拡大縮小で、**方向キー**で動かします。操作中は、<kbd>1</kbd>、<kbd>2</kbd>、<kbd>3</kbd>は操作を切り替えるのではなく、X、Y、Z軸を選びます。たとえば、<kbd>2</kbd>のあとに<kbd>3</kbd>を押すと、垂直なZ軸のまわりに回ります。<kbd>OK</kbd>で確定し、<kbd>C</kbd>でキャンセルします。

![縦向きのNokia N95。1と方向キーでLeonが動き、2と3（Z軸）でその軸のまわりに回り、3で大きくなります。毎回OKで確定します](img/objeto-teclas-nokia.webp)

![Android](img/icono-android.svg) **タッチスクリーンでは**、キーボードがなくても、上で見たようにギズモを使うか、3D Viewportのツールバーの**コマンド**を使えます。**Move**、**Rotate**、**Scale**のどれかをタップし、ビューのどこかで指をドラッグすると、オブジェクトが指についてきます。ツールバーの表示が変わり、**緑のチェックマーク**で確定、**赤い×印**でキャンセルし、**X**、**Y**、**Z**のボタンで動きをその軸に固定します。

![ツールバーのMoveをタップし、ビューの上で指をドラッグすると、Leonがついてきます。緑のチェックマークをタップすると確定します](img/objeto-comandos-dedo.webp)

### 正確な数値で

正確に作業するには、動きを数値で入力します。ちょうど90°回す、`0.5`で半分の大きさにする、`2`でちょうど2倍の大きさにする、1.5メートル動かす、といった操作です。**Whisk3Dの1単位は1メートルです。**

操作中は、3D Viewportのメニューバーに、実行中の操作と値が表示されます。

![PC](img/icono-pc.svg) **キーボードで：** <kbd>G</kbd>、<kbd>R</kbd>、<kbd>S</kbd>のあとに数値を入力して、<kbd>Enter</kbd>を押します。<kbd>R</kbd> <kbd>Z</kbd> <kbd>9</kbd> <kbd>0</kbd> <kbd>Enter</kbd>で垂直な軸のまわりに90°回り、<kbd>S</kbd> <kbd>0</kbd> <kbd>.</kbd> <kbd>5</kbd> <kbd>Enter</kbd>で半分の大きさに、<kbd>S</kbd> <kbd>2</kbd> <kbd>Enter</kbd>で2倍になります。<kbd>G</kbd> <kbd>X</kbd> <kbd>1</kbd> <kbd>.</kbd> <kbd>5</kbd> <kbd>Enter</kbd>で、Xの方向に1.5メートル動きます。

![Android](img/icono-android.svg) **タッチスクリーンで：** ツールバーの**Move**、**Rotate**、**Scale**で操作を始め、値が表示されている上のバーをタップします。Whisk3Dのテンキーが開きます。数値を入力して**OK**をタップし、緑のチェックマークで確定します。テンキーでは`90/2`のような計算もできます。

![ツールバーのRotateをタップし、次にZをタップします。上のバーをタップするとテンキーが開き、90とOKを入力すると、Leonがちょうど90度回ります。緑のチェックマークで確定します](img/objeto-numero-dedo.webp)

Object Modeのショートカットはすべてマニュアルにあります：[移動・回転・拡大縮小](../editor/transformar.md)と[Object Mode](../editor/modo-objeto.md)。

## 移動、回転、拡大縮小の基準

### 原点

どのオブジェクトにも**原点**があります。ギズモが出ている点です。トランスフォームの基準になる点で、オブジェクトは原点のまわりに回り、原点を基準に大きくなったり小さくなったりします。Propertiesに表示される**位置**は、原点の位置です。

プリミティブでは、原点は中心にあります。インポートしたモデルでは、そのモデルを作ったプログラムが置いた場所にあります。Leonでは足元です。

![選択した立方体の原点を近くで見たところ。中心にある緑の点です](img/objeto-origen.webp)

### 3Dカーソル

**3Dカーソル**は、3D Viewportにある十字の付いた円です。最初はワールドの中心にあります。

![3Dカーソルを近くで見たところ。照準のような、4本の線が付いた緑の円です](img/objeto-cursor3d.webp)
 使い道は2つあります。

- **Add**で追加したものは、すべてそこに現れます。
- [ピボットポイント](#ピボットポイント)で説明するように、回転や拡大縮小の中心にもできます。

3Dカーソルは**Snap**メニューで動かします。このメニューでは、オブジェクトをカーソルの位置に移すこともできます。

| | Snapメニューの開き方 |
|---|---|
| ![PC](img/icono-pc.svg) PC | <kbd>Shift</kbd> + <kbd>S</kbd> |
| メニュー | Object → Snap（Edit Modeでは Mesh → Snap） |

| オプション | 内容 |
|---|---|
| Cursor to Selected | 3Dカーソルを、選択したものの中心に移します。Edit Modeでは、選択した頂点、辺、面の中心に移します。 |
| Cursor to Active | 3Dカーソルを、アクティブなオブジェクトの原点に移します。 |
| Cursor to World Origin | ワールドの中心に戻します。 |
| Cursor to Grid | いちばん近いグリッドの点に移します。 |
| Selection to Cursor | 選択したものを3Dカーソルの位置に移します。 |
| Selection to Cursor (Keep Offset) | 同じですが、複数のオブジェクトでは互いの距離を保ちます。グループがそのまま移動します。 |
| Selection to Active | 選択したものをアクティブなオブジェクトの位置に移します。 |
| Selection to Grid | 選択した各オブジェクトを、いちばん近いグリッドの点に合わせます。 |

たとえば、だれかの手に箱を持たせたいときや、あるオブジェクトを別のオブジェクトのちょうど同じ位置に置きたいときは、移動先のオブジェクトを選択して**Cursor to Selected**を選び、次に移したいオブジェクトを選択して**Selection to Cursor**を選びます。

![Leonを選択して、Shift+S、Cursor to Selectedを選ぶと、3Dカーソルが足元に移ります。次に箱を選択して、Shift+S、Selection to Cursorを選ぶと、箱がそこに現れます](img/objeto-cursor.webp)

### ピボットポイント

**ピボットポイント**は、選択したものを回転、拡大縮小するときの中心です。3D Viewportのバーで、**Global**の左にあるピボットのボタンで選びます（アイコンは選んだピボットによって変わります）。

| ピボット | 回転と拡大縮小の中心 |
|---|---|
| **Median Point** | 選択したもの全体の中心。最初はこれです。オブジェクトが1つだけなら、その原点です。 |
| **Active Element** | アクティブなオブジェクト（最後に選択したもの）の原点。ほかのオブジェクトはそのまわりを回ります。 |
| **Individual Origins** | 各オブジェクトがそれぞれの原点を中心にします。すべてが同時に、それぞれの場所で回ります。 |
| **3D Cursor** | 3Dカーソル。 |

**3D Cursor**を使うと、どんなものでも、どの点のまわりにでも回せます。（Snapメニューで）カーソルをその点に置いてから回します。テーブルのまわりに椅子を並べるときや、時計の針など、何かのまわりを回るものに便利です。

![1列に並んだ3つの箱を90°回します。Median Pointでは中心のまわりに一緒に回り、Individual Originsではそれぞれがその場で回り、3D Cursorでは横に置いたカーソルのまわりに回ります](img/objeto-pivote.webp)

### GlobalとLocal

1つの軸で移動、回転、拡大縮小するとき、その軸は**ワールド**の軸にも、**オブジェクト**の軸にもできます。3D Viewportのバーの**Global**のボタンで選びます。

| Orientation | 軸 |
|---|---|
| **Global** | ワールドの軸。いつも同じで、Zが上向きです。最初はこれです。 |
| **Local** | オブジェクト自身の軸。オブジェクトと一緒に回ります。 |
| **View** | 画面の軸。Xが横、Yが上です。 |
| **Normal** | Edit Modeで、選択した面が向いている方向です。 |

違いがわかるのは、オブジェクトが回っているときです。たとえば、40°回したLeonの場合、**Global**ではY軸はワールドの軸なので、Leonは向いている方向に対して斜めに動きます。**Local**ではY軸がLeonと一緒に回っているので、まっすぐ前に歩きます。角を曲がった車も同じで、前に進ませるにはLocalの軸で動かします。

![PC](img/icono-pc.svg) キーボードでは、軸のキーを2回押すとGlobalからLocalに切り替わります。<kbd>G</kbd> <kbd>Y</kbd>はワールドのYの方向に、<kbd>G</kbd> <kbd>Y</kbd> <kbd>Y</kbd>はオブジェクトのYの方向に動かします。Nokia N95では、移動中に<kbd>2</kbd> <kbd>2</kbd>で同じことができます。

![40°回したLeon。ギズモがGlobalのときは、矢印はワールドのグリッドに沿っています。Localでは矢印がLeonと一緒に回り、緑の矢印でLeonが向いている方向にまっすぐ進みます](img/objeto-local-global.webp)

### 原点を変える

3Dメッシュの原点は、**Object → Set Origin**で、メッシュを動かさずに別の場所に移せます。やり方は、蝶番を軸に開くドアを例にして、チュートリアル[原点を変える：ドア](puerta.md)で説明しています。

## プロパティ

アクティブなオブジェクトの**プロパティ**は、Propertiesビューポートにあります。**Object**タブ（立方体のタブ）は、どのオブジェクトでも同じです。上に**Transform**カードがあり、位置、回転、スケールが並んでいます。数値は手で入力できます。数値をクリック（またはタップ）して入力します。3D Viewportでオブジェクトを動かすとこの数値が変わり、数値を変えるとオブジェクトが動きます。

ほかのタブは、オブジェクトの種類によって変わります。ライトにはライトのタブがあり、メッシュにはマテリアルとモディファイアーのタブがあります。

### ひし形：アニメーションできるもの

多くのプロパティの横には**ひし形**があります。ひし形は、そのプロパティが**アニメーションできる**という意味です。ひし形をクリックすると、現在のフレームでの値が保存され（*キーフレーム*）、緑のひし形をもう一度クリックすると削除されます。キーフレームが複数あると、プロパティは時間とともに自動で変わります。

ひし形の色で、プロパティの状態がわかります。**灰色**はまだアニメーションされていない状態、明るい**緑**はアニメーションされていて、このフレームにキーフレームがある状態、**薄い緑**はアニメーションされているけれど、このフレームにはキーフレームがない状態です。

![Leonを選択したProperties。位置、回転、スケールのあるTransformカードと、右側の強調されたひし形の列](img/objeto-propiedades.webp)

アニメーションについては、あとで専用のチュートリアルがあります。

### スケールは1のままがよい

ひとつアドバイスです：**オブジェクトのスケールは1のままにしておきましょう**。Scaleでオブジェクトを大きくしたり小さくしたりするのは手軽ですが、拡大縮小したオブジェクトはあとで問題の原因になることがあります。子がスケールを受け継いで回転するとゆがんだり、物理や衝突、一部のモディファイアーの計算がおかしくなったりします。

オブジェクトを拡大縮小したら、**スケールを適用します**。今の大きさがそのオブジェクトの本当の大きさになり、見た目は変わらずにスケールが1に戻ります。

| | スケールの適用のしかた |
|---|---|
| ![PC](img/icono-pc.svg) PC | <kbd>Ctrl</kbd> + <kbd>A</kbd> → Scale |
| メニュー | Object → Apply → Scale |

![拡大縮小した箱。Propertiesではスケールが2と0.5になっています。Ctrl+A → Scaleでスケールが1に戻り、箱の見た目は変わりません](img/objeto-escala-raton.webp)

同じメニューの**Location**と**Rotation**は、位置と回転に同じことをします。**All Transforms**は3つすべてを適用します。

## Outliner：シーンのオブジェクト

**Outliner**は、シーンにあるすべてのオブジェクトの一覧です。行をクリック（またはタップ）すると、3D Viewportと同じようにそのオブジェクトが選択されます。PCでは右上にあります。

オブジェクトは**別のオブジェクトの中に**入れることができます。中に入ったオブジェクトは、少し右にずれて、外側のオブジェクトの下にぶら下がるように表示されます。外側が**親**、内側が**子**です。子は親の**トランスフォームを受け継ぎます**。親を移動、回転、拡大縮小すると、子も一緒に動きます。子は単独で動かすこともできますが、その動きはいつも親が基準です。

Leonがその例です。目に見える4つのパーツであるメッシュは、アーマチュア`leon_rig`の子です。アーマチュアを動かすと、Leon全体が動きます。

![leon_rigを展開したOutliner。中にleonからleon.003までの4つのメッシュがあり、右にずれて表示されています](img/objeto-outliner.webp)

オブジェクトを別のオブジェクトの中に入れることを、**ペアレント**（親子付け）と言います。

| | ペアレントのしかた |
|---|---|
| ![PC](img/icono-pc.svg) PC | Outlinerで、子の行をドラッグして、親の行の上で離します。または、子を選択し、次に親を（<kbd>Shift</kbd>を押しながら）選択して、<kbd>Ctrl</kbd> + <kbd>P</kbd>を押します。 |
| ![Android](img/icono-android.svg) タッチスクリーン | 子を選択します。ツールバーで**Shift**をオンにして親をタップし、そのあとObjectメニュー → Set Parentを選びます。 |
| ![Nokia](img/icono-nokia.svg) Nokia N95 | Outlinerがアクティブで、子を選択した状態で、<kbd>1</kbd>を押します。**右**の方向キーで上の行の中に入れ、**左**で外に出します。もう一度<kbd>1</kbd>を押すと確定します。 |
| メニュー | Object → Set Parent。外すには Object → Clear Parent |

![PC](img/icono-pc.svg) 動画では、Outlinerで箱を`leon_rig`までドラッグしています。箱はその子になり、Leonを動かすと箱も一緒に動きます。

![Outlinerで箱の行をleon_rigまでドラッグすると、その中に入ります。GでLeonを動かすと、箱も一緒に動きます](img/objeto-emparentar-raton.webp)

## オブジェクトの種類

オブジェクトはすべて**Add**メニューから追加します（3D Viewportのバーの**+**ボタン、またはPCでは<kbd>Shift</kbd> + <kbd>A</kbd>）。新しいものは3Dカーソルの位置に現れ、選択された状態になります。

![Addメニューが開き、すべての種類のオブジェクトが並んでいます](img/objeto-tipos.webp)

基本的なものは次のとおりです。

| オブジェクト | 内容 |
|---|---|
| [3Dメッシュ](../editor/objeto-malla.md) | 3Dモデルです。キャラクター、家、石など。頂点、辺、面でできていて、マテリアルとテクスチャで表示されます。Add → Meshのプリミティブ（立方体、球、円柱…）は、モデリングを始めるためのメッシュです。 |
| [カメラ](../editor/objeto-camara.md) | ゲームとレンダーの視点です。アクティブなカメラに映るものが、プレイしたときに見えるもので、画像や動画に出力されるものです。 |
| [ライト](../editor/objeto-luz.md) | シーンを照らします。種類は3つあります：Point（電球）、Sun（平行な光線の、昼の光）、Spot（懐中電灯のような円錐）。 |
| [アーマチュア](../editor/objeto-esqueleto.md) | メッシュを動かすボーンのつながりで、キャラクターのアニメーションに使います。Leonにもあり、アーマチュアが歩くとメッシュもついていきます。 |
| [サウンド](../editor/objeto-sonido.md) | シーンに置いたサウンドです。音楽のようにバックグラウンドで鳴らすことも、オブジェクトのある位置から鳴らすこともできます。 |
| エンプティ | 形のないオブジェクトで、シーンの中の1点です。ほかのオブジェクトをまとめる親や、基準点として使います。 |
| コレクション | Outlinerでオブジェクトを整理するためのフォルダーです。 |

ほかにも、パス、フォグ、パーティクル、衝突用のヒットボックス、ゲーム用の2Dインターフェース、最適化用のオブジェクトがあります。今後も、さらに多くの種類が追加されていきます。このチュートリアルではオブジェクト全般について説明しています。それぞれのオブジェクトには専用の記事があり、プロパティを1つずつ説明しています。

## すべてのオブジェクトにあるもの

トランスフォームとプロパティのほかに、どのオブジェクトにも次のものを付けられます。

- Luaの**スクリプト**。ゲームの中での動きを与えます。自分で動く、キーに反応する、衝突する、などです。あとで説明します。
- **アニメーション**。ひし形のあるプロパティは、どれもアニメーションできます。専用のチュートリアルがあります。
- **コンストレイント**。別のオブジェクトに結びつけるルールで、その位置をコピーする、いつもカメラの方を向く、などがあります。[コンストレイント](../editor/restricciones.md)で説明しています。

種類によっては、それ専用のものもあります。たとえば3Dメッシュには**モディファイアー**があり、形を壊さずに変えられます。鏡のように反転させる、繰り返す、なめらかにする、などです。[3Dメッシュ](../editor/objeto-malla.md)で説明しています。

## 3Dモデルをインポートする

Whisk3Dでモデリングするだけでなく、ほかのプログラムで作ったモデルを読み込むこともできます。読み込める形式は次のとおりです。

| 形式 | 読み込まれるもの |
|---|---|
| **GLB**と**glTF** | メッシュ、マテリアルとテクスチャ、アーマチュア、アニメーション。いちばん多くの情報を持つ形式で、Leonも.glbです。 |
| **OBJ** | メッシュ、マテリアルとテクスチャ（.mtlと一緒に）。アーマチュアとアニメーションはありません。 |
| **FBX** | メッシュ、マテリアル、アーマチュア、アニメーション。 |
| **STL** | 形だけです。三角形だけで、マテリアルも色もありません。3DプリントやCADのプログラムで使われる形式です。 |

**Add → Imports**で、形式を選んでからファイルを選んでインポートします。

![PC](img/icono-pc.svg) PCでは、フォルダーからファイルをドラッグして、3D Viewportの上にドロップすることもできます。

![Add → Imports → GLBを開き、leon.glbを選ぶと、Leonがシーンに現れ、Outlinerにアーマチュアとメッシュが表示されます](img/objeto-importar.webp)

アーマチュアのあるモデルは、**メッシュが中に入ったアーマチュア**として読み込まれます。[Outliner](#outlinerシーンのオブジェクト)で見たように、アーマチュアが親で、メッシュがその子です。アニメーションはアーマチュアに保存され、すぐに使えます。

モデルを別のプログラムや3Dプリンターに持っていくには、逆の手順を使います。Properties → フロッピーディスクのタブ → **Export**で、OBJ、glTF、GLB、STLに書き出せます。
