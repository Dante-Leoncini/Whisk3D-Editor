# ドアをモデリングする

初めての簡単なモデルを作りましょう。ドアです！ 始めるには、シーンに最初からある立方体が使えます。大きさは2 × 2 × 2メートルです。

私（Dante）は、空間を作るときによくドアを使います。建築を学んでいたときに身につけたことです。ドアの高さはほとんどの場合2メートルで、人の背は（ふつうは）ドアより低いものです。シーンにドアが1つあれば、ほかのすべてのものの大きさの目安がすぐにわかります。

## 床に置く

立方体は中心が床の高さにあるので、半分が床の下にあります。床の上に載るように、Z軸方向に1メートル上げます。立方体を選択した状態で：

![PC](img/icono-pc.svg) <kbd>G</kbd>を押すと、立方体がマウスについてきます。次に<kbd>Z</kbd>を押すと、Z軸に固定されます（青い線が表示されます）。`1`と入力して<kbd>Enter</kbd>を押します。

![Gで立方体がマウスについてきて、Zで垂直な軸の青い線の上に固定されます。1でちょうど1メートル上がり、Enterでそこに確定して、床の上に載ります](img/modelar-subir-raton.webp)

![Android](img/icono-android.svg) ツールバーの**Move**をタップし、次に**Z**をタップします。上のバーをタップしてテンキーを開き、`1`、**OK**とタップして、緑のチェックマークをタップします。

![ツールバーのMoveとZをタップします。上のバーをタップするとテンキーが開き、1とOKで立方体が上がり、チェックマークで確定します。下にMoveのパネルが表示され、タップで展開し、Acceptで閉じます](img/modelar-subir-dedo.webp)

![Nokia](img/icono-nokia.svg) <kbd>1</kbd>（移動）、<kbd>3</kbd>（Z軸）、**鉛筆キー**を押したまま<kbd>1</kbd>、そして<kbd>OK</kbd>です。

![Nokia N95。1で移動が始まり、3でZ軸に固定され、鉛筆キーと1で値を入力し、OKで確定します](img/modelar-subir-nokia.webp)

それぞれの機器での数値の入力方法は、[正確な数値で](modo-objeto.md#正確な数値で)で説明しています。

### 直前の操作を修正する

移動、回転、拡大縮小をすると、左下のツールバーの代わりに、小さなパネル**直前の操作を調整**が表示されます。折りたたまれているときは、何をしたか（たとえば**Move**）だけが表示されます。タイトルをタップまたはクリックすると展開します。

![展開したMoveのパネル。X 0、Y 0、Z 1メートル、OrientationはGlobal、Proportional Editingのチェックボックス、CancelとAcceptのボタンがあります](img/modelar-ficha.webp)

どの値も修正できます。1メートルではなく1.2メートルにしたかった場合は、Zをタップして`1.2`と入力すると、新しい値で操作がやり直されます。**Accept**でパネルが閉じてツールバーに戻り、**Cancel**で操作が取り消されます。

## 形を作る

ドアをモデリングする方法は2つあります。

### いちばん簡単だけど、おすすめしない方法：オブジェクトを拡大縮小する

Object Modeで、立方体をX軸とY軸の方向に、ドアの形になるまで拡大縮小します。たとえば、<kbd>S</kbd> <kbd>X</kbd> `0.45` <kbd>Enter</kbd>（幅90 cm）、<kbd>S</kbd> <kbd>Y</kbd> `0.05` <kbd>Enter</kbd>（厚さ10 cm）です。

おすすめしないのは、オブジェクトのスケールが軸ごとに違う値（0.45、0.05、1）になってしまうからです。理想は、3つの軸すべてでスケールが**1**であることです（[スケールは1のままがよい](modo-objeto.md#スケールは1のままがよい)を参照）。この方法で作った場合は、**必ずトランスフォームを適用してください**：<kbd>Ctrl</kbd> + <kbd>A</kbd> → **Scale**（またはObject → Apply → Scale）。形は変わらず、スケールが1に戻ります。

![Object Modeで、S X 0.45とS Y 0.05で立方体がドアの形になり、Propertiesには軸ごとに違うスケールが表示されます。Ctrl+AとScaleで適用すると、スケールが1に戻ります](img/modelar-escalar-raton.webp)

![Android](img/icono-android.svg) タッチスクリーンでは：**Scale**、**X**、上のバー、`0.45`、OKとタップし、**Y**と`0.05`でも同じようにします。そのあと**Object → Apply → Scale**を選びます。

![ツールバーとテンキーで、Xを0.45、Yを0.05に拡大縮小します。そのあとObject、Apply、Scaleで、スケールが1に戻ります](img/modelar-escalar-dedo.webp)

### おすすめの方法：Edit Mode

立方体を選択した状態で、Edit Modeに入ります。<kbd>Tab</kbd>を押すか、3D Viewportのモードのボタンで**Edit Mode**を選びます。入ると、すべての頂点が選択された状態になります。

Edit Modeでは、**頂点**、**辺**、**面**を選択します。これが基本です。そして、Object Modeと同じように、移動、回転、拡大縮小ができます（[Edit Mode](../editor/modo-edicion.md)を参照）。

すべてを選択した状態で、思いどおりのドアになるまで、XとYの方向に縮めます。Zは必要ありません。もう2メートルあるからです！ 変わるのはオブジェクトではなくメッシュなので、スケールは1のままです。

**目分量で、ギズモを使って：** ギズモの中心を1回クリック（またはタップ）するとRotateに、もう1回で**Scale**に切り替わります。赤い先端（X）をつかんで、好きな幅になるまで中心に向かってドラッグします。次に緑の先端（Y）を、ドアのように薄くなるまでドラッグします。

![Edit Modeで、ギズモの中心を2回クリックすると拡大縮小に切り替わります。赤い先端を中心に向かってドラッグすると立方体が細くなり、次に緑の先端をドラッグすると、ドアのように薄くなります](img/modelar-gizmo-raton.webp)

![指でも同じです。ギズモの中心を2回タップし、赤と緑の先端を中心に向かってドラッグします](img/modelar-gizmo-dedo.webp)

**数値で：** <kbd>S</kbd>、<kbd>X</kbd>、`0.45`、<kbd>Enter</kbd>、そして<kbd>S</kbd>、<kbd>Y</kbd>、`0.05`、<kbd>Enter</kbd>です。

![Tabで立方体がEdit Modeになり、すべてが緑になります。S、X、0.45、Enterで幅が狭くなり、S、Y、0.05、Enterで薄くなります。オブジェクトのスケールは1のままです](img/modelar-edicion-raton.webp)

![Android](img/icono-android.svg) タッチスクリーンでは：モードのボタン → **Edit Mode**。次に**Scale**、**X**、上のバーをタップ、`0.45`、**OK**、チェックマークとタップし、**Y**と`0.05`でも同じようにします。

![モードのボタンでEdit Modeに切り替えます。Scale、X、上のバー、0.45、OKで幅が狭くなり、Yと0.05でも同じようにします](img/modelar-edicion-dedo.webp)

![Nokia](img/icono-nokia.svg) Nokia N95では：<kbd>OK</kbd>でEdit Modeに切り替わります。<kbd>3</kbd>（拡大縮小）、<kbd>1</kbd>（X軸）、鉛筆キーを押したまま`0` <kbd>*</kbd> `45`（<kbd>*</kbd>が小数点です）、そして<kbd>OK</kbd>です。<kbd>2</kbd>（Y軸）と`0.05`でも同じようにします。

![Nokia N95。OKでEdit Modeに切り替わります。3と1でXの方向に拡大縮小し、鉛筆キーと0.45で値を入力し、OKで確定します。3、2、0.05でも同じようにします](img/modelar-edicion-nokia.webp)

## 正確な寸法で

目分量ではなく、たとえば幅がちょうど**90 cm**のドアにしたい場合は、**Vertex / Edge / Face**のボタンで**Face**を選び、側面の1つをクリックします。立方体の幅は2メートルなので、0.9メートルにするには余分な分を引く必要があります。その側面を**1.1メートル**動かせばよいわけです。<kbd>G</kbd> <kbd>X</kbd> `-1.1` <kbd>Enter</kbd>。

![Edit ModeでFaceを選び、右の側面をクリックしてそれだけを選択します。G、X、-1.1、Enterで動かすと、立方体の幅が0.9メートルになります](img/modelar-exacto-raton.webp)

![指で：選択のボタンでFace、側面をタップ、Move、X、上のバー、-1.1、OK。立方体の幅が0.9メートルになります](img/modelar-exacto-dedo.webp)

動かすときは、**X**で動きを1つの軸に固定して、立方体がゆがまないようにします。

- ![PC](img/icono-pc.svg) <kbd>X</kbd>キーで。
- ![Android](img/icono-android.svg) ツールバーの**X**をタップして。`-1.1`は、上のバーをタップして開くテンキーで入力します。
- ![Nokia](img/icono-nokia.svg) 移動中に<kbd>1</kbd>を押して。数値は鉛筆キーを押したまま入力します。<kbd>#</kbd>で符号が変わり、<kbd>*</kbd>が小数点です。面は仮想マウスで選択します（右ソフトキー、方向キー、<kbd>OK</kbd>）。

厚さは、すべてを選択して、前と同じように<kbd>S</kbd> <kbd>Y</kbd> `0.05` <kbd>Enter</kbd>です。

これで初めての3Dモデルができました！ おめでとうございます。
