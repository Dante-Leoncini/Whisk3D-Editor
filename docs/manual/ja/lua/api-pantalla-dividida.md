# 画面分割（同じ機器で2人プレイ）

| 関数 | 説明 |
|---|---|
| `setVistas(n [, "lado" \| "arriba"])` | `2`で画面を2つに分けます（左右に並べるか、上下に並べるか）。`1`で全画面に戻ります。2Dインターフェース（HUD）は1回だけ、2つのビューの上に重ねて描画されます。 |
| `setVistaCamara(i, camara)` | ビュー`i`（1または2）のカメラ。指定しなければ、アクティブなカメラです。 |
| `vista() → i, n` | 描画中のビュー（1または2。描画中でなければ0）と、ビューの数。 |
| `antesDeVista(i)` | （スクリプト側で定義します。）`setVistas`を呼んだスクリプトで、エンジンが各ビューを描画する前に呼び出します。ここで、カメラの方を向くもの（看板、パーティクル）をそのビューのカメラの方へ向け直したり、そのビューに映してはいけないものを隠したりします。時間とともに進むものは動かさないでください：それは`actualizar`で行います。 |

それぞれの半分は、そのカメラで写した1枚の完全な画像です：ゲームの画面枠（カメラのアスペクト比）が2つに分かれます。

## 1人に1台のゲームパッド

`boton`、`botonApretado`、`stick`、`gatillo`は、**ゲームパッドの番号**（1〜4。最初に操作された順）を受け付けます：`boton("a", 2)`、`stick("izq", 1)`。番号を付けなければ、これまでどおりどれでも（全部まとめて）反応します。キーボードには番号がないので、自分で割り振ってください（たとえば、プレイヤー1は矢印キーと数字、プレイヤー2はWASDと文字。QWERTYキーボード付きのNokiaでは文字も届きます）。

```lua
function actualizar(dt)
  local x1, y1 = stick("izq", 1)
  local x2, y2 = stick("izq", 2)
  if tecla("w") then y2 = -1 end
  mover(jugador1, x1 * dt * 5, y1 * dt * 5, 0)
  mover(jugador2, x2 * dt * 5, y2 * dt * 5, 0)
end
```
