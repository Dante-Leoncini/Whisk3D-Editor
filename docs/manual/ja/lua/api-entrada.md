# キーボード、ゲームパッド、タッチ、マウス

| 関数 | 説明 |
|---|---|
| `key(name) → bool` | キーが押されている（押している間ずっと）。 |
| `keyPressed(name) → bool` | ちょうどこのフレームで押された（1回の押下につき1回だけ）。 |
| `button(name [, gamepad])`、`buttonPressed(name [, gamepad])` | ゲームパッドのボタンで同じことをします。`gamepad`（1〜4）を指定するとそのゲームパッドのボタン、指定しないとどのゲームパッドのボタンでも対象になります。 |
| `stick(["left"\|"right"] [, gamepad]) → x, y` | ゲームパッドのスティック。-1〜1（上が-1）。 |
| `trigger(["left"\|"right"] [, gamepad]) → 0..1` | アナログトリガー。 |
| `controls() → n`、`control([n]) → name, tipo` | 接続されているゲームパッドの数と種類（`"xbox"`、`"playstation"`、`"nintendo"`、`"generico"`）。 |
| `tap() → x, y, touching` | 画面上の指（またはマウスのクリック）。 |
| `finger([n]) → x, y, active` | マルチタッチ：n番目の指（1〜4）。 |
| `touch() → bool` | 画面がタッチ式である：スマートフォンやタブレット（Android、iPhoneのブラウザー…）、または画面がすでにタッチされたことのある機器。画面上のコントロールを、必要なところでだけ表示するために使います。 |
| `tilt() → x, y, z` | スマートフォンの加速度センサー。単位はgで、見えているとおりの（回転済みの）画面の軸で返します：`x`はハンドルのように右へどれだけ傾いているか（角度のサイン）、まっすぐ立てると`y = 1`、上向きに寝かせると`z = 1`です。加速度センサーのない機器では`nil`。 |
| `vibrate(ms [, force])` | `ms`ミリ秒、`force`（0〜1）の強さで振動します：スマートフォンのバイブレーター（Android、ブラウザー）とゲームパッドの振動モーター（PC）。スマートフォンでは、強さに応じてパルスが短くなります。振動させるものがない機器や、プレイヤーが振動をオフにしている場合は何もしません。 |
| `pressed(obj) → bool` | その2D要素が、このフレームでタップまたはクリックされた（ボタン）。 |
| `mouse() → x, y, dentro` | マウスの位置。 |
| `captureMouse(bool)`、`mouseRel() → dx, dy`、`mouseCaptured()` | マウスで視点を動かすためのマウスキャプチャー（一人称のゲーム）。PCとブラウザーで使えます。ブラウザーでは、ゲーム内での最初のクリックかキー入力でマウスがキャプチャーされます。<kbd>Esc</kbd>で解放され、ゲームが一時停止します。 |
