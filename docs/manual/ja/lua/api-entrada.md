# キーボード、ゲームパッド、タッチ、マウス

| 関数 | 説明 |
|---|---|
| `tecla(nombre) → bool` | キーが押されている（押している間ずっと）。 |
| `teclaApretada(nombre) → bool` | ちょうどこのフレームで押された（1回の押下につき1回だけ）。 |
| `boton(nombre [, mando])`、`botonApretado(nombre [, mando])` | ゲームパッドのボタンで同じことをします。`mando`（1〜4）を指定するとそのゲームパッドのボタン、指定しないとどのゲームパッドのボタンでも対象になります。 |
| `stick(["izq"\|"der"] [, mando]) → x, y` | ゲームパッドのスティック。-1〜1（上が-1）。 |
| `gatillo(["izq"\|"der"] [, mando]) → 0..1` | アナログトリガー。 |
| `controles() → n`、`control([n]) → nombre, tipo` | 接続されているゲームパッドの数と種類（`"xbox"`、`"playstation"`、`"nintendo"`、`"generico"`）。 |
| `toque() → x, y, tocando` | 画面上の指（またはマウスのクリック）。 |
| `dedo([n]) → x, y, activo` | マルチタッチ：n番目の指（1〜4）。 |
| `tactil() → bool` | 画面がタッチ式である：スマートフォンやタブレット（Android、iPhoneのブラウザー…）、または画面がすでにタッチされたことのある機器。画面上のコントロールを、必要なところでだけ表示するために使います。 |
| `inclinacion() → x, y, z` | スマートフォンの加速度センサー。単位はgで、見えているとおりの（回転済みの）画面の軸で返します：`x`はハンドルのように右へどれだけ傾いているか（角度のサイン）、まっすぐ立てると`y = 1`、上向きに寝かせると`z = 1`です。加速度センサーのない機器では`nil`。 |
| `vibrar(ms [, fuerza])` | `ms`ミリ秒、`fuerza`（0〜1）の強さで振動します：スマートフォンのバイブレーター（Android、ブラウザー）とゲームパッドの振動モーター（PC）。スマートフォンでは、強さに応じてパルスが短くなります。振動させるものがない機器や、プレイヤーが振動をオフにしている場合は何もしません。 |
| `apretado(obj) → bool` | その2D要素が、このフレームでタップまたはクリックされた（ボタン）。 |
| `raton() → x, y, dentro` | マウスの位置。 |
| `capturarRaton(bool)`、`ratonRel() → dx, dy`、`ratonCapturado()` | マウスで視点を動かすためのマウスキャプチャー（一人称のゲーム）。PCとブラウザーで使えます。ブラウザーでは、ゲーム内での最初のクリックかキー入力でマウスがキャプチャーされます。<kbd>Esc</kbd>で解放され、ゲームが一時停止します。 |
