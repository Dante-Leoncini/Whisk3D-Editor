# エンジンがスクリプトを呼び出すタイミング

スクリプトで特別な名前の関数を定義すると、エンジンが適切なタイミングで自動的に呼び出します。どれも省略可能なので、必要なものだけを書いてください。

| 関数 | 呼ばれるタイミング |
|---|---|
| `inicio()` | 1回だけ、Playしたとき（または`instanciar`でオブジェクトが作られた直後）。オブジェクトを探したり、変数を準備したりするのに使います。 |
| `actualizar(dt)` | 毎フレーム、オブジェクトが**表示されていて**、アクティブなシーンにある間。`dt`は前のフレームから経過した秒数です（0.001〜0.1）。 |
| `alEntrar(otro, miHitbox, suHitbox)` | ヒットボックスが別のヒットボックスに触れ始めたとき。 |
| `alQuedarse(otro, miHitbox, suHitbox)` | 触れ合っている間、毎フレーム。 |
| `alSalir(otro, miHitbox, suHitbox)` | 触れ合わなくなったとき（片方が非表示または無効になった場合も含みます）。 |
| `alTocar(otro, impulso, x, y, z, nx, ny, nz)` | 2つの**剛体**が衝突したとき。`x, y, z`は接触点、`nx, ny, nz`は相手への方向です。 |

ヒットボックスのイベントは、そのヒットボックスのスクリプトと、その親オブジェクトのスクリプトが受け取ります。相手が剛体の場合、`suHitbox`は`nil`になります。

## dtを使って動かす

速度には必ず`dt`を掛けてください。そうすれば、高性能なPCでも遅い電話でも、ゲームが同じ速さで進みます：

```lua
function actualizar(dt)
  mover(yo(), 3 * dt, 0, 0)   -- +X方向に毎秒3単位
end
```

## 1フレーム内の順序

1. 物理（速度、剛体）と衝突イベント：`alTocar`、`alSalir`、`alEntrar`、`alQuedarse`。
2. すべてのスクリプトの`actualizar(dt)`（Outlinerの順）。
3. アニメーション（シーン、クリップ、アーマチュア）。
4. フレームの終わり：保留中の`destruir()`が適用され、インスタンス化したオブジェクトが追加され、要求された`cambiarEscena()`が実行されます。

## ゲームを停止したとき

Stopを押すと、すべてのスクリプトが終了し、共有領域が消去され、シーンはPlay前の状態に戻ります。ゲームの実行中にスクリプトを編集すると、そのオブジェクトはスクリプトを再読み込みします：変数は初期状態に戻り、`inicio()`がもう一度呼ばれます。
