# Whisk3D Coreマニュアル

**Whisk3D Core**は、Whisk3Dの土台になっている抽象化レイヤーです。処理を頼む方法（描画する、音を鳴らす、ファイルを読む、キー入力を受け取る）は1つだけで、実装はシステムごとに異なります。このマニュアルは、CまたはC++でプログラミングをしていて、Coreの上に直接ゲームを作りたい人のためのものです。レビュー用の草稿です。

プロジェクトのページ（ブラウザーで動くサンプル付き）：**[Whisk3D Core](https://leoncini.com.ar/proyecto.php?id=whisk3d-core&lang=ja)**。コードはGitHubの**[Whisk3D-Core](https://github.com/Dante-Leoncini/Whisk3D-Core)**にあり、MITライセンスです。
