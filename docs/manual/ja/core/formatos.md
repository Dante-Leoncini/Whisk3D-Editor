# 数学、シーン、フォーマット

独自の**ベクトル、4x4行列、クォータニオン**（`math/`）があり、PCでもレトロなシステムでも同じようにコンパイルできます。その上に**シーン**（`objects/`）があります：親子の階層を持つオブジェクト、メッシュ、マテリアル、ライト（ディレクショナル、ポイント、スポット）、カメラ、アーマチュア。そして**アニメーション**（`animation/`）：キーフレーム、アーマチュア、頂点、フリップブック、ロコモーション。

独自のフォーマットは、小さなマシンでも速く読めるように作られています：

| フォーマット | 内容 |
|---|---|
| `.w3d` | プロジェクト：標準のZIPです（どの解凍ツールでも開けます）。無圧縮で書き込み、圧縮されたものも読めます。ZIP64には非対応 |
| `.w3dm` | 1行ずつのテキストで書いたジオメトリ：読みやすく、手で編集でき、N95でも簡単に読めます |
| `.w3db` | 同じメッシュのバイナリ版で、そのままメモリに載せられる形：開くことは配列をコピーすることです |
| `.w3dt` | GPUにそのまま渡せるテクスチャ（16ビット、ミップマップ作成済み） |
| `.w3dpack` | ChaCha20で暗号化したアセットのコンテナー。鍵はアプリケーションが用意します |
| 埋め込みpak | ビルドしたゲームのファイルを、XORで難読化したもの。のぞき見を防ぐためのもので、暗号ではありません |
| glTF / GLB | 1つのヘッダー（`io/w3dGltf.h`）に収めたローダーとレンダラー。エディターの外で使うためのものです |
