# 物理

すべて自前で、C++03で書かれています。外部のエンジンは使わず、毎フレームのメモリ確保もしません。誰も使っていなければ、コストはまったくかかりません：各ステップは最初の行で抜けます。

- **W3dFisica：** 軸に沿ったボックスの速度と跳ね返り。それだけです。
- **W3dRigido：** 質量を持つ向き付きのボックス、重力、摩擦と跳ね返りを含む力積、レイキャスト、接触イベント。
- **W3dColMalla：** ステージの三角形（スロープ、段差）の上を歩き、壁で止まるための処理。何千もの三角形を調べずに済むよう、グリッドを使います。
- **W3dHitbox：** 通知するだけのボックス（`alEntrar`、`alQuedarse`、`alSalir`、`alTocar`）。
- **W3dRagdoll：** ラグドールと、2ボーンのインバースキネマティクス、FABRIK。
- **W3dNav：** 床のグリッド上で、ある点から別の点までの経路を求めます（A*のあとに経路を引き締めます）。

これが重要な理由：エディターのPlayとビルドしたゲームは、同じ`dt`で同じステップを呼ぶので、ゲームはどちらでも、PCでもN95でも同じように動きます。Luaからは：[シンプルな物理](../lua/api-fisica-simple.md)、[剛体、衝突、ヒットボックス](../lua/api-cuerpos-rigidos.md)。
