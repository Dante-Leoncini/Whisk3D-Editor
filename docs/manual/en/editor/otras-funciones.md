# Other 3D Viewport functions

| Function | Description | How to use it |
|---|---|---|
| Camera View | Looks through the active camera with a frame the size of the render. Inside it, the wheel or pinching does an inspection zoom without moving the camera. | <kbd>Num0</kbd> |
| Local View | Isolates the selection and its children (parents are not drawn: selecting a mesh does not show its armature's bones); **Local View** shows at the top left. Repeating restores everything. | <kbd>/</kbd> |
| 3D Cursor | The point where new objects are created; it also works as a pivot. It's placed with the Snap menu (<kbd>Shift+S</kbd>). | <kbd>Shift+S</kbd> |
| Ray Tracing | Realistic render with soft shadows, transparency, reflections (the material's roughness and metallic), normal maps and spot lights. It's enabled in Properties → Render and shown in Render Preview. It traces on the **GPU** (Vulkan: NVIDIA, AMD or Intel; with the RTX/RDNA2/Arc ray tracing cores when the driver offers them) or on the CPU. **Only the final image** hides how it fills in. The material's **Transmission** (0 to 1) says how much of it is glass: light passes through bent by the **IOR** (1 = none, 1.33 water, 1.5 glass) and with **Roughness** comes out frosted; what is transparent through alpha passes straight (with transmission 0, the IOR bends the transparent part, as before). See [Hand-written shaders](shaders.md#with-ray-tracing); **Transparency layers** limits how many a ray crosses (beyond that it is black). Caustics are not simulated. **New noise each image** (on by default) changes the noise pattern in every image, so in an animation it does not stay stuck to the screen. | Properties → Render → Ray Tracing, Device |
| Denoiser and upscaling | The **denoiser** cleans the noise of a few passes: **GPU (A-Trous)** on any card with Vulkan (real time), **Open Image Denoise** (CPU) and **OptiX** (NVIDIA). **Upscaling** (x2, x3, x4) traces at a fraction of the view's resolution, cleans and enlarges it: more frames per second. Everything is optional: what the machine doesn't have doesn't show up. The **Upscaler** picks how it is enlarged: Linear, or **FSR 1** (AMD, open): sharper edges, on any card (by CPU). | Properties → Render → Denoiser, Upscaling |
| Motion vectors and motion blur | **Motion vectors** saves an extra image (`_vectores`) where each pixel says how far it moved on screen since the previous frame (red = X, green = Y; 128 = still, each step = half a pixel). It is an ordinary OpenGL pass that paints each vertex with its motion, so it also works on OpenGL ES 1.1. **Motion blur** uses those vectors to blur the image by CPU along the motion; **Shutter** (0 to 1) is how much of the frame the camera stays open (0.5 = the classic 180°). | Properties → Render → Motion vectors, Motion blur |
| Ray traced motion blur | With **Ray Tracing** on, **Ray traced motion blur** traces each pass at another moment of the shutter (Render Image and Render Animation): the moving meshes and the camera between the neighboring frames. It is real blur (shadows, reflections, what is behind what moves); use enough passes so the copies do not show. **Shutter** (0.01 to 1, 0.5 by default) and **Position**: **Center of frame**, **Start of frame** or **End of frame**. It replaces the motion-vector blur. | Properties → Render → Ray traced motion blur |
| Camera depth of field | Each camera has **Depth of field**: **F-stop** (like a real lens: smaller = more blur), **Focus distance** (m, animable with its keyframe diamond) and **Focus object** (the focus follows that object by itself). The orange line and cross on the camera mark the focused plane. **Ray Tracing** does it for real from the lens (looking through the camera); the post-processing **Depth of field** can use the same focus and the same F-stop. Ticking it shows its options right away. | Properties → Camera → Depth of field |
| Post Processing | A card under **Render**, like a modifier stack: **Add** effects, reorder them (**Move Up** / **Move Down**) and **Remove** them; each one with its own settings. **Film grain** (intensity, size, colored), **Depth of field** from the depth (sharp range; with **Use camera focus**, the focus and F-stop of the active camera, and if that camera has depth of field turned off nothing is blurred; without it, the focus distance and the blur set by hand) and **Motion blur** from the motion pass (shutter). These are camera effects: in the **Rendered** view they show only **when looking through the active camera** and only **inside its frame** (in fullscreen game mode, over the whole screen), and they go into the rendered images. Made for real time in games: with OpenGL ES 2.0 and Vulkan everything runs on the GPU (the depth, normal, motion and Solid views too); with OpenGL ES 1.1 (the N95) and with the PC's default OpenGL it runs on the CPU and the card says so (on PC, **Settings → Graphics → OpenGL ES 2.0** or **Vulkan** moves it to the GPU). It is independent from the ray-traced blur and depth of field: you can use one, the other or both. | Properties → Render → Post Processing |
| Graphics | The editor carries three backends in the same program: **OpenGL** (the fixed pipeline, works on old cards), **OpenGL ES 2.0** (shaders) and **Vulkan**. You pick one and it applies on restart; if Vulkan doesn't work on that machine, it keeps using OpenGL. | Properties → Settings → Graphics |
| Game mode | With the "Game" animation playing, clicks and keys go to the game. <kbd>Esc</kbd> pauses. | Play / Stop buttons in the bar |
