# Keyboard Shortcuts

Every function in the tables below can be reassigned, and each one can have **one or several** key combinations (or none). It works on PC, Android (with a physical keyboard) and Web. On the N95 the window can't capture keys: there, the `atajos.ini` file is edited by hand.

## How to change a shortcut

1. Open **Properties → File/Render tab → Settings card → Keyboard Shortcuts...**
2. Choose the **Context** (General, 3D Viewport, During a transform, UV Editor, Timeline, Outliner, 2D Editor, Properties, Script Editor). The left/right arrows also change it.
3. Choose the function in the list and tap **Add shortcut** (or tap the chosen row again). "Press a key..." appears.
4. Press the new combination (for example <kbd>Ctrl+M</kbd>). <kbd>Esc</kbd> cancels without changing anything.

| Button | What it does |
|---|---|
| Add shortcut | Adds a combination to the function. If another function in the same context had it, it's taken away from that one and you get a warning. |
| Clear | Leaves the function without a shortcut. |
| Reset | Returns the function to its default shortcut. |
| Reset all | All functions go back to their defaults. |

The menus show the **configured** shortcut next to each option: if you reassign a function, the menu shows the new combination. On the N95 the menus show the phone key (for example <kbd>1</kbd> for Move or <kbd>C</kbd> for Delete); if a Bluetooth keyboard is connected, they show that keyboard's key when they understand it.

Changed combinations are shown in green. When a default shortcut is taken away from its function, that key becomes free: it no longer does anything in that context.

The shortcuts of each context apply when the pointer is over that panel; the **General** ones apply everywhere. The **During a transform** ones apply while something is being moved, rotated or scaled, and they take priority. In the script editor, letters always type: there you can only reassign combinations with <kbd>Ctrl</kbd>, <kbd>Alt</kbd> or F keys.

## The atajos.ini file

Changes are saved automatically in `res/atajos.ini`, next to `config.ini`. Only the changed functions are listed, and the file can be edited by hand:

```ini
# function = combination, another combination   (empty = no shortcut)
3d.mover = G, Ctrl+M
3d.ocultar = Ctrl+Q
xf.cancelar = Esc, Q
3d.overlays =
```

Key names: letters and numbers as they are, `Enter`, `Esc`, `Tab`, `Space`, `Backspace`, `Delete`, `Home`, `End`, `PageUp`, `PageDown`, `Left`, `Right`, `Up`, `Down`, `F1`…`F12`, `Num0`…`Num9`, `Num.`, `NumEnter`, `Comma`, `Plus`. Modifiers: `Ctrl+`, `Shift+`, `Alt+`.

## Fixed keys (not reassignable)

Some keys aren't in the list because they depend on what you're doing: the arrows when navigating menus and panels, <kbd>Enter</kbd> and <kbd>Esc</kbd> in menus and windows, the outliner arrows while moving a row, the IDE keyboard while typing, and the phone keypad on the N95 (see [Navigation](navegacion.md)).
