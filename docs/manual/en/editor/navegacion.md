# Navigating the 3D Viewport

## With the mouse (PC)

| Function | Description | How to use it |
|---|---|---|
| Orbit | Rotates the view around the pivot point. | Middle button + drag, or <kbd>Alt</kbd> + left button + drag. |
| Pan | Moves the view sideways. | <kbd>Shift</kbd> + middle button, or <kbd>Alt+Shift</kbd> + left button + drag. |
| Zoom | Zooms in or out. | Mouse wheel. |
| Select | Picks what's under the pointer (decided on release). | Left click; <kbd>Shift</kbd>+click adds or removes. |
| Box Select | Dragging over the background draws a rectangle. | Drag with the left button, or <kbd>B</kbd>. |
| Context menu | Opens the mode's menu at the pointer (during a transform, it cancels it). | Right click. |
| Lock Orbit | What used to orbit now pans: the view behaves like a 2D board. | View menu → Lock Orbit. |
| Lock the camera to the view | Looking through the active camera, navigating moves the camera: this is how you set up the shot. | Click the padlock (at the bottom, in the camera view), or View menu → Lock the camera to the view. |

## With the keyboard

| Function | Description | Shortcut |
|---|---|---|
| Front / Back View | Looks from the front or from behind. | <kbd>Num1</kbd> / <kbd>Ctrl+Num1</kbd> |
| Right / Left View | Looks from the side. | <kbd>Num3</kbd> / <kbd>Ctrl+Num3</kbd> |
| Top / Bottom View | Looks from above or from below. | <kbd>Num7</kbd> / <kbd>Ctrl+Num7</kbd> |
| Perspective / Orthographic | Toggles between the two projections. | <kbd>Num5</kbd> |
| Roll the view | Rotates the view 15° around its axis. | <kbd>Num4</kbd> / <kbd>Num6</kbd> |
| Camera View | Looks through the active camera (press again to leave). | <kbd>Num0</kbd> |
| Set Active Camera | The active object becomes the active camera. | <kbd>Ctrl+Num0</kbd> |
| Frame Selected | Centers the view on the selection and adjusts the zoom. | <kbd>Num.</kbd> (numeric keypad period) |
| Local View | Shows only the selection and frames it; pressing again restores everything. | <kbd>/</kbd> |
| Import model | Opens the file browser to import OBJ, FBX, glTF or GLB (PC only). | <kbd>Num9</kbd> |

## With your fingers (Android, touch Web)

| Function | Description | Gesture |
|---|---|---|
| Orbit | Rotates the view. | Drag one finger. |
| Zoom and pan | Pinching zooms in or out; moving both fingers together pans. | Two fingers. |
| Select | Picks what's under your finger. | Tap and lift without moving. |
| Frame Selected | Same as <kbd>Num.</kbd>. | Double tap with two fingers. |
| Touch modifiers | Shift and Ctrl buttons in the bottom bar: they stay on (green) to add to the selection or pick paths. | Tap Shift / Ctrl. |
| View (navigate) | In Edit Mode and in the paint modes, your finger navigates instead of selecting or painting. | Monitor-shaped button in the bottom bar. |

## With the Nokia N95 keypad

| Function | Key |
|---|---|
| Orbit | Arrows (hold) |
| Zoom / Frame Selected | <kbd>0</kbd> + up/down / <kbd>0</kbd> alone |
| Pan | <kbd>\*</kbd> + arrows |
| Views (front, side, top) / Perspective-Orthographic | <kbd>#</kbd> + arrows / <kbd>#</kbd> alone |
| Move / Rotate / Scale (during the transform: X / Y / Z axis) | <kbd>1</kbd> / <kbd>2</kbd> / <kbd>3</kbd> |
| Confirm / Cancel | OK (center) / <kbd>C</kbd> |
| Delete (with nothing to cancel) / Undo and Redo | <kbd>C</kbd> / <kbd>C</kbd> + left or right |
| Change the shading | <kbd>6</kbd> |
| Extrude (Edit Mode) | <kbd>7</kbd> |
| Loop Cut (Edit Mode) / camera view (outside Edit Mode) | <kbd>8</kbd> |
| Lock Orbit | <kbd>9</kbd> |
| Lock the camera to the view (looking through the camera) | Left selection key → View menu |
| Cycle the selection / add, remove, all or none | Pencil / Pencil + arrows |
| Menu bar / virtual cursor | Left / right selection key |
| Switch viewport, resize, maximize | Green key (alone, + arrows, + OK) |
| Fullscreen game mode | Green key + <kbd>0</kbd> (again: the image fills the whole screen; again: back). No UI, no camera border and no dark area around it (black bars remain only if the camera declares an aspect ratio different from the screen's, until the second press), and the arrows do not pan: you see the game as it is |

The N95 also accepts a Bluetooth mouse and keyboard. To type text, T9 is used.
