# Whisk3D UI manual

**Whisk3D UI** is Whisk3D's interface library: buttons, tabs, drop-down menus, property cards, text and icons, drawn on top of Whisk3D Core. The editor is built with it. This manual is for people who program in C or C++ and want to use it for the interface of their game or program. Draft for review.

The project page: **[Whisk3D UI](https://leoncini.com.ar/proyecto.php?id=whisk3d-ui&lang=en)**. The code is in **[Whisk3D-UI](https://github.com/Dante-Leoncini/Whisk3D-UI)**, on GitHub, under the MIT license.
