# Particles, fog and visibility

| Function | What it does |
|---|---|
| `emit(obj [, n])`, `setEmitting(obj, bool)` | A burst of particles, or turning an emitter on/off. |
| `getFog(obj)`, `setFog(obj, density [, r, g, b, inicio, fin])` | Read and change the fog. |
| `setSector`, `visCell`, `setVisAnchor`, `setVisCurveT`, `setBatch` | Advanced control over which parts of the level get drawn. |
