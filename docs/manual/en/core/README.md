# Whisk3D Core manual

**Whisk3D Core** is the abstraction layer Whisk3D is built on: a single way to ask for things (draw, play a sound, read files, receive key presses) and a different implementation for each system. This manual is for people who program in C or C++ and want to make a game directly on top of the Core. Draft for review.

The project page, with examples that run in the browser: **[Whisk3D Core](https://leoncini.com.ar/proyecto.php?id=whisk3d-core&lang=en)**. The code is in **[Whisk3D-Core](https://github.com/Dante-Leoncini/Whisk3D-Core)**, on GitHub, under the MIT license.
