# Partículas, niebla y visibilidad

| Función | Qué hace |
|---|---|
| `emit(obj [, n])`, `setEmitting(obj, bool)` | Una ráfaga de partículas, o prender/apagar un emisor. |
| `getFog(obj)`, `setFog(obj, density [, r, g, b, inicio, fin])` | Leer y cambiar la niebla. |
| `setSector`, `visCell`, `setVisAnchor`, `setVisCurveT`, `setBatch` | Control avanzado de qué partes del nivel se dibujan. |
