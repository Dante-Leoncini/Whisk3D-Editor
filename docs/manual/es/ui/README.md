# Manual de Whisk3D UI

**Whisk3D UI** es la biblioteca de interfaz de Whisk3D: botones, pestañas, menús desplegables, tarjetas de propiedades, texto e íconos, dibujados sobre Whisk3D Core. El editor está hecho con ella. Este manual es para quien programa en C o C++ y quiere usarla para la interfaz de su juego o programa. Borrador para revisar.

La página del proyecto: **[Whisk3D UI](https://leoncini.com.ar/proyecto.php?id=whisk3d-ui&lang=es)**. El código está en **[Whisk3D-UI](https://github.com/Dante-Leoncini/Whisk3D-UI)**, en GitHub, con licencia MIT.
