# Manual de Whisk3D Core

**Whisk3D Core** es la capa de abstracción sobre la que está hecho Whisk3D: una sola forma de pedir las cosas (dibujar, hacer sonar, leer archivos, recibir las teclas) y una implementación distinta para cada sistema. Este manual es para quien programa en C o C++ y quiere hacer un juego directamente sobre el Core. Borrador para revisar.

La página del proyecto, con ejemplos que corren en el navegador: **[Whisk3D Core](https://leoncini.com.ar/proyecto.php?id=whisk3d-core&lang=es)**. El código está en **[Whisk3D-Core](https://github.com/Dante-Leoncini/Whisk3D-Core)**, en GitHub, con licencia MIT.
