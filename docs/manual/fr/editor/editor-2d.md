# Éditeur 2D

Pour construire des interfaces de jeu, des HUD et des jeux 2D : textes, images, rectangles, conteneurs, slice 9, boutons et vidéos.

| Fonction | Description | Raccourci |
|---|---|---|
| Ajouter | Texte, Image, Rectangle, Conteneur, Slice 9, Bouton, Développer, Vidéo ; Importer w3dui. | Menu Ajouter |
| Sélectionner | Un clic choisit (glisser déplace) ; <kbd>Shift</kbd>+clic ajoute ; un clic dans le vide désélectionne. | Clic ; <kbd>A</kbd> / <kbd>Alt+A</kbd> / <kbd>Ctrl+I</kbd> |
| Déplacer / Tourner / Échelle | <kbd>X</kbd> / <kbd>Y</kbd> verrouillent l'axe ; on peut taper la valeur. | <kbd>G</kbd> / <kbd>R</kbd> / <kbd>S</kbd> |
| Redimensionner | Les poignées de l'élément actif. | Glisser |
| Dupliquer / Supprimer | Copie décalée et saisie / suppression avec confirmation. | <kbd>Shift+D</kbd> / <kbd>X</kbd> |
| Définir parent / Effacer parent | La sélection devient enfant de l'élément actif, ou se rattache de nouveau à l'UI. | Menu Objet |
| Curseur 2D | Se place avec <kbd>Shift</kbd>+clic dans le vide. | <kbd>Shift</kbd>+clic |
| Vue du jeu | Le canevas s'affiche exactement comme sur l'appareil, sans repères. | <kbd>Num0</kbd> (<kbd>Esc</kbd> pour sortir) |
| Cadrer / Zoom 1:1…4:1 | Cadre la sélection ; zoom exact pixel pour pixel. | <kbd>Num.</kbd> / menu Vue |
