# Armatures

## Mode Édition (armature)

| Fonction | Description | Raccourci |
|---|---|---|
| Sélectionner | Choisit une extrémité de l'os ou l'os entier ; le faire glisser le déplace aussitôt. | Clic ; <kbd>Shift</kbd> ajoute |
| Tout / Aucun | Sélectionne ou désélectionne tous les os. | <kbd>A</kbd> / <kbd>Alt+A</kbd> |
| Extruder l'os | Crée un nouvel os depuis chaque extrémité sélectionnée. | <kbd>E</kbd> |
| Déplacer / Tourner / Échelle | Avec les axes et les plans, comme d'habitude. | <kbd>G</kbd> / <kbd>R</kbd> / <kbd>S</kbd> |
| Dupliquer | Copie les os et les laisse saisis. | <kbd>Shift+D</kbd> |
| Supprimer | Supprime les os (leurs enfants passent au grand-parent). | <kbd>X</kbd> ou <kbd>Delete</kbd> |
| Définir parent | Garder décalage ou Connecté. | <kbd>Ctrl+P</kbd> |
| Déconnecter / Effacer parent | Détache l'os de son parent. | <kbd>Alt+P</kbd> |

## Mode Pose

Uniquement pour les armatures. Sert à poser et à animer.

| Fonction | Description | Raccourci |
|---|---|---|
| Sélectionner un os | Choisit un os. | Clic ; <kbd>Shift</kbd> ajoute |
| Déplacer / Tourner / Échelle | Pose les os sélectionnés. | <kbd>G</kbd> / <kbd>R</kbd> / <kbd>S</kbd> |
| Effacer position / rotation / échelle | Remet l'os dans sa pose de repos pour ce canal. | <kbd>Alt+G</kbd> / <kbd>Alt+R</kbd> / <kbd>Alt+S</kbd> |
| Insérer image clé | Enregistre la pose à la frame actuelle. | <kbd>I</kbd> / <kbd>Shift+I</kbd> |
