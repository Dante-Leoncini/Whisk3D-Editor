# Particules, brouillard et visibilité

| Fonction | Ce qu'elle fait |
|---|---|
| `emit(obj [, n])`, `setEmitting(obj, bool)` | Une rafale de particules, ou activer/désactiver un émetteur. |
| `getFog(obj)`, `setFog(obj, density [, r, g, b, inicio, fin])` | Lire et modifier le brouillard. |
| `setSector`, `visCell`, `setVisAnchor`, `setVisCurveT`, `setBatch` | Contrôle avancé des parties du niveau qui sont dessinées. |
