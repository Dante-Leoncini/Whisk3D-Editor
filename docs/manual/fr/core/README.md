# Manuel de Whisk3D Core

**Whisk3D Core** est la couche d'abstraction sur laquelle repose Whisk3D : une seule façon de demander les choses (dessiner, jouer un son, lire des fichiers, recevoir les touches) et une implémentation différente pour chaque système. Ce manuel s'adresse à ceux qui programment en C ou en C++ et veulent faire un jeu directement sur le Core. Brouillon à relire.

La page du projet, avec des exemples qui tournent dans le navigateur : **[Whisk3D Core](https://leoncini.com.ar/proyecto.php?id=whisk3d-core&lang=fr)**. Le code se trouve dans **[Whisk3D-Core](https://github.com/Dante-Leoncini/Whisk3D-Core)**, sur GitHub, sous licence MIT.
