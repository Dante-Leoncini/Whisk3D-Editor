# Manuel de Whisk3D UI

**Whisk3D UI** est la bibliothèque d'interface de Whisk3D : boutons, onglets, menus déroulants, cartes de propriétés, texte et icônes, dessinés sur Whisk3D Core. L'éditeur est construit avec elle. Ce manuel s'adresse à ceux qui programment en C ou en C++ et veulent l'utiliser pour l'interface de leur jeu ou de leur programme. Brouillon à relire.

La page du projet : **[Whisk3D UI](https://leoncini.com.ar/proyecto.php?id=whisk3d-ui&lang=fr)**. Le code se trouve dans **[Whisk3D-UI](https://github.com/Dante-Leoncini/Whisk3D-UI)**, sur GitHub, sous licence MIT.
