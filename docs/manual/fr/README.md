# Manuels de Whisk3D

- [Tutoriels](tutoriales/README.md) : pas à pas, avec des images et des animations de l'éditeur.
- [Manuel de Whisk3D Editor](editor/README.md) : ce que l'éditeur sait faire, classé par panneau et par mode.
- [Lua dans Whisk3D](lua/README.md) : les bases du langage et tout ce que Whisk3D y ajoute pour programmer des jeux.
- [Manuel de Whisk3D UI](ui/README.md) : la bibliothèque de l'interface (boutons, menus, cartes, texte), pour ceux qui programment en C ou en C++.
- [Manuel de Whisk3D Core](core/README.md) : la couche d'abstraction qui fait fonctionner Whisk3D sur tous les systèmes, pour ceux qui programment en C ou en C++.
