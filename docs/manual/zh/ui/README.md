# Whisk3D UI 手册

**Whisk3D UI** 是 Whisk3D 的界面库：按钮、选项卡、下拉菜单、属性卡片、文本和图标，都基于 Whisk3D Core 绘制。编辑器就是用它做的。本手册面向使用 C 或 C++ 编程、想用它来制作自己游戏或程序界面的人。待审阅草稿。

项目页面：**[Whisk3D UI](https://leoncini.com.ar/proyecto.php?id=whisk3d-ui&lang=zh)**。代码托管在 GitHub 上的 **[Whisk3D-UI](https://github.com/Dante-Leoncini/Whisk3D-UI)**，采用 MIT 许可证。
