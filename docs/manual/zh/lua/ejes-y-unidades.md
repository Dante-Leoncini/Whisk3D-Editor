# 坐标轴、单位和对象

- **3D：** 在脚本中，**Z 轴朝上**，与 Properties 面板一致：X 和 Y 是地面（宽度和深度），Z 是高度。你在面板中看到的，就是脚本读取和写入的值。位置、旋转和缩放都是相对于对象的父级而言的。旋转以**度**为单位。
- **2D（屏幕和 UI）：** 使用画布的像素，(0, 0) 位于**中心**；+x 向右，+y 向**下**。
- **对象：** 查找或返回对象的函数（`yo`、`buscar`、`objeto`……）给出的值没有字段也没有方法：你要把它传给其他函数来使用。两个对象可以用 `==` 比较。如果对象已被销毁，它的表现就和 `nil` 一样。
- **容错：** 几乎所有函数在收到 `nil` 或类型不对的对象时都不会出错：读取类的函数返回 0、`""` 或 `false`，写入类的函数什么也不做。
- **索引：** 和 Lua 一样，几乎所有索引都从 1 开始（顶点、手指、层、例程步骤）。例外是例程的内存（`memoria`），它的范围是 0 到 255。
