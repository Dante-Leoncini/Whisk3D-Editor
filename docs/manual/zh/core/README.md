# Whisk3D Core 手册

**Whisk3D Core** 是 Whisk3D 赖以构建的抽象层：用同一种方式提出请求（绘制、播放声音、读取文件、接收按键），而每个系统各有一套不同的实现。本手册面向使用 C 或 C++ 编程、想直接基于 Core 制作游戏的人。待审阅草稿。

项目页面，附有可在浏览器中运行的示例：**[Whisk3D Core](https://leoncini.com.ar/proyecto.php?id=whisk3d-core&lang=zh)**。代码托管在 GitHub 上的 **[Whisk3D-Core](https://github.com/Dante-Leoncini/Whisk3D-Core)**，采用 MIT 许可证。
