# 数学、场景和格式

自带的**向量、4x4 矩阵和四元数**（`math/`），在 PC 和复古平台上编译结果一致。在此之上是**场景**（`objects/`）：带父子层级的对象、网格、材质、灯光（平行光、点光源和聚光灯）、相机和骨架。还有**动画**（`animation/`）：关键帧、骨架、顶点、序列帧（flipbook）和移动动画（locomotion）。

自有格式的设计目标是让小机器也能快速读取：

| 格式 | 是什么 |
|---|---|
| `.w3d` | 项目：一个标准 ZIP（任何解压工具都能打开）。写入时不压缩，读取时也支持压缩的。不支持 ZIP64 |
| `.w3dm` | 按行组织的文本几何数据：易读、可手工编辑，N95 也能轻松读取 |
| `.w3db` | 同样的网格，以二进制保存，已经可以直接放进内存：打开它就是复制数组 |
| `.w3dt` | 一张可以直接交给 GPU 的纹理（16 位，mipmap 已生成） |
| `.w3dpack` | 用 ChaCha20 加密的资源容器；密钥由应用程序提供 |
| 内嵌 pak | 编译后游戏的文件，用 XOR 混淆。用来防好奇的人，不是密码学 |
| glTF / GLB | 一个单头文件（`io/w3dGltf.h`）的读取器和渲染器，供在编辑器之外使用 |
