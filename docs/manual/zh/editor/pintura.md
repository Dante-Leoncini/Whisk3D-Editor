# 绘制模式

> [!NOTE]
> 这三种绘制模式**仅适用于 3D 网格**：选中相机、灯光、骨架、曲线或 2D 元素时，它们不会出现。绘制时，单击不会改变选择；要绘制另一个对象，请在 Outliner 中选择它。

## 三种模式的共同点

| 功能 | 说明 | 使用方法 |
|---|---|---|
| 绘制 | 只绘制可见的正面（开启 X-Ray 时，背面也会绘制）。每一笔都是一个撤销步骤。 | 单击并拖动 |
| Radius | 画笔的大小，单位为像素。修改时，视图中心会出现一个实际大小的圆。 | 工具栏上方的可拖动滑条 |
| Value | 画笔的强度。 | 可拖动滑条 |
| Falloff | 画笔边缘如何柔化；也可以自己绘制一条曲线。 | 衰减按钮 |
| View（触屏） | 开启：手指用来导航。关闭：手指用来绘制。 | 显示器形状的按钮 |

## Weight Paint

绘制一根骨骼对每个顶点的影响程度（蓝色 = 无影响，红色 = 完全影响）。网格能随骨架正确变形，靠的就是它。

| 功能 | 说明 |
|---|---|
| 画笔模式 | 加（+）、减（−）或等于（=，设为精确值）。 |
| 顶点组 | 要绘制哪个组（骨骼）；可以添加新组。如果一个都没有，第一笔会自动创建一个。 |
| 标记 | 在每个顶点上显示一个小方块；画笔只作用于这些顶点。 |
| 仅限所选 | 保护未选中的部分（显示为变暗）。 |

## Vertex Paint

在 **3D 网格**的顶点上绘制颜色（不能用于图像或 2D 元素：那些要用纹理绘制）。它非常轻量，是在 N95 上上色的推荐方式。

| 功能 | 说明 |
|---|---|
| Color | 打开颜色选择器（RGB、HSV、十六进制或调色板索引）。 |
| Per-Vertex / Per-Corner | 逐顶点时，颜色在相邻的面之间共享；逐角时，每个面都可以有自己的颜色（硬边）。 |
| Color Layers | 选择或创建颜色层。 |
| 标记 / 仅限所选 | 与 Weight Paint 中相同。 |

## Texture Paint

直接在 3D 对象上绘制，笔画会落到它的纹理上。

| 功能 | 说明 |
|---|---|
| 自动纹理 | 如果网格没有纹理，第一笔时会自动创建：一个专属材质、自动 UV，以及一张材质颜色的 1024×1024 图像（N95 上为 256×256）。 |
| Color、Falloff、Radius、Value | 与其他模式相同。 |
| Save Texture | 绘制内容在保存之前都只存在于内存中。有未保存的修改时，软盘图标会变成绿色。选项：Save、Save As…、Save inside the .w3d 和 Save outside the .w3d… |
