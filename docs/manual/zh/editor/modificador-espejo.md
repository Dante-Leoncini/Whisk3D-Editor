# Mirror

**Mirror** 修改器把网格镜像到一个平面的另一侧。凡是对称的东西都能用它：你只需建模角色、脸或汽车的一半，另一半会自动以镜像的形式出现。工作时，你在一侧所做的修改会在另一侧同步重复。

![完整的 Modifiers 选项卡，立方体上加了 Mirror 修改器](../tutoriales/img/modificador-espejo.webp)

## 如何添加

1. 选中网格。
2. 在 Properties 中，打开 **Modifiers** 选项卡（扳手图标）。只有当活动对象是网格时才会出现。
3. 点击 **Add**，选择 **Mirror**。

它在 Modifiers 卡片的列表中以内部名称 **Mirror** 显示，下方会展开一张包含其参数的卡片。

修改器不会破坏网格：原始网格保持不变，你可以继续编辑它，看到的则是修改后的结果。你可以随时关闭它，用 **Move Up** 和 **Move Down**（有两个或以上修改器时才会出现）调整它在列表中的位置，用 **Remove** 移除它，或者用 **Apply Modifier** 把它烘焙到网格中。

## 参数

| 参数 | 作用 |
|---|---|
| Display in Viewport | 关闭后不计算镜像：视图中和渲染时都不会出现。可以用来对比开启和关闭的效果。 |
| Display in Edit Mode | 关闭后，编辑网格时只显示原始的那一半；回到 Object Mode 时镜像才会出现。 |
| Mirror X | 左右镜像。默认开启：做角色或汽车用的就是它。 |
| Mirror Y | 前后镜像。 |
| Mirror Z | 上下镜像。 |
| Mirror Object | 设为 **None** 时，镜像平面经过网格的原点。如果选择另一个对象（例如一个 Empty），平面就经过该对象的原点，并随它一起旋转；它的缩放不起作用。移动或旋转该对象时，镜像会立即更新。 |
| Merge | 焊接接缝：几乎位于平面上的顶点会被吸附到平面上，由两半共用。这样中间不会留下一条缝，平滑着色也能从一侧无缝过渡到另一侧：半个球体看起来就是一个完整的球体。默认开启。 |
| Merge Distance | 顶点离平面多近才会被焊接（默认为 0.001 m）。如果接缝没有合上，就稍微调大一点；如果把不想要的顶点也焊上了，就调小一点。它也是 Clipping 的容差。 |
| Clipping | 在 Edit Mode 中移动顶点时，不允许它们越过平面到另一侧：到达平面的顶点会贴在平面上，只能在平面上滑动。中间的顶点不会脱离平面，这样接缝就不会意外裂开。默认开启。 |
| Apply Modifier | 把镜像烘焙到网格中：两半都变成真正的顶点，修改器也从列表中移除。四边形面仍然是四边形。此操作可以撤销。 |

如果开启了多个轴，每次镜像都基于前一次的结果进行。同时开启 X 和 Y 时，你只需建模对象的四分之一，就能得到全部四个部分。

## 顺序很重要

修改器按从上到下的顺序生效：每个修改器都在前一个的结果上工作。Mirror 几乎总是放在第一个：

- **Mirror 放在 [Subdivision Surface](modificador-subdivision.md) 上方：**先拼出完整的模型，再整体平滑，中间不会留下痕迹。反过来的话，每一半会分别平滑，接合处会出现一道折痕。
- **Mirror 放在 [Array](modificador-array.md) 上方：**Array 复制的是已经完整的对象，它的 Relative Offset 使用整个对象的尺寸。

对 Mirror 执行 Apply Modifier 只会烘焙 Mirror 本身，不管它在列表中的哪个位置：其他修改器都会保留。

## 建议

- 把网格的原点放在模型的中心，因为镜像平面经过那里。位于中间的顶点要正好放在平面上。
- 为了建模方便，可以在正交模式下从正面观看（参见[在 3D Viewport 中导航](../tutoriales/navegacion.md#前视图侧视图和顶视图)）：Mirror X 的平面会显示为中间的一条竖线。
- 模型完成后，如果你想分别修整每一半（例如让角色不那么完全对称），就应用 Mirror。
