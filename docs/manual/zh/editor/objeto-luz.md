# Light

**灯光**照亮场景：开启了 Lighting 的材质，会根据照到它的灯光显得更亮或更暗。本文是其属性的参考；如何添加和移动对象，请参阅 [Object Mode](../tutoriales/modo-objeto.md) 教程。

![完整的 Light 选项卡，选中了一盏 Point 灯光](../tutoriales/img/objeto-luz-propiedades.webp)

## 三种类型

| 类型 | 照明方式 | 用途 |
|---|---|---|
| **Point** | 从一个点向四面八方照射，就像一个灯泡。 | 台灯、蜡烛、篝火、物体发出的光。 |
| **Sun** | 平行光线，全部来自同一个方向。重要的是它朝向哪里，而不是它在哪里。 | 室外的日光。 |
| **Spot** | 以锥形照射，就像手电筒。 | 手电筒、汽车大灯、舞台聚光灯。 |

Add → Light 创建一盏 Point 灯光；Add → Sun 和 Add → Spot 则直接创建另外两种。之后可以在 **Type** 属性中更改类型。

Sun 和 Spot 通过旋转对象来调整方向。Sun 始终会绘制一条朝照射方向延伸到地面的线；选中灯光时，Spot 会显示它的锥形，Point 会显示一个大小与其 **Distance** 相同的球体。

| 选项卡 | 内容 |
|---|---|

## Light 卡片

| 属性 | 作用 |
|---|---|
| Ignore order | 勾选时（默认），无论灯光在 Outliner 中的什么位置，它都会照亮整个场景。取消勾选后，它只照亮在 Outliner 中排在它**之后**绘制的内容：可以用来让特定的灯光只照亮特定的东西。 |
| Type | Point、Sun 或 Spot。 |
| GL Light ◆ | 使用 OpenGL 的 8 盏灯中的哪一盏（0 到 7）。参见[超过 8 盏灯](#超过-8-盏灯)。 |
| Diffuse ◆ | 灯光的颜色。 |
| Intensity ◆ | 照明的强度。1 就是颜色本身；更高则更强。 |
| Ambient ◆ | 一种均匀的光，能照到所有地方，包括没有朝向灯光的面。初始为黑色（没有环境光）。稍微调高一点，阴影就不会是全黑的。 |
| Specular ◆ | 灯光在材质上留下的高光颜色。初始为黑色（没有高光）。 |
| Att Constant、Att Linear、Att Quadratic ◆ | **衰减**：灯光随距离减弱的方式。Constant 在各处均匀地减弱它；Linear 随距离逐渐减弱；Quadratic 在远处减弱得快得多。Sun 中没有这些选项。 |
| Spot Cutoff ◆ | 仅限 Spot：锥形张开的角度，单位为度，从中心量到边缘。设为 45 时，锥形总共张开 90°。 |
| Spot Exponent ◆ | 仅限 Spot：光在锥形内的分布方式。0 表示均匀照射；值越高，光越集中在中心，边缘越暗。 |
| Distance | 在光线追踪中，Point 灯光或 Spot 能照到多远，单位为米；也是所绘制锥形的长度。0 表示不限。Sun 中没有这个选项。 |
| Radius | 用于光线追踪：光源的大小。0 产生边缘锐利的硬阴影；越大，阴影边缘越柔和。对于 Sun，单位是度。 |
| Rays | 用于光线追踪：这盏灯发出多少条阴影光线。光线越多，柔和的阴影越干净，但也越慢。0 表示使用 File / Render 选项卡中的设置。 |

### Distance 和衰减

两者都会改变灯光能被察觉的范围，但方式不同：

- **衰减**始终有效，在 3D Viewport、游戏和光线追踪中都是如此：光会随距离逐渐变弱，但永远不会完全消失。
- **Distance** 是光线追踪中的一个截止点：光会平滑减弱，恰好在那里降到零，超出之后就不再照明。在 OpenGL 中它不会截断：那里起作用的是衰减。它也可以作为参考，因为球体或锥形会显示光照的终点。

## 超过 8 盏灯

OpenGL 最多**同时绘制 8 盏灯**，编号为 0 到 7：这就是 **GL Light** 属性。场景中可以有多得多的灯光；超过 8 盏后，新的灯光会和之前的某一盏共用编号。而光线追踪则会使用所有灯光。

取消勾选 **Ignore order** 后，可以有意地重复使用某个编号：一盏 GL Light 为 0 的灯光，照亮在 Outliner 中排在它之后绘制的内容；更靠下的另一盏 GL Light 同样为 0 的灯光，会为后面的内容取代它。这样，一个很长的场景可以在每个区域使用不同的灯光，而不会超过 8 盏。

## 示例

| 场景 | 如何搭建 |
|---|---|
| 白天的室外 | 一盏 Sun，Diffuse 带一点点黄色，再加一些天蓝色的 Ambient，让阴影不至于全黑。 |
| 有一盏台灯的房间 | 在台灯处放一盏 Point，把 Att Linear 稍微调高，让光在照到墙壁时逐渐变暗。用于光线追踪时，把 Distance 设成房间的大小。 |
| 手电筒 | 一盏 Spot，Spot Cutoff 小、Spot Exponent 高，用 [Child Of](restricciones.md#child-of) 约束固定在角色的手上。 |
| 闪烁的灯光 | 在 Intensity 上设置关键帧（◆），让数值忽高忽低。 |
