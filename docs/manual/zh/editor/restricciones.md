# Constraints

**约束**（英文为 *constraint*）让一个对象从另一个对象那里获取某样东西：它的位置、它的旋转、始终朝向相机，或者像子级一样跟随它。它能让东西自动摆好位置，而不必手动制作动画：跟在角色脚下的影子、始终正对着你的平面树、粘在手上的剑。本文介绍每种约束及其所有参数；如何添加和移动对象，请参阅 [Object Mode](../tutoriales/modo-objeto.md) 教程。

## 在哪里

在 Properties → **Constraints** 选项卡中。所有 3D 对象都有这个选项卡：网格、相机、灯光、骨架、声音、空物体。界面中的 2D 元素没有。

在逐一介绍之前，先说三件对所有约束都适用的事：

- **它们不会改变对象的数值。**约束是在绘制时叠加上去的。Object 选项卡的 Transform 卡片仍然显示对象自身的位置和旋转；如果关闭或删除约束，对象会准确地回到那里。
- **它们针对每个视图分别计算。**依赖相机的约束（Billboard，或来源为 **View** 的约束）使用正在绘制的那台相机：打开两个 3D Viewport 时，每个视图都会从自己的视点看到结果。在游戏中则使用活动相机。
- **它们在任何地方的效果都一样：**在编辑器中、在编译后的游戏中、在 Android 上，以及在 Nokia N95 上。

## Constraints 卡片

| 属性 | 作用 |
|---|---|
| 列表 | 对象的约束。选中的约束会显示在下方的卡片中。 |
| Add | 包含四种类型的菜单：**Copy Location**、**Copy Rotation**、**Billboard** 和 **Child Of**。 |
| Remove | 删除所选约束。 |
| Move Up / Move Down | 调整顺序（有两个或以上时才会出现）。 |

**顺序**很重要：约束按从上到下的顺序生效，每个约束都在上方约束的结果上工作。如果两个约束影响同一样东西，排在下面的那个生效。

## 所有约束的共同点

下方会出现所选约束的卡片，以约束名称为标题。所有类型都有下面这三行：

| 属性 | 作用 |
|---|---|
| Enabled | 开启或关闭约束而不删除它。可以用来对比有它和没有它时的效果。 |
| Show in Edit Mode | 关闭时（默认），编辑对象的顶点期间不应用约束：网格在它真正所在的位置显示和编辑。开启后，在 Edit Mode 中也会应用。 |
| Influence | 影响的权重，从 0 到 100 %。为 100 时完全应用；为 0 时不起作用；介于两者之间时，对象会停在它原本的位置和约束要把它带到的位置之间（为 50 时，正好在中间）。 |

**Show in Edit Mode** 默认关闭是有意为之：编辑一棵追着相机转的树，或者一个跑到别处去的网格，是非常别扭的。

## Copy Location

![完整的 Constraints 选项卡，立方体上加了 Copy Location 约束](../tutoriales/img/restricciones-copiar-posicion.webp)

**复制另一个对象的位置**：在所选的轴上，对象会准确地放到来源所在的位置。

| 属性 | 作用 |
|---|---|
| Source | 从哪里复制。**None**、**View**（正在绘制的那台相机），或者场景中除它自己以及挂在它下面的对象之外的任何对象。 |
| Copy X、Copy Y、Copy Z | 复制哪些轴。这些轴与 Transform 卡片中的相同：Z 是高度。未勾选的轴保持对象自身的数值。 |

它原样复制位置，不保留距离：三个轴都勾选时，对象会和来源重叠在一起。要让它错开一些，可以取消勾选不需要跟随的轴，或者在 Edit Mode 中移动网格（要在保持距离的同时跟随某个东西，请参见 [Child Of](#child-of)）。

卡片上的提示：

- “No source: this constraint does nothing.” 来源为 None 时会出现；删除来源对象时也会出现：按钮会自动变为 None。
- “No axes: this constraint does nothing.” 三个轴都未勾选时会出现。

**示例：**

- **角色脚下的圆形影子：**一个带有深色斑块的平面，勾选 Copy X 和 Copy Y，不勾选 Copy Z。它会在整个地面上跟在角色脚下，角色跳起时影子仍然留在地上。
- **永远走不到的天空：**一个画着天空的大球体，来源设为 **View**。天空始终以相机为中心，所以无论走多远，都永远到不了边缘。
- **跟随角色的灯光：**一盏以角色为来源的灯光，只勾选 Copy X 和 Copy Y。它从上方跟着角色，保持灯光自身的高度。

## Copy Rotation

![完整的 Constraints 选项卡，立方体上加了 Copy Rotation 约束](../tutoriales/img/restricciones-copiar-rotacion.webp)

**复制另一个对象的旋转**：对象会和来源一样旋转，但不会离开自己的位置。

| 属性 | 作用 |
|---|---|
| Source | 从哪里复制：**None**、**View**（正在绘制的那台相机），或者场景中除它自己以及挂在它下面的对象之外的某个对象。 |
| Copy X、Copy Y、Copy Z | 复制哪些旋转，使用的轴与 Transform 卡片中的旋转相同。三个都勾选时，对象的朝向与来源完全相同；只勾选一两个时，只复制这些角度，其余的保持对象自身的值。 |

它的提示与 Copy Location 相同（“No source…”和“No axes…”）。Influence 取中间值时，旋转总是走最短的路径。

**示例：**

- **酒吧的吊扇：**只为其中一台的扇叶制作旋转动画，其他吊扇的扇叶复制它的旋转。由于它们都是笔直吊着的，三个轴都勾选就够了。要改变所有吊扇的转速，只需修改那一台的动画。
- **在第一人称视角下固定在屏幕上的东西**（游戏中的手和武器、飞船的驾驶舱）：在同一个对象上加两个约束，Copy Location 和 Copy Rotation，来源都设为 **View**。对象会跟着相机走，并随相机一起旋转。在 Edit Mode 中移动网格，让它位于前方、偏下、偏右的位置。

## Billboard

![完整的 Constraints 选项卡，立方体上加了 Billboard 约束](../tutoriales/img/restricciones-billboard.webp)

让对象**正对相机**：它会自动旋转，始终面向屏幕。它没有来源：始终是正在绘制的那台相机。

| 属性 | 作用 |
|---|---|
| Mode | **Upright (does not tilt)**：只左右转动，就像一个人转身，并且始终保持直立。**Face the camera**：相机在上方或下方时，还会倾斜以面向相机。 |

Billboard 对齐的是屏幕的**平面**，而不是相机所在的点：视图中所有的 billboard 都与屏幕平行。

Influence 为 100 时，旋转由 billboard 决定，Transform 卡片中的旋转不起作用。如果平面显示为侧面朝前，就在 Edit Mode 中旋转它（由于 Show in Edit Mode 默认关闭，在那里看到的是没有约束的样子）。

卡片上的提示：“With influence between 0 and 100 the billboard can flip 180 degrees when it crosses the camera. Use 100% to avoid it.” 这是它与不断旋转的朝向混合的方式造成的：如果这种翻转让你困扰，就使用 100 %。

**示例：**

- **低成本的树：**一个带有树木照片（带透明）的平面，模式设为 Upright (does not tilt)。从任何方向看都像一棵完整的树，而它只是一个平面：非常适合在 Nokia N95 上铺满一片森林。
- **烟雾、火花、灯的光晕、背景中的太阳：**一个带纹理的平面，模式设为 Face the camera，这样从上方看也是正面。
- **显示角色名字的牌子或血条**，放在头顶上：使用 Face the camera，并设为角色的子级，让它跟着角色。

## Child Of

![完整的 Constraints 选项卡，立方体上加了 Child Of 约束](../tutoriales/img/restricciones-child-of.webp)

让对象表现得像另一个对象或骨架中某根**骨骼**的**子级**，即使它在 Outliner 中挂在别的地方。来源移动、旋转或缩放时，它都会跟着，就像粘在上面一样。

| 属性 | 作用 |
|---|---|
| Source | 充当父级的对象：**None**，或者场景中除它自己以及挂在它下面的对象之外的某个对象。这里没有 View 选项。 |
| Bone | 仅当来源是骨架时：它挂在哪根骨骼上。**None** 表示跟随整个骨架。 |
| Location | 是否跟随来源的移动。 |
| Rotation | 来源旋转时它是否旋转。 |
| Scale | 是否随来源一起变大或变小。 |
| Set Inverse | 把对象留在添加约束之前的位置，并从那一刻起让它跟随来源。 |
| Clear Inverse | 重新从来源开始测量对象的位置：Location 为 0, 0, 0 时，它正好位于来源处（或骨骼的根部）。 |

如果删除了来源，会出现提示“No source: this constraint does nothing.”，和其他约束一样。

### 设置或清除逆矩阵

选择来源时，对象会跳一下：它的位置改为从来源开始测量。有两种工作方式：

- **先摆好再设置：**把对象放到它该在的位置（例如手中的剑），选择来源和骨骼，然后点击 **Set Inverse**：它会回到你放的位置，并从那里开始跟随来源。
- **清除后输入：**使用 **Clear Inverse** 后，对象的 Transform 卡片就变成了到来源的距离。适合知道确切数值的情况：Location 设为 0, 0, 0 就会把它正好放在骨骼上。

约束创建时逆矩阵是清除状态，所以选择来源时对象会跳一下。

### Child Of 中的 Influence

为 0 时由对象真正的父级（Outliner 中的那个）决定，为 100 时由来源决定。所以，一把剑可以在 Outliner 中是角色的子级（这样把角色带到别处时，剑会跟着走），同时还对手部使用 Child Of：它会跟随手部，而不会被移动两次。

**示例：**

- **Leon 手中的武器：**Child Of，以 Leon 的骨架为来源，在 Bone 中选择右手的骨骼；把武器在手中摆好，然后点击 Set Inverse。对于刚性物体，这比用骨架让网格变形轻量得多，在 Nokia N95 上差别很明显。
- **帽子或眼镜：**做法相同，使用头部的骨骼。
- **跟随但不转动的相机：**只勾选 Location。相机会以相同的距离跟着角色，但角色转身时它不会跟着转。
- **移动平台上的物体：**对平台使用 Child Of，勾选 Location 和 Rotation，让它随平台一起移动，而不必改变它在 Outliner 中的位置。

## 何时使用哪一种

| 要让对象…… | 约束 |
|---|---|
| 移到另一个对象或相机所在的位置 | Copy Location |
| 和另一个对象或相机一样旋转 | Copy Rotation |
| 始终正对相机 | Billboard |
| 跟随另一个对象或一根骨骼，并保持距离 | Child Of |

如果两个对象互相复制（A 复制 B，B 又复制 A），Whisk3D 会打断这个循环以免卡死，并在 [Console](consola.md) 中给出提示：其中一个会保持自己的位置。解决办法是去掉其中一个约束。
