# 移动、旋转和缩放

在 Object Mode、Edit Mode、Pose 和骨骼编辑中，用法都一样。

| 功能 | 说明 | 快捷键 |
|---|---|---|
| Move（平移） | 所选内容跟随指针移动。 | <kbd>G</kbd> |
| Rotate | 绕轴心旋转。再按一次 <kbd>R</kbd> 可在自由旋转（轨迹球）和环绕旋转之间切换。 | <kbd>R</kbd> |
| Scale | 以轴心为中心放大或缩小。 | <kbd>S</kbd> |
| 约束到某个轴 | 在变换过程中使用。再按一次会依次切换 Global → Local → View → 自由。 | <kbd>X</kbd> / <kbd>Y</kbd> / <kbd>Z</kbd> |
| 约束到某个平面 | 排除该轴（在另外两个轴上移动）。 | <kbd>Shift+X</kbd> / <kbd>Shift+Y</kbd> / <kbd>Shift+Z</kbd> |
| 精确数值 | 输入一个数字或算式（`2*3`、`(1+0.5)/2`）。<kbd>-</kbd> 反转正负号，<kbd>Backspace</kbd> 删除。 | 数字键 |
| Confirm | 确认操作。 | 左键单击、<kbd>Enter</kbd>、绿色对勾 |
| Cancel | 一切恢复原状。 | <kbd>Esc</kbd>、右键单击、红色叉号 |
| 微调 | 一点一点地移动、旋转或缩放。 | 方向键 |

变换进行期间，顶部栏会显示正在进行的操作，例如“Move X 1.5 along global X”。在触屏上，点一下这个栏会打开数字键盘。

## Gizmo

在 Object Mode 和 Edit Mode 中，Gizmo 显示在轴心处（可以在 Overlays → Gizmo 中开关）。

| 功能 | 说明 |
|---|---|
| 移动 Gizmo | 箭头 = 单个轴；方块 = 一个平面；中心圆 = 自由移动。 |
| 旋转 Gizmo | 每个轴一个彩色半圆，一个白色圆环用于面向视图旋转，内部区域用于自由旋转。 |
| 缩放 Gizmo | 每个轴一个方形端点；中心圆用于等比缩放。 |
| 切换 Gizmo | 在 Gizmo 上快速单击（或轻点）一下而不拖动，会从 Move 切换到 Rotate，再到 Scale，然后回到 Move。 |

## 调整上一步操作

移动、旋转或缩放之后（在 Object Mode 或 Edit Mode 中），左下角会出现一个面板，显示刚才的操作：X、Y、Z 数值（或角度）、方向，以及比例编辑及其选项。修改某个数值，会用新值重新执行该操作。**Cancel** 会撤销该操作，**Accept** 则保留它。在面板外单击也等于接受。面板打开期间，3D Viewport 的工具栏会隐藏。

面板带有绿色边框，因为它是拥有焦点的窗口。如果它高于屏幕高度的一半，就会缩小到一半高，你可以用手指拖动（不要碰到选项）、用滚轮或方向键来滚动。使用键盘或手机时：方向键在各行之间移动，<kbd>OK</kbd> / <kbd>Enter</kbd> 编辑数值而不关闭面板，**Accept**、<kbd>Esc</kbd> 或 <kbd>Delete</kbd>（N95 上是 <kbd>C</kbd>）会关闭面板并保留修改，只有 **Cancel** 才会撤销。

## 工具栏

工具栏上有 Undo 和 Redo、最近使用过的操作，以及比例编辑按钮。变换期间，它会显示对勾（接受）、叉号（取消）、方向以及 X / Y / Z 轴（同时开启两个轴 = 一个平面）。在触屏上，挤出之后会出现 **Repeat**，它会确认当前挤出并再挤出一次。
