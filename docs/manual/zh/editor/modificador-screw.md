# Screw

**Screw**（螺旋）修改器让一个轮廓绕某个轴旋转，并生成它旋转时扫过的表面，就像车床一样。你只需画出花瓶、高脚杯或瓶子的半边轮廓，Screw 就会把它变成完整的物体。如果轮廓在旋转的同时还向上升，就会得到螺纹或弹簧。

![完整的 Modifiers 选项卡，立方体上加了 Screw 修改器](../tutoriales/img/modificador-tornillo.webp)

## 如何添加

1. 选中带有轮廓的网格。
2. 在 Properties 中，打开 **Modifiers** 选项卡（扳手图标）。
3. 点击 **Add**，选择 **Screw**。

它在列表中以内部名称 **Screw** 显示，下方会展开一张包含其参数的卡片。和所有修改器一样，它不会破坏网格：轮廓依然存在，你可以一边编辑它一边看结果。你可以关闭它，用 **Move Up** 和 **Move Down** 调整它的位置，用 **Remove** 移除它，或者用 **Apply Modifier** 烘焙它。

## 轮廓

轮廓是一条线：由边连接起来的顶点，没有面。旋转轴经过网格的**原点**，所以每个顶点到原点的距离，就是物体在那个高度上的半径。一种画法如下：

1. **Add → Mesh → Vertex** 在原点创建一个独立的顶点，并直接进入 Edit Mode。
2. 从正面观看（参见[在 3D Viewport 中导航](../tutoriales/navegacion.md#前视图侧视图和顶视图)）。
3. 用 **Extrude Vertices**（Mesh → Vertex 菜单）逐点挤出下一个顶点：先向侧面挤出做底部，再向上挤出做侧壁。

位于轴上的顶点会把物体封闭起来：第一个顶点在原点，就是花瓶底部的中心。

## 参数

| 参数 | 作用 |
|---|---|
| Display in Viewport | 关闭后不旋转：视图中和渲染时都只显示轮廓。 |
| Display in Edit Mode | 关闭后，编辑轮廓时只显示那条线。 |
| Angle | 轮廓从第一步到最后一步旋转的度数（默认为 360，即一整圈）。设为 180 时得到半个物体。负值会朝反方向旋转。可以超过 360：设为 1080 时转三圈。 |
| Screw | 从旋转开始到结束，轮廓沿轴上升多少米。为 0 时就是车床（花瓶、高脚杯、瓶子）；为其他值时得到螺纹或弹簧。 |
| Axis | 绕哪个轴旋转：X、Y 或 Z。默认为 **Z**，即竖直轴：在前视图中画的轮廓会立起来，就像放在桌上的花瓶。 |
| Steps Viewport | 在视图中沿旋转方向生成多少份轮廓副本，范围为 2 到 512（默认为 16）。步数越多，越圆，也越耗资源。 |
| Render | 执行 **Render Image** 或 **Render Animation** 时使用的步数（默认为 32）。 |
| Stretch U | 沿旋转方向生成 UV 坐标，让纹理像标签一样包裹物体。 |
| Stretch V | 沿轮廓从上到下生成 UV 坐标。两者都关闭时没有 UV。 |
| Smooth | 对生成的表面使用平滑着色：看起来是圆滑的，而不是一个个平面。默认开启。 |
| Merge | 焊接落在同一位置的顶点：轮廓上接触到轴的顶点（底部、封口瓶子的瓶口），以及旋转一圈闭合处的接缝。默认开启。 |
| Flip Normals | 翻转面的朝向。如果物体看起来是反的、发暗，或者像是从内部看过去的，就用它。 |
| Apply Modifier | 按 **Steps Viewport** 把结果烘焙到网格中。见下面的说明。 |

只有当 Angle 为 360 且 Screw 为 0 时，这一圈才会自动闭合、没有接缝。如果是其他角度，或者轮廓在上升，起点和终点就会保持开口。

## 示例

- **花瓶：**半边轮廓，Angle 360，Screw 0，步数在 16 到 32 之间。
- **螺纹：**一段远离轴的短轮廓，Angle 1080，Screw 设为 3：转三圈，每圈上升一米。调高步数，免得螺旋看起来折折弯弯的。

![Nokia](../tutoriales/img/icono-nokia.svg) 在 Nokia N95 上，每多一步就要多绘制一份轮廓副本。建模时把 Steps Viewport 设得低一些，把高的步数留给 Render。

> [!NOTE]
> 对 Screw 执行 Apply Modifier 会烘焙列表中**所有**已开启的修改器，而不只是这一个，并清空列表：已关闭的修改器，以及不生成几何体的修改器（例如 [Armature](modificador-esqueleto.md)），也会一并移除。此操作可以撤销。
