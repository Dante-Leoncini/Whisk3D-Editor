# Empty

**Empty** 是没有网格的对象：渲染时和游戏中都看不到它。它用作参考点：作为挂在它下面的其他对象旋转或缩放的轴心，作为相机或约束瞄准的位置，或者作为动画的控制器。用 **Add → Empty** 在 3D 光标处添加。如何添加和移动对象，请参阅 [Object Mode](../tutoriales/modo-objeto.md) 教程。

在 3D Viewport 中，它用线条绘制。新建的 Empty 是一个**平躺在地面上的圆**，容易看到，也容易抓取。绘制的形状、大小和旋转可以在它的卡片中更改。这**只影响它的显示方式**：不会改变对象本身、它的变换，也不会影响它的子级。

## 选项卡

| 选项卡 | 内容 |
|---|---|
| Object | 位置、旋转、缩放、名称和可见性，和所有对象一样：参见 [3D Mesh](objeto-malla.md#object-选项卡)。缩放 Empty 也会缩放它的子级。 |
| Empty（十字图标） | 即下面的卡片。 |
| Constraints | 参见 [Constraints](restricciones.md)。 |
| Scripts | 对象的 Lua 脚本。参见 [Whisk3D 中的 Lua](../lua/README.md)。 |

## Empty 卡片

| 属性 | 作用 |
|---|---|
| Shape | 绘制方式，每种都有自己的图标：**Cross**（三个轴）、**Square**、**Cube**、**Circle** 或 **Sphere**（三个圆，每个轴一个）。正方形和圆在创建时平躺在地面上。在小屏幕上（Nokia N95、PSP、3DS 和 Dreamcast），圆和球体只用一半的线条绘制：在那些屏幕上看不出差别，设备要绘制的也更少。 |
| Size | 绘制图形的尺寸，单位为米，从一端量到另一端。1 就是一米。 |
| Rotation X, Y, Z | 旋转绘制的图形，单位为度。例如，**X** 设为 90 的圆会立起来。 |

这些设置都不会移动或旋转对象：Empty 仍然在原来的位置，它的子级也不受任何影响。这些设置会随项目一起保存。

## 用途

- **轴心：**作为 Empty 子级的对象，会以 Empty 为中心旋转和缩放。例如，一个球的父级是放在它底部的 Empty，缩放这个 Empty 时，球就会被压扁在地面上。
- **整理场景：**挂在同一个 Empty 下的多个对象，只需移动这个 Empty 就能一起移动。
- **目标：**[约束](restricciones.md)可以瞄准一个 Empty，例如让相机一直注视着它。
