# Boolean

**Boolean** 修改器把网格和另一个网格组合起来：从中减去另一个网格的体积、加上它的体积，或者只保留两者共有的部分。手工建模很费劲的东西都可以用它：墙上的窗洞、杯子的内腔、一道槽，或者把两个部件熔合成一个。

![完整的 Modifiers 选项卡，立方体上加了 Boolean 修改器](../tutoriales/img/modificador-booleano.webp)

## 如何添加

1. 选中要改变的网格（例如墙）。
2. 在 Properties 中，打开 **Modifiers** 选项卡（扳手图标）。
3. 点击 **Add**，选择 **Boolean**。

它在列表中以内部名称 **Boolean** 显示，下方会展开一张包含其参数的卡片。和所有修改器一样，它不会破坏网格：墙在底下依然完整，移除修改器后洞就消失了。你可以关闭它，用 **Move Up** 和 **Move Down** 调整它的位置，用 **Remove** 移除它，或者用 **Apply Modifier** 烘焙它。

## 参数

| 参数 | 作用 |
|---|---|
| Display in Viewport | 关闭后不执行运算：视图中和渲染时显示的都是原始网格。 |
| Display in Edit Mode | 关闭后，编辑时显示的是未经运算的网格。 |
| Intersect | 只保留同时位于两个网格内部的部分。 |
| Union | 把两者合并成一个表面，并去掉留在内部的面。 |
| Difference | 从这个网格中减去另一个网格的体积：打洞就用它。默认选中。 |
| Object | 另一个网格，即**切割体**。设为 **None** 时不起作用。列表会显示场景中的所有对象，但只有网格才有效。 |
| Apply Modifier | 把结果烘焙到网格中。见下面的说明。 |

选中的运算显示为绿色。

## 示例：墙上的窗户

1. 添加一个 **Cube**，把它缩放成一面墙：又宽又高又薄。
2. 再添加一个 **Cube**（要做圆窗就添加 **Cylinder**），放到窗户的位置，让它从墙的一侧穿到另一侧。
3. 选中墙，给它添加 **Boolean**，保持 **Difference**，并在 **Object** 中选择切割体。
4. 隐藏切割体（使用 [Object Mode](modo-objeto.md) 的 Hide / Show，或在 Object 选项卡中取消勾选 **Visible**）。洞就留下来了。

隐藏的切割体仍然会切割。要移动它，请重新显示它，或在 Outliner 中选中它。

## 值得了解的事项

- 两个网格都必须是**封闭的**，表面上不能有洞：否则 Boolean 无法判断哪些在内部、哪些在外部。
- 移动、旋转、缩放或编辑切割体时，切口会立即更新。这样你可以一边看结果一边调整窗户。
- 切割没有碰到的面保持原样：四边形仍然是四边形。被切到的面会变成多边形，而不是三角形，因此应用之后网格仍然便于编辑。
- 切割体带来的面（例如窗洞内侧的边缘）使用网格的第一个材质。
- UV 和顶点颜色会保留下来；在切割处会进行插值。
- 位于同一平面上的部分不会合并：两个贴在一起的盒子做并集后，顶面会被分成好几块。

![Nokia](../tutoriales/img/icono-nokia.svg) 在 Nokia N95 上，每次移动或编辑切割体时都会重新计算切割。对于大型网格，先把它调整好，再应用修改器，然后继续处理已经切好的网格。

> [!NOTE]
> 对 Boolean 执行 Apply Modifier 会烘焙列表中**所有**已开启的修改器，而不只是这一个，并清空列表：已关闭的修改器，以及不生成几何体的修改器（例如 [Armature](modificador-esqueleto.md)），也会一并移除。此操作可以撤销。切割体不会被删除：它会作为一个普通对象保留下来。
