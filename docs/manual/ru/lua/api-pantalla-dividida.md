# Разделённый экран (два игрока на одном устройстве)

| Функция | Что делает |
|---|---|
| `setViews(n [, "lado" \| "up"])` | `2` делит экран на два (рядом друг с другом или один над другим); `1` возвращает целый экран. 2D-интерфейс (HUD) рисуется один раз, поверх обоих. |
| `setCameraView(i, camera)` | Камера вида `i` (1 или 2). Если не задана — активная. |
| `view() → i, n` | Вид, который сейчас рисуется (1 или 2; 0 вне рисования), и сколько всего видов. |
| `beforeView(i)` | (Её определяет твой скрипт.) Движок вызывает её перед рисованием каждого вида, в скрипте, который вызвал `setViews`. Здесь ты разворачиваешь к ЭТОЙ камере то, что смотрит на камеру (таблички, частицы), или прячешь то, что этому виду видеть не нужно. Не двигай ничего, что меняется со временем: это делается в `update`. |

Каждая половина — это целое изображение со своей камерой: кадр игры (соотношение сторон камеры) делится на две части.

## У каждого свой геймпад

`button`, `buttonPressed`, `stick` и `trigger` принимают **номер геймпада** (от 1 до 4, в порядке, в котором их впервые
тронули): `button("a", 2)`, `stick("left", 1)`. Без номера — любой (все вместе), как всегда. У клавиатуры номера нет:
распредели её сам (например, игрок 1 — стрелки и цифры, игрок 2 — WASD и буквы; на Nokia с клавиатурой QWERTY буквы
тоже приходят).

```lua
function update(dt)
  local x1, y1 = stick("left", 1)
  local x2, y2 = stick("left", 2)
  if key("w") then y2 = -1 end
  move(jugador1, x1 * dt * 5, y1 * dt * 5, 0)
  move(jugador2, x2 * dt * 5, y2 * dt * 5, 0)
end
```
