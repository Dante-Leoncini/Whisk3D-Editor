# Разделённый экран (два игрока на одном устройстве)

| Функция | Что делает |
|---|---|
| `setVistas(n [, "lado" \| "arriba"])` | `2` делит экран на два (рядом друг с другом или один над другим); `1` возвращает целый экран. 2D-интерфейс (HUD) рисуется один раз, поверх обоих. |
| `setVistaCamara(i, camara)` | Камера вида `i` (1 или 2). Если не задана — активная. |
| `vista() → i, n` | Вид, который сейчас рисуется (1 или 2; 0 вне рисования), и сколько всего видов. |
| `antesDeVista(i)` | (Её определяет твой скрипт.) Движок вызывает её перед рисованием каждого вида, в скрипте, который вызвал `setVistas`. Здесь ты разворачиваешь к ЭТОЙ камере то, что смотрит на камеру (таблички, частицы), или прячешь то, что этому виду видеть не нужно. Не двигай ничего, что меняется со временем: это делается в `actualizar`. |

Каждая половина — это целое изображение со своей камерой: кадр игры (соотношение сторон камеры) делится на две части.

## У каждого свой геймпад

`boton`, `botonApretado`, `stick` и `gatillo` принимают **номер геймпада** (от 1 до 4, в порядке, в котором их впервые
тронули): `boton("a", 2)`, `stick("izq", 1)`. Без номера — любой (все вместе), как всегда. У клавиатуры номера нет:
распредели её сам (например, игрок 1 — стрелки и цифры, игрок 2 — WASD и буквы; на Nokia с клавиатурой QWERTY буквы
тоже приходят).

```lua
function actualizar(dt)
  local x1, y1 = stick("izq", 1)
  local x2, y2 = stick("izq", 2)
  if tecla("w") then y2 = -1 end
  mover(jugador1, x1 * dt * 5, 0, y1 * dt * 5)
  mover(jugador2, x2 * dt * 5, 0, y2 * dt * 5)
end
```
