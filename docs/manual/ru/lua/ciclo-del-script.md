# Когда движок вызывает твой скрипт

Твой скрипт определяет функции с особыми именами, и движок сам вызывает их в нужный момент. Все они необязательны: пиши только те, что тебе нужны.

| Функция | Когда вызывается |
|---|---|
| `inicio()` | Один раз, при нажатии Play (или сразу после создания объекта через `instanciar`). Нужна, чтобы найти объекты и подготовить переменные. |
| `actualizar(dt)` | В каждом кадре, пока объект **видим** и находится в активной сцене. `dt` — секунды, прошедшие с предыдущего кадра (от 0.001 до 0.1). |
| `alEntrar(otro, miHitbox, suHitbox)` | Когда хитбокс начинает касаться другого. |
| `alQuedarse(otro, miHitbox, suHitbox)` | В каждом кадре, пока они продолжают касаться друг друга. |
| `alSalir(otro, miHitbox, suHitbox)` | Когда они перестают касаться (а также если один из них скрывается или отключается). |
| `alTocar(otro, impulso, x, y, z, nx, ny, nz)` | Когда сталкиваются два **твёрдых тела**. `x, y, z` — точка контакта, а `nx, ny, nz` — направление к другому телу. |

События хитбокса получают скрипты самого хитбокса и скрипты его родительского объекта. Если другой объект — твёрдое тело, `suHitbox` приходит как `nil`.

## Движение с dt

Всегда умножай скорости на `dt`. Так игра идёт с одинаковой скоростью и на мощном ПК, и на медленном телефоне:

```lua
function actualizar(dt)
  mover(yo(), 3 * dt, 0, 0)   -- 3 единицы в секунду в сторону +X
end
```

## Порядок внутри кадра

1. Физика (скорости, твёрдые тела) и события столкновений: `alTocar`, `alSalir`, `alEntrar`, `alQuedarse`.
2. `actualizar(dt)` всех скриптов, в порядке Аутлайнера.
3. Анимации (сцена, клипы, скелеты).
4. Конец кадра: применяются отложенные `destruir()`, добавляются созданные объекты и выполняется запрошенный `cambiarEscena()`.

## При остановке игры

При нажатии Stop все скрипты закрываются, общее пространство очищается, и сцена возвращается к состоянию до Play. Если ты редактируешь скрипт во время игры, объект перезагружает его: его переменные обнуляются, и `inicio()` вызывается снова.
