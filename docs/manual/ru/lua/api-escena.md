# Сцена: поиск, создание и удаление

| Функция | Что делает |
|---|---|
| `find(name [, root]) → obj \| nil` | Ищет объект по имени в Аутлайнере (или только внутри `root`). |
| `selected() → { obj, … }` | Объекты, выделенные в редакторе (для [кнопок](scripts-y-objetos.md#кнопки), которые работают как дополнения редактора). |
| `getName(obj) → text` | Имя объекта. |
| `getType(obj) → text` | Что это: `"mesh"`, `"light"`, `"camera"`, `"empty"`, `"armature"`, `"text"`, `"image"`, `"button"`, `"hitbox"`, `"prefab"`, `"rutina"`… (`""`, если объекта нет). |
| `instantiate(prefab [, x, y, z [, rotY [, parent]]]) → obj \| nil` | Создаёт копию префаба в этой позиции (rotY в градусах). `"Libreria/Escena"` создаёт копию из подключённой библиотеки. С `parent` копия становится потомком этого объекта (положение и поворот задаются относительно него). |
| `destroy(obj) → bool` | Удаляет объект в конце кадра. |
| `importW3D(path) → obj \| nil` | Добавляет в сцену другой файл .w3d во время игры. |
| `streamLoad(obj)` / `streamUnload(obj)` / `streamAuto(obj)` | Вручную загружает или выгружает часть уровня (стриминг) или возвращает её в автоматический режим. |
| `isLoaded(obj) → bool` | Загружена ли уже эта часть. |
