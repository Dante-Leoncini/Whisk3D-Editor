# Сцены и кат-сцены

| Функция | Что делает |
|---|---|
| `changeScene(name [, restart])` | Переходит к другой сцене (меню, уровень 2…) в конце кадра. |
| `playScene(name [, "funcion"])` | Воспроизводит 3D-сцену как кат-сцену, поставив игру на паузу; по окончании вызывает указанную функцию. |
| `stopScene3D()`, `scenePlaying()` | Прерывает кат-сцену / сообщает, какая сейчас воспроизводится. |
| `draw3D([on])` | Выключает или включает весь 3D (например, за непрозрачным меню). |
