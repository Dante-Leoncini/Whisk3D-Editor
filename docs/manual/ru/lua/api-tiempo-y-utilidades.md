# Время, случайные числа и утилиты

| Функция | Что делает |
|---|---|
| `random() → 0..1`, `random(min, max) → integer` | Случайные числа. |
| `clockMs() → ms` | Миллисекунды, чтобы измерить, сколько времени что-то занимает. |
| `unixTime() → seconds, ms` | Системное время в формате Unix: секунды с 1.1.1970 по UTC и отдельно миллисекунды (0–999). |
| `unixTimeMs() → ms`, `unixTimeSec() → seconds` | То же время Unix одним числом: в миллисекундах (целое) или в секундах с дробной частью. Измерить — значит вычесть: `t = unixTimeSec() - start`. Точно с 64-битным Lua (все платформы, кроме Dreamcast; там — `unixTime()`). |
| `date([seconds [, utc]]) → table` | Дата и время для времени Unix (если не передать — текущее), местное или по UTC при `utc = true`: `year`, `month`, `day`, `hour`, `min`, `sec`, `wday` (1 = воскресенье), `yday`. |
| `luaProfile(frames [, label])` | Измеряет, какие части скрипта работают медленно (`luaProfile(0)` выключает замер). |
| `createLine(name, points)`, `linePoint(id, s)` | Плавная замкнутая кривая, которую рассчитывает движок (маршруты). |

Время с начала: сохрани `unixTimeSec()` в `start()` и потом вычти (реальное время), или суммируй `dt` в переменной (игровое время).
