# Время, случайные числа и утилиты

| Функция | Что делает |
|---|---|
| `random() → 0..1`, `random(min, max) → integer` | Случайные числа. |
| `clockMs() → ms` | Миллисекунды, чтобы измерить, сколько времени что-то занимает. |
| `luaProfile(frames [, label])` | Измеряет, какие части скрипта работают медленно (`luaProfile(0)` выключает замер). |
| `createLine(name, points)`, `linePoint(id, s)` | Плавная замкнутая кривая, которую рассчитывает движок (маршруты). |

Функции "время с начала игры" нет: суммируй `dt` в переменной.
