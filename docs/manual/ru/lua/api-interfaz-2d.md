# 2D-интерфейс и экран

| Функция | Что делает |
|---|---|
| `pantalla() → ancho, alto` | Размер холста. |
| `margenPantalla() → mx, my` | Сколько экрана остаётся с каждой стороны вокруг холста фиксированного размера, в единицах холста, до настоящих краёв (полосы вокруг кадра — тоже экран). В вертикальной ориентации с холстом 4:3 индикатор, сдвинутый на `my` вверх, прижимается к верхнему краю. |
| `marcoPantalla() → x, y, ancho, alto` | Прямоугольник 3D-изображения (кадр камеры, без полос) в единицах холста, от его центра. |
| `capturarPantalla(nombre [, conHud]) → ruta` | Копирует 3D-изображение этого кадра (когда сцена отрисована; с `conHud` — после HUD) в текстуру. Путь (`"pantalla:<nombre>"`) подходит для `setTextura`, материала или шага "Привязать текстуру" процедуры. |
| `capturaUV(nombre) → u0, v0, u1, v1` | Часть захваченной текстуры, где изображение не перевёрнуто, для `setUVRect` (или `nil`, если копия ещё не сделана: она делается при отрисовке кадра). |
| `areaSegura() → x, y, w, h` | Часть экрана без выреза (не использовать в `inicio`). |
| `escala() → f` | Без аргументов: коэффициент для подгонки размеров под экран (меньшая сторона / 480). |
| `posPx(obj) → x, y`, `setPosPx(obj, x, y)` | Положение 2D-элемента (`nil` оставляет эту ось без изменений). |
| `tamPx(obj) → w, h`, `setTamPx(obj, w, h)` | Размер 2D-элемента. |
| `cajaUI(obj) → x, y, w, h` | Прямоугольник, который элемент реально занимает (x, y = центр). |
| `setTexto(obj, valor)`, `setTam(texto, px)` | Меняет текст у текста или кнопки, а также размер шрифта. |
| `setTextura(img, "ruta.png")`, `setUVRect`, `setFlipbook` | Меняет изображение, вырезает его часть (при u1 < u0 или v1 < v0 — зеркально) или анимирует лист кадров. |
| `setOpacidad(obj, 0..1)`, `fundir(obj, objetivo, paso)` | Прозрачность и плавные переходы. |
| `setRot2D(obj, grados)` | Поворачивает 2D-элемент. |
| `chocan(a, b) → bool` | Перекрываются ли два 2D-элемента на экране. |
| `limitar(obj, area [, eje])`, `dentro(area, x [, y])` | Удерживать элемент внутри другого или проверить, находится ли точка внутри. |
| `salir()` | Закрывает игру (в редакторе ничего не делает). |
