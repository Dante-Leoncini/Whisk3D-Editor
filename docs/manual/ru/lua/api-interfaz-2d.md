# 2D-интерфейс и экран

| Функция | Что делает |
|---|---|
| `screen() → width, height` | Размер холста. |
| `screenMargin() → mx, my` | Сколько экрана остаётся с каждой стороны вокруг холста фиксированного размера, в единицах холста, до настоящих краёв (полосы вокруг кадра — тоже экран). В вертикальной ориентации с холстом 4:3 индикатор, сдвинутый на `my` вверх, прижимается к верхнему краю. |
| `screenFrame() → x, y, width, height` | Прямоугольник 3D-изображения (кадр камеры, без полос) в единицах холста, от его центра. |
| `captureScreen(name [, withHud]) → path` | Копирует 3D-изображение этого кадра (когда сцена отрисована; с `withHud` — после HUD) в текстуру. Путь (`"pantalla:<name>"`) подходит для `setTexture`, материала или шага "Привязать текстуру" процедуры. |
| `captureUV(name) → u0, v0, u1, v1` | Часть захваченной текстуры, где изображение не перевёрнуто, для `setUVRect` (или `nil`, если копия ещё не сделана: она делается при отрисовке кадра). |
| `safeArea() → x, y, w, h` | Часть экрана без выреза (не использовать в `start`). |
| `getScale() → f` | Без аргументов: коэффициент для подгонки размеров под экран (меньшая сторона / 480). |
| `getPosPx(obj) → x, y`, `setPosPx(obj, x, y)` | Положение 2D-элемента (`nil` оставляет эту ось без изменений). |
| `getSizePx(obj) → w, h`, `setSizePx(obj, w, h)` | Размер 2D-элемента. |
| `uiBox(obj) → x, y, w, h` | Прямоугольник, который элемент реально занимает (x, y = центр). |
| `setText(obj, value)`, `setSize(text, px)` | Меняет текст у текста или кнопки, а также размер шрифта. |
| `setTexture(img, "ruta.png")`, `setUVRect`, `setFlipbook` | Меняет изображение, вырезает его часть (при u1 < u0 или v1 < v0 — зеркально) или анимирует лист кадров. |
| `setOpacity(obj, 0..1)`, `fade(obj, objetivo, paso)` | Прозрачность и плавные переходы. |
| `setRot2D(obj, degrees)` | Поворачивает 2D-элемент. |
| `collide(a, b) → bool` | Перекрываются ли два 2D-элемента на экране. |
| `limit(obj, area [, axis])`, `inside(area, x [, y])` | Удерживать элемент внутри другого или проверить, находится ли точка внутри. |
| `quit()` | Закрывает игру (в редакторе ничего не делает). |
