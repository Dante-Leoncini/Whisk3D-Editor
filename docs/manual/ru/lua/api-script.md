# Скрипт и обмен данными

| Функция | Что делает |
|---|---|
| `yo() → obj` | Объект, которому принадлежит этот скрипт. |
| `objeto(prop) → obj \| nil` | Объект, выбранный в поле `prop` таблицы `propiedades`. |
| `opcion(prop) → texto` | Вариант, выбранный в выпадающем списке из `propiedades`; если ничего не выбрано — первый в списке (по умолчанию). |
| `propiedad(prop) → valor` | Собственное число, да/нет или текст этого объекта (или объявленное значение по умолчанию). |
| `parametro(prop [, def]) → número` | Как `propiedad`, но всегда число; если такого нет, возвращает `def` (или 0). |
| `objetivo() → obj \| nil` | Цель ("target") объекта-владельца. |
| `compartido(clave) → valor` | Читает общее пространство всех скриптов. |
| `setCompartido(clave, valor)` | Записывает число, да/нет или текст в общее пространство; `nil` удаляет значение. |
