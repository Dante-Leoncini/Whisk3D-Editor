# Скрипт и обмен данными

| Функция | Что делает |
|---|---|
| `self() → obj` | Объект, которому принадлежит этот скрипт. |
| `object(prop) → obj \| nil` | Объект, выбранный в поле `prop` таблицы `properties`. |
| `option(prop) → text` | Вариант, выбранный в выпадающем списке из `properties`; если ничего не выбрано — первый в списке (по умолчанию). |
| `property(prop) → value` | Собственное число, да/нет или текст этого объекта (или объявленное значение по умолчанию). |
| `param(prop [, def]) → número` | Как `property`, но всегда число; если такого нет, возвращает `def` (или 0). |
| `target() → obj \| nil` | Цель ("target") объекта-владельца. |
| `getShared(clave) → value` | Читает общее пространство всех скриптов. |
| `setShared(clave, value)` | Записывает число, да/нет или текст в общее пространство; `nil` удаляет значение. |
