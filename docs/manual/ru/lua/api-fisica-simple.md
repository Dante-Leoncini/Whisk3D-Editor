# Простая физика (скорость и отскоки)

| Функция | Что делает |
|---|---|
| `getVelocity(obj, vx [, vy, vz])` / `getVelocity(obj) → vx, vy, vz` | Задаёшь скорость, и движок сам двигает объект. |
| `accelerate(obj, factor [, tope])` | Ускоряет объект, умножая его скорость. |
| `box(obj [, x, y, z])` | Размер его коробки столкновений: в 3D — ширина (X), глубина (Y) и высота (Z); в 2D — ширина и высота в пикселях. |
| `bounce(obj, other)`, `bounceOn(obj, area [, sides])`, `bounceInside(obj, area)` | Отскоки от другого объекта или от границ области (возвращают `true`, если отскок был). |
