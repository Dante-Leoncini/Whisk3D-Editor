# Клавиатура, геймпад, сенсорный экран и мышь

| Функция | Что делает |
|---|---|
| `key(name) → bool` | Клавиша нажата (пока ты её удерживаешь). |
| `keyPressed(name) → bool` | Клавиша нажата именно в этом кадре (один раз за нажатие). |
| `button(name [, gamepad])`, `buttonPressed(name [, gamepad])` | То же самое для кнопки геймпада. С `gamepad` (от 1 до 4) — кнопка этого геймпада; без него — любого. |
| `stick(["left"\|"right"] [, gamepad]) → x, y` | Стик геймпада, от -1 до 1 (вверх — это -1). |
| `trigger(["left"\|"right"] [, gamepad]) → 0..1` | Аналоговый курок. |
| `controls() → n`, `control([n]) → name, tipo` | Сколько геймпадов подключено и какого они типа (`"xbox"`, `"playstation"`, `"nintendo"`, `"generico"`). |
| `tap() → x, y, touching` | Палец (или клик мыши) на экране. |
| `finger([n]) → x, y, active` | Мультитач: палец номер n (от 1 до 4). |
| `touch() → bool` | Экран сенсорный: телефон или планшет (Android, браузер на iPhone…) или любое устройство, на котором уже касались экрана. Чтобы показывать экранные элементы управления только там, где они нужны. |
| `tilt() → x, y, z` | Акселерометр телефона, в g, по осям экрана так, как его видно (уже с учётом поворота): `x` — насколько он повёрнут вправо, как руль (синус угла); если держать его вертикально и ровно, получается `y = 1`, а если положить экраном вверх — `z = 1`. `nil`, если у устройства нет акселерометра. |
| `vibrate(ms [, force])` | Вибрация длительностью `ms` миллисекунд с силой `force` от 0 до 1: вибромотор телефона (Android, браузер) и моторы геймпадов (ПК). На телефоне сила укорачивает импульс. Ничего не делает, если вибрировать нечем или если игрок отключил вибрацию. |
| `pressed(obj) → bool` | Этого 2D-элемента коснулись или кликнули по нему в этом кадре (кнопки). |
| `mouse() → x, y, dentro` | Где находится мышь. |
| `captureMouse(bool)`, `mouseRel() → dx, dy`, `mouseCaptured()` | Захват мыши, чтобы осматриваться мышью (игры от первого лица). На ПК и в браузере; в браузере мышь захватывается при первом клике или нажатии клавиши в игре. <kbd>Esc</kbd> освобождает её и ставит игру на паузу. |
