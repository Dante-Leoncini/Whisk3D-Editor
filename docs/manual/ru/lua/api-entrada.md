# Клавиатура, геймпад, сенсорный экран и мышь

| Функция | Что делает |
|---|---|
| `tecla(nombre) → bool` | Клавиша нажата (пока ты её удерживаешь). |
| `teclaApretada(nombre) → bool` | Клавиша нажата именно в этом кадре (один раз за нажатие). |
| `boton(nombre [, mando])`, `botonApretado(nombre [, mando])` | То же самое для кнопки геймпада. С `mando` (от 1 до 4) — кнопка этого геймпада; без него — любого. |
| `stick(["izq"\|"der"] [, mando]) → x, y` | Стик геймпада, от -1 до 1 (вверх — это -1). |
| `gatillo(["izq"\|"der"] [, mando]) → 0..1` | Аналоговый курок. |
| `controles() → n`, `control([n]) → nombre, tipo` | Сколько геймпадов подключено и какого они типа (`"xbox"`, `"playstation"`, `"nintendo"`, `"generico"`). |
| `toque() → x, y, tocando` | Палец (или клик мыши) на экране. |
| `dedo([n]) → x, y, activo` | Мультитач: палец номер n (от 1 до 4). |
| `tactil() → bool` | Экран сенсорный: телефон или планшет (Android, браузер на iPhone…) или любое устройство, на котором уже касались экрана. Чтобы показывать экранные элементы управления только там, где они нужны. |
| `inclinacion() → x, y, z` | Акселерометр телефона, в g, по осям экрана так, как его видно (уже с учётом поворота): `x` — насколько он повёрнут вправо, как руль (синус угла); если держать его вертикально и ровно, получается `y = 1`, а если положить экраном вверх — `z = 1`. `nil`, если у устройства нет акселерометра. |
| `vibrar(ms [, fuerza])` | Вибрация длительностью `ms` миллисекунд с силой `fuerza` от 0 до 1: вибромотор телефона (Android, браузер) и моторы геймпадов (ПК). На телефоне сила укорачивает импульс. Ничего не делает, если вибрировать нечем или если игрок отключил вибрацию. |
| `apretado(obj) → bool` | Этого 2D-элемента коснулись или кликнули по нему в этом кадре (кнопки). |
| `raton() → x, y, dentro` | Где находится мышь. |
| `capturarRaton(bool)`, `ratonRel() → dx, dy`, `ratonCapturado()` | Захват мыши, чтобы осматриваться мышью (игры от первого лица). На ПК и в браузере; в браузере мышь захватывается при первом клике или нажатии клавиши в игре. <kbd>Esc</kbd> освобождает её и ставит игру на паузу. |
