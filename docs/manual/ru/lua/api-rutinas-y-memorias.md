# Процедуры и память

Процедуры (списки шагов отрисовки, которые собираются на панели Свойства) могут читать значения, записанные из Lua. Каждый блок памяти — это именованный набор из 256 чисел, и шаги читают его как `@nombre[i]`.

| Функция | Что делает |
|---|---|
| `setMemoria(nombre, i, v)`, `memoria(nombre, i)`, `setMemorias(nombre, i, v1, v2, ...)` | Запись и чтение памяти (индекс от **0** до 255). |
| `setPaso(rutina, i, campo, ...)`, `leerPaso(rutina, i, campo)` | Изменить или прочитать шаг процедуры (поля: `"on"`, `"n"`, `"color"`, `"ref"`, `"modo"`, `"entero"`). |
| `paso(nombre, ...)` | Выполняет шаг отрисовки; работает только внутри функции, вызванной шагом процедуры "Вызвать Lua". |

В процедуре, у которой **Повтор** больше 1, блок памяти `bucle` сообщает номер текущего прохода: `@bucle[0]` — текущий проход (начиная с 0), а `@bucle[1]` — общее количество.
