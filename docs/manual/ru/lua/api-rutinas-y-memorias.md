# Процедуры и память

Процедуры (списки шагов отрисовки, которые собираются на панели Свойства) могут читать значения, записанные из Lua. Каждый блок памяти — это именованный набор из 256 чисел, и шаги читают его как `@nombre[i]`.

| Функция | Что делает |
|---|---|
| `setMemory(name, i, v)`, `getMemory(name, i)`, `setMemories(name, i, v1, v2, ...)` | Запись и чтение памяти (индекс от **0** до 255). |
| `setStep(routine, i, field, ...)`, `getStep(routine, i, field)` | Изменить или прочитать шаг процедуры (поля: `"on"`, `"n"`, `"color"`, `"ref"`, `"modo"`, `"entero"`). |
| `step(name, ...)` | Выполняет шаг отрисовки; работает только внутри функции, вызванной шагом процедуры "Вызвать Lua". |

В процедуре, у которой **Повтор** больше 1, блок памяти `loop` сообщает номер текущего прохода: `@loop[0]` — текущий проход (начиная с 0), а `@loop[1]` — общее количество.
