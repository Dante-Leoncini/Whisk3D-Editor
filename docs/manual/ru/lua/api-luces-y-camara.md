# Свет и камера

| Функция | Что делает |
|---|---|
| `getColor(light) → r, g, b`, `setColor(light, r, g, b)` | Цвет источника света. |
| `getEnergy(light) → e`, `setEnergy(light, e)` | Его яркость, от 0 до 1 (чтобы он мерцал или постепенно гас). |
| `setActiveCamera(cam)` | Меняет камеру, через которую видна игра. |
| `getLens(cam) → fov, near, far`, `setLens(cam [, fov, near, far])` | Угол обзора и расстояния отсечения. |
| `cameraXZ() → fx, fy, rx, ry` | Куда смотрит камера в плоскости пола, по X и Y: вперёд (`fx, fy`) и вправо (`rx, ry`), чтобы двигать персонажа относительно камеры. (Название осталось с тех времён, когда полом была плоскость XZ.) |
| `screenOf(obj) → x, y, front` | Где 3D-объект находится на экране (чтобы поставить над ним 2D-метку). |
| `setRail(cam, curve [, offset])`, `setRailNode`, `setRailLook`, `getRail` | Заставить камеру следовать по кривой (рельсу). |
| `resolution() → width, height` | Реальный размер 3D-изображения в пикселях. |
