# Перемещение, вращение и масштабирование в 3D

| Функция | Что делает |
|---|---|
| `posicion(obj) → x, y, z` | Где находится объект. |
| `setPosicion(obj, x, y, z)` | Ставит его в точное место (игнорируя физику). |
| `mover(obj, dx, dy, dz)` | Сдвигает его от текущего места (используй вместе с `dt`). |
| `rotacion(obj) → x, y, z` | Его вращение в градусах. |
| `setRotacion(obj, x, y, z [, orden])` | Точное вращение, то же, что в карточке Трансформация. `orden` задаёт порядок, в котором применяются оси, например `"ZXY"` (сначала курс вокруг вертикали, как у машины). |
| `rotacionX(obj)`, `rotacionY(obj)`, `rotacionZ(obj) → градусы` | Поворот по одной оси. `rotacionZ` — поворот вокруг вертикали. |
| `setRotacionX(obj, g)`, `setRotacionY(obj, g)`, `setRotacionZ(obj, g)` | Меняет только одну ось; две другие остаются как были. Например, `setRotacionZ(obj, rotacionZ(obj) + 90 * dt)` вращает объект вокруг вертикали. |
| `girar(obj, dx, dy, dz)` | Поворачивает его вокруг собственных осей. |
| `girarHacia(obj, dx, dy [, factor])` | Плавно поворачивает его к направлению в плоскости пола (X и Y). |
| `mirarA(obj, x, y, z)` | Направляет его на точку (перед камеры). |
| `escala(obj) → sx, sy, sz` | Его масштаб. |
| `setEscala(obj, s [, sy, sz])` | Точный масштаб; с одним числом масштабирует равномерно. |
| `escalar(obj, f)` | Умножает текущий масштаб. |
| `puntoMundo(obj, x, y, z) → x, y, z` | Переводит точку объекта в мировые координаты. |
| `visible(obj) → bool`, `setVisible(obj, bool)` | Показывает или скрывает его. Скрытый объект перестаёт получать `actualizar`. |
| `setTinte(obj, r, g, b [, a])` | Меняет его цвет (значения от 0 до 1). |
