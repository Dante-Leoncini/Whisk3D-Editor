# Перемещение, вращение и масштабирование в 3D

| Функция | Что делает |
|---|---|
| `getPosition(obj) → x, y, z` | Где находится объект. |
| `setPosition(obj, x, y, z)` | Ставит его в точное место (игнорируя физику). |
| `move(obj, dx, dy, dz)` | Сдвигает его от текущего места (используй вместе с `dt`). |
| `getRotation(obj) → x, y, z` | Его вращение в градусах. |
| `setRotation(obj, x, y, z [, order])` | Точное вращение, то же, что в карточке Трансформация. `order` задаёт порядок, в котором применяются оси, например `"ZXY"` (сначала курс вокруг вертикали, как у машины). |
| `getRotationX(obj)`, `getRotationY(obj)`, `getRotationZ(obj) → градусы` | Поворот по одной оси. `getRotationZ` — поворот вокруг вертикали. |
| `setRotationX(obj, g)`, `setRotationY(obj, g)`, `setRotationZ(obj, g)` | Меняет только одну ось; две другие остаются как были. Например, `setRotationZ(obj, getRotationZ(obj) + 90 * dt)` вращает объект вокруг вертикали. |
| `rotate(obj, dx, dy, dz)` | Поворачивает его вокруг собственных осей. |
| `rotateTowards(obj, dx, dy [, factor])` | Плавно поворачивает его к направлению в плоскости пола (X и Y). |
| `lookAt(obj, x, y, z)` | Направляет его на точку (перед камеры). |
| `getScale(obj) → sx, sy, sz` | Его масштаб. |
| `setScale(obj, s [, sy, sz])` | Точный масштаб; с одним числом масштабирует равномерно. |
| `scale(obj, f)` | Умножает текущий масштаб. |
| `worldPoint(obj, x, y, z) → x, y, z` | Переводит точку объекта в мировые координаты. |
| `isVisible(obj) → bool`, `setVisible(obj, bool)` | Показывает или скрывает его. Скрытый объект перестаёт получать `update`. |
| `setTint(obj, r, g, b [, a])` | Меняет его цвет (значения от 0 до 1). |
