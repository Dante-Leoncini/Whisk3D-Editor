# Сообщения и отладка

| Функция | Что делает |
|---|---|
| `print(...)` | Пишет в журнал (лог) движка, а не на экран. |
| `info(msg)`, `warning(msg)`, `error(msg)` | Информационные сообщения, предупреждения или ошибки в журнале. `error` **не** прерывает скрипт. |
| `debugLog(msg)`, `isDebug()` | Сообщения только в отладочных сборках. |
| `logCount()`, `logLine(i)` | Читать журнал из игры (собственная консоль). |
