# Частицы, туман и видимость

| Функция | Что делает |
|---|---|
| `emit(obj [, n])`, `setEmitting(obj, bool)` | Выброс частиц или включение/выключение излучателя. |
| `getFog(obj)`, `setFog(obj, density [, r, g, b, inicio, fin])` | Чтение и изменение тумана. |
| `setSector`, `visCell`, `setVisAnchor`, `setVisCurveT`, `setBatch` | Расширенное управление тем, какие части уровня рисуются. |
