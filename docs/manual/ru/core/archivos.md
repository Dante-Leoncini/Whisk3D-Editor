# Файлы

Один API для чтения и записи: `w3dFileSystem::ReadFileBytes`, `ReadTextFile`, `WriteTextFile`, `ReadFileRange` (кусок файла, чтобы загружать меши по частям), `ListDir`, `FileExists`. Никто не вызывает `fopen` сам по себе.

`ReadFileBytes` ищет в таком порядке:

1. **Подключённая библиотека** (пути `lib:<nombre>/...`).
2. **Встроенный pak:** игра, собранная с «Ассеты: Упаковано», несёт все свои файлы внутри исполняемого файла.
3. **Смонтированный контейнер:** открытый .w3d. Контейнер **монтируется, а не распаковывается**: текстуры, шрифты, скрипты и интерфейсы загружаются прямо из zip, и никому не нужно менять свой код.
4. **Ассеты APK** (Android): относительный путь читается из APK через `AAssetManager` из NDK.
5. **Диск.**

Перед поиском пути нормализуются (без `.` и `..`). Файл .mtl, который указывал `modelos/crash/../../texturas/sombra_blob.png`, не находился ни в одном индексе, и внутри APK текстура выходила белой.

| Система | Ресурсы (`res/`) | Куда пишется |
|---|---|---|
| Windows, Linux | Рядом с исполняемым файлом (в Linux также `<prefijo>/share/Whisk3d/res`) | Папка пользователя; настройки — в папку SDL (`SDL_GetPrefPath`) |
| Android | Внутри APK | `/storage/emulated/0`; экспортированное — в «Загрузки» |
| Браузер | Упакованы в `.data`, смонтированы в `/res` | Настройки — в `localStorage`; при сохранении файл скачивается ([как](../editor/proyecto.md)) |
| Symbian | Собственные пути телефона | `E:/` (карта памяти) или `C:/` |
| Dreamcast | Romdisk внутри исполняемого файла (`/rd`) | `/ram`, который стирается при выключении |
| PSP | Рядом с `EBOOT.PBP` | `ms0:/` (или `ef0:/` на PSP Go) |
| PS Vita | Внутри `.vpk` (`app0:res`) | `ux0:` |
| 3DS | romfs из `.3dsx` (`romfs:`) | SD-карта (`sdmc:/`) |

Ещё две части модуля:

- **W3dRecursos** ведёт учёт каждого тяжёлого ресурса (текстур, мешей, анимаций): кто его использует и когда его освободить. То, что не нужно сразу, загружается порциями, понемногу в каждом кадре.
- **W3dConfig** хранит настройки в виде `clave=valor`. В браузере они идут в `localStorage`, в остальных системах — в текстовый файл. Он не выделяет динамическую память, поэтому так же работает в Symbian. Из Lua: [Сохраняемые настройки](../lua/api-configuracion.md).
