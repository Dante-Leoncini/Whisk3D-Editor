# Сеть

**w3dRed** позволяет играть по локальной сети, Wi-Fi или интернету, по UDP. Один игрок **хостит** партию (порт 47023), а остальные **ищут** её в локальной сети или **присоединяются** по адресу. Всё проходит через хост, до 8 игроков. Сообщения могут быть **надёжными** (доходят все и по порядку: «готов», «начать») или **ненадёжными** (то, что отправляется каждый кадр, где следующее сообщение заменяет потерянное).

```cpp
w3dRed::Hostear("mi_juego", "La partida de Dante", 2);
// или, с другой стороны:
w3dRed::Buscar("mi_juego");   // ... w3dRed::Partidas() ... w3dRed::Unirse(direccion);
w3dRed::Enviar(-1, datos, bytes, true);   // -1 = всем остальным
```

| Система | Сокеты |
|---|---|
| Windows | Winsock |
| Linux, macOS, Android | POSIX (список интерфейсов — начиная с Android 7) |
| Symbian | Сокеты Open C |
| Dreamcast | Сокеты KallistiOS, через сетевой адаптер |
| Браузер, PSP, PS Vita, 3DS | Пока без сети: `Soportada()` возвращает `false` |

Игра не использует сеть, если приложение ей этого не разрешает (`SetPermitida`): редактор спрашивает об этом при открытии проекта, который её использует. Из Lua: [Сетевая игра](../lua/api-red.md).
