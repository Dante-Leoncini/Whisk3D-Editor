# Руководство по Whisk3D Core

**Whisk3D Core** — это слой абстракции, на котором построен Whisk3D: один способ просить о чём-то (рисовать, воспроизводить звук, читать файлы, получать нажатия клавиш) и своя реализация для каждой системы. Это руководство для тех, кто программирует на C или C++ и хочет сделать игру прямо на Core. Черновик для проверки.

Страница проекта с примерами, которые работают в браузере: **[Whisk3D Core](https://leoncini.com.ar/proyecto.php?id=whisk3d-core&lang=ru)**. Код лежит в **[Whisk3D-Core](https://github.com/Dante-Leoncini/Whisk3D-Core)** на GitHub, под лицензией MIT.
