# Математика, сцена и форматы

Собственные **векторы, матрицы 4x4 и кватернионы** (`math/`), которые одинаково компилируются на ПК и на ретро-системах. Поверх них — **сцена** (`objects/`): объекты с иерархией «родитель — потомок», меши, материалы, источники света (направленный, точечный и прожектор), камеры и скелеты. И **анимации** (`animation/`): ключевые кадры, скелеты, вершины, флипбуки и локомоция.

Собственные форматы рассчитаны на то, чтобы маленькая машина читала их быстро:

| Формат | Что это |
|---|---|
| `.w3d` | Проект: стандартный ZIP (открывается любым архиватором). Записывается без сжатия, но читается и сжатым. Без ZIP64 |
| `.w3dm` | Геометрия в построчном текстовом виде: читаемая, редактируемая вручную и простая для чтения на N95 |
| `.w3db` | Тот же меш в двоичном виде, уже готовый для памяти: открыть его — значит скопировать массивы |
| `.w3dt` | Текстура, готовая для GPU (16 бит и готовые mipmap-уровни) |
| `.w3dpack` | Контейнер ассетов, зашифрованный ChaCha20; ключ задаёт приложение |
| Встроенный pak | Файлы собранной игры, обфусцированные XOR. Это защита от любопытных, а не криптография |
| glTF / GLB | Загрузчик и рендерер в одном заголовке (`io/w3dGltf.h`) для использования вне редактора |
