# Карточки и свойства

## Карточка

`GroupPropertie` (`Propieties/GroupPropertie.h`) — это карточка с заголовком и строками. Каждая строка — это свойство, класс, который наследуется от `PropertieBase` и указывает на твою переменную: карточка показывает её и меняет прямо там.

```cpp
GroupPropertie* player = new GroupPropertie("Jugador");
player->icon = IconType::gamepad;        // необязательно: между стрелкой и заголовком

PropFloat* vel = new PropFloat("Velocidad", " m/s");
vel->value = &velocidad;
player->properties.push_back(vel);

player->Resize(width, 0);    // высоту рассчитывает карточка
player->Render();            // в текущем начале координат
```

Карточка владеет своими строками: при её удалении они тоже удаляются.

- У заголовка есть стрелка, чтобы свернуть карточку (`open`). С `arrow = false` её нет: для всплывающего окна.
- Ниже две колонки: подпись слева и значение справа. `valueWidth` — доля ширины, которую занимает значение: по умолчанию 0.5.
- `reserveKeyBtn = true` оставляет справа от всего колонку для ромба анимации.
- Почти все строки имеют высоту строки текста плюс `gap`. Число, флажок или цвет без переменной (`value` равно `NULL`) не занимают места и не рисуются.
- `visible = false` прячет всю карточку.

У выбранной строки подпись в `accent`, значение белое и рамка белая; во время редактирования значение и рамка становятся `accent`. Строка под мышью рисуется белым: её отмечает тот, кто содержит карточку, с помощью `PropHoverGroup` и `PropHoverRow`.

## Выбрать и редактировать

`selectIndex` — выбранная строка: `-2` — никакая, `-1` — заголовок, от `0` и выше — строка.

| Функция | Что делает |
|---|---|
| `NextSelect()`, `PrevSelect()` | Переходят к строке ниже или выше. Пропускают промежутки и строки без переменной. Возвращают `true` при выходе из карточки, чтобы перейти к следующей |
| `EnterPropertieSelect()` | На заголовке сворачивает или разворачивает карточку. На строке — редактирует её |
| `button_up()`, `button_down()`, `button_left()`, `button_right()` | Во время редактирования передаются строке |
| `Cancel()` | Оставляет строку как была |

`editing` говорит, редактируется ли сейчас какая-то строка. С его помощью стрелки либо меняют значение, либо перемещают выбор:

```cpp
if (player->editing) player->button_up();   // меняет значение
else player->PrevSelect();                    // строка выше
```

Мышь обрабатывает тот, кто содержит карточку: сама она не знает, где оказалась на экране. Сверху находятся рамка (`borderGS`) и заголовок (`RowHeightGS + gapGS`). Каждая строка имеет высоту, которую возвращает её `Resize(width)`.

## Строки

| Класс | Что это | Как редактируется |
|---|---|---|
| `PropFloat` | Число | Стрелками или вводом с клавиатуры |
| `PropBool` | Флажок, прижатый вправо | OK включает или выключает его |
| `PropColor` | Квадрат цвета, прижатый вправо | OK входит в редактирование и запоминает цвет на случай отмены |
| `PropButton` | Кнопка | OK вызывает её действие |
| `PropButtonRow` | Несколько кнопок в одной строке | Влево и вправо выбирают одну; OK нажимает её |
| `PropText` | Текстовое поле | OK переводит в него фокус для ввода |
| `PropListMeshParts` | Список с прокруткой | Вверх и вниз выбирают |
| `PropLabel` | Текст для чтения, в одну или несколько строк | Не выбирается |
| `PropSeparator` | Линия | Не выбирается |
| `PropGap` | Промежуток величиной `gap` | Не выбирается |
| `PropSelectText` | Поле с подписью, без значения | Пока ничего не делает |

### Число

```cpp
PropFloat* life = new PropFloat("Vida");
life->value = &lifePlayer;
life->SetRange(0, 100);           // не выходит за эти пределы
life->integer = true;              // показывается и меняется целыми числами
life->fineStep = 1;               // вверх и вниз
life->thickStep = 10;            // влево и вправо
life->onChange = OnChangeLife;   // void AlCambiarVida()
```

| Поле | Что делает |
|---|---|
| `unit` | Текст вплотную к числу, например `°`. Это второй аргумент конструктора |
| `fineStep`, `thickStep` | Сколько прибавляют стрелки: по умолчанию 0.01 и 0.1 |
| `integer` | Показывает округлённое число, и стрелки отсчитывают от округлённого. Без этого число показывается с четырьмя знаками после запятой |
| `centered` | Число посередине своего поля |
| `arrows` | Рисует `<` и `>` по бокам. Клик по ним обрабатывает контейнер |
| `options`, `nOptions` | С `integer`: число — это индекс, и показывается название этого варианта, переведённое через `W3dMenuTranslate` |
| `accelerates` | Влево и вправо начинают с шага 1 и при повторе увеличивают его до 10 |
| `dragStep` | Насколько меняется значение на пиксель при перетаскивании. Перетаскивание делает контейнер |

`Set(v)` присваивает значение в пределах диапазона и вызывает `onChange`. Стрелки проходят через него.

Чтобы ввести число с клавиатуры:

```cpp
life->StartEditText();   // показывает значение, всё выделено
// клавиши идут в g_activeTextField: см. «Ввод и текстовые поля»
NumEditCommit();               // Enter: применяет
NumEditCancel();               // Esc: остаётся как было
```

`NumEditActive()` говорит, редактируется ли сейчас число. Текст, который не является числом, равен 0.

### Флажок

`value` указывает на `bool`. `onChange` вызывается при каждом изменении. Подпись занимает всё место слева от флажка и, если не помещается, обрезается с `..`.

### Цвет

`value` указывает на четыре `float` (RGBA). UI рисует квадрат; выбор цвета к UI не относится. Во время редактирования стрелки меняют только первый компонент.

### Кнопка

`action` — функция, которую она вызывает. `gray = true` делает её приглушённой, и она ничего не делает. `hidden = true` — строка не занимает места.

С `withLabel = true` строка состоит из имени и кнопки: имя слева, шириной в свой текст, до 55 % строки, а кнопка — на всём остальном месте. `labelChars` задаёт ширину имени, чтобы выровнять несколько строк. С `button->dropdown` у неё есть маленькая стрелка меню. Кроме того:

- `AddPrefix(action, help)` ставит перед кнопкой квадрат, чтобы показать цвет.
- `AddExtra(icon, action, help)` ставит справа до двух маленьких кнопок только с иконкой. `slotsExtras` резервирует для них место, чтобы они были выровнены между строками. `ExtraInX(x)` говорит, какая из них оказалась в этой x, для клика.

### Строка кнопок

```cpp
PropButtonRow* row = new PropButtonRow();
row->Add("Aceptar", Accept);
row->Add("Cancelar", Cancel);
player->properties.push_back(row);
```

Кнопки делят ширину поровну. Невидимые пропускаются, а остальные делят их место. `Fire(i)` нажимает кнопку `i`: её вызывает контейнер, когда клик приходится на эту часть.

### Текстовое поле

```cpp
PropText* name = new PropText("Nombre", "Jugador 1");
// в name->field.text — то, что было введено
```

`onClick`: вместо редактирования вызывает эту функцию, например, чтобы открыть файловый браузер. `error = true` окрашивает в красный рамку выбранной строки, пока в поле что-нибудь не введут. `hidden = true` — строка не занимает места. OK переводит фокус в поле через `TextFieldFocus`, которая сейчас определена в редакторе. О вводе текста см. [Ввод и текстовые поля](entrada.md).

### Текст

`PropLabel("texto")` — одна строка. `PropLabel("texto", true)` переносит по пробелам, чтобы текст поместился в ширину; слово, которое само по себе не помещается, остаётся целым. `red = true` — для ошибки. `hidden = true` — строка не занимает места.

### Список

`PropListMeshParts` показывает `rowsMax` строк, по умолчанию 3, с маленькой полосой прокрутки, если строк больше. Выбранная строка всегда остаётся на виду. `Cancel` возвращает `selectIndex` к тому, что было при входе в редактирование.

Для произвольного списка он пока не годится: в зависимости от `mode` он читает список из сцены (части меша, его UV-развёртки, цветовые слои, модификаторы, группы вершин, кости, анимации, ограничители, скрипты) или запрашивает его у хуков функций редактора (`MixRow*`, `RoutineRow*`, `PostRow*`).

## Ромб анимации

Анимируемая строка (`animProp` от 0 и выше, в `PropFloat`, `PropBool`, `PropColor` и `PropButton`) показывает справа ромб, если у карточки есть `reserveKeyBtn`. Его цвет показывает состояние:

| Состояние | Цвет | Что означает |
|---|---|---|
| 0 | Серый | Без анимации |
| 1 | `accent`, приглушённый | Анимировано, но ключевого кадра здесь нет |
| 2 | `accent` | Здесь есть ключевой кадр |
| 3 | Зелёный | Значение изменилось и не сохранено |

Ромб относится к UI; а то, какое у него состояние, — нет. Он спрашивает это у хука, который устанавливает программа, а клик вызывает другой хук:

```cpp
W3dKeyframeState = MiState;   // int MiEstado(int prop, int comp): от 0 до 3
W3dKeyframeToggle = MiToggle;   // void MiToggle(int prop, int comp): ставит или убирает ключевой кадр
```

Без хуков ромб остаётся серым. Карточка не вызывает `W3dKeyframeToggle`: его вызывает тот, кто обрабатывает клик. `g_kfFocusProp` указывает на строку, ромб которой в фокусе клавиатуры, и отмечает его белой рамкой. `W3dRenderDiamondKey(state)` рисует отдельный ромб.
