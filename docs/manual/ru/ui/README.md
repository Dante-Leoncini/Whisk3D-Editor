# Руководство по Whisk3D UI

**Whisk3D UI** — это библиотека интерфейса Whisk3D: кнопки, вкладки, выпадающие меню, карточки свойств, текст и иконки, нарисованные поверх Whisk3D Core. Редактор сделан с её помощью. Это руководство для тех, кто программирует на C или C++ и хочет использовать её для интерфейса своей игры или программы. Черновик для проверки.

Страница проекта: **[Whisk3D UI](https://leoncini.com.ar/proyecto.php?id=whisk3d-ui&lang=ru)**. Код лежит в **[Whisk3D-UI](https://github.com/Dante-Leoncini/Whisk3D-UI)** на GitHub, под лицензией MIT.
