# 2D-редактор

Для создания игровых интерфейсов, HUD и 2D-игр: тексты, изображения, прямоугольники, контейнеры, slice 9, кнопки и видео.

| Функция | Описание | Сочетание |
|---|---|---|
| Добавить | Текст, Изображение, Прямоугольник, Контейнер, Slice 9, Кнопка, Раскрыть, Видео; Импорт w3dui. | Меню Добавить |
| Выделить | Клик выбирает (перетаскивание перемещает); <kbd>Shift</kbd>+клик добавляет; клик по пустому месту снимает выделение. | Клик; <kbd>A</kbd> / <kbd>Alt+A</kbd> / <kbd>Ctrl+I</kbd> |
| Переместить / Вращать / Масштаб | <kbd>X</kbd> / <kbd>Y</kbd> фиксируют ось; значение можно ввести с клавиатуры. | <kbd>G</kbd> / <kbd>R</kbd> / <kbd>S</kbd> |
| Изменение размера | Точки захвата активного элемента. | Перетаскивание |
| Дублировать / Удалить | Копия со смещением, сразу захваченная / удаление с подтверждением. | <kbd>Shift+D</kbd> / <kbd>X</kbd> |
| Задать родителя / Снять родителя | Выделение становится потомком активного элемента или снова подчиняется UI. | Меню Объект |
| 2D-курсор | Ставится через <kbd>Shift</kbd>+клик по пустому месту. | <kbd>Shift</kbd>+клик |
| Вид игры | Холст выглядит точно так же, как на устройстве, без направляющих. | <kbd>Num0</kbd> (<kbd>Esc</kbd> — выход) |
| Показать выделенное / Масштаб 1:1…4:1 | Кадрирует выделение; точный зум пиксель в пиксель. | <kbd>Num.</kbd> / меню Вид |
