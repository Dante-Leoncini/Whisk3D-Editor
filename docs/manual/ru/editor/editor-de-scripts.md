# Редактор скриптов (IDE)

Текстовый редактор для Lua-скриптов и [своих шейдеров](shaders.md) (`.glsl`) с номерами строк, подсветкой синтаксиса, направляющими отступов и поддержкой ñ и букв с диакритикой. Пока он в фокусе, буквы вводят текст (а не запускают горячие клавиши редактора). На Android касание текста открывает клавиатуру. На N95 текст вводится через T9.

| Функция | Описание | Сочетание |
|---|---|---|
| Скрипт | Выбор .lua проекта для редактирования или Загрузить .lua… (внешний файл). | Меню Скрипт |
| Сохранить | Сохраняет скрипт. Если он хранится внутри .w3d, сохраняет и проект. | <kbd>Ctrl+S</kbd> или Файл → Сохранить |
| Сохранить как… | Другое имя, внутри или снаружи проекта, в выбранной папке. | Файл |
| Сохранить внутри .w3d | Только если скрипт внешний: помещает его в проект. | Файл |
| Сохранить вне .w3d… | Только если скрипт внутренний: выносит его в файл; объекты начинают использовать этот файл. | Файл |
| Обновить | Загружает файл в том виде, в каком он лежит на диске (то, что правили в другом редакторе). Если в редакторе есть несохранённые изменения, спрашивает, прежде чем их отбросить (их можно вернуть через <kbd>Ctrl+Z</kbd>). Если игра запущена, объекты, использующие скрипт, перезагружаются на лету. | Кнопка |
| Шейдеры (.glsl) | Открываются из материала (маленькая кнопка в строке **Шейдер**), из Библиотеки или из селектора и подсвечиваются как GLSL. Рядом с именем появляется **Компилировать**: он компилирует то, что ты пишешь (если шейдер использует материал, сохраняет его и компилирует этот материал). Сохранение шейдера компилирует его во всех материалах, которые его используют, и сообщает, скомпилировался ли он, или показывает ошибку с номером строки. | <kbd>Ctrl+S</kbd> |
| Защита при сохранении | Если внешний файл изменился снаружи с момента открытия, Сохранить спрашивает, прежде чем его перезаписать. Сохранить также перезагружает скрипт на лету, если игра запущена. | Автоматически |
| Отступы (Tab) | <kbd>Tab</kbd> дополняет до следующего кратного 4; если выделено несколько строк, добавляет им уровень, а <kbd>Shift+Tab</kbd> убирает его. Вертикальные линии отмечают каждый уровень; линия блока, где стоит курсор, светлее. | <kbd>Tab</kbd> / <kbd>Shift+Tab</kbd> |
| Меню Правка | Отменить, Повторить, Вырезать, Копировать, Вставить, Найти… и Заменить… | Кнопка Правка |
| Меню Выделить | Выделить всё. | Кнопка Выделить |
| Отменить / Повторить | Для текста скрипта (не для сцены). | <kbd>Ctrl+Z</kbd> / <kbd>Ctrl+Y</kbd> или <kbd>Ctrl+Shift+Z</kbd> |
| Найти / Заменить | Открывает панель справа вверху: искомый текст, количество совпадений ("3 из 7"), Учитывать регистр, Слово целиком, Предыдущее / Следующее, а в Заменить — новый текст и кнопки Заменить и Заменить все (один шаг отмены). Совпадения подсвечиваются в коде. Панель не блокирует редактор: если указатель над скриптом, можно продолжать печатать. Закрывается кнопкой Закрыть или <kbd>Esc</kbd>. | <kbd>Ctrl+F</kbd> / <kbd>Ctrl+H</kbd> |
| Копировать / Вырезать / Вставить | С системным буфером обмена. | <kbd>Ctrl+C</kbd> / <kbd>Ctrl+X</kbd> / <kbd>Ctrl+V</kbd> |
| Выделить всё / Отменить | Отменить действует на текст, а не на сцену. | <kbd>Ctrl+A</kbd> / <kbd>Ctrl+Z</kbd> |
| Выделение пальцем | Двойное касание выделяет слово, тройное — всю строку. Когда есть выделение, на его концах появляются две ручки (зелёные кружки): их можно перетаскивать, чтобы подправить выделение. | Касания |
| Лупа (сенсорный экран) | Если ненадолго задержать палец на коде, над пальцем появляется увеличенная строка с курсором; при перетаскивании курсор следует за пальцем и остаётся там, где палец отпущен. | Долгое нажатие |
| Выделение на N95 | Стрелки двигают курсор; при удержании клавиши-карандаша стрелки выделяют текст от позиции курсора. Пока карандаш удерживается, внизу появляется панель: левая софт-клавиша **копирует**, а правая **вставляет**. | Карандаш + стрелки / софт-клавиши |
| Перемещение по тексту | Стрелки, Home, End, PageUp, PageDown (с <kbd>Shift</kbd> — выделяют); <kbd>Ctrl+Home</kbd> / <kbd>Ctrl+End</kbd> переходят в начало или в конец. | Клавиатура |
