# Script Editor (IDE)

Текстовый редактор для Lua-скриптов и [своих шейдеров](shaders.md) (`.glsl`) с номерами строк, подсветкой синтаксиса, направляющими отступов и поддержкой ñ и букв с диакритикой. Пока он в фокусе, буквы вводят текст (а не запускают горячие клавиши редактора). На Android касание текста открывает клавиатуру. На N95 текст вводится через T9.

| Функция | Описание | Сочетание |
|---|---|---|
| Script | Выбор .lua проекта для редактирования или Load .lua… (внешний файл). | Меню Script |
| Save | Сохраняет скрипт. Если он хранится внутри .w3d, сохраняет и проект. | <kbd>Ctrl+S</kbd> или File → Save |
| Save As… | Другое имя, внутри или снаружи проекта, в выбранной папке. | File |
| Save inside the .w3d | Только если скрипт внешний: помещает его в проект. | File |
| Save outside the .w3d… | Только если скрипт внутренний: выносит его в файл; объекты начинают использовать этот файл. | File |
| Refresh | Загружает файл в том виде, в каком он лежит на диске (то, что правили в другом редакторе). Если в редакторе есть несохранённые изменения, спрашивает, прежде чем их отбросить (их можно вернуть через <kbd>Ctrl+Z</kbd>). Если игра запущена, объекты, использующие скрипт, перезагружаются на лету. | Кнопка |
| Шейдеры (.glsl) | Открываются из материала (маленькая кнопка в строке **Shader**), из Library или из селектора и подсвечиваются как GLSL. Рядом с именем появляется **Compile**: он компилирует то, что ты пишешь (если шейдер использует материал, сохраняет его и компилирует этот материал). Сохранение шейдера компилирует его во всех материалах, которые его используют, и сообщает, скомпилировался ли он, или показывает ошибку с номером строки. | <kbd>Ctrl+S</kbd> |
| Защита при сохранении | Если внешний файл изменился снаружи с момента открытия, Save спрашивает, прежде чем его перезаписать. Save также перезагружает скрипт на лету, если игра запущена. | Автоматически |
| Отступы (Tab) | <kbd>Tab</kbd> дополняет до следующего кратного 4; если выделено несколько строк, добавляет им уровень, а <kbd>Shift+Tab</kbd> убирает его. Вертикальные линии отмечают каждый уровень; линия блока, где стоит курсор, светлее. | <kbd>Tab</kbd> / <kbd>Shift+Tab</kbd> |
| Меню Edit | Undo, Redo, Cut, Copy, Paste, Find… и Replace… | Кнопка Edit |
| Меню Select | Select All. | Кнопка Select |
| Undo / Redo | Для текста скрипта (не для сцены). | <kbd>Ctrl+Z</kbd> / <kbd>Ctrl+Y</kbd> или <kbd>Ctrl+Shift+Z</kbd> |
| Find / Replace | Открывает панель справа вверху: искомый текст, количество совпадений ("3 of 7"), Match case, Whole word, Previous / Next, а в Replace — новый текст и кнопки Replace и Replace all (один шаг отмены). Совпадения подсвечиваются в коде. Панель не блокирует редактор: если указатель над скриптом, можно продолжать печатать. Закрывается кнопкой Close или <kbd>Esc</kbd>. | <kbd>Ctrl+F</kbd> / <kbd>Ctrl+H</kbd> |
| Copy / Cut / Paste | С системным буфером обмена. | <kbd>Ctrl+C</kbd> / <kbd>Ctrl+X</kbd> / <kbd>Ctrl+V</kbd> |
| Select All / Undo | Undo действует на текст, а не на сцену. | <kbd>Ctrl+A</kbd> / <kbd>Ctrl+Z</kbd> |
| Выделение пальцем | Двойное касание выделяет слово, тройное — всю строку. Когда есть выделение, на его концах появляются две ручки (зелёные кружки): их можно перетаскивать, чтобы подправить выделение. | Касания |
| Лупа (сенсорный экран) | Если ненадолго задержать палец на коде, над пальцем появляется увеличенная строка с курсором; при перетаскивании курсор следует за пальцем и остаётся там, где палец отпущен. | Долгое нажатие |
| Выделение на N95 | Стрелки двигают курсор; при удержании клавиши Pencil стрелки выделяют текст от позиции курсора. Пока Pencil удерживается, внизу появляется панель: левая софт-клавиша **копирует**, а правая **вставляет**. | Pencil + стрелки / софт-клавиши |
| Перемещение по тексту | Стрелки, Home, End, PageUp, PageDown (с <kbd>Shift</kbd> — выделяют); <kbd>Ctrl+Home</kbd> / <kbd>Ctrl+End</kbd> переходят в начало или в конец. | Клавиатура |
