# Объектный режим

| Функция | Описание | Как использовать |
|---|---|---|
| Выделить | Выбирает объект. Клик по пустому месту снимает выделение. | Клик; <kbd>Shift</kbd>+клик добавляет или убирает |
| Переместить / Вращать / Масштаб | См. [Перемещение, вращение и масштабирование](transformar.md). | <kbd>G</kbd> / <kbd>R</kbd> / <kbd>S</kbd>, гизмо |
| Добавить | Создаёт новый объект в 3D-курсоре (см. [меню Добавить](#меню-добавить)). | <kbd>Shift+A</kbd> или кнопка + |
| Применить | Запекает в меш положение, вращение, масштаб или всё сразу (объект остаётся в 0, 0, 0 без вращения и с масштабом 1). | <kbd>Ctrl+A</kbd> |
| Задать центр | Геометрию к центру, Центр к геометрии, Центр к 3D-курсору. | Меню Объект |
| Привязка | Перемещает 3D-курсор к выделенному, к активному объекту, в начало координат мира или на сетку, а выделенное — к курсору, к активному объекту или на сетку. | <kbd>Shift+S</kbd> или меню Объект → Привязка |
| Дублировать объекты | Независимая копия; сразу захвачена для перемещения. | <kbd>Shift+D</kbd> |
| Дублировать связанно | Копия, которая использует тот же меш, что и оригинал (правка одной меняет обе). | <kbd>Alt+D</kbd> |
| Объединить | Объединяет выделенные меши в активном объекте. | <kbd>Ctrl+J</kbd> |
| Задать родителя | Выделенное становится потомком активного объекта (с сохранением трансформации или без). | <kbd>Ctrl+P</kbd> |
| Снять родителя | Убирает родителя (с сохранением положения или без). | <kbd>Alt+P</kbd> |
| Удалить | Удаляет выделенные объекты (спрашивает подтверждение). | <kbd>X</kbd> или <kbd>Delete</kbd> |
| Скрыть / Показать | Переключает видимость активного объекта. | <kbd>H</kbd> |
| Создать префаб / Распаковать префаб | Превращает выделение в многоразовый префаб или снова разделяет экземпляр. | Меню Объект |
| Вставить ключевой кадр | Сохраняет положение, вращение и/или масштаб в текущем кадре (меню каналов). <kbd>Shift+I</kbd> сохраняет всё без вопросов. | <kbd>I</kbd> |
| Удалить / Очистить ключевые кадры | Удаляет ключевой кадр в текущем кадре или всю анимацию. | Меню Анимация |
| След движения | Рисует путь, который проходят анимированные объекты. | Меню Анимация |
| Смена режима | Меш: Объект ↔ Редактирование. Скелет: Объект ↔ Поза. Кривая: редактирование узлов. | <kbd>Tab</kbd> |

## Меню Добавить

Только в Объектном режиме. Новое появляется в 3D-курсоре и остаётся выделенным. Примитивы открывают панель для настройки их размеров.

| Функция | Описание |
|---|---|
| Меш | Плоскость, Куб, Окружность, UV-сфера, Конус, Цилиндр (с размером, радиусом, сегментами, сглаженным затенением). Также Вершина (отдельная точка, чтобы начать моделирование) и Ссылка (плоскость с изображением, для обводки). |
| Пустышка | Объект без меша, для группировки или как опорная точка. |
| Камера / Свет / Туман | Камера, источник света и туман сцены. У света есть **Тип**: Точечный, Солнце (направленный) или Прожектор (конус, рисуется во вьюпорте); в Добавить есть и Солнце, и Прожектор. **Интенсивность** делает свет сильнее (анимируется); **Расстояние** (м) — докуда достаёт точечный свет или прожектор, это же длина его конуса (0 = без ограничения; трассировка лучей плавно гасит свет на этом расстоянии). Когда свет выделен, прожектор показывает свой конус, а точечный свет — сферу этого радиуса; солнце всегда показывает линию до пола в ту сторону, куда светит. |
| Звук | Звук, размещённый в сцене (значок динамика). Играет вместе с таймлайном в **секундах**, а не в кадрах; с **Позиционный (3D)** слышен оттуда, где находится (громче, чем ближе камера, с той стороны, где он); без этого — как музыка. Если бросить .wav в 3D-вид, он создаётся там. |
| Арматура | Скелет с одной костью, для анимации персонажей. |
| Путь | Кривая из двух узлов (редактируется как меш: <kbd>E</kbd> добавляет узлы). |
| Коллекция | Папка для упорядочивания объектов. |
| UI | 2D-интерфейс для игр (редактируется в 2D-редакторе). |
| Хитбокс | Коробка для обнаружения столкновений; если есть активный объект, создаётся как его потомок, по его размеру. |
| Физика | Не создаёт объект: добавляет твёрдое тело к активному объекту. |
| Частицы | Излучатель частиц. |
| LOD / Отсечение / Grid Cull | Объекты оптимизации: уровни детализации и скрытие того, что не видно. |
| Очистить Z / Область экрана | Инструменты отрисовки: очистить глубину или обрезать область экрана. |
| Префаб / Сцена / Прокси W3D | Вставить префаб проекта, другую сцену или префаб из внешней библиотеки. |
| Импорт | OBJ, FBX, glTF, GLB, STL или интерфейс Whisk3D UI. STL (3D-печать, CAD), где вверх направлена ось Z, импортируется с поворотом, чтобы модель стояла, а совпадающие вершины сливаются. |
| Ядро (дополнительно) | Процедуры: списки шагов отрисовки, которые собираются вручную (трансформация, отрисовка, текстуры, свет, туман, смешивание, глубина, управление, Вызвать Lua). Включает **Цикл процедуры**: процедуру, которая повторяет свои шаги несколько раз (например, "переместить, нарисовать" 20 раз), как массив, но быстрее. |
