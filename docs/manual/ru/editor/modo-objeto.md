# Object Mode

| Функция | Описание | Как использовать |
|---|---|---|
| Select | Выбирает объект. Клик по пустому месту снимает выделение. | Клик; <kbd>Shift</kbd>+клик добавляет или убирает |
| Move / Rotate / Scale | См. [Перемещение, вращение и масштабирование](transformar.md). | <kbd>G</kbd> / <kbd>R</kbd> / <kbd>S</kbd>, гизмо |
| Add | Создаёт новый объект в 3D-курсоре (см. [меню Add](#Меню-add)). | <kbd>Shift+A</kbd> или кнопка + |
| Apply | Запекает в меш положение, вращение, масштаб или всё сразу (объект остаётся в 0, 0, 0 без вращения и с масштабом 1). | <kbd>Ctrl+A</kbd> |
| Set Origin | Geometry to Origin, Origin to Geometry, Origin to 3D Cursor. | Меню Object |
| Duplicate Objects | Независимая копия; сразу захвачена для перемещения. | <kbd>Shift+D</kbd> |
| Duplicate Linked | Копия, которая использует тот же меш, что и оригинал (правка одной меняет обе). | <kbd>Alt+D</kbd> |
| Join | Объединяет выделенные меши в активном объекте. | <kbd>Ctrl+J</kbd> |
| Set Parent | Выделенное становится потомком активного объекта (с сохранением трансформации или без). | <kbd>Ctrl+P</kbd> |
| Clear Parent | Убирает родителя (с сохранением положения или без). | <kbd>Alt+P</kbd> |
| Delete | Удаляет выделенные объекты (спрашивает подтверждение). | <kbd>X</kbd> или <kbd>Delete</kbd> |
| Hide / Show | Переключает видимость активного объекта. | <kbd>H</kbd> |
| Create Prefab / Unpack Prefab | Превращает выделение в многоразовый префаб или снова разделяет экземпляр. | Меню Object |
| Insert Keyframe | Сохраняет положение, вращение и/или масштаб в текущем кадре (меню каналов). <kbd>Shift+I</kbd> сохраняет всё без вопросов. | <kbd>I</kbd> |
| Delete / Clear Keyframe | Удаляет ключевой кадр в текущем кадре или всю анимацию. | Меню Animation |
| Motion Trail | Рисует путь, который проходят анимированные объекты. | Меню Animation |
| Смена режима | Меш: Object ↔ Edit. Скелет: Object ↔ Pose. Кривая: редактирование узлов. | <kbd>Tab</kbd> |

## Меню Add

Только в Object Mode. Новое появляется в 3D-курсоре и остаётся выделенным. Примитивы открывают панель для настройки их размеров.

| Функция | Описание |
|---|---|
| Mesh | Plane, Cube, Circle, UV Sphere, Cone, Cylinder (с размером, радиусом, сегментами, сглаженным затенением). Также Vertex (отдельная точка, чтобы начать моделирование) и Reference (плоскость с изображением, для обводки). |
| Empty | Объект без меша, для группировки или как опорная точка. |
| Camera / Light / Fog | Камера, источник света и туман сцены. У света есть **Type**: Point, Sun (направленный) или Spot (конус, рисуется во вьюпорте); в Add есть и Sun, и Spot. **Intensity** делает свет сильнее (анимируется); **Distance** (м) — докуда достаёт точечный свет или прожектор, это же длина его конуса (0 = без ограничения; трассировка лучей плавно гасит свет на этом расстоянии). Когда свет выделен, прожектор показывает свой конус, а точечный свет — сферу этого радиуса; солнце всегда показывает линию до пола в ту сторону, куда светит. |
| Sound | Звук, размещённый в сцене (значок динамика). Играет вместе с таймлайном в **секундах**, а не в кадрах; с **Positional (3D)** слышен оттуда, где находится (громче, чем ближе камера, с той стороны, где он); без этого — как музыка. Если бросить .wav в 3D-вид, он создаётся там. |
| Armature | Скелет с одной костью, для анимации персонажей. |
| Path | Кривая из двух узлов (редактируется как меш: <kbd>E</kbd> добавляет узлы). |
| Collection | Папка для упорядочивания объектов. |
| UI | 2D-интерфейс для игр (редактируется в 2D Editor). |
| Hitbox | Коробка для обнаружения столкновений; если есть активный объект, создаётся как его потомок, по его размеру. |
| Physics | Не создаёт объект: добавляет твёрдое тело к активному объекту. |
| Particles | Излучатель частиц. |
| LOD / Culling / Grid Cull | Объекты оптимизации: уровни детализации и скрытие того, что не видно. |
| Clear Depth / Screen Rect | Инструменты отрисовки: очистить глубину или обрезать область экрана. |
| Prefab / Scene / Proxy W3D | Вставить префаб проекта, другую сцену или префаб из внешней библиотеки. |
| Imports | OBJ, FBX, glTF, GLB или интерфейс Whisk3D UI. |
| Core (advanced) | Процедуры: списки шагов отрисовки, которые собираются вручную (трансформация, отрисовка, текстуры, свет, туман, смешивание, глубина, управление, Call Lua). Включает **Routine loop**: процедуру, которая повторяет свои шаги несколько раз (например, "переместить, нарисовать" 20 раз), как массив, но быстрее. |
