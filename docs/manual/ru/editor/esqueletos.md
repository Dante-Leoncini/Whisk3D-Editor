# Скелеты

## Режим редактирования скелета

| Функция | Описание | Сочетание |
|---|---|---|
| Выделить | Выбирает конец кости или всю кость; перетаскивание сразу её перемещает. | Клик; <kbd>Shift</kbd> добавляет |
| Все / Нет | Выделяет все кости или снимает с них выделение. | <kbd>A</kbd> / <kbd>Alt+A</kbd> |
| Выдавить кость | Создаёт новую кость из каждого выделенного конца. | <kbd>E</kbd> |
| Переместить / Вращать / Масштаб | С осями и плоскостями, как обычно. | <kbd>G</kbd> / <kbd>R</kbd> / <kbd>S</kbd> |
| Дублировать | Копирует кости и оставляет их захваченными. | <kbd>Shift+D</kbd> |
| Удалить | Удаляет кости (их потомки переходят к «деду»). | <kbd>X</kbd> или <kbd>Delete</kbd> |
| Задать родителя | Сохранить смещение или Соединённый. | <kbd>Ctrl+P</kbd> |
| Отсоединить / Снять родителя | Отсоединяет кость от её родителя. | <kbd>Alt+P</kbd> |

## Режим позы

Только для скелетов. Нужен, чтобы ставить позы и анимировать.

| Функция | Описание | Сочетание |
|---|---|---|
| Выбор кости | Выбирает кость. | Клик; <kbd>Shift</kbd> добавляет |
| Переместить / Вращать / Масштаб | Ставит в позу выделенные кости. | <kbd>G</kbd> / <kbd>R</kbd> / <kbd>S</kbd> |
| Сбросить положение / вращение / масштаб | Возвращает кость в позу покоя по этому каналу. | <kbd>Alt+G</kbd> / <kbd>Alt+R</kbd> / <kbd>Alt+S</kbd> |
| Вставить ключевой кадр | Сохраняет позу в текущем кадре. | <kbd>I</kbd> / <kbd>Shift+I</kbd> |
