# Timeline

Показывает и редактирует анимацию: лист ключевых кадров (dope sheet) или редактор кривых. Показывает анимацию **выделенного**.

## Верхняя панель

| Функция | Описание |
|---|---|
| Транспорт | В начало, предыдущий ключевой кадр, предыдущий кадр, воспроизведение назад, воспроизведение / пауза, следующий кадр, следующий ключевой кадр, в конец. |
| Start / End / FPS | Диапазон и скорость анимации (клик — ввести значение). |
| Animation | Какая анимация редактируется (сцена, клипы, скелеты, объекты, флипбуки, Game, Mix), а также создание новых. |
| Auto Key | Красный: каждая трансформация сама записывает ключевые кадры. |
| Curves / Dope Sheet | Переключает между листом ключевых кадров и редактором кривых. |
| Select, Key, View, Pivot | Меню выделения, операций с ключевыми кадрами, кадрирования и боковой панели, а также выбор точки, от которой масштабирует <kbd>S</kbd> (центр или текущий кадр). |

## Перемещение по времени

| Функция | Описание | Сочетание |
|---|---|---|
| Смена кадра | Клик или перетаскивание по номерам кадров (scrub). Текущий кадр (зелёный) можно ввести с клавиатуры. | Клик |
| Previous frame / Next frame | На один кадр назад или вперёд. | <kbd>Left</kbd> / <kbd>Right</kbd> |
| Previous keyframe / Next keyframe | Переход к ближайшему ключевому кадру. | <kbd>Down</kbd> / <kbd>Up</kbd> |
| Go to start / Go to end | Первый или последний кадр. | <kbd>Home</kbd> / <kbd>End</kbd> |
| Play / Pause | Из любой панели. | <kbd>Space</kbd> |
| Зум и панорамирование | Колесо = зум (в кривых <kbd>Ctrl</kbd> = только время, <kbd>Shift</kbd> = только значение); средняя кнопка = панорамирование. | Колесо / средняя кнопка |
| Frame Selected | Подгоняет вид под выделенное. | <kbd>Num.</kbd> |

## Редактирование ключевых кадров (dope sheet и кривые)

| Функция | Описание | Сочетание |
|---|---|---|
| Select | Клик по ромбу или по строке, чтобы взять все её ключевые кадры; <kbd>Shift</kbd> добавляет. | Клик; <kbd>A</kbd> / <kbd>Alt+A</kbd> / <kbd>Ctrl+I</kbd> |
| Перемещение ключевых кадров | Сдвигает ключевые кадры во времени (также перетаскиванием ромба). | <kbd>G</kbd> |
| Масштабирование ключевых кадров | Растягивает или сжимает относительно опорной точки. | <kbd>S</kbd> |
| Rotate handles | Только в кривых. | <kbd>R</kbd> |
| Duplicate | Копирует ключевые кадры и оставляет их захваченными. | <kbd>Shift+D</kbd> |
| Delete | Удаляет выделенные ключевые кадры (или кривые выделенных строк). | <kbd>X</kbd> |
| Interpolation | Constant, Linear или Bezier. | <kbd>T</kbd> |
| Handle Type | Free, Aligned, Vector, Automatic, Auto Clamped (только кривые). | <kbd>V</kbd> |
| Smart Euler | Убирает лишние обороты в выделенных вращениях. | Меню Key |
| Скрытие кривой | Глаз в каждой строке скрывает её. | Клик по глазу |
| Точные значения | Кадр, значение и рукоятки выбранного ключевого кадра. | Properties → Animation → Keyframe |

## Звуки

| Функция | Описание | Клавиши |
|---|---|---|
| Полоса звука | У каждого выбранного объекта Sound есть полоса: где он начинается и сколько длится, в **секундах** (смена FPS её не сдвигает). С зацикливанием повторяется до конца. | — |
| Сдвинуть | Перетащить полосу или <kbd>G</kbd> без выбранных ключей (двигает все выбранные звуки). <kbd>Ctrl</kbd> привязывает к кадрам. | Перетаскивание / <kbd>G</kbd> |
| Обрезать | Взять полосу за край. | Перетащить край |
| Waveform / Volume line | Меню View: форма волны и кривая громкости внутри полосы (полоса занимает три строки). Без них — просто полоса. | Меню View |
