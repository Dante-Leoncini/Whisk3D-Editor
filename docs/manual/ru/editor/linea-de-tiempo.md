# Таймлайн

Показывает и редактирует анимацию: лист ключевых кадров (dope sheet) или редактор кривых. Показывает анимацию **выделенного**.

## Верхняя панель

| Функция | Описание |
|---|---|
| Транспорт | В начало, предыдущий ключевой кадр, предыдущий кадр, воспроизведение назад, воспроизведение / пауза, следующий кадр, следующий ключевой кадр, в конец. |
| Начало / Конец / FPS | Диапазон и скорость анимации (клик — ввести значение). |
| Анимация | Какая анимация редактируется (сцена, клипы, скелеты, объекты, флипбуки, Игра, Микс), а также создание новых. |
| Автоключ | Красный: каждая трансформация сама записывает ключевые кадры. |
| Кривые / Лист экспозиции | Переключает между листом ключевых кадров и редактором кривых. |
| Выделить, Ключ, Вид, Опорная точка | Меню выделения, операций с ключевыми кадрами, кадрирования и боковой панели, а также выбор точки, от которой масштабирует <kbd>S</kbd> (центр или текущий кадр). |

## Перемещение по времени

| Функция | Описание | Сочетание |
|---|---|---|
| Смена кадра | Клик или перетаскивание по номерам кадров (scrub). Текущий кадр (зелёный) можно ввести с клавиатуры. | Клик |
| Предыдущий кадр / Следующий кадр | На один кадр назад или вперёд. | <kbd>Left</kbd> / <kbd>Right</kbd> |
| Предыдущий ключевой кадр / Следующий ключевой кадр | Переход к ближайшему ключевому кадру. | <kbd>Down</kbd> / <kbd>Up</kbd> |
| В начало / В конец | Первый или последний кадр. | <kbd>Home</kbd> / <kbd>End</kbd> |
| Пуск / Пауза | Из любой панели. | <kbd>Space</kbd> |
| Зум и панорамирование | Колесо = зум (в кривых <kbd>Ctrl</kbd> = только время, <kbd>Shift</kbd> = только значение); средняя кнопка = панорамирование. | Колесо / средняя кнопка |
| Показать выделенное | Подгоняет вид под выделенное. | <kbd>Num.</kbd> |

## Редактирование ключевых кадров (dope sheet и кривые)

| Функция | Описание | Сочетание |
|---|---|---|
| Выделить | Клик по ромбу или по строке, чтобы взять все её ключевые кадры; <kbd>Shift</kbd> добавляет. | Клик; <kbd>A</kbd> / <kbd>Alt+A</kbd> / <kbd>Ctrl+I</kbd> |
| Перемещение ключевых кадров | Сдвигает ключевые кадры во времени (также перетаскиванием ромба). | <kbd>G</kbd> |
| Масштабирование ключевых кадров | Растягивает или сжимает относительно опорной точки. | <kbd>S</kbd> |
| Вращать рукоятки | Только в кривых. | <kbd>R</kbd> |
| Дублировать | Копирует ключевые кадры и оставляет их захваченными. | <kbd>Shift+D</kbd> |
| Удалить | Удаляет выделенные ключевые кадры (или кривые выделенных строк). | <kbd>X</kbd> |
| Интерполяция | Константа, Линейная или Безье. | <kbd>T</kbd> |
| Тип рукоятки | Свободная, Выровненная, Вектор, Автоматическая, Авто с ограничением (только кривые). | <kbd>V</kbd> |
| Умный Эйлер | Убирает лишние обороты в выделенных вращениях. | Меню Ключ |
| Скрытие кривой | Глаз в каждой строке скрывает её. | Клик по глазу |
| Точные значения | Кадр, значение и рукоятки выбранного ключевого кадра. | Свойства → Анимация → Ключевой кадр |

## Звуки

| Функция | Описание | Клавиши |
|---|---|---|
| Полоса звука | У каждого выбранного объекта Звук есть полоса: где он начинается и сколько длится, в **секундах** (смена FPS её не сдвигает). С зацикливанием повторяется до конца. | — |
| Сдвинуть | Перетащить полосу или <kbd>G</kbd> без выбранных ключей (двигает все выбранные звуки). <kbd>Ctrl</kbd> привязывает к кадрам. | Перетаскивание / <kbd>G</kbd> |
| Обрезать | Взять полосу за край. | Перетащить край |
| Форма волны / Линия громкости | Меню Вид: форма волны и кривая громкости внутри полосы (полоса занимает три строки). Без них — просто полоса. | Меню Вид |
