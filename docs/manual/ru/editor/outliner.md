# Outliner

Список всего, что есть в сцене, а также библиотека ресурсов проекта. На Android не отображается (работа идёт в 3D Viewport и Properties).

## Меню View (глаз)

| Функция | Описание |
|---|---|
| Scene / Library / Libraries | Что выводится в списке: дерево сцены, все ресурсы проекта или ресурсы другого подключённого .w3d (только чтение). |
| Constructor / Routines | Показывают или скрывают процедуру Constructor (то, что выполняется один раз при запуске) и остальные процедуры. |
| Visibility icons / Render icons | Показывают или скрывают столбцы глаза и камеры. |
| Grid | В Library: миниатюры вместо списка. |
| Link .w3d… / Unlink | Использует другой проект как библиотеку или отключает его. |

## Вид Scene

| Функция | Описание | Как использовать |
|---|---|---|
| Select | Выбирает объект. <kbd>Shift</kbd>+клик берёт диапазон; <kbd>Ctrl</kbd>+клик добавляет или убирает. | Клик |
| Развернуть / свернуть | Показывает или скрывает потомков. | Стрелка; <kbd>Left</kbd> / <kbd>Right</kbd> |
| Visible / Renderable | Глаз скрывает объект (это можно анимировать); камера исключает его из рендера. | Клик по глазу / камере |
| Порядок и родители | Отпустить перед другой строкой, после неё или поверх неё (как потомка). | Перетащить строку |
| Move (reorder) | С клавиатуры: вверх/вниз меняет порядок, влево выводит из родителя, вправо помещает под предыдущий объект, <kbd>Enter</kbd> подтверждает. | <kbd>G</kbd> |
| Rename | Строка превращается в текстовое поле. | Двойной клик или <kbd>F2</kbd> |
| Duplicate / Duplicate Linked | Как в 3D Viewport. | <kbd>Shift+D</kbd> / <kbd>Alt+D</kbd> |
| Hide / Show | Переключает видимость. | <kbd>H</kbd> |
| Delete | С подтверждением. | <kbd>X</kbd> или <kbd>Delete</kbd> |
| Create / Unpack Prefab | Из меню Object. | Правый клик |
| Show active | Прокручивает список до активного объекта. | <kbd>Num.</kbd> |
| Прокрутка списка | Колесо или перетаскивание (в том числе пальцем). | Колесо / перетаскивание |

## Вид Library

| Функция | Описание |
|---|---|
| Ресурсы | Меши, материалы, текстуры, анимации, префабы, сцены, звуки, скрипты, [шейдеры](shaders.md), шрифты и видео, по папкам. Материал или шейдер, перетаскиваемый на меш в 3D Viewport, показывается на части под указателем ещё до того, как его отпустить. Зелёная галочка = используется; красный крестик = сирота; `*` = не сохранён. |
| Filter / List или Grid | Показать только один тип; смотреть миниатюры. |
| Перетаскивание ресурса | В папку (перемещает его), в 3D Viewport (меш = новый объект, материал или текстура = назначается тому, на что его бросили, префаб = экземпляр) или в выпадающий список Properties. |
| New Folder / Move to Folder | Упорядочивание (папки нужны только для порядка). |
| Duplicate Resource / Select Users / Purge Orphans | Скопировать, найти, кто использует ресурс, удалить то, что никто не использует. |
| Inside the .w3d / External | Из Properties (карточка Resource): переносит ресурс внутрь проекта или наружу. |

## Сцены, игры и префабы

Кнопка с именем сцены (в Outliner и в 3D Viewport) показывает список сцен, игр и префабов проекта. Там можно создавать новые, выбирать начальную сцену и превращать сцену в игру (или наоборот).
