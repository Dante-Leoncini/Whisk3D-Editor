# Перемещение, вращение и масштабирование

Работает одинаково в Объектном режиме, Режиме редактирования, Режиме позы и при редактировании костей.

| Функция | Описание | Сочетание |
|---|---|---|
| Переместить (перенос) | Выделенное следует за указателем. | <kbd>G</kbd> |
| Вращать | Вращает вокруг опорной точки. Повторное нажатие <kbd>R</kbd> переключает между свободным вращением (трекбол) и орбитальным. | <kbd>R</kbd> |
| Масштаб | Увеличивает или уменьшает относительно опорной точки. | <kbd>S</kbd> |
| Ограничение по оси | Во время трансформации. Повторное нажатие переключает по кругу Глобальная → Локальная → Вид → свободно. | <kbd>X</kbd> / <kbd>Y</kbd> / <kbd>Z</kbd> |
| Ограничение плоскостью | Исключает эту ось (перемещение по двум другим). | <kbd>Shift+X</kbd> / <kbd>Shift+Y</kbd> / <kbd>Shift+Z</kbd> |
| Точное значение | Ввести число или выражение (`2*3`, `(1+0.5)/2`). <kbd>-</kbd> меняет знак, <kbd>Backspace</kbd> стирает. | Цифры |
| Подтвердить | Применяет операцию. | Левый клик, <kbd>Enter</kbd>, зелёная галочка |
| Отмена | Всё возвращается как было. | <kbd>Esc</kbd>, правый клик, красный крестик |
| Мелкие шаги | Перемещает, вращает или масштабирует понемногу. | Стрелки |

Пока операция идёт, верхняя панель показывает, что происходит, например "Переместить X 1.5 вдоль глобальной X". На сенсорном экране касание этой панели открывает цифровую клавиатуру.

## Гизмо

Гизмо появляется над опорной точкой в Объектном режиме и в Режиме редактирования (включается и выключается в Наложения → Гизмо).

| Функция | Описание |
|---|---|
| Гизмо перемещения | Стрелки — одна ось; квадраты — плоскость; центральный круг — свободно. |
| Гизмо вращения | По цветной полуокружности на каждую ось, белое кольцо для вращения в плоскости вида и внутренняя область для свободного вращения. |
| Гизмо масштабирования | Квадратные наконечники на каждой оси; центральный круг масштабирует равномерно. |
| Смена гизмо | Клик мышью или касание пальцем по гизмо без перетаскивания переключает «Переместить» на «Вращать», затем на «Масштаб» и обратно на «Переместить». Работает одинаково на ПК, в браузере и на сенсорных экранах. |

## Настройка последней операции

После перемещения, вращения или масштабирования (в Объектном режиме или Режиме редактирования) внизу слева появляется панель с тем, что было сделано: значения X, Y, Z (или угол), ориентация и пропорциональное редактирование с его параметрами. Изменение значения повторяет операцию с новым значением. **Отмена** отменяет её, а **Принять** оставляет. Клик вне панели тоже подтверждает. Пока панель открыта, панель инструментов 3D-вьюпорта скрыта.

У панели зелёная рамка, потому что это окно с фокусом. Если она не помещается в половину высоты экрана, она уменьшается до этой половины и прокручивается перетаскиванием пальца (не касаясь параметров), колесом или стрелками. С клавиатуры или на телефоне: стрелки перемещают по строкам, <kbd>OK</kbd> / <kbd>Enter</kbd> редактирует значение, не закрывая панель, **Принять**, <kbd>Esc</kbd> или <kbd>Delete</kbd> (<kbd>C</kbd> на N95) закрывают её, сохраняя изменение, и только **Отмена** его отменяет.

## Панель инструментов

На ней есть Отменить и Повторить, последние использованные действия и кнопка пропорционального редактирования. Во время трансформации она показывает галочку (принять), крестик (отменить), ориентацию и оси X / Y / Z (две включённые оси = плоскость). На сенсорном экране после выдавливания появляется кнопка **Повтор**: она принимает операцию и снова выполняет выдавливание.
