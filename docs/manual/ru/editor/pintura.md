# Режимы рисования

> [!NOTE]
> Все три режима рисования — **только для 3D-мешей**: они не появляются для камер, источников света, скелетов, кривых и 2D-элементов. Во время рисования клик не меняет выделение; чтобы рисовать на другом объекте, выбери его в Аутлайнере.

## Общее для всех трёх

| Функция | Описание | Как использовать |
|---|---|---|
| Рисование | Рисует только видимые лицевые грани (с Рентгеном — также задние). Каждый мазок — отдельный шаг отмены. | Клик и перетаскивание |
| Радиус | Размер кисти в пикселях. При его изменении в центре вида появляется круг реального размера. | Перетаскиваемый ползунок над панелью инструментов |
| Значение | Интенсивность кисти. | Перетаскиваемый ползунок |
| Спад | Как сглаживается край кисти; можно нарисовать собственную кривую. | Кнопка спада |
| Вид (сенсорный экран) | Включено: палец перемещает вид. Выключено: палец рисует. | Кнопка в виде монитора |

## Рисование весов

Рисует, насколько кость влияет на каждую вершину (синий = никак, красный = полностью). Именно благодаря этому меш правильно деформируется вместе со скелетом.

| Функция | Описание |
|---|---|
| Режим кисти | Добавить (+), Вычесть (−) или Уравнять (=, ставит точное значение). |
| Группа вершин | Какая группа (кость) рисуется; можно добавлять группы. Если групп нет, первый мазок создаёт одну. |
| Метки | Показывает квадратик на каждой вершине; кисть действует только на них. |
| Только выделенное | Защищает невыделенное (оно затемнено). |

## Раскраска вершин

Рисует цвета по вершинам **3D-меша** (не подходит для изображений и 2D-элементов: для этого есть Рисование текстуры). Это очень лёгкий режим, и именно его рекомендуется использовать для раскраски на N95.

| Функция | Описание |
|---|---|
| Цвет | Открывает выбор цвета (RGB, HSV, шестнадцатеричный код или индекс палитры). |
| По вершинам / По углам | С «По вершинам» цвет общий для соседних граней; с «По углам» у каждой грани может быть свой (жёсткие границы). |
| Слои цвета | Выбор или создание цветовых слоёв. |
| Метки / Только выделенное | Так же, как в Рисовании весов. |

## Рисование текстуры

Рисует прямо по 3D-объекту, а мазок попадает в его текстуру.

| Функция | Описание |
|---|---|
| Автоматическая текстура | Если у меша нет текстуры, она создаётся сама при первом мазке: собственный материал, автоматические UV и изображение 1024×1024 (256×256 на N95) цвета материала. |
| Цвет, Спад, Радиус, Значение | Как в других режимах. |
| Сохранить текстуру | Рисунок хранится в памяти, пока его не сохранят. Дискета становится зелёной, если есть несохранённые изменения. Варианты: Сохранить, Сохранить как…, Сохранить внутри .w3d и Сохранить вне .w3d… |
