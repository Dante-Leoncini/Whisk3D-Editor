# UV-редактор

Показывает, как текстура ложится на меш. Чтобы редактировать, меш должен быть в **Режиме редактирования в 3D-вьюпорте**; иначе редактор только показывает текстуру. У UV-редактора свой собственный режим: он не меняет режим 3D-вьюпорта. Инструменты развёртки и проецирования UV находятся в 3D-вьюпорте (Режим редактирования, клавиша <kbd>U</kbd>).

## Навигация и верхняя панель

| Функция | Описание | Как использовать |
|---|---|---|
| Зум / Панорамирование | Приближает к указателю / сдвигает вид. | Колесо / средняя кнопка или стрелки; на сенсорном экране: 1 палец сдвигает, 2 пальца — зум |
| Режим | Объектный режим, Режим редактирования, Рисование весов, Редактировать кости и Режим позы (последние два — если у меша есть 2D-скелет). | Кнопка режима, <kbd>Tab</kbd> |
| Вершина / Ребро / Грань | Что выделяется в Режиме редактирования. | Кнопка |
| Опорная точка | 3D-курсор, Индивидуальные центры или Средняя точка. | Кнопка |
| Курсор | Курсор к выделению, Выделение к курсору, Курсор в центр. | Меню |
| Вид | Синхронизировать выделение (UV-выделение совпадает с выделением меша), Повтор текстуры (мозаика), Показать Chrome UV, Показать выделенное, Показать всё. | Меню; <kbd>Num.</kbd> |
| Текстура | Какая текстура показывается: Новая текстура…, Авто (активная часть) или любая текстура проекта. | Меню |
| Новая текстура | Создаёт изображение (имя, размер, цвет, прозрачность; Пустая, UV-сетка или Цветная сетка), сохраняет его в проекте и назначает материалу. | Текстура → Новая текстура… |
| Mipmap | Показывает конкретный уровень mipmap, чтобы его проверить. | Кнопка Mip |
| Правка | Включает и выключает рисование текстуры прямо на изображении. | Кнопка Правка |
| Сохранить (дискета, видна всегда) | Сохранить, Сохранить как…, Сохранить вне .w3d…, Сохранить внутри .w3d, Экспорт UV-развёртки… | Меню |
| Экспорт UV-развёртки | Сохраняет PNG с прозрачным фоном: полупрозрачные грани (плотнее там, где они перекрываются) и непрозрачные линии. Можно выбрать имя, папку и разрешение (по умолчанию 512, 256 на N95, или размер показанной текстуры). | Сохранить → Экспорт UV-развёртки… |
| Анимация | Вставка, удаление или очистка ключевых кадров UV-слоя или 2D-позы. | Меню |

## Объектный режим (UV)

Клик выбирает, что редактировать: 2D-скелет (если коснуться кости) или геометрию. <kbd>Tab</kbd> входит в редактирование выбранного.

## Режим редактирования (UV)

| Функция | Описание | Сочетание |
|---|---|---|
| Выделить | Вершины, рёбра или грани UV. Без синхронизации 3D-вьюпорт фильтрует: видны только грани, выделенные в 3D. | Клик; <kbd>Shift</kbd>+клик |
| Все / Нет / Инвертировать | Для видимого. | <kbd>A</kbd> / <kbd>Alt+A</kbd> / <kbd>Ctrl+I</kbd> |
| Выделить связанное | UV-остров под указателем (<kbd>Shift</kbd> добавляет). | <kbd>L</kbd> |
| Выделение рамкой | Прямоугольник; <kbd>Shift</kbd> добавляет. | <kbd>B</kbd> |
| Переместить / Вращать / Масштаб | Трансформирует UV. <kbd>X</kbd> / <kbd>Y</kbd> фиксируют ось; значение можно ввести с клавиатуры (1.0 = одна плитка). | <kbd>G</kbd> / <kbd>R</kbd> / <kbd>S</kbd> |
| Установка 2D-курсора | Ставит курсор туда, где кликнули. | Правый клик |
| Вставить ключевой кадр | Сохраняет UV-слой в активную вершинную анимацию. | <kbd>I</kbd> |

## Рисование весов (UV)

Рисует веса 2D-костей на UV-развёртке, с теми же элементами управления, что и в 3D-вьюпорте (режим +/−/=, группа, метки, спад, только выделенное). <kbd>Ctrl</kbd>+клик по кости выбирает её для рисования.

## Редактировать кости и Режим позы (2D-скелет)

| Функция | Описание | Сочетание |
|---|---|---|
| Добавить Арматура 2D / Кость | Создаёт 2D-скелет меша (с его UV-группой) или добавляет кость. | Меню Добавить |
| Выделить | Конец кости или вся кость; перетаскивание её перемещает. | Клик; <kbd>A</kbd> / <kbd>Alt+A</kbd> / <kbd>Ctrl+I</kbd> / <kbd>L</kbd> / <kbd>B</kbd> |
| Переместить / Вращать / Масштаб | В режиме «Редактировать кости» меняет положение покоя; в Режиме позы ставит позу (взвешенные UV следуют за костью). | <kbd>G</kbd> / <kbd>R</kbd> / <kbd>S</kbd> |
| Выдавить / Дублировать / Удалить | Только в режиме «Редактировать кости». | <kbd>E</kbd> / <kbd>Shift+D</kbd> / <kbd>X</kbd> |
| Задать родителя / Снять родителя | Сохранить смещение или Соединённый / Отсоединить. | <kbd>Ctrl+P</kbd> / <kbd>Alt+P</kbd> |
| Вставить ключевой кадр | В Режиме позы: меню каналов или всё сразу с <kbd>Shift+I</kbd>. | <kbd>I</kbd> |

## Рисование текстуры (UV)

Кнопкой **Правка** можно рисовать прямо на изображении, с цветом, спадом, радиусом и силой. Сохраняется через дискету.
