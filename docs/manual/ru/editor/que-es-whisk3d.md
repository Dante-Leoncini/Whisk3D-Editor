# Что такое Whisk3D

Whisk3D — это свободный **3D-редактор и игровой движок**, написанный с нуля. Идея в том, чтобы создавать что угодно на том, что у тебя есть: он работает на ПК, на телефоне, а также на консолях и старых устройствах, не завися ни от современного железа, ни от проприетарных программ.

## Что можно делать

С **Whisk3D Editor** можно:

- **Моделировать** в 3D: меши с вершинами, рёбрами и гранями, и [модификаторы](objeto-malla.md#вкладка-модификаторы), которые работают, не разрушая меш.
- Делать для них **риг**: собрать [скелет](esqueletos.md) персонажа и нарисовать, насколько сильно двигает каждая кость.
- **Анимировать**: ключевые кадры, редактор кривых и скелетная анимация ([Таймлайн](linea-de-tiempo.md)).
- **Освещать** сцену точечными источниками, солнцем и прожекторами.
- **Рендерить** изображения и видео, в реальном времени или с **трассировкой лучей** (мягкие тени, отражения и прозрачность).
- **Рисовать** цвета вершин и текстуры прямо на модели ([Режимы рисования](pintura.md)).
- **Создавать игры**: логика пишется на [Lua](../lua/README.md) во встроенном [редакторе скриптов](editor-de-scripts.md); интерфейсы (меню, HUD) собираются в [2D-редакторе](editor-2d.md), а игра компилируется под каждую систему прямо из редактора.
- Импортировать и экспортировать модели в OBJ, FBX, glTF, GLB и STL.

Кроме того, у Whisk3D есть **собственный свободный формат** для сохранения проектов и игр: **`.w3d`**. Игру в `.w3d` можно открыть напрямую на любой системе, где работает Whisk3D, или **скомпилировать** под конкретную систему, чтобы выжать максимум из её железа. См. статью [W3D: свободный формат, чтобы видеоигры не умирали](https://leoncini.com.ar/articulo.php?id=w3d-formato-abierto&lang=ru).

Игры можно делать и **без редактора**, программируя прямо на **Whisk3D Core** на C и C++. Этот путь только для опытных пользователей, которые уже умеют программировать на C и C++: см. [Руководство по Whisk3D Core](../core/empezar.md).

## Где работает

| Система | |
|---|---|
| **ПК** | Windows, Linux и macOS |
| **Телефоны** | Android (начиная с 2.3) и Nokia N95 и N8 (Symbian) |
| **Браузер** | Любой современный браузер (WebGL) |
| **Консоли** | Sega Dreamcast, Sony PSP, PlayStation Vita и Nintendo 3DS |

## Как он устроен

Whisk3D — это три проекта, один поверх другого, как три шестерёнки, которые вращаются вместе:

- **Whisk3D Editor** (зелёная шестерёнка): редактор со всем, что описано выше.
- **[Whisk3D UI](https://leoncini.com.ar/proyecto.php?id=whisk3d-ui&lang=ru)** (жёлтая): отвечает за **интерфейс**: кнопки, меню, карточки свойств, текст и иконки. Редактор сделан на ней. См. [Руководство по Whisk3D UI](../ui/README.md).
- **[Whisk3D Core](https://leoncini.com.ar/proyecto.php?id=whisk3d-core&lang=ru)** (красная): **слой абстракции**. Whisk3D UI использует его для всего, что делает.

Игра или проект, созданные в редакторе, живут **внутри** редактора, а их логика написана на Lua. Но Editor и Whisk3D UI **необязательны**: можно пользоваться своими инструментами. Игра на C или C++ может использовать Whisk3D UI для своего интерфейса без редактора или обращаться **напрямую к Core**, со своим интерфейсом и своими инструментами. Обойтись нельзя только без Core.

![Архитектура Whisk3D в три слоя: сверху Editor (зелёный) с твоей игрой или проектом на Lua внутри; посередине Whisk3D UI (жёлтый); внизу Whisk3D Core (красный). Editor и UI необязательны: снаружи одна игра на C++ может использовать UI, а другая — напрямую Core. Core общается с каждой системой через свой бэкенд](img/whisk3d-capas.webp)

Core — это **секретный ингредиент**. Каждая система по-своему рисует, воспроизводит звук, читает файлы и получает нажатия клавиш: ПК использует OpenGL, у Dreamcast свой графический чип, у PSP и 3DS свои библиотеки, у браузера — WebGL. Ни редактор, ни игры не обращаются к каждой системе сами: они просят Core, всегда одинаково ("нарисуй этот меш", "воспроизведи этот звук", "открой этот файл"), а Core знает, как сделать это на каждой из них. Поэтому **один и тот же код** работает на таких разных машинах, а добавить новую систему — значит научить Core общаться с ней, а не переписывать редактор.

Как он это делает, во всех подробностях (графика, звук, файлы, ввод, сеть, логи): [Руководство по Whisk3D Core](../core/README.md).

## Проект

Вся работа сохраняется в файл проекта `.w3d`. Внутри хранятся сцена и ресурсы: текстуры (`texturas/`), скрипты (`scripts/`), звуки, сцены, префабы. Ресурс может находиться **внутри** .w3d или **снаружи**, как отдельный файл на диске; пункты меню "Сохранить внутри .w3d" и "Сохранить вне .w3d" переносят его из одного места в другое. См. [Проект](proyecto.md).

> [!NOTE]
> Это руководство описывает то, что Whisk3D умеет сегодня. Названия функций приведены так, как они отображаются в редакторе на русском языке. Указаны клавиши по умолчанию: их можно изменить в разделе [Горячие клавиши](atajos.md).
