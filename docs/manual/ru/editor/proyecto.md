# Проект (.w3d) и файлы

| Функция | Описание | Где |
|---|---|---|
| Открыть проект | Открывает .w3d (также двойным кликом в системе). | Свойства → Файл/Рендер → Файл |
| Сохранить / Сохранить как | Сохраняет в папку и под именем, указанными в карточке; Сохранить как спрашивает другое. Если имя не задано, поле становится красным. | Карточка Файл, <kbd>Ctrl+S</kbd> |
| Сохранить версию | Сохраняет и вдобавок оставляет пронумерованную копию (`proyecto_v03.w3d`). | Карточка Файл |
| Извлечь ассеты | Копирует всё содержимое в папку (копии не меняют проект). | Карточка Файл |
| Меши текстом | Сохраняет меши как читаемый текст вместо двоичного формата. | Карточка Файл |
| Импорт | OBJ, FBX, glTF, GLB и интерфейсы .w3dui. Импортированное копируется внутрь проекта (без дубликатов). | 3D-вьюпорт → Добавить → Импорт |
| Экспорт | OBJ, glTF или GLB выделенного объекта (с модификаторами и трансформациями или без них). | Свойства → Экспорт |
| Несохранённые изменения | Отредактированное, но не сохранённое (скрипты, раскрашенные текстуры) помечается `*`. При закрытии или открытии другого проекта предупреждение перечисляет, что будет потеряно. | Автоматически |
| Ресурс внутри или снаружи | Внешний ресурс не копируется: сохраняется его путь, а если файл пропал, выводится предупреждение. | Карточка Ресурс; "Сохранить внутри / вне .w3d" в IDE и UV-редакторе |

Сохранение никогда не оставляет файл записанным наполовину: сначала пишется временная копия, а затем она переименовывается.

## В браузере (веб-версия)

Браузер не позволяет странице самой читать и записывать файлы на компьютере. Поэтому в веб-версии:

- **Открыть проект**, **Импорт** и выбор текстуры открывают файловый диалог браузера: появляется окно с кнопкой **Выбрать файл**. Для OBJ выбирают сразу .obj, его .mtl и его текстуры; для glTF — .gltf и его .bin.
- **Сохранить** (<kbd>Ctrl+S</kbd>), **Сохранить как**, **Сохранить версию** и **Извлечь ассеты** скачивают файл в папку загрузок браузера. Так же работает **Экспорт** (OBJ скачивается вместе со своим .mtl и текстурами), и так же скачиваются рендер, UV-карта, раскрашенные текстуры, сохранённые снаружи, и внешние скрипты.
- Когда редактор просит папку для сохранения, никакой файловый диалог не открывается: файл сразу скачивается.
- Если браузер спрашивает, можно ли странице скачать несколько файлов, нужно согласиться. Иначе скачается только первый.
- Всё открытое живёт в памяти страницы: при её перезагрузке теряется всё, что не было скачано.
