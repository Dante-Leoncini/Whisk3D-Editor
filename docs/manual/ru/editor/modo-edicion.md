# Режим редактирования (меши)

Вход — клавишей <kbd>Tab</kbd> на меше. Работа идёт с **вершинами**, **рёбрами** или **гранями** в зависимости от кнопки на верхней панели.

## Выделение

| Функция | Описание | Сочетание |
|---|---|---|
| Выделить | Выбирает вершину, ребро или грань. | Клик; <kbd>Shift</kbd>+клик переключает |
| Выделить связанное | Весь связанный остров под указателем. | <kbd>L</kbd> |
| Выделить петлю | Кольцо рёбер или граней. | <kbd>Shift+Alt</kbd>+клик |
| Кратчайший путь | Выделяет путь между активным элементом и тем, по которому кликнули. | <kbd>Ctrl</kbd>+клик |
| Кратчайший путь (заливка области) | Выделяет всю область между ними. | <kbd>Ctrl+Shift</kbd>+клик |
| Все / Нет / Инвертировать / Выделение рамкой | Как в Объектном режиме, но для элементов меша. | <kbd>A</kbd> / <kbd>Alt+A</kbd> / <kbd>Ctrl+I</kbd> / <kbd>B</kbd> |

## Моделирование

| Функция | Описание | Сочетание |
|---|---|---|
| Переместить / Вращать / Масштаб | Трансформирует выделенное. Если перемещение уже идёт, повторное нажатие <kbd>G</kbd> переключает на скольжение. | <kbd>G</kbd> / <kbd>R</kbd> / <kbd>S</kbd> |
| Сжать/раздуть | Сдвигает каждую вершину вдоль её нормали (раздувает или сдувает). | <kbd>Alt+S</kbd> |
| Выдавить | Выдавливает новую геометрию из выделенного (грани выходят вдоль своей нормали). | <kbd>E</kbd> |
| Петлевой разрез и сдвиг | Разрезает кольцо рёбер. Колесо меняет количество разрезов; клик применяет, после чего разрез можно сдвинуть. | <kbd>Ctrl+R</kbd> |
| Новое ребро/грань из вершин | Соединяет выделенные вершины ребром или гранью. | <kbd>F</kbd> |
| Соединить путь вершин | Разрезает по прямой между двумя вершинами. | <kbd>J</kbd> |
| Сдвиг вершин | Сдвигает вершины вдоль их рёбер. | <kbd>Shift+V</kbd> |
| Разорвать | Разрывает меш по выделению. | <kbd>V</kbd> |
| Дублировать | Копирует выделенное и оставляет его захваченным. | <kbd>Shift+D</kbd> |
| Разделить | Переносит выделенные грани в новый объект. | <kbd>P</kbd> |
| Слить | Сливает вершины: В центре, У курсора, Схлопнуть или По расстоянию. | <kbd>M</kbd> |
| Автослияние | По окончании перемещения сливает вершины, оказавшиеся ближе порогового значения. | Меню Меш |
| Удалить | Вершины, рёбра, грани или петли рёбер. | <kbd>X</kbd> или <kbd>Delete</kbd> |
| Пересчитать нормали / Перевернуть | Исправляет направление граней или разворачивает их. | <kbd>Shift+N</kbd> |
| Триангулировать грани | Разбивает на треугольники грани, у которых больше 3 сторон. | <kbd>Ctrl+T</kbd> |
| Гладкое затенение / Плоское затенение | Как освещается поверхность. | Меню Грань |
| Пометить / Снять острое | Рёбра, которые выглядят жёсткими, даже если меш сглажен. | Меню Ребро |
| Пометить / Снять шов | Где меш разрезается при развёртке UV. | Меню Ребро или UV |
| Контекстное меню | Операции текущего подрежима (вершины, рёбра или грани) у указателя. | <kbd>W</kbd> или правый клик |
| Вставить ключевой кадр | Сохраняет форму меша в текущем кадре (вершинная анимация). | <kbd>I</kbd> |

## Меню UV

| Функция | Описание | Сочетание |
|---|---|---|
| Развернуть | По углам, конформно или с мин. растяжением: раскрывает меш по его швам. | <kbd>U</kbd> |
| Умная UV-проекция | Сама разрезает и разворачивает в зависимости от углов между гранями. | <kbd>U</kbd> |
| Упаковка лайтмапа / По активным квадам | Острова уложены без перекрытий / UV выровнены по активной грани. | <kbd>U</kbd> |
| Кубическая, Цилиндрическая, Сферическая проекция, Проекция из вида | Простые проекции. | <kbd>U</kbd> |
| Сбросить | Каждая грань занимает всё изображение. | <kbd>U</kbd> |

## Редактирование кривых (путей)

Клавишей <kbd>Tab</kbd> на кривой её узлы редактируются как меш из точек: <kbd>G</kbd> перемещает, <kbd>E</kbd> добавляет следующий узел, <kbd>X</kbd> удаляет.
