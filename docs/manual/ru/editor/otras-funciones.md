# Другие функции 3D-вьюпорта

| Функция | Описание | Как использовать |
|---|---|---|
| Вид из камеры | Вид через активную камеру с рамкой размера рендера. Внутри неё колесо или щипок дают зум для осмотра, не сдвигая камеру. | <kbd>Num0</kbd> |
| Локальный вид | Изолирует выделенное и его потомков (родители не рисуются: при выборе меша кости его скелета не видны); вверху слева появляется надпись **Локальный вид**. Повторное нажатие возвращает всё. | <kbd>/</kbd> |
| 3D-курсор | Точка, где появляются новые объекты; также служит опорной точкой. Ставится через меню Привязка (<kbd>Shift+S</kbd>). | <kbd>Shift+S</kbd> |
| Трассировка лучей | Реалистичный рендер с мягкими тенями, прозрачностью, отражениями (шероховатость и металличность материала), картами нормалей и прожекторами. Включается в Свойства → Рендер и виден в режиме Предпросмотр рендера. Трассирует на **GPU** (Vulkan: NVIDIA, AMD или Intel; с ядрами трассировки RTX/RDNA2/Arc, если драйвер их даёт) или на CPU. **Только итоговое изображение** скрывает постепенное построение. **Пропускание** материала (от 0 до 1) говорит, какая часть — стекло: свет проходит, преломляясь по **IOR** (1 = нет, 1.33 вода, 1.5 стекло), а с **Шероховатость** выходит матовым; прозрачное по альфе проходит прямо (при пропускании 0 IOR преломляет прозрачную часть, как раньше). См. [Свои шейдеры](shaders.md#с-трассировкой-лучей); **Слои прозрачности** ограничивает, сколько слоёв проходит луч (дальше чёрный). Каустики не моделируются. **Новый шум в каждом кадре** (включено по умолчанию) меняет шум в каждом кадре, чтобы в анимации он не «прилипал» к экрану. | Свойства → Рендер → Трассировка лучей, Устройство |
| Шумоподавление и апскейлинг | **Шумоподавление** убирает шум после нескольких проходов: **GPU (A-Trous)** на любой карте с Vulkan (в реальном времени), **Open Image Denoise** (CPU) и **OptiX** (NVIDIA). **Апскейлинг** (x2, x3, x4) трассирует в доле разрешения вида, очищает и увеличивает: больше кадров в секунду. Всё необязательно: чего нет на машине, то не показывается. **Апскейлер** выбирает способ увеличения: Линейная или **FSR 1** (AMD, открытый): более чёткие края, на любой видеокарте (на CPU). | Свойства → Рендер → Шумоподавление, Апскейлинг |
| Векторы и размытие движения | **Векторы движения** сохраняет ещё одно изображение (`_vectores`), где каждый пиксель показывает, насколько он сдвинулся на экране с прошлого кадра (красный = X, зелёный = Y; 128 = на месте, шаг = полпикселя). Это обычный проход OpenGL, который красит каждую вершину цветом её движения, поэтому он работает и в OpenGL ES 1.1. **Размытие движения** по этим векторам размывает изображение на CPU вдоль движения; **Затвор** (от 0 до 1) — какую часть кадра затвор камеры открыт (0,5 = классические 180°). | Свойства → Рендер → Векторы движения, Размытие движения |
| Трассированное размытие движения | При включённой **Трассировка лучей** **Трассир. размытие движения** трассирует каждый проход в другой момент затвора (Рендер изображения и Рендер анимации): движущиеся сетки и камера между соседними кадрами. Это настоящее размытие (тени, отражения, то, что за движущимся); ставьте достаточно проходов, чтобы не было видно копий. **Затвор** (от 0,01 до 1, по умолчанию 0,5) и **Позиция**: **Середина кадра**, **Начало кадра** или **Конец кадра**. Заменяет размытие по векторам. | Свойства → Рендер → Трассир. размытие движения |
| Глубина резкости камеры | У каждой камеры есть **Глубина резкости**: **Диафрагма (f)** (как у настоящего объектива: меньше = сильнее размытие), **Дистанция фокуса** (м, анимируется своим ромбиком ключа) и **Объект фокуса** (фокус сам следует за этим объектом). Оранжевая линия и крестик у камеры отмечают плоскость фокуса. **Трассировка лучей** делает это по-настоящему от объектива (при взгляде через камеру); **Глубина резкости** постобработки может брать тот же фокус и ту же диафрагму. Если поставить галочку, его параметры появляются сразу. | Свойства → Камера → Глубина резкости |
| Постобработка | Карточка под **Рендер**, как стек модификаторов: эффекты добавляются (**Добавить**), переставляются (**Поднять** / **Опустить**) и убираются (**Убрать**); у каждого свои параметры. **Зерно плёнки** (сила, размер, цветное), **Глубина резкости** по глубине (резкая зона; с **Использовать фокус камеры** — фокус и диафрагма активной камеры, а если у этой камеры глубина резкости выключена, ничего не размывается; без него — дистанция фокуса и размытие вручную) и **Размытие движения** по проходу движения (затвор). Это эффекты камеры: в режиме **Рендер** они видны только **при взгляде через активную камеру** и только **внутри её рамки** (в игровом режиме на весь экран — на всём экране) и попадают в отрендеренные изображения. Сделано для реального времени в играх: в OpenGL ES 2.0 и Vulkan всё идёт на GPU (виды глубины, нормалей, движения и Сплошной тоже); в OpenGL ES 1.1 (N95) и со стандартным OpenGL на ПК — на CPU, и карточка об этом предупреждает (на ПК **Настройки → Графика → OpenGL ES 2.0** или **Vulkan** переносит его на GPU). Независимо от трассированных размытия и глубины резкости: можно использовать одно, другое или оба. | Свойства → Рендер → Постобработка |
| Графика | В редакторе три бэкенда в одной программе: **OpenGL** (фиксированный конвейер, работает на старых картах), **OpenGL ES 2.0** (шейдеры) и **Vulkan**. Выбор применяется после перезапуска; если Vulkan на этой машине не работает, остаётся OpenGL. | Свойства → Настройки → Графика |
| Игровой режим | Когда анимация "Игра" запущена через Воспроизвести, клики и клавиши идут в игру. <kbd>Esc</kbd> ставит на паузу. | Кнопки Воспроизвести / Стоп на панели |
