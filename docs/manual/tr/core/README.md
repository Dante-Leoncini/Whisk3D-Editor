# Whisk3D Core kılavuzu

**Whisk3D Core**, Whisk3D'nin üzerine kurulduğu soyutlama katmanıdır: işleri istemenin tek bir yolu (çizmek, ses çalmak, dosya okumak, tuşları almak) ve her sistem için ayrı bir uygulama. Bu kılavuz, C ya da C++ ile programlayan ve doğrudan Core üzerinde bir oyun yapmak isteyenler içindir. Gözden geçirilecek taslak.

Tarayıcıda çalışan örnekleriyle projenin sayfası: **[Whisk3D Core](https://leoncini.com.ar/proyecto.php?id=whisk3d-core&lang=es)**. Kod, GitHub'da **[Whisk3D-Core](https://github.com/Dante-Leoncini/Whisk3D-Core)** deposunda, MIT lisansıyla.
