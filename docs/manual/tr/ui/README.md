# Whisk3D UI kılavuzu

**Whisk3D UI**, Whisk3D'nin arayüz kütüphanesidir: Whisk3D Core üzerine çizilen düğmeler, sekmeler, açılır menüler, özellik kartları, metin ve simgeler. Editör onunla yapılmıştır. Bu kılavuz, C ya da C++ ile programlayan ve onu kendi oyununun ya da programının arayüzü için kullanmak isteyenler içindir. Gözden geçirilecek taslak.

Projenin sayfası: **[Whisk3D UI](https://leoncini.com.ar/proyecto.php?id=whisk3d-ui&lang=es)**. Kod, GitHub'da **[Whisk3D-UI](https://github.com/Dante-Leoncini/Whisk3D-UI)** deposunda, MIT lisansıyla.
