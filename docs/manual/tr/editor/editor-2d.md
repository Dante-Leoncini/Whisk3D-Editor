# 2D Düzenleyici

Oyun arayüzleri, HUD'lar ve 2D oyunlar kurmak için: metinler, görüntüler, dikdörtgenler, kapsayıcılar, slice 9, düğmeler ve videolar.

| İşlev | Açıklama | Kısayol |
|---|---|---|
| Ekle | Metin, Görüntü, Dikdörtgen, Kapsayıcı, Slice 9, Düğme, Genişlet, Video; w3dui İçe Aktar. | Ekle menüsü |
| Seç | Tık seçer (sürüklemek taşır); <kbd>Shift</kbd>+tık ekler; boş alana tıklamak seçimi kaldırır. | Tık; <kbd>A</kbd> / <kbd>Alt+A</kbd> / <kbd>Ctrl+I</kbd> |
| Taşı / Döndür / Ölçekle | <kbd>X</kbd> / <kbd>Y</kbd> ekseni kilitler; değeri yazabilirsin. | <kbd>G</kbd> / <kbd>R</kbd> / <kbd>S</kbd> |
| Yeniden boyutlandırma | Etkin öğenin tutma noktaları. | Sürükleme |
| Çoğalt / Sil | Kaydırılmış ve tutulmuş bir kopya / onay isteyerek siler. | <kbd>Shift+D</kbd> / <kbd>X</kbd> |
| Ebeveyn Ata / Ebeveyni Kaldır | Seçim etkin öğenin çocuğu olur ya da yeniden doğrudan UI'a bağlanır. | Nesne menüsü |
| 2D İmleç | Boş alanda <kbd>Shift</kbd>+tık ile yerleştirilir. | <kbd>Shift</kbd>+tık |
| Oyun görünümü | Tuval, kılavuz çizgileri olmadan tam olarak cihazdaki gibi görünür. | <kbd>Num0</kbd> (<kbd>Esc</kbd> ile çıkılır) |
| Seçileni Çerçevele / Zoom 1:1…4:1 | Seçimi kadraja alır; piksel piksel tam yakınlaştırma. | <kbd>Num.</kbd> / Görünüm menüsü |
