# Whisk3D के ट्यूटोरियल

Whisk3D इस्तेमाल करना सीखने के लिए ट्यूटोरियल। ये व्यावहारिक उदाहरणों के साथ Whisk3D के अलग-अलग टूल समझाते हैं, किसी दरवाज़े जैसी सरल चीज़ से लेकर मध्यम और ज़्यादा उन्नत स्तर तक। प्रोग्राम के ट्यूटोरियल और वीडियो यहाँ धीरे-धीरे जोड़े जाएँगे। कोई भी सवाल हो तो Discord या Telegram पर पूछें।
