# ओरिजिन बदलना: एक दरवाज़ा

इस ट्यूटोरियल में आप एक दरवाज़े को कब्ज़े से खुलने वाला बनाएँगे। इसके लिए उसका **ओरिजिन** बदलना होगा: वह पॉइंट जिसके चारों ओर ऑब्जेक्ट घूमता है (Object Mode ट्यूटोरियल में [ओरिजिन](modo-objeto.md#ओरिजिन) देखें)।

हम पिछले ट्यूटोरियल, [एक दरवाज़ा मॉडल करना](modelar-puerta.md), वाले दरवाज़े से शुरू करते हैं, जिसका ओरिजिन बीच में है। अगर आपने उसे एक बगल वाला फ़ेस खिसकाकर बनाया था, तो ओरिजिन खिसका हुआ रह गया होगा: **Object → Set Origin → Origin to Geometry** उसे वापस बीच में ले आता है।

## दरवाज़ा ग़लत तरह घूमता है

उसे घुमाकर देखें। दरवाज़ा अपने केंद्र पर घूमता है, घूमने वाले दरवाज़े की तरह, कब्ज़े से नहीं:

![PC](img/icono-pc.svg) Gizmo से: उसके बीच में एक क्लिक उसे **Rotate** पर ले जाता है, और नीला छल्ला दरवाज़े को खड़े अक्ष पर घुमाता है।

![Gizmo के बीच में एक क्लिक उसे Rotate पर ले जाता है; नीला छल्ला ड्रैग होता है और दरवाज़ा अपने केंद्र पर घूमता है, घूमने वाले दरवाज़े की तरह, और लौट आता है](img/puerta-gira-mal-raton.webp)

![Android](img/icono-android.svg) उंगली से: Gizmo के बीच में एक टैप उसे **Rotate** पर ले जाता है, और नीला छल्ला ड्रैग किया जाता है।

![उंगली Gizmo के बीच में टैप करके उसे Rotate पर ले जाती है; फिर नीले छल्ले को ड्रैग करती है और दरवाज़ा अपने केंद्र पर घूमता है, और लौट आता है](img/puerta-gira-mal-dedo.webp)

![Nokia](img/icono-nokia.svg) Nokia N95 पर Gizmo बंद रहता है: <kbd>2</kbd> (रोटेट), <kbd>3</kbd> (Z अक्ष, यानी खड़ा अक्ष) और ऐरो; <kbd>OK</kbd> पुष्टि करता है।

![एक Nokia N95: 2 और 3 खड़े अक्ष पर रोटेट करना शुरू करते हैं; दायाँ ऐरो दरवाज़े को उसके केंद्र पर घुमाता है, बायाँ उसे लौटाता है और OK पुष्टि करता है](img/puerta-gira-mal-nokia.webp)

यह ग़लत तरह इसलिए घूमता है क्योंकि इसका ओरिजिन बीच में है। चलिए उसे कब्ज़े पर ले चलते हैं।

## ओरिजिन को कब्ज़े पर ले जाना

1. **Edit Mode में जाएँ।** मोड वाले बटन पर एक क्लिक और **Edit Mode** पर दूसरा (PC पर <kbd>Tab</kbd> से भी)।

   ![खुला हुआ मोड वाला बटन, Edit Mode हाइलाइट किया हुआ](img/puerta-paso-1.webp)

2. **फ़ेस चुनें।** Edit Mode में **Vertex / Edge / Face** बटन दिखता है: एक क्लिक करें और **Face** चुनें।

   ![खुला हुआ Vertex, Edge, Face बटन, Face हाइलाइट किया हुआ](img/puerta-paso-2.webp)

3. **कब्ज़े वाला फ़ेस चुनें।** दरवाज़े के बगल वाले संकरे फ़ेस पर एक क्लिक, उस तरफ़ जहाँ कब्ज़ा लगता है: वह हरा हो जाता है।

   ![दरवाज़े के बगल वाला संकरा फ़ेस, हरे रंग में चुना हुआ और एक घेरे से चिह्नित](img/puerta-paso-3.webp)

4. **3D कर्सर को वहाँ ले जाएँ।** **Mesh** मेनू में, **Snap** → **Cursor to Selected**: 3D कर्सर कब्ज़े पर आ जाता है।

   ![खुला हुआ Mesh मेनू, Snap सबमेनू के साथ और Cursor to Selected हाइलाइट किया हुआ](img/puerta-paso-4.webp)

5. **Object Mode में वापस जाएँ।** मोड वाले बटन पर एक क्लिक और **Object Mode** पर दूसरा (या <kbd>Tab</kbd>)।

   ![खुला हुआ मोड वाला बटन, Object Mode हाइलाइट किया हुआ; 3D कर्सर पहले से कब्ज़े पर है](img/puerta-paso-5.webp)

6. **ओरिजिन को 3D कर्सर पर ले जाएँ।** **Object** मेनू में, **Set Origin** → **Origin to 3D Cursor**। दरवाज़ा नहीं हिलता: हिलता है उसका ओरिजिन, और उसके साथ Gizmo, जो कब्ज़े पर आ जाता है।

   ![खुला हुआ Object मेनू, Set Origin सबमेनू के साथ और Origin to 3D Cursor हाइलाइट किया हुआ](img/puerta-paso-6.webp)

## अब यह सही घूमता है

Gizmo से उसे फिर से घुमाएँ: अब वह कब्ज़े से खुलता और बंद होता है।

![ओरिजिन कब्ज़े पर होने से, Gizmo का नीला छल्ला दरवाज़े को तब तक खोलता है जब तक वह बगल की ओर न हो जाए, और फिर बंद कर देता है](img/puerta-gira-bien-raton.webp)

![उंगली से, नीला छल्ला दरवाज़े को कब्ज़े से खोलता है और फिर बंद कर देता है](img/puerta-gira-bien-dedo.webp)

![एक Nokia N95: 2, 3 और दायाँ ऐरो दरवाज़े को कब्ज़े से खोलते हैं; बायाँ उसे बंद करता है और OK पुष्टि करता है](img/puerta-gira-bien-nokia.webp)

![Android](img/icono-android.svg) टचस्क्रीन पर ऊपर वाले कदम वैसे ही हैं, टैप के साथ: मेनू एक टैप से खुलते हैं और एक टैप से चुने जाते हैं।

![Nokia](img/icono-nokia.svg) Nokia N95 पर, <kbd>OK</kbd> Object Mode से Edit Mode पर ले जाता है और मेनू बाईं सिलेक्शन कुंजी से खुलते हैं।

## Set Origin के विकल्प

| विकल्प | क्या करता है |
|---|---|
| **Origin to Geometry** | ओरिजिन को मेश के केंद्र पर ले जाता है। |
| **Origin to 3D Cursor** | ओरिजिन को वहाँ ले जाता है जहाँ 3D कर्सर है। |
| **Geometry to Origin** | उलटा: ओरिजिन को वहीं रहने देता है और मेश को तब तक खिसकाता है जब तक उसका केंद्र उस पर न आ जाए। |

अगले ट्यूटोरियल में हम इसका हैंडल बनाएँगे: [दरवाज़े का हैंडल मॉडल करना](modelar-picaporte.md)।
