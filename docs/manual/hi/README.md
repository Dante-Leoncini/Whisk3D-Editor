# Whisk3D के ट्यूटोरियल और मैनुअल

- [ट्यूटोरियल](tutoriales/README.md): कदम-दर-कदम, एडिटर की तस्वीरों और एनिमेशन के साथ।
- [Whisk3D Editor मैनुअल](editor/README.md): एडिटर क्या-क्या कर सकता है, पैनल और मोड के क्रम में।
- [Whisk3D में Lua](lua/README.md): भाषा की बुनियादी बातें और गेम प्रोग्राम करने के लिए Whisk3D इसमें जो कुछ जोड़ता है।
- [Whisk3D UI मैनुअल](ui/README.md): इंटरफ़ेस की लाइब्रेरी (बटन, मेनू, कार्ड, टेक्स्ट), C या C++ में प्रोग्राम करने वालों के लिए।
- [Whisk3D Core मैनुअल](core/README.md): एब्स्ट्रैक्शन लेयर, जिसकी वजह से Whisk3D हर सिस्टम पर चलता है, C या C++ में प्रोग्राम करने वालों के लिए।
