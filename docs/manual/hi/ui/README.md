# Whisk3D UI मैनुअल

**Whisk3D UI** Whisk3D की इंटरफ़ेस लाइब्रेरी है: बटन, टैब, ड्रॉपडाउन मेनू, प्रॉपर्टी कार्ड, टेक्स्ट और आइकन, जो Whisk3D Core पर ड्रॉ होते हैं। एडिटर इसी से बना है। यह मैनुअल उनके लिए है जो C या C++ में प्रोग्राम करते हैं और इसे अपने गेम या प्रोग्राम के इंटरफ़ेस के लिए इस्तेमाल करना चाहते हैं। समीक्षा के लिए ड्राफ़्ट।

प्रोजेक्ट का पेज: **[Whisk3D UI](https://leoncini.com.ar/proyecto.php?id=whisk3d-ui&lang=hi)**। कोड GitHub पर **[Whisk3D-UI](https://github.com/Dante-Leoncini/Whisk3D-UI)** में है, MIT लाइसेंस के तहत।
