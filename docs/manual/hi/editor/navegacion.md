# 3D Viewport में नेविगेशन

## माउस से (PC)

| फ़ंक्शन | विवरण | कैसे इस्तेमाल करें |
|---|---|---|
| ऑर्बिट | पिवट पॉइंट के चारों ओर व्यू को घुमाता है। | बीच वाला बटन + ड्रैग, या <kbd>Alt</kbd> + बायाँ बटन + ड्रैग। |
| पैन (खिसकाना) | व्यू को बगल की ओर खिसकाता है। | <kbd>Shift</kbd> + बीच वाला बटन, या <kbd>Alt+Shift</kbd> + बायाँ बटन + ड्रैग। |
| ज़ूम | पास लाता है या दूर ले जाता है। | माउस व्हील। |
| Select | पॉइंटर के नीचे वाली चीज़ चुनता है (बटन छोड़ने पर तय होता है)। | बायाँ क्लिक; <kbd>Shift</kbd>+क्लिक जोड़ता या हटाता है। |
| Box Select | बैकग्राउंड पर ड्रैग करने से एक आयत बनता है। | बाएँ बटन से ड्रैग करें, या <kbd>B</kbd>। |
| Context menu | पॉइंटर की जगह पर मौजूदा मोड का मेनू खोलता है (ट्रांसफ़ॉर्म के दौरान, उसे रद्द करता है)। | दायाँ क्लिक। |
| Lock Orbit | जो ऑर्बिट करता था, वह अब पैन करता है: व्यू एक 2D बोर्ड जैसा बन जाता है। | View मेनू → Lock Orbit। |

## कीबोर्ड से

| फ़ंक्शन | विवरण | शॉर्टकट |
|---|---|---|
| Front View / Back View | सामने से या पीछे से देखता है। | <kbd>Num1</kbd> / <kbd>Ctrl+Num1</kbd> |
| Right View / Left View | बगल से देखता है। | <kbd>Num3</kbd> / <kbd>Ctrl+Num3</kbd> |
| Top View / Bottom View | ऊपर से या नीचे से देखता है। | <kbd>Num7</kbd> / <kbd>Ctrl+Num7</kbd> |
| Perspective / Orthographic | दोनों प्रोजेक्शन के बीच बदलता है। | <kbd>Num5</kbd> |
| Roll Left / Roll Right | व्यू को उसके अपने अक्ष पर 15° घुमाता है। | <kbd>Num4</kbd> / <kbd>Num6</kbd> |
| Camera View | सक्रिय कैमरे से देखता है (दोबारा दबाने पर बाहर आता है)। | <kbd>Num0</kbd> |
| Set Active Camera | सक्रिय ऑब्जेक्ट सक्रिय कैमरा बन जाता है। | <kbd>Ctrl+Num0</kbd> |
| Frame Selected | व्यू को चुनी हुई चीज़ों पर केंद्रित करता है और ज़ूम ठीक करता है। | <kbd>Num.</kbd> (न्यूमेरिक कीपैड का पॉइंट) |
| Local View | सिर्फ़ चुनी हुई चीज़ें दिखाता है और उन्हें फ़्रेम करता है; दोबारा दबाने पर सब कुछ वापस आ जाता है। | <kbd>/</kbd> |
| मॉडल इम्पोर्ट करना | OBJ, FBX, glTF या GLB इम्पोर्ट करने के लिए फ़ाइल ब्राउज़र खोलता है (सिर्फ़ PC)। | <kbd>Num9</kbd> |

## उंगलियों से (Android, टच वाला Web)

| फ़ंक्शन | विवरण | जेस्चर |
|---|---|---|
| ऑर्बिट | व्यू को घुमाता है। | एक उंगली से ड्रैग करें। |
| ज़ूम और पैन | पिंच करने से पास या दूर होता है; दोनों उंगलियों को एक साथ खिसकाने से पैन होता है। | दो उंगलियाँ। |
| Select | उंगली के नीचे वाली चीज़ चुनता है। | बिना हिलाए टैप करें और उंगली उठा लें। |
| Frame Selected | <kbd>Num.</kbd> जैसा ही। | दो उंगलियों से डबल टैप। |
| टच मॉडिफ़ायर | निचली बार के Shift और Ctrl बटन: ये चालू (हरे) रहते हैं, ताकि आप चयन में जोड़ सकें या पाथ चुन सकें। | Shift / Ctrl पर टैप करें। |
| व्यू (नेविगेट करना) | Edit Mode में और पेंट मोड में, उंगली चुनने या पेंट करने के बजाय नेविगेट करती है। | निचली बार में मॉनिटर के आकार वाला बटन। |

## Nokia N95 के कीपैड से

| फ़ंक्शन | कुंजी |
|---|---|
| ऑर्बिट | ऐरो कुंजियाँ (दबाए रखें) |
| ज़ूम / Frame Selected | <kbd>0</kbd> + ऊपर/नीचे / सिर्फ़ <kbd>0</kbd> |
| पैन | <kbd>\*</kbd> + ऐरो |
| व्यू (सामने, बगल, ऊपर) / Perspective-Orthographic | <kbd>#</kbd> + ऐरो / सिर्फ़ <kbd>#</kbd> |
| Move / Rotate / Scale (ट्रांसफ़ॉर्म के दौरान: X / Y / Z अक्ष) | <kbd>1</kbd> / <kbd>2</kbd> / <kbd>3</kbd> |
| Confirm / Cancel | OK (बीच वाली) / <kbd>C</kbd> |
| Delete (जब रद्द करने को कुछ न हो) / Undo और Redo | <kbd>C</kbd> / <kbd>C</kbd> + बायाँ या दायाँ |
| शेडिंग बदलना | <kbd>6</kbd> |
| Extrude (Edit Mode) | <kbd>7</kbd> |
| Loop Cut (Edit Mode) / Camera View (एडिट के बाहर) | <kbd>8</kbd> |
| Lock Orbit | <kbd>9</kbd> |
| चयन को बारी-बारी से बदलना / जोड़ना, हटाना, सब या कुछ नहीं | Pencil / Pencil + ऐरो |
| मेनू बार / वर्चुअल कर्सर | बाईं / दाईं सिलेक्शन कुंजी |
| व्यूपोर्ट बदलना, आकार बदलना, मैक्सिमाइज़ करना | हरी कुंजी (अकेली, + ऐरो, + OK) |
| फ़ुल स्क्रीन गेम मोड | हरी कुंजी + <kbd>0</kbd> (फिर से: इमेज पूरी स्क्रीन ढक लेती है; फिर से: वापस)। UI नहीं, कैमरे का बॉर्डर नहीं और आसपास का गहरा हिस्सा नहीं (काली पट्टियाँ सिर्फ़ तब रहती हैं जब कैमरा स्क्रीन से अलग आस्पेक्ट बताता है, दूसरी बार दबाने तक), और तीर पैन नहीं करते: गेम जैसा है वैसा दिखता है |

N95 Bluetooth माउस और कीबोर्ड भी स्वीकार करता है। टेक्स्ट लिखने के लिए T9 का इस्तेमाल होता है।
