# Script Editor (IDE)

Lua स्क्रिप्ट और [लिखे गए शेडर](shaders.md) (`.glsl`) के लिए टेक्स्ट एडिटर, जिसमें लाइन नंबर, सिंटैक्स कलर, इंडेंटेशन गाइड और ñ व एक्सेंट वाले अक्षरों का सपोर्ट है। जब फ़ोकस इस पर होता है, तो अक्षर टाइप होते हैं (एडिटर के शॉर्टकट नहीं चलाते)। Android पर, टेक्स्ट को टैप करने से कीबोर्ड खुलता है। N95 पर T9 से लिखा जाता है।

| फ़ंक्शन | विवरण | शॉर्टकट |
|---|---|---|
| Script | प्रोजेक्ट की कौन-सी .lua एडिट होगी, यह चुनें, या Load .lua… (कोई बाहरी फ़ाइल)। | Script मेनू |
| Save | स्क्रिप्ट सेव करता है। अगर वह .w3d के अंदर है, तो प्रोजेक्ट भी सेव करता है। | <kbd>Ctrl+S</kbd> या File → Save |
| Save As… | दूसरा नाम, प्रोजेक्ट के अंदर या बाहर, आपकी पसंद के फ़ोल्डर में। | File |
| Save inside the .w3d | सिर्फ़ तब, जब स्क्रिप्ट बाहरी हो: उसे प्रोजेक्ट के अंदर डाल देता है। | File |
| Save outside the .w3d… | सिर्फ़ तब, जब स्क्रिप्ट अंदरूनी हो: उसे बाहर एक फ़ाइल में निकालता है; ऑब्जेक्ट उसी फ़ाइल का इस्तेमाल करने लगते हैं। | File |
| Refresh | फ़ाइल को वैसा ही ले आता है जैसी वह डिस्क पर है (जो किसी दूसरे एडिटर में एडिट हुई हो)। अगर एडिटर में बिना सेव किए बदलाव हैं, तो उन्हें हटाने से पहले पूछता है (और उन्हें <kbd>Ctrl+Z</kbd> से वापस पाया जा सकता है)। गेम चलते समय, यह स्क्रिप्ट इस्तेमाल करने वाले ऑब्जेक्ट को लाइव दोबारा लोड करता है। | बटन |
| शेडर (.glsl) | मटीरियल से (**Shader** पंक्ति का छोटा बटन), Library से या सिलेक्टर से खुलते हैं और GLSL की तरह रंगे जाते हैं। नाम के पास **Compile** दिखता है: यह आप जो लिख रहे हैं उसे कंपाइल करता है (अगर कोई मटीरियल इसे इस्तेमाल करता है, तो उसे सेव करके उस मटीरियल को कंपाइल करता है)। शेडर सेव करने पर वह उसे इस्तेमाल करने वाले सभी मटीरियल में कंपाइल होता है, और बताता है कि कंपाइल हुआ या एरर उसकी लाइन के साथ दिखाता है। | <kbd>Ctrl+S</kbd> |
| सेव करते समय सुरक्षा | अगर बाहरी फ़ाइल खोलने के बाद बाहर से बदल गई हो, तो Save उसे ओवरराइट करने से पहले पूछता है। अगर गेम चल रहा है, तो Save स्क्रिप्ट को लाइव दोबारा लोड भी करता है। | अपने-आप |
| इंडेंटेशन (Tab) | <kbd>Tab</kbd> अगले 4 के गुणज तक भरता है; कई लाइनें चुनी होने पर उनमें एक लेवल जोड़ता है और <kbd>Shift+Tab</kbd> उसे हटाता है। खड़ी लाइनें हर लेवल को दिखाती हैं; कर्सर वाले ब्लॉक की लाइन ज़्यादा साफ़ दिखती है। | <kbd>Tab</kbd> / <kbd>Shift+Tab</kbd> |
| Edit मेनू | Undo, Redo, Cut, Copy, Paste, Find… और Replace… | Edit बटन |
| Select मेनू | Select All। | Select बटन |
| Undo / Redo | स्क्रिप्ट के टेक्स्ट पर (सीन पर नहीं)। | <kbd>Ctrl+Z</kbd> / <kbd>Ctrl+Y</kbd> या <kbd>Ctrl+Shift+Z</kbd> |
| Find / Replace | ऊपर दाईं ओर एक पैनल खोलता है: खोजने वाला टेक्स्ट, कितने मिलान हैं ("3 of 7"), Match case, Whole word, Previous / Next, और Replace में नया टेक्स्ट, Replace और Replace all के साथ (अनडू का एक ही कदम)। मिलान कोड में हाइलाइट होते हैं। पैनल एडिटर को ब्लॉक नहीं करता: पॉइंटर स्क्रिप्ट पर हो तो आप लिखते रह सकते हैं। यह Close या <kbd>Esc</kbd> से बंद होता है। | <kbd>Ctrl+F</kbd> / <kbd>Ctrl+H</kbd> |
| Copy / Cut / Paste | सिस्टम के क्लिपबोर्ड के साथ। | <kbd>Ctrl+C</kbd> / <kbd>Ctrl+X</kbd> / <kbd>Ctrl+V</kbd> |
| Select All / Undo | Undo टेक्स्ट पर असर डालता है, सीन पर नहीं। | <kbd>Ctrl+A</kbd> / <kbd>Ctrl+Z</kbd> |
| उंगली से चुनना | डबल टैप शब्द चुनता है, ट्रिपल टैप पूरी लाइन। चयन होने पर उसके सिरों पर दो हैंडल (हरे गोले) दिखते हैं: चयन एडजस्ट करने के लिए उन्हें ड्रैग करें। | टैप |
| मैग्निफ़ायर (टच) | कोड पर उंगली को एक पल स्थिर रखने से उंगली के ऊपर कर्सर के साथ बड़ी की हुई लाइन दिखती है; ड्रैग करने पर कर्सर उंगली के साथ चलता है और जहाँ आप उंगली उठाते हैं, वहीं रुक जाता है। | लंबा दबाना |
| N95 पर चुनना | ऐरो कुंजियाँ कर्सर को हिलाती हैं; Pencil कुंजी दबाए रखने पर ऐरो कुंजियाँ कर्सर की जगह से चयन करती हैं। जब तक Pencil दबी रहती है, नीचे एक बार दिखती है: बाईं सिलेक्शन कुंजी **कॉपी** करती है और दाईं **पेस्ट**। | Pencil + ऐरो / softkey |
| टेक्स्ट में घूमना | ऐरो कुंजियाँ, Home, End, PageUp, PageDown (<kbd>Shift</kbd> के साथ ये चयन करती हैं); <kbd>Ctrl+Home</kbd> / <kbd>Ctrl+End</kbd> शुरुआत या अंत पर ले जाती हैं। | कीबोर्ड |
