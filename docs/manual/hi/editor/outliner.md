# Outliner

सीन में मौजूद हर चीज़ की सूची, और साथ ही प्रोजेक्ट के रिसोर्स की लाइब्रेरी भी। Android पर यह नहीं दिखता (वहाँ आप 3D Viewport और Properties से काम करते हैं)।

## View मेनू (आँख)

| फ़ंक्शन | विवरण |
|---|---|
| Scene / Library / Libraries | क्या सूची में आएगा: सीन का ट्री, प्रोजेक्ट के सारे रिसोर्स, या किसी लिंक की हुई दूसरी .w3d के रिसोर्स (सिर्फ़ पढ़ने के लिए)। |
| Constructor / Routines | Constructor रूटीन (जो शुरू में सिर्फ़ एक बार चलती है) और बाकी रूटीन दिखाते या छिपाते हैं। |
| Visibility icons / Render icons | आँख वाले और कैमरे वाले कॉलम दिखाते या छिपाते हैं। |
| Grid | Library में: सूची की जगह थंबनेल। |
| Link .w3d… / Unlink | किसी दूसरे प्रोजेक्ट को लाइब्रेरी की तरह इस्तेमाल करता है, या उसे छोड़ देता है। |

## Scene व्यू

| फ़ंक्शन | विवरण | कैसे इस्तेमाल करें |
|---|---|---|
| Select | ऑब्जेक्ट चुनता है। <kbd>Shift</kbd>+क्लिक एक रेंज चुनता है; <kbd>Ctrl</kbd>+क्लिक जोड़ता या हटाता है। | क्लिक |
| खोलना / समेटना | चाइल्ड को दिखाता या छिपाता है। | ऐरो; <kbd>Left</kbd> / <kbd>Right</kbd> |
| Visible / Renderable | आँख ऑब्जेक्ट को छिपाती है (यह एनिमेट हो सकता है); कैमरा उसे रेंडर से बाहर रखता है। | आँख / कैमरे पर क्लिक |
| क्रम बदलना और पैरेंट करना | किसी दूसरी पंक्ति के पहले, बाद में या उसके ऊपर (चाइल्ड के रूप में) छोड़ें। | पंक्ति को ड्रैग करें |
| Move (reorder) | कीबोर्ड से: ऊपर/नीचे क्रम बदलता है, बायाँ पैरेंट से बाहर निकालता है, दायाँ पिछली पंक्ति के अंदर डालता है, <kbd>Enter</kbd> पुष्टि करता है। | <kbd>G</kbd> |
| Rename | पंक्ति एक टेक्स्ट फ़ील्ड बन जाती है। | डबल क्लिक या <kbd>F2</kbd> |
| Duplicate / Duplicate Linked | 3D Viewport की तरह। | <kbd>Shift+D</kbd> / <kbd>Alt+D</kbd> |
| Hide / Show | दिखाने और छिपाने के बीच बदलता है। | <kbd>H</kbd> |
| Delete | पुष्टि के साथ। | <kbd>X</kbd> या <kbd>Delete</kbd> |
| Create Prefab / Unpack Prefab | Object मेनू से। | दायाँ क्लिक |
| Show active | सूची को सक्रिय ऑब्जेक्ट तक स्क्रॉल करता है। | <kbd>Num.</kbd> |
| सूची स्क्रॉल करना | व्हील, या ड्रैग (उंगली से भी)। | व्हील / ड्रैग |

## Library व्यू

| फ़ंक्शन | विवरण |
|---|---|
| रिसोर्स | मेश, मटीरियल, टेक्सचर, एनिमेशन, प्रीफ़ैब, सीन, साउंड, स्क्रिप्ट, [शेडर](shaders.md), फ़ॉन्ट और वीडियो, फ़ोल्डरों में। 3D Viewport में किसी मेश पर ड्रैग किया गया मटीरियल या शेडर छोड़ने से पहले ही पॉइंटर के नीचे वाले हिस्से पर दिखता है। हरा टिक = इस्तेमाल में; लाल क्रॉस = अनाथ; `*` = सेव नहीं हुआ। |
| Filter / सूची या Grid | सिर्फ़ एक प्रकार दिखाना; थंबनेल देखना। |
| रिसोर्स को ड्रैग करना | किसी फ़ोल्डर में (उसे वहाँ ले जाता है), 3D Viewport में (मेश = नया ऑब्जेक्ट, मटीरियल या टेक्सचर = जिस पर छोड़ा उसे दे दिया जाता है, प्रीफ़ैब = इंस्टेंस) या Properties की किसी ड्रॉपडाउन सूची में। |
| New Folder / Move to Folder | व्यवस्थित करना (फ़ोल्डर सिर्फ़ क्रम से रखने के लिए हैं)। |
| Duplicate Resource / Select Users / Purge Orphans | कॉपी करना, यह पता करना कि उसे कौन इस्तेमाल करता है, और जिसे कोई इस्तेमाल नहीं करता उसे डिलीट करना। |
| Inside the .w3d / External | Properties से (Resource कार्ड): रिसोर्स को प्रोजेक्ट के अंदर या बाहर ले जाता है। |

## सीन, गेम और प्रीफ़ैब

सीन के नाम वाला बटन (Outliner में और 3D Viewport में) प्रोजेक्ट के सीन, गेम और प्रीफ़ैब की सूची दिखाता है। वहीं से आप नए बनाते हैं, शुरुआती सीन चुनते हैं और किसी सीन को गेम में बदलते हैं (या उलटा)।
