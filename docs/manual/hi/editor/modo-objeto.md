# Object Mode

| फ़ंक्शन | विवरण | कैसे इस्तेमाल करें |
|---|---|---|
| Select | एक ऑब्जेक्ट चुनता है। खाली जगह पर क्लिक करने से चयन हट जाता है। | क्लिक; <kbd>Shift</kbd>+क्लिक जोड़ता या हटाता है |
| Move / Rotate / Scale | [मूव, रोटेट और स्केल करना](transformar.md) देखें। | <kbd>G</kbd> / <kbd>R</kbd> / <kbd>S</kbd>, गिज़्मो |
| Add | 3D कर्सर पर एक नया ऑब्जेक्ट बनाता है ([Add मेनू](#add-मेनू) देखें)। | <kbd>Shift+A</kbd> या + बटन |
| Apply | पोज़िशन, रोटेशन, स्केल या सब कुछ मेश में बेक कर देता है (ऑब्जेक्ट 0, 0, 0 पर, बिना रोटेशन के और स्केल 1 पर रह जाता है)। | <kbd>Ctrl+A</kbd> |
| Set Origin | Geometry to Origin, Origin to Geometry, Origin to 3D Cursor। | Object मेनू |
| Duplicate Objects | स्वतंत्र कॉपी; वह मूव करने के लिए पकड़ी हुई रहती है। | <kbd>Shift+D</kbd> |
| Duplicate Linked | ऐसी कॉपी जो मूल ऑब्जेक्ट के साथ मेश शेयर करती है (एक को एडिट करने से दोनों एडिट होते हैं)। | <kbd>Alt+D</kbd> |
| Join | चुनी हुई मेश को सक्रिय ऑब्जेक्ट में मिला देता है। | <kbd>Ctrl+J</kbd> |
| Set Parent | चुनी हुई चीज़ें सक्रिय ऑब्जेक्ट की चाइल्ड बन जाती हैं (ट्रांसफ़ॉर्म रखते हुए या बिना रखे)। | <kbd>Ctrl+P</kbd> |
| Clear Parent | पैरेंट हटा देता है (पोज़िशन रखते हुए या बिना रखे)। | <kbd>Alt+P</kbd> |
| Delete | चुने हुए ऑब्जेक्ट डिलीट करता है (पुष्टि माँगता है)। | <kbd>X</kbd> या <kbd>Delete</kbd> |
| Hide / Show | सक्रिय ऑब्जेक्ट को दिखाने और छिपाने के बीच बदलता है। | <kbd>H</kbd> |
| Create Prefab / Unpack Prefab | चयन को दोबारा इस्तेमाल होने वाले प्रीफ़ैब में बदलता है, या किसी इंस्टेंस को फिर से अलग करता है। | Object मेनू |
| Insert Keyframe | मौजूदा फ़्रेम में पोज़िशन, रोटेशन और/या स्केल सेव करता है (चैनलों का मेनू)। <kbd>Shift+I</kbd> बिना पूछे सब कुछ सेव करता है। | <kbd>I</kbd> |
| Delete Keyframe / Clear Keyframe | मौजूदा फ़्रेम का कीफ़्रेम या पूरा एनिमेशन डिलीट करता है। | Animation मेनू |
| Motion Trail | एनिमेटेड ऑब्जेक्ट जिस रास्ते पर चलते हैं, उसे ड्रॉ करता है। | Animation मेनू |
| मोड बदलना | मेश: Object ↔ Edit। आर्मेचर: Object ↔ Pose। कर्व: नोड एडिट करना। | <kbd>Tab</kbd> |

## Add मेनू

सिर्फ़ Object Mode में। नई चीज़ 3D कर्सर पर दिखती है और चुनी हुई रहती है। प्रिमिटिव एक पैनल खोलते हैं, जिसमें आप उनका माप एडजस्ट कर सकते हैं।

| फ़ंक्शन | विवरण |
|---|---|
| Mesh | Plane, Cube, Circle, UV Sphere, Cone, Cylinder (साइज़, रेडियस, सेगमेंट और स्मूद शेडिंग के साथ)। साथ ही Vertex (मॉडलिंग शुरू करने के लिए एक अकेला पॉइंट) और Reference (ट्रेस करने के लिए इमेज वाला एक प्लेन)। |
| Empty | बिना मेश का ऑब्जेक्ट, ग्रुप बनाने के लिए या रेफ़रेंस पॉइंट के रूप में। |
| Camera / Light / Fog | सीन का कैमरा, लाइट और फ़ॉग। लाइट का **Type** होता है: Point, Sun (दिशात्मक) या Spot (एक कोन, व्यूपोर्ट में दिखता है); Add में Sun और Spot सीधे भी हैं। **Intensity** इसे तेज़ करता है (एनिमेट हो सकता है); **Distance** (मीटर) बताता है कि पॉइंट या स्पॉट लाइट कहाँ तक पहुँचती है, और यही उसके कोन की लंबाई है (0 = कोई सीमा नहीं; रे ट्रेसिंग वहाँ रोशनी धीरे-धीरे बुझा देती है)। लाइट चुनी होने पर स्पॉट अपना कोन और पॉइंट लाइट उस दूरी का गोला दिखाती है; सूरज हमेशा फ़र्श तक एक रेखा दिखाता है, उस दिशा में जहाँ वह रोशनी डालता है। |
| Sound | सीन में रखी एक ध्वनि (स्पीकर आइकन)। टाइमलाइन के साथ **सेकंड** में बजती है, फ़्रेम में नहीं; **Positional (3D)** से यह अपनी जगह से सुनाई देती है (कैमरा जितना पास, उतनी तेज़, उसी तरफ़ से); इसके बिना संगीत की तरह। 3D व्यू में .wav छोड़ने पर वहीं एक बनती है। |
| Armature | एक बोन वाला आर्मेचर, कैरेक्टर एनिमेट करने के लिए। |
| Path | दो नोड वाला कर्व (मेश की तरह एडिट होता है: <kbd>E</kbd> नोड जोड़ता है)। |
| Collection | ऑब्जेक्ट व्यवस्थित करने के लिए एक फ़ोल्डर। |
| UI | गेम के लिए एक 2D इंटरफ़ेस (2D Editor में एडिट होता है)। |
| Hitbox | टक्कर पहचानने वाला एक बॉक्स; अगर कोई सक्रिय ऑब्जेक्ट है, तो यह उसका चाइल्ड बनकर और उसी के साइज़ का बनता है। |
| Physics | कोई ऑब्जेक्ट नहीं बनाता: सक्रिय ऑब्जेक्ट में एक रिजिड बॉडी जोड़ता है। |
| Particles | एक पार्टिकल एमिटर। |
| LOD / Culling / Grid Cull | ऑप्टिमाइज़ेशन वाले ऑब्जेक्ट: डिटेल के लेवल, और जो नहीं दिखता उसे छिपाना। |
| Clear Depth / Screen Rect | ड्रॉइंग टूल: गहराई साफ़ करना या स्क्रीन के किसी हिस्से को काटकर अलग करना। |
| Prefab / Scene / Proxy W3D | प्रोजेक्ट का कोई प्रीफ़ैब, कोई दूसरा सीन, या किसी बाहरी लाइब्रेरी का प्रीफ़ैब डालना। |
| Imports | OBJ, FBX, glTF, GLB या Whisk3D UI इंटरफ़ेस। |
| Core (advanced) | रूटीन: ड्रॉइंग के कदमों की सूचियाँ जो हाथ से बनाई जाती हैं (ट्रांसफ़ॉर्म, ड्रॉ, टेक्सचर, लाइट, फ़ॉग, ब्लेंडिंग, डेप्थ, कंट्रोल, Call Lua)। इसमें **Routine loop** भी शामिल है: एक रूटीन जो अपने कदमों को कई बार दोहराती है (जैसे "ट्रांसलेट, ड्रॉ" 20 बार), ऐरे की तरह, लेकिन ज़्यादा तेज़। |
