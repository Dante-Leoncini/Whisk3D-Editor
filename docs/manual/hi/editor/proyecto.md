# प्रोजेक्ट (.w3d) और फ़ाइलें

| फ़ंक्शन | विवरण | कहाँ |
|---|---|---|
| Open project | एक .w3d खोलता है (सिस्टम से डबल क्लिक करके भी)। | Properties → File/Render → File |
| Save / Save As | कार्ड में दिए फ़ोल्डर में और उसी नाम से सेव करता है; Save As दूसरा नाम पूछता है। अगर नाम नहीं दिया गया है, तो फ़ील्ड लाल हो जाता है। | File कार्ड, <kbd>Ctrl+S</kbd> |
| Save version | सेव करता है और साथ में एक नंबर वाली कॉपी भी रखता है (`proyecto_v03.w3d`)। | File कार्ड |
| Extract assets | अंदर की हर चीज़ को एक फ़ोल्डर में कॉपी करता है (कॉपियों से प्रोजेक्ट नहीं बदलता)। | File कार्ड |
| Meshes as text | मेश को बाइनरी के बजाय पढ़ने लायक टेक्स्ट के रूप में सेव करता है। | File कार्ड |
| Imports | OBJ, FBX, glTF, GLB और .w3dui इंटरफ़ेस। इम्पोर्ट की गई चीज़ प्रोजेक्ट के अंदर कॉपी होती है (बिना डुप्लिकेट के)। | 3D Viewport → Add → Imports |
| Export | चुने हुए ऑब्जेक्ट का OBJ, glTF या GLB (मॉडिफ़ायर और ट्रांसफ़ॉर्मेशन के साथ या उनके बिना)। | Properties → Export |
| बिना सेव किए बदलाव | जो एडिट हुआ पर सेव नहीं हुआ (स्क्रिप्ट, पेंट किए गए टेक्सचर), उस पर `*` का निशान लगता है। बंद करते समय या दूसरा प्रोजेक्ट खोलते समय, एक चेतावनी बताती है कि क्या खो जाएगा। | अपने-आप |
| रिसोर्स अंदर या बाहर | बाहरी रिसोर्स कॉपी नहीं होता: उसका पाथ सेव होता है और अगर वह न मिले तो चेतावनी दी जाती है। | Resource कार्ड; IDE और UV Editor में "Save inside / outside the .w3d" |

सेव करते समय फ़ाइल कभी अधूरी नहीं रहती: पहले एक अस्थायी कॉपी लिखी जाती है और फिर उसका नाम बदला जाता है।

## ब्राउज़र में (वेब वर्ज़न)

ब्राउज़र किसी पेज को अपने-आप PC की फ़ाइलें पढ़ने या लिखने नहीं देता। इसलिए, वेब वर्ज़न में:

- **Open project**, **Imports** और टेक्सचर चुनना ब्राउज़र का फ़ाइल एक्सप्लोरर खोलते हैं: **Choose file** बटन वाला एक बॉक्स दिखता है। OBJ के लिए .obj, उसकी .mtl और उसके टेक्सचर एक साथ चुने जाते हैं; glTF के लिए, .gltf और उसकी .bin।
- **Save** (<kbd>Ctrl+S</kbd>), **Save As**, **Save version** और **Extract assets** फ़ाइल को ब्राउज़र के डाउनलोड फ़ोल्डर में डाउनलोड करते हैं। यही **Export** के साथ होता है (OBJ अपनी .mtl और अपने टेक्सचर के साथ, बगल में, डाउनलोड होता है), और रेंडर, UV मैप, बाहर सेव किए गए पेंट किए हुए टेक्सचर और बाहरी स्क्रिप्ट के साथ भी।
- जब एडिटर सेव करने के लिए कोई फ़ोल्डर माँगता है, तो कोई एक्सप्लोरर नहीं खुलता: फ़ाइल सीधे डाउनलोड हो जाती है।
- अगर ब्राउज़र पूछे कि क्या पेज कई फ़ाइलें डाउनलोड कर सकता है, तो अनुमति दें। वरना सिर्फ़ पहली फ़ाइल डाउनलोड होती है।
- जो खोला गया है, वह पेज की मेमोरी में रहता है: पेज रीलोड करने पर वह सब खो जाता है जो डाउनलोड नहीं किया गया।
