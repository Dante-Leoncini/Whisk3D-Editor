# Timeline

एनिमेशन दिखाता और एडिट करता है: कीफ़्रेम शीट (dope sheet) या कर्व एडिटर। यह **चुनी हुई** चीज़ों का एनिमेशन दिखाता है।

## ऊपरी बार

| फ़ंक्शन | विवरण |
|---|---|
| ट्रांसपोर्ट | शुरुआत पर जाएँ, पिछला कीफ़्रेम, पिछला फ़्रेम, उलटा चलाएँ, चलाएँ / रोकें, अगला फ़्रेम, अगला कीफ़्रेम, अंत पर जाएँ। |
| Start / End / FPS | एनिमेशन की रेंज और रफ़्तार (टाइप करने के लिए क्लिक करें)। |
| Animation | कौन-सा एनिमेशन एडिट होगा (सीन, क्लिप, आर्मेचर, ऑब्जेक्ट, फ़्लिपबुक, Game, Mix), और नए बनाना। |
| Auto Key | लाल होने पर: हर ट्रांसफ़ॉर्म अपने-आप कीफ़्रेम रिकॉर्ड करता है। |
| Curves / Dope Sheet | कीफ़्रेम शीट और कर्व एडिटर के बीच बदलता है। |
| Select, Key, View, Pivot | चयन के मेनू, कीफ़्रेम पर ऑपरेशन, फ़्रेमिंग और साइड पैनल, और <kbd>S</kbd> किस जगह से स्केल करेगा (केंद्र या मौजूदा फ़्रेम)। |

## समय में घूमना

| फ़ंक्शन | विवरण | शॉर्टकट |
|---|---|---|
| फ़्रेम बदलना | फ़्रेम नंबरों पर क्लिक या ड्रैग करें (scrub)। मौजूदा फ़्रेम (हरा) टाइप भी किया जा सकता है। | क्लिक |
| Previous frame / Next frame | एक फ़्रेम पीछे या आगे। | <kbd>Left</kbd> / <kbd>Right</kbd> |
| Previous keyframe / Next keyframe | सबसे पास वाले कीफ़्रेम पर कूदता है। | <kbd>Down</kbd> / <kbd>Up</kbd> |
| Go to start / Go to end | पहला या आख़िरी फ़्रेम। | <kbd>Home</kbd> / <kbd>End</kbd> |
| Play / Pause | किसी भी पैनल से। | <kbd>Space</kbd> |
| ज़ूम और पैन | व्हील = ज़ूम (कर्व में, <kbd>Ctrl</kbd> = सिर्फ़ समय, <kbd>Shift</kbd> = सिर्फ़ वैल्यू); बीच वाला बटन = पैन। | व्हील / बीच वाला बटन |
| Frame Selected | व्यू को चुनी हुई चीज़ों के हिसाब से एडजस्ट करता है। | <kbd>Num.</kbd> |

## कीफ़्रेम एडिट करना (dope sheet और कर्व)

| फ़ंक्शन | विवरण | शॉर्टकट |
|---|---|---|
| Select | किसी डायमंड पर क्लिक करें, या किसी पंक्ति पर क्लिक करके उसके सारे कीफ़्रेम लें; <kbd>Shift</kbd> जोड़ता है। | क्लिक; <kbd>A</kbd> / <kbd>Alt+A</kbd> / <kbd>Ctrl+I</kbd> |
| कीफ़्रेम मूव करना | कीफ़्रेम को समय में खिसकाता है (किसी डायमंड को ड्रैग करके भी)। | <kbd>G</kbd> |
| कीफ़्रेम स्केल करना | पिवट से फैलाता या सिकोड़ता है। | <kbd>S</kbd> |
| Rotate handles | सिर्फ़ कर्व में। | <kbd>R</kbd> |
| Duplicate | कीफ़्रेम की कॉपी बनाता है और उन्हें पकड़े रखता है। | <kbd>Shift+D</kbd> |
| Delete | चुने हुए कीफ़्रेम (या पंक्तियों के कर्व) डिलीट करता है। | <kbd>X</kbd> |
| Interpolation | Constant, Linear या Bezier। | <kbd>T</kbd> |
| Handle type | Free, Aligned, Vector, Automatic, Auto Clamped (सिर्फ़ कर्व)। | <kbd>V</kbd> |
| Smart Euler | चुने हुए रोटेशन में से फ़ालतू चक्कर हटाता है। | Key मेनू |
| कोई कर्व छिपाना | हर पंक्ति की आँख उसे छिपाती है। | आँख पर क्लिक |
| सटीक वैल्यू | चुने हुए कीफ़्रेम का फ़्रेम, वैल्यू और हैंडल। | Properties → Animation → Keyframe |

## ध्वनियाँ

| फ़ंक्शन | विवरण | शॉर्टकट |
|---|---|---|
| ध्वनि की पट्टी | हर चुने हुए Sound ऑब्जेक्ट की एक पट्टी होती है: कहाँ शुरू होती है और कितनी लंबी है, **सेकंड** में (FPS बदलने से नहीं खिसकती)। लूप हो तो अंत तक दोहराती है। | — |
| खिसकाना | पट्टी को खींचें, या कोई कीफ़्रेम चुने बिना <kbd>G</kbd> (सभी चुनी ध्वनियाँ खिसकती हैं)। <kbd>Ctrl</kbd> फ़्रेम पर टिकाता है। | खींचना / <kbd>G</kbd> |
| काटना | पट्टी का एक सिरा पकड़ें। | सिरा खींचें |
| Waveform / Volume line | View मेनू: पट्टी के अंदर वेवफ़ॉर्म और वॉल्यूम कर्व (पट्टी तीन पंक्तियाँ लेती है)। इनके बिना सिर्फ़ पट्टी। | View मेनू |
