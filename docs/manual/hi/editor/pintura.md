# पेंट मोड

> [!NOTE]
> तीनों पेंट मोड **सिर्फ़ 3D मेश के लिए** हैं: ये कैमरे, लाइट, आर्मेचर, कर्व या 2D एलिमेंट के साथ नहीं दिखते। पेंट करते समय क्लिक से चयन नहीं बदलता; किसी दूसरे ऑब्जेक्ट को पेंट करने के लिए उसे Outliner में चुनें।

## तीनों में एक जैसी चीज़ें

| फ़ंक्शन | विवरण | कैसे इस्तेमाल करें |
|---|---|---|
| पेंट करना | सिर्फ़ सामने वाले दिखने वाले फ़ेस पर पेंट करता है (X-Ray के साथ पीछे वाले फ़ेस पर भी)। हर स्ट्रोक अनडू का एक कदम है। | क्लिक करके ड्रैग करें |
| Radius | ब्रश का साइज़, पिक्सेल में। इसे बदलने पर व्यू के बीच में असली साइज़ का एक गोला दिखता है। | टूलबार के ऊपर ड्रैग करने वाली बार |
| Value | ब्रश की तीव्रता। | ड्रैग करने वाली बार |
| Falloff | ब्रश का किनारा कैसे नरम होता है; आप अपना खुद का कर्व भी बना सकते हैं। | Falloff बटन |
| व्यू (टच) | चालू: उंगली नेविगेट करती है। बंद: उंगली पेंट करती है। | मॉनिटर के आकार वाला बटन |

## Weight Paint

पेंट करता है कि कोई बोन हर वर्टेक्स पर कितना असर डालती है (नीला = बिल्कुल नहीं, लाल = पूरा)। इसी से मेश आर्मेचर के साथ ठीक से मुड़ती है।

| फ़ंक्शन | विवरण |
|---|---|
| ब्रश मोड | जोड़ना (+), घटाना (−) या बराबर करना (=, सटीक वैल्यू लगाता है)। |
| Vertex Group | कौन-सा ग्रुप (बोन) पेंट होगा; आप ग्रुप जोड़ भी सकते हैं। अगर कोई ग्रुप नहीं है, तो पहला स्ट्रोक एक ग्रुप बना देता है। |
| मार्कर | हर वर्टेक्स पर एक छोटा वर्ग दिखाता है; ब्रश सिर्फ़ उन्हीं पर काम करता है। |
| Selected only | जो चुना नहीं गया है उसे सुरक्षित रखता है (वह गहरा दिखता है)। |

## Vertex Paint

किसी **3D मेश** के वर्टेक्स पर रंग पेंट करता है (यह इमेज या 2D एलिमेंट के लिए नहीं है: उसके लिए टेक्सचर पेंटिंग है)। यह बहुत हल्का है और N95 पर रंग देने का सुझाया गया तरीका है।

| फ़ंक्शन | विवरण |
|---|---|
| Color | कलर पिकर खोलता है (RGB, HSV, हेक्साडेसिमल या पैलेट का कोई इंडेक्स)। |
| Per-Vertex / Per-Corner | Per-Vertex में रंग फ़ेस के बीच शेयर होता है; Per-Corner में हर फ़ेस का अपना रंग हो सकता है (सख़्त किनारे)। |
| Color Layers | कलर लेयर चुनना या बनाना। |
| मार्कर / Selected only | Weight Paint जैसा ही। |

## Texture Paint

सीधे 3D ऑब्जेक्ट पर पेंट करता है और स्ट्रोक उसके टेक्सचर में पहुँच जाता है।

| फ़ंक्शन | विवरण |
|---|---|
| अपने-आप बनने वाला टेक्सचर | अगर मेश में टेक्सचर नहीं है, तो पहले स्ट्रोक पर वह अपने-आप बन जाता है: एक अपना मटीरियल, अपने-आप बने UV और मटीरियल के रंग की 1024×1024 (N95 पर 256×256) की इमेज। |
| Color, Falloff, Radius, Value | दूसरे मोड की तरह। |
| Save Texture | पेंटिंग तब तक मेमोरी में रहती है जब तक उसे सेव न किया जाए। बिना सेव किए बदलाव होने पर डिस्केट हरा हो जाता है। विकल्प: Save, Save As…, Save inside the .w3d और Save outside the .w3d… |
