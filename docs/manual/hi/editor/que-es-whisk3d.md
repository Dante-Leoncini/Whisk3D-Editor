# Whisk3D क्या है

Whisk3D एक मुक्त **3D एडिटर और गेम इंजन** है, जो बिल्कुल शुरू से बनाया गया है। इसका विचार यह है कि आपके पास जो कुछ भी है, उसी से आप जो चाहें बना सकें: यह PC पर, फ़ोन पर, और कंसोल और पुराने डिवाइस पर भी चलता है, आधुनिक हार्डवेयर या प्रोप्राइटरी सॉफ़्टवेयर पर निर्भर हुए बिना।

## क्या-क्या किया जा सकता है

**Whisk3D Editor** से आप ये कर सकते हैं:

- 3D में **मॉडलिंग**: वर्टेक्स, एज और फ़ेस वाली मेश, और [मॉडिफ़ायर](objeto-malla.md#modifiers-टैब), जो मेश को नष्ट किए बिना काम करते हैं।
- उनकी **रिगिंग**: किसी कैरेक्टर का [आर्मेचर](esqueletos.md) बनाना और पेंट करना कि हर बोन कितना हिलाती है।
- **एनिमेशन**: कीफ़्रेम, कर्व एडिटर और आर्मेचर वाले एनिमेशन ([Timeline](linea-de-tiempo.md))।
- सीन को पॉइंट, सन और स्पॉट लाइट से **रोशन** करना।
- इमेज और वीडियो **रेंडर** करना, रियल टाइम में या **रे ट्रेसिंग** के साथ (नरम छायाएँ, रिफ़्लेक्शन और ट्रांसपेरेंसी)।
- वर्टेक्स के रंग और टेक्सचर सीधे मॉडल पर **पेंट** करना ([पेंट मोड](pintura.md))।
- **गेम बनाना**: लॉजिक [Lua](../lua/README.md) में लिखा जाता है, बिल्ट-इन [स्क्रिप्ट एडिटर](editor-de-scripts.md) के साथ; इंटरफ़ेस (मेनू, HUD) [2D Editor](editor-2d.md) में बनाए जाते हैं, और गेम उसी एडिटर से हर सिस्टम के लिए कंपाइल होता है।
- OBJ, FBX, glTF, GLB और STL में मॉडल इम्पोर्ट और एक्सपोर्ट करना।

इसके अलावा, प्रोजेक्ट और गेम सेव करने के लिए Whisk3D का **अपना मुक्त फ़ॉर्मेट** है: **`.w3d`**। `.w3d` में बना गेम किसी भी ऐसे सिस्टम पर सीधे खोला जा सकता है जहाँ Whisk3D चलता है, या किसी ख़ास सिस्टम के लिए **कंपाइल** किया जा सकता है, ताकि उसके हार्डवेयर का पूरा फ़ायदा मिले। लेख [W3D: एक मुक्त फ़ॉर्मेट, ताकि वीडियो गेम कभी न मरें](https://leoncini.com.ar/articulo.php?id=w3d-formato-abierto&lang=hi) देखें।

गेम **एडिटर के बिना** भी बनाए जा सकते हैं, सीधे **Whisk3D Core** पर C और C++ में प्रोग्राम करके। यह रास्ता सिर्फ़ अनुभवी उपयोगकर्ताओं के लिए है, जो पहले से C और C++ में प्रोग्राम करना जानते हैं: [Whisk3D Core मैनुअल](../core/empezar.md) देखें।

## यह कहाँ चलता है

| सिस्टम | |
|---|---|
| **PC** | Windows, Linux और macOS |
| **फ़ोन** | Android (2.3 से) और Nokia N95 और N8 (Symbian) |
| **ब्राउज़र** | कोई भी आधुनिक ब्राउज़र (WebGL) |
| **कंसोल** | Sega Dreamcast, Sony PSP, PlayStation Vita और Nintendo 3DS |

## यह कैसे बना है

Whisk3D तीन प्रोजेक्ट हैं, एक के ऊपर एक, जैसे तीन गियर जो साथ-साथ घूमते हैं:

- **Whisk3D Editor** (हरा गियर): एडिटर, ऊपर बताई गई सारी चीज़ों के साथ।
- **[Whisk3D UI](https://leoncini.com.ar/proyecto.php?id=whisk3d-ui&lang=hi)** (पीला): **इंटरफ़ेस** सँभालता है: बटन, मेनू, प्रॉपर्टी के कार्ड, टेक्स्ट और आइकन। एडिटर इसी से बना है। [Whisk3D UI मैनुअल](../ui/README.md) देखें।
- **[Whisk3D Core](https://leoncini.com.ar/proyecto.php?id=whisk3d-core&lang=hi)** (लाल): **एब्स्ट्रैक्शन लेयर**। Whisk3D UI अपना हर काम इसी से करता है।

एडिटर में बना कोई गेम या प्रोजेक्ट एडिटर के **अंदर** रहता है, और उसका लॉजिक Lua में लिखा होता है। लेकिन Editor और Whisk3D UI **वैकल्पिक** हैं: आप अपने खुद के टूल इस्तेमाल कर सकते हैं। C या C++ में बना कोई गेम एडिटर के बिना अपने इंटरफ़ेस के लिए Whisk3D UI इस्तेमाल कर सकता है, या अपने इंटरफ़ेस और अपने टूल के साथ **सीधे Core से** बात कर सकता है। बस Core का होना ज़रूरी है।

![तीन परतों में Whisk3D की संरचना: ऊपर Editor (हरा), जिसके अंदर Lua में आपका गेम या प्रोजेक्ट है; बीच में Whisk3D UI (पीला); नीचे Whisk3D Core (लाल)। Editor और UI वैकल्पिक हैं: बाहर से, C++ में बना एक गेम UI इस्तेमाल कर सकता है और दूसरा सीधे Core। Core हर सिस्टम से उसके अपने बैकएंड के ज़रिए बात करता है](img/whisk3d-capas.webp)

Core ही **असली राज़** है। हर सिस्टम अपने तरीके से ड्रॉ करता है, आवाज़ निकालता है, फ़ाइलें पढ़ता है और कुंजियाँ लेता है: PC OpenGL इस्तेमाल करता है, Dreamcast की अपनी ग्राफ़िक्स चिप है, PSP और 3DS की अपनी लाइब्रेरी हैं, और ब्राउज़र WebGL इस्तेमाल करता है। न एडिटर और न ही गेम हर सिस्टम से अलग-अलग बात करते हैं: वे Core से चीज़ें माँगते हैं, हमेशा एक ही तरीके से ("यह मेश ड्रॉ करो", "यह साउंड चलाओ", "यह फ़ाइल खोलो"), और Core जानता है कि हर सिस्टम पर यह कैसे करना है। इसीलिए **एक ही कोड** इतनी अलग-अलग मशीनों पर चलता है, और किसी नए सिस्टम को जोड़ने का मतलब है Core को उससे बात करना सिखाना, एडिटर को दोबारा लिखना नहीं।

यह सब कैसे होता है, पूरे विस्तार से (ग्राफ़िक्स, साउंड, फ़ाइलें, इनपुट, नेटवर्क, लॉग): [Whisk3D Core मैनुअल](../core/README.md)।

## प्रोजेक्ट

सारा काम एक `.w3d` प्रोजेक्ट फ़ाइल में सेव होता है। उसके अंदर सीन के साथ-साथ रिसोर्स भी रहते हैं: टेक्सचर (`texturas/`), स्क्रिप्ट (`scripts/`), साउंड, सीन, प्रीफ़ैब। कोई रिसोर्स .w3d के **अंदर** रह सकता है या **बाहर**, डिस्क पर एक अलग फ़ाइल के रूप में; "Save inside the .w3d" और "Save outside the .w3d" मेनू उसे एक जगह से दूसरी जगह ले जाते हैं। [प्रोजेक्ट](proyecto.md) देखें।

> [!NOTE]
> यह मैनुअल बताता है कि Whisk3D आज क्या-क्या कर सकता है। फ़ंक्शन के नाम वही हैं जो एडिटर में अंग्रेज़ी में दिखते हैं, क्योंकि एडिटर अभी हिंदी में उपलब्ध नहीं है। यहाँ बताई गई कुंजियाँ डिफ़ॉल्ट हैं: आप इन्हें [कीबोर्ड शॉर्टकट](atajos.md) में बदल सकते हैं।
