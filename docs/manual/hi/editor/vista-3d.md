# 3D Viewport

3D Viewport वह जगह है जहाँ सीन दिखता है और एडिट होता है। यह अलग-अलग **मोड** में काम करता है: क्लिक, कुंजियाँ और मेनू क्या करते हैं, यह मौजूदा मोड पर निर्भर करता है। मोड ऊपरी बार के सिलेक्टर से चुना जाता है (यह सिर्फ़ तब दिखता है जब सक्रिय ऑब्जेक्ट मेश या आर्मेचर हो) या <kbd>Tab</kbd> से।

| मोड | किन ऑब्जेक्ट के लिए | किस काम आता है |
|---|---|---|
| [Object Mode](modo-objeto.md) | सभी | पूरे ऑब्जेक्ट बनाना, मूव, रोटेट, स्केल, डुप्लिकेट और पैरेंट करना, और डिलीट करना। |
| [Edit Mode](modo-edicion.md) | मेश और कर्व | वर्टेक्स, एज और फ़ेस एडिट करना (मॉडलिंग)। |
| [Armature Edit Mode](esqueletos.md#armature-edit-mode) | आर्मेचर | बोन बनाना और उन्हें सही जगह रखना। |
| [Pose Mode](esqueletos.md#pose-mode) | आर्मेचर | बोन को पोज़ देना और एनिमेट करना। |
| [Weight Paint](pintura.md#weight-paint) | सिर्फ़ 3D मेश | पेंट करना कि हर बोन हर वर्टेक्स को कितना हिलाती है। |
| [Vertex Paint](pintura.md#vertex-paint) | सिर्फ़ 3D मेश | सीधे वर्टेक्स पर रंग पेंट करना। |
| [Texture Paint](pintura.md#texture-paint) | सिर्फ़ 3D मेश | टेक्सचर पर पेंट करना, सीधे ऑब्जेक्ट के ऊपर। |

## 3D Viewport की ऊपरी बार

| बटन | विवरण |
|---|---|
| मोड सिलेक्टर | मोड बदलता है (Object, Edit, Pose, Paint…)। |
| Vertex / Edge / Face | सिर्फ़ Edit Mode में: क्या चुना जाएगा। |
| Transform Pivot Point | रोटेट और स्केल किसके चारों ओर होगा: 3D Cursor, Individual Origins, Median Point या Active Element। साथ में Lock Normals चेकबॉक्स। |
| Orientation | ट्रांसफ़ॉर्म के अक्ष: Global, Local, Normal (फ़ेस की दिशा) या View। |
| Snap | Snap के विकल्प। चालू होने पर हरा हो जाता है (<kbd>Shift+Tab</kbd>)। |
| Proportional Editing | किसी चीज़ को हिलाने पर, उसके पास वाली चीज़ें भी नरमी से साथ चलती हैं। चालू होने पर हरा हो जाता है (<kbd>O</kbd>)। |
| View | कैमरे, व्यू पॉइंट, फ़्रेम करना, लोकल व्यू, पर्सपेक्टिव, ऑर्बिट लॉक करना, कैमरे को व्यू से लॉक करना। |
| Select | सब, कुछ नहीं, उलटना, बॉक्स, लिंक्ड, लूप और पाथ। |
| Add (+) | सिर्फ़ Object Mode में: नए ऑब्जेक्ट बनाना। |
| Mesh | सिर्फ़ Edit Mode में: मॉडलिंग के ऑपरेशन। |
| Save Texture (डिस्केट) | सिर्फ़ Texture Paint में। बिना सेव की गई पेंटिंग होने पर हरा। |
| Animation (डायमंड) | कीफ़्रेम डालना, डिलीट करना और साफ़ करना; मोशन ट्रेल। |
| Context | मोड का मेनू: Object, Vertex/Edge/Face, Armature या Pose। |
| Overlays (आँख) | कौन-सी सहायक चीज़ें दिखेंगी: फ़र्श, अक्ष, गिज़्मो, 3D कर्सर, नॉर्मल, आँकड़े, एक्स-रे। |
| Render (कैमरा) | शेडिंग मोड। |
| Scene | प्रोजेक्ट का कौन-सा सीन, गेम या प्रीफ़ैब एडिट होगा, यह चुनना, और नए बनाना। |
| UV | सिर्फ़ Edit Mode में: UV को अनरैप और प्रोजेक्ट करना। |

## कई मोड में एक जैसे मेनू

### Select

| फ़ंक्शन | विवरण | शॉर्टकट |
|---|---|---|
| All | सब कुछ चुनता है। | <kbd>A</kbd> |
| None | सारा चयन हटा देता है। | <kbd>Alt+A</kbd> |
| Invert | जो चुना हुआ है वह अचयनित हो जाता है, और उलटा भी। | <kbd>Ctrl+I</kbd> |
| Box Select | बाएँ से दाएँ ड्रैग करने पर (हरा) सिर्फ़ वही चुना जाता है जो पूरी तरह अंदर हो; दाएँ से बाएँ (नीला) बस छू जाना काफ़ी है। <kbd>Shift</kbd> जोड़ता है। | <kbd>B</kbd> |
| Show selection | चुनी हुई चीज़ों की आउटलाइन दिखाता या छिपाता है। | मेनू |

### Render (शेडिंग मोड)

| फ़ंक्शन | विवरण |
|---|---|
| Render Preview | सीन की लाइटों के साथ। अगर रे ट्रेसिंग चालू है, तो ट्रेस की गई इमेज धीरे-धीरे दिखाता है। |
| Material Preview | डिफ़ॉल्ट मोड: व्यू की तरफ़ से एक न्यूट्रल लाइट, जो सीन की लाइटों पर निर्भर नहीं करती। |
| Solid Preview / Wireframe Preview / ZBuffer Preview | ठोस स्लेटी, सिर्फ़ एज, या गहराई। |
| Normal View / Alpha Preview | नॉर्मल रंगों में, या ट्रांसपेरेंसी काले-सफ़ेद में। |
| Motion vectors | पिछले फ़्रेम से हर पिक्सेल स्क्रीन पर कितना हिला (लाल = X, हरा = Y; लैवेंडर = स्थिर, जैतूनी = पृष्ठभूमि)। रेंडर के `_vectores` पास वाली ही इमेज। |
| Wireframe: Only Visible | वायरफ़्रेम व्यू सिर्फ़ वही दिखाता है जो सचमुच ड्रॉ होता है। |

### Overlays

| फ़ंक्शन | विवरण | शॉर्टकट |
|---|---|---|
| Show Overlays | सारी विज़ुअल सहायक चीज़ें एक साथ चालू या बंद करता है। | <kbd>K</kbd> |
| Floor, X Axis, Y Axis, Origins, 3D Cursor, Relationship Lines | हर सहायक चीज़ अलग से। | मेनू |
| Gizmo | मूव/रोटेट/स्केल का गिज़्मो। | मेनू |
| Objects | आर्मेचर, लाइट, कैमरे, एम्प्टी, पार्टिकल, कर्व, हिटबॉक्स दिखाना या छिपाना। | मेनू |
| Normals | वर्टेक्स, कस्टम या फ़ेस नॉर्मल को उनके साइज़ के साथ ड्रॉ करता है। | मेनू |
| Statistics | FPS, वर्टेक्स, फ़ेस, ड्रॉ कॉल और समय। | मेनू |
| X-Ray | एडिट हो रही मेश अर्ध-पारदर्शी दिखती है और आप पीछे वाले एलिमेंट भी चुन सकते हैं। | मेनू |

### Snap

| फ़ंक्शन | विवरण | शॉर्टकट |
|---|---|---|
| Enable | जो चीज़ हिल रही है, वह वर्टेक्स, एज, फ़ेस या उनके केंद्रों से चिपक जाती है। | <kbd>Shift+Tab</kbd> |
| Snap Base और Snap Target | हिलाई गई चीज़ का कौन-सा पॉइंट चिपकेगा (Closest, Center, Median, Active) और किससे। | मेनू |
| Face Project / Face Nearest | रीटोपोलॉजी के लिए: वर्टेक्स किसी दूसरी सतह पर टिक जाते हैं। | मेनू |
| Affect Move / Rotate / Scale | Snap किन ऑपरेशन में काम करेगा। | मेनू |
| Snap menu (कर्सर) | Selection to Grid, Selection to Cursor या Selection to Active; Cursor to Selected, Cursor to World Origin, Cursor to Grid या Cursor to Active। | <kbd>Shift+S</kbd> |

### Proportional Editing

| फ़ंक्शन | विवरण | शॉर्टकट |
|---|---|---|
| Enable | मूव, रोटेट या स्केल करने पर, आस-पास की चीज़ें दूरी के हिसाब से साथ चलती हैं। | <kbd>O</kbd> |
| Connected Only | दूरी को एज के रास्ते मापता है: अलग पड़े टुकड़ों को साथ नहीं खींचता। | मेनू |
| Falloff | असर का आकार: Smooth, Sphere, Root, Inverse Square, Sharp, Linear, Constant, Random। | मेनू |
| Proportional Size | असर का दायरा। ट्रांसफ़ॉर्म के दौरान इसे व्हील से या <kbd>PageUp</kbd> / <kbd>PageDown</kbd> से बदला जा सकता है। | मेनू / व्हील |
