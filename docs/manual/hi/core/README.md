# Whisk3D Core मैनुअल

**Whisk3D Core** वह एब्स्ट्रैक्शन लेयर है जिस पर Whisk3D बना है: चीज़ें माँगने का एक ही तरीका (ड्रॉ करना, साउंड बजाना, फ़ाइलें पढ़ना, कुंजियाँ लेना) और हर सिस्टम के लिए अलग इम्प्लीमेंटेशन। यह मैनुअल उनके लिए है जो C या C++ में प्रोग्राम करते हैं और सीधे Core पर गेम बनाना चाहते हैं। समीक्षा के लिए ड्राफ़्ट।

प्रोजेक्ट का पेज, ब्राउज़र में चलने वाले उदाहरणों के साथ: **[Whisk3D Core](https://leoncini.com.ar/proyecto.php?id=whisk3d-core&lang=hi)**। कोड GitHub पर **[Whisk3D-Core](https://github.com/Dante-Leoncini/Whisk3D-Core)** में है, MIT लाइसेंस के तहत।
