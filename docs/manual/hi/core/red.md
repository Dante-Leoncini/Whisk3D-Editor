# नेटवर्क

**w3dRed** लोकल नेटवर्क, वाई-फ़ाई या इंटरनेट पर, UDP से खेलता है। एक खिलाड़ी मैच **होस्ट** करता है (पोर्ट 47023) और बाकी उसे लोकल नेटवर्क पर **खोजते** हैं या किसी पते से **जुड़ते** हैं। सब कुछ होस्ट से होकर जाता है, अधिकतम 8 खिलाड़ी। मैसेज **भरोसेमंद** हो सकते हैं (सब पहुँचते हैं और क्रम में: "तैयार", "शुरू करो") या **गैर-भरोसेमंद** (जो हर फ़्रेम भेजा जाता है, जहाँ अगला खोए हुए की जगह ले लेता है)।

```cpp
w3dRed::Hostear("mi_juego", "La partida de Dante", 2);
// या, दूसरी तरफ़ से:
w3dRed::Buscar("mi_juego");   // ... w3dRed::Partidas() ... w3dRed::Unirse(direccion);
w3dRed::Enviar(-1, datos, bytes, true);   // -1 = बाकी सभी को
```

| सिस्टम | सॉकेट |
|---|---|
| Windows | Winsock |
| Linux, macOS, Android | POSIX (इंटरफ़ेस की सूची, Android 7 से) |
| Symbian | Open C के सॉकेट |
| Dreamcast | KallistiOS के सॉकेट, नेटवर्क एडैप्टर से |
| ब्राउज़र, PSP, PS Vita, 3DS | अभी नेटवर्क नहीं: `Soportada()` `false` देता है |

कोई गेम नेटवर्क इस्तेमाल नहीं करता अगर ऐप्लिकेशन उसे इसकी अनुमति न दे (`SetPermitida`): एडिटर नेटवर्क इस्तेमाल करने वाला प्रोजेक्ट खोलते समय पूछता है। Lua से: [नेटवर्क पर खेलना](../lua/api-red.md)।
