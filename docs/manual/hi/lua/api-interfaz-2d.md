# 2D इंटरफ़ेस और स्क्रीन

| फ़ंक्शन | क्या करता है |
|---|---|
| `pantalla() → ancho, alto` | कैनवास का साइज़। |
| `margenPantalla() → mx, my` | किसी तय साइज़ वाले कैनवास के चारों ओर, हर तरफ़ कितनी स्क्रीन बचती है, कैनवास की इकाइयों में, स्क्रीन के असली किनारों तक (फ़्रेमिंग की पट्टियाँ भी स्क्रीन ही हैं)। पोर्ट्रेट में 4:3 कैनवास के साथ: किसी मीटर को `my` जितना ऊपर खिसकाने से वह ऊपरी किनारे से सट जाता है। |
| `marcoPantalla() → x, y, ancho, alto` | 3D इमेज का फ़्रेम (कैमरे की फ़्रेमिंग, पट्टियों के बिना), कैनवास की इकाइयों में, उसके केंद्र से। |
| `capturarPantalla(nombre [, conHud]) → ruta` | इस फ़्रेम की 3D इमेज को एक टेक्सचर में कॉपी करता है (सीन पूरा होने पर; `conHud` के साथ, HUD के बाद)। पाथ (`"pantalla:<nombre>"`) `setTextura`, किसी मटीरियल या किसी रूटीन के "Bind texture" कदम में इस्तेमाल होता है। |
| `capturaUV(nombre) → u0, v0, u1, v1` | कैप्चर किए गए टेक्सचर का वह हिस्सा जिसमें इमेज सीधी है, `setUVRect` के लिए (या `nil`, अगर कॉपी अभी नहीं बनी: वह फ़्रेम ड्रॉ होते समय बनती है)। |
| `areaSegura() → x, y, w, h` | स्क्रीन का वह हिस्सा जिसमें notch नहीं है (`inicio` में इस्तेमाल न करें)। |
| `escala() → f` | बिना आर्ग्युमेंट के: साइज़ को स्क्रीन के हिसाब से ढालने का फ़ैक्टर (छोटी भुजा / 480)। |
| `posPx(obj) → x, y`, `setPosPx(obj, x, y)` | किसी 2D एलिमेंट की पोज़िशन (`nil` देने पर वह अक्ष जैसा है वैसा ही रहता है)। |
| `tamPx(obj) → w, h`, `setTamPx(obj, w, h)` | किसी 2D एलिमेंट का साइज़। |
| `cajaUI(obj) → x, y, w, h` | वह आयत जो वह सच में घेरता है (x, y = केंद्र)। |
| `setTexto(obj, valor)`, `setTam(texto, px)` | किसी टेक्स्ट या बटन का टेक्स्ट बदलता है, और फ़ॉन्ट का साइज़ भी। |
| `setTextura(img, "ruta.png")`, `setUVRect`, `setFlipbook` | इमेज बदलता है, उसका एक हिस्सा काटकर दिखाता है (u1 < u0 या v1 < v0 देने पर, वह हिस्सा मिरर होकर दिखता है), या फ़्रेम की शीट को एनिमेट करता है। |
| `setOpacidad(obj, 0..1)`, `fundir(obj, objetivo, paso)` | ट्रांसपेरेंसी और फ़ेड। |
| `setRot2D(obj, grados)` | किसी 2D एलिमेंट को रोटेट करता है। |
| `chocan(a, b) → bool` | क्या दो 2D एलिमेंट स्क्रीन पर एक-दूसरे पर चढ़ रहे हैं। |
| `limitar(obj, area [, eje])`, `dentro(area, x [, y])` | किसी एलिमेंट को दूसरे के अंदर बनाए रखना, या पूछना कि कोई पॉइंट अंदर है या नहीं। |
| `salir()` | गेम बंद करता है (एडिटर में कुछ नहीं करता)। |
