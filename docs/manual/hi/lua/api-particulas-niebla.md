# पार्टिकल, फ़ॉग और दृश्यता

| फ़ंक्शन | क्या करता है |
|---|---|
| `emit(obj [, n])`, `setEmitting(obj, bool)` | पार्टिकल की एक बौछार, या किसी एमिटर को चालू/बंद करना। |
| `getFog(obj)`, `setFog(obj, density [, r, g, b, inicio, fin])` | फ़ॉग पढ़ना और बदलना। |
| `setSector`, `visCell`, `setVisAnchor`, `setVisCurveT`, `setBatch` | लेवल के कौन-से हिस्से ड्रॉ होंगे, इस पर एडवांस कंट्रोल। |
