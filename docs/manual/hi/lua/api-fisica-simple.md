# सरल फ़िज़िक्स (वेग और उछाल)

| फ़ंक्शन | क्या करता है |
|---|---|
| `getVelocity(obj, vx [, vy, vz])` / `getVelocity(obj) → vx, vy, vz` | आप उसे एक वेग देते हैं और इंजन उसे अपने-आप चलाता है। |
| `accelerate(obj, factor [, tope])` | उसके वेग को गुणा करके उसे तेज़ करता है। |
| `box(obj [, x, y, z])` | उसके टक्कर बॉक्स का साइज़: 3D में चौड़ाई (X), गहराई (Y) और ऊँचाई (Z); 2D में पिक्सेल में चौड़ाई और ऊँचाई। |
| `bounce(obj, other)`, `bounceOn(obj, area [, sides])`, `bounceInside(obj, area)` | किसी दूसरे ऑब्जेक्ट से या किसी क्षेत्र के किनारों से उछलना (उछलने पर `true` लौटाते हैं)। |
