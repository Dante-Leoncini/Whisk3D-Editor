# कीबोर्ड, कंट्रोलर, टच और माउस

| फ़ंक्शन | क्या करता है |
|---|---|
| `tecla(nombre) → bool` | कुंजी दबी हुई है (जब तक आप उसे दबाए रखते हैं)। |
| `teclaApretada(nombre) → bool` | ठीक इसी फ़्रेम में दबाई गई (हर बार दबाने पर सिर्फ़ एक बार)। |
| `boton(nombre [, mando])`, `botonApretado(nombre [, mando])` | यही, कंट्रोलर के किसी बटन के लिए। `mando` (1 से 4) देने पर उसी कंट्रोलर का बटन; उसके बिना, किसी भी कंट्रोलर का। |
| `stick(["izq"\|"der"] [, mando]) → x, y` | कंट्रोलर का स्टिक, -1 से 1 तक (ऊपर -1 है)। |
| `gatillo(["izq"\|"der"] [, mando]) → 0..1` | एनालॉग ट्रिगर। |
| `controles() → n`, `control([n]) → nombre, tipo` | कितने कंट्रोलर हैं और किस प्रकार के हैं (`"xbox"`, `"playstation"`, `"nintendo"`, `"generico"`)। |
| `toque() → x, y, tocando` | स्क्रीन पर उंगली (या माउस का क्लिक)। |
| `dedo([n]) → x, y, activo` | मल्टी-टच: n नंबर की उंगली (1 से 4)। |
| `tactil() → bool` | स्क्रीन टच वाली है: कोई फ़ोन या टैबलेट (Android, iPhone का ब्राउज़र…) या कोई भी डिवाइस जिसकी स्क्रीन पहले छुई जा चुकी हो। ऑन-स्क्रीन कंट्रोल सिर्फ़ वहीं दिखाने के लिए जहाँ उनकी ज़रूरत हो। |
| `inclinacion() → x, y, z` | फ़ोन का एक्सेलेरोमीटर, g में, स्क्रीन के उन अक्षों में जैसे वह दिख रही है (घुमाव के बाद): `x` बताता है कि फ़ोन स्टीयरिंग व्हील की तरह दाईं ओर कितना घूमा है (कोण का साइन); सीधा खड़ा करने पर `y = 1`, और मुँह ऊपर करके लिटाने पर `z = 1`। अगर डिवाइस में एक्सेलेरोमीटर नहीं है तो `nil`। |
| `vibrar(ms [, fuerza])` | `ms` मिलीसेकंड तक `fuerza` (0 से 1) के साथ वाइब्रेट करता है: फ़ोन का वाइब्रेटर (Android, ब्राउज़र) और कंट्रोलर की मोटर (PC)। फ़ोन पर `fuerza` पल्स को छोटा करती है। जहाँ वाइब्रेट करने के लिए कुछ न हो, या खिलाड़ी ने वाइब्रेशन बंद कर दिया हो, वहाँ यह कुछ नहीं करता। |
| `apretado(obj) → bool` | इस फ़्रेम में वह 2D एलिमेंट टैप या क्लिक हुआ (बटन)। |
| `raton() → x, y, dentro` | माउस कहाँ है। |
| `capturarRaton(bool)`, `ratonRel() → dx, dy`, `ratonCapturado()` | माउस से चारों ओर देखने के लिए कैप्चर किया गया माउस (फ़र्स्ट-पर्सन गेम)। PC पर और ब्राउज़र में; ब्राउज़र में माउस गेम में पहले क्लिक या पहली कुंजी पर कैप्चर होता है। <kbd>Esc</kbd> उसे छोड़ देता है और गेम को पॉज़ कर देता है। |
