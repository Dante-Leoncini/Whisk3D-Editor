# मैसेज और डीबगिंग

| फ़ंक्शन | क्या करता है |
|---|---|
| `print(...)` | इंजन के लॉग में लिखता है, स्क्रीन पर नहीं। |
| `info(msg)`, `warning(msg)`, `error(msg)` | लॉग में जानकारी, चेतावनी या एरर के मैसेज। `error` स्क्रिप्ट को **नहीं** रोकता। |
| `debugLog(msg)`, `isDebug()` | ऐसे मैसेज जो सिर्फ़ डीबग वर्ज़न में आते हैं। |
| `logCount()`, `logLine(i)` | गेम के अंदर से लॉग पढ़ना (अपना खुद का कंसोल)। |
