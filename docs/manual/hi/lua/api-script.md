# स्क्रिप्ट और आपसी बातचीत

| फ़ंक्शन | क्या करता है |
|---|---|
| `self() → obj` | वह ऑब्जेक्ट जिसकी यह स्क्रिप्ट है। |
| `object(prop) → obj \| nil` | `properties` के `prop` फ़ील्ड में चुना गया ऑब्जेक्ट। |
| `option(prop) → text` | `properties` की किसी ड्रॉपडाउन सूची में चुना गया विकल्प; अगर कुछ नहीं चुना गया, तो सूची का पहला (डिफ़ॉल्ट)। |
| `property(prop) → value` | इस ऑब्जेक्ट की अपनी संख्या, हाँ/नहीं या टेक्स्ट (या घोषित की गई डिफ़ॉल्ट वैल्यू)। |
| `param(prop [, def]) → número` | `property` जैसा, लेकिन हमेशा संख्या; अगर वह मौजूद न हो तो `def` (या 0) लौटाता है। |
| `target() → obj \| nil` | मालिक ऑब्जेक्ट का लक्ष्य ("target")। |
| `getShared(clave) → value` | सभी स्क्रिप्ट की साझा जगह से पढ़ता है। |
| `setShared(clave, value)` | साझा जगह में एक संख्या, हाँ/नहीं या टेक्स्ट लिखता है; `nil` उसे मिटा देता है। |
