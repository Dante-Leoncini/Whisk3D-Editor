# स्क्रिप्ट और आपसी बातचीत

| फ़ंक्शन | क्या करता है |
|---|---|
| `yo() → obj` | वह ऑब्जेक्ट जिसकी यह स्क्रिप्ट है। |
| `objeto(prop) → obj \| nil` | `propiedades` के `prop` फ़ील्ड में चुना गया ऑब्जेक्ट। |
| `opcion(prop) → texto` | `propiedades` की किसी ड्रॉपडाउन सूची में चुना गया विकल्प; अगर कुछ नहीं चुना गया, तो सूची का पहला (डिफ़ॉल्ट)। |
| `propiedad(prop) → valor` | इस ऑब्जेक्ट की अपनी संख्या, हाँ/नहीं या टेक्स्ट (या घोषित की गई डिफ़ॉल्ट वैल्यू)। |
| `parametro(prop [, def]) → número` | `propiedad` जैसा, लेकिन हमेशा संख्या; अगर वह मौजूद न हो तो `def` (या 0) लौटाता है। |
| `objetivo() → obj \| nil` | मालिक ऑब्जेक्ट का लक्ष्य ("target")। |
| `compartido(clave) → valor` | सभी स्क्रिप्ट की साझा जगह से पढ़ता है। |
| `setCompartido(clave, valor)` | साझा जगह में एक संख्या, हाँ/नहीं या टेक्स्ट लिखता है; `nil` उसे मिटा देता है। |
