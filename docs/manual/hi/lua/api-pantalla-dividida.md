# स्प्लिट स्क्रीन (एक ही डिवाइस पर दो खिलाड़ी)

| फ़ंक्शन | क्या करता है |
|---|---|
| `setVistas(n [, "lado" \| "arriba"])` | `2` स्क्रीन को दो हिस्सों में बाँटता है (एक-दूसरे के बगल में या एक-दूसरे के ऊपर); `1` पूरी स्क्रीन पर लौटाता है। 2D इंटरफ़ेस (HUD) एक बार, दोनों के ऊपर ड्रॉ होता है। |
| `setVistaCamara(i, camara)` | व्यू `i` (1 या 2) का कैमरा। सेट न करने पर, सक्रिय कैमरा। |
| `vista() → i, n` | वह व्यू जो ड्रॉ हो रहा है (1 या 2; ड्रॉइंग के बाहर 0) और कितने व्यू हैं। |
| `antesDeVista(i)` | (इसे आपकी स्क्रिप्ट परिभाषित करती है।) इंजन इसे हर व्यू ड्रॉ करने से पहले कॉल करता है, उस स्क्रिप्ट में जिसने `setVistas` को कॉल किया था। यहाँ आप कैमरे की ओर देखने वाली चीज़ों (बोर्ड, पार्टिकल) को उसी कैमरे की ओर घुमाते हैं, या वह छिपाते हैं जो उस व्यू को नहीं दिखना चाहिए। समय के साथ आगे बढ़ने वाली किसी चीज़ को यहाँ न हिलाएँ: वह `actualizar` में जाती है। |

हर आधा हिस्सा अपने कैमरे के साथ एक पूरी इमेज है: गेम का फ़्रेम (कैमरे का आस्पेक्ट) दो हिस्सों में बँट जाता है।

## हर एक के लिए एक कंट्रोलर

`boton`, `botonApretado`, `stick` और `gatillo` **कंट्रोलर का नंबर** लेते हैं (1 से 4, उस क्रम में जिसमें उन्हें पहली बार
हिलाया गया था): `boton("a", 2)`, `stick("izq", 1)`। बिना नंबर के, कोई भी (सब एक साथ), हमेशा की तरह। कीबोर्ड का
कोई नंबर नहीं होता: उसे आप ख़ुद बाँटें (जैसे, खिलाड़ी 1 ऐरो और नंबरों से, खिलाड़ी 2 WASD और अक्षरों से;
QWERTY कीबोर्ड वाले Nokia पर अक्षर भी आते हैं)।

```lua
function actualizar(dt)
  local x1, y1 = stick("izq", 1)
  local x2, y2 = stick("izq", 2)
  if tecla("w") then y2 = -1 end
  mover(jugador1, x1 * dt * 5, y1 * dt * 5, 0)
  mover(jugador2, x2 * dt * 5, y2 * dt * 5, 0)
end
```
