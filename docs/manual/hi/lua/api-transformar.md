# 3D में मूव, रोटेट और स्केल करना

| फ़ंक्शन | क्या करता है |
|---|---|
| `getPosition(obj) → x, y, z` | वह कहाँ है। |
| `setPosition(obj, x, y, z)` | उसे एक सटीक जगह पर रखता है (फ़िज़िक्स को अनदेखा करता है)। |
| `move(obj, dx, dy, dz)` | उसे उसकी मौजूदा जगह से खिसकाता है (इसे `dt` के साथ इस्तेमाल करें)। |
| `getRotation(obj) → x, y, z` | उसका रोटेशन, डिग्री में। |
| `setRotation(obj, x, y, z [, order])` | सटीक रोटेशन, वही जो Transform कार्ड में है। `order` से चुना जाता है कि अक्ष किस क्रम में लागू हों, उदाहरण के लिए `"ZXY"` (पहले ऊर्ध्वाधर अक्ष के चारों ओर दिशा, जैसे किसी वाहन में)। |
| `getRotationX(obj)`, `getRotationY(obj)`, `getRotationZ(obj) → डिग्री` | सिर्फ़ एक अक्ष का घुमाव। `getRotationZ` खड़ी धुरी के चारों ओर का घुमाव है। |
| `setRotationX(obj, g)`, `setRotationY(obj, g)`, `setRotationZ(obj, g)` | सिर्फ़ एक अक्ष बदलता है; बाकी दो वैसे ही रहते हैं। जैसे `setRotationZ(obj, getRotationZ(obj) + 90 * dt)` उसे खड़ी धुरी के चारों ओर घुमाता है। |
| `rotate(obj, dx, dy, dz)` | उसे उसके अपने अक्षों पर घुमाता है। |
| `rotateTowards(obj, dx, dy [, factor])` | उसे फ़र्श पर किसी दिशा (X और Y) की ओर धीरे-धीरे घुमाता है। |
| `lookAt(obj, x, y, z)` | उसे किसी पॉइंट की ओर करता है (कैमरे का सामने वाला हिस्सा)। |
| `getScale(obj) → sx, sy, sz` | उसका स्केल। |
| `setScale(obj, s [, sy, sz])` | सटीक स्केल; सिर्फ़ एक संख्या देने पर सभी दिशाओं में बराबर स्केल करता है। |
| `scale(obj, f)` | मौजूदा स्केल को गुणा करता है। |
| `worldPoint(obj, x, y, z) → x, y, z` | ऑब्जेक्ट के किसी पॉइंट को वर्ल्ड कोऑर्डिनेट में बदलता है। |
| `isVisible(obj) → bool`, `setVisible(obj, bool)` | उसे दिखाता या छिपाता है। छिपे हुए ऑब्जेक्ट को `update` मिलना बंद हो जाता है। |
| `setTint(obj, r, g, b [, a])` | उसका रंग बदलता है (0 से 1 तक की वैल्यू)। |
