# नेटवर्क पर खेलना (LAN, वाई-फ़ाई या इंटरनेट)

नेटवर्क वाले मैच में एक **होस्ट** होता है (जो उसे बनाता है: खिलाड़ी 0) और वे जो उसमें **जुड़ते** हैं (1, 2…)। सब कुछ
होस्ट से होकर जाता है: कोई खिलाड़ी होस्ट को भेजता है और होस्ट उसे बाकी सबको बाँटता है। जो एक ही नेटवर्क पर हैं (एक ही LAN या एक ही
वाई-फ़ाई) वे एक-दूसरे को अपने आप ढूँढ लेते हैं; इंटरनेट पर होस्ट के पते से जुड़ना होता है (और होस्ट के राउटर में
पोर्ट 47023 खुला होना चाहिए)।

| फ़ंक्शन | क्या करता है |
|---|---|
| `redDisponible() → bool [, motivo]` | क्या यह गेम नेटवर्क इस्तेमाल कर सकता है। अगर नहीं, तो कारण: `"sin permiso"` (एडिटर ने इस प्रोजेक्ट को अनुमति नहीं दी) या `"sin red"` (इस प्लेटफ़ॉर्म पर अभी नेटवर्क नहीं है)। |
| `redDispositivo() → texto` | इस डिवाइस का नाम (वह जो दूसरे मैच खोजते समय देखते हैं)। इसे एडिटर में बदला जाता है: **Settings** कार्ड, *Device name*। |
| `redDireccion() → texto` | लोकल नेटवर्क पर इस डिवाइस का IP (इंटरनेट से जुड़ने के लिए या उसे टाइप करके जुड़ने के लिए)। |
| `redHostear(nombre [, maximo [, juego]]) → bool [, error]` | एक मैच बनाता है और खिलाड़ियों का इंतज़ार करता है (`maximo` में होस्ट भी गिना जाता है: डिफ़ॉल्ट 2)। `juego` आपके गेम का नाम है: सिर्फ़ उसी गेम के मैच दिखते हैं। |
| `redAbrir(bool)` | होस्ट खोज में दिखता है और खिलाड़ियों को स्वीकार करता है (`true`) या नहीं (जैसे, जब मैच शुरू हो चुका हो)। |
| `redBuscar([juego]) → bool` | लोकल नेटवर्क पर मैच खोजना शुरू करता है। इसे फिर से कॉल करने पर सूची **अपडेट** होती है। |
| `redPartidas() → { {nombre, dispositivo, jugadores, maximo, direccion}, … }` | वे मैच जिन्होंने जवाब दिया (जब तक आप खोजते हैं, यह अपने आप अपडेट होती है)। |
| `redUnirse(direccion) → bool` | किसी मैच में शामिल होता है: `redPartidas()` का `direccion`, या टाइप किया हुआ पता (`"192.168.0.10"`, `"x.x.x.x:puerto"`)। |
| `redEstado() → estado, error` | `"nada"`, `"buscando"`, `"esperando"` (आप होस्ट हैं), `"conectando"`, `"conectado"` या `"error"` (कारण के साथ)। |
| `redYo() → id` | मैच में आपका नंबर (0 = होस्ट; -1 जब कोई मैच नहीं)। |
| `redJugadores() → { {id, nombre, yo}, … }` | जो मैच में हैं (नाम उनके डिवाइस का नाम है)। |
| `redSilencio([id]) → segundos, limite` | उस खिलाड़ी से कितनी देर से कुछ नहीं आया (बिना `id` के: जिससे सबसे ज़्यादा देर से नहीं आया)। जो जुड़ता है वह सिर्फ़ होस्ट को सुनता है, इसलिए उसके लिए यह होस्ट की चुप्पी है। `limite` (8 s) पार होने पर उसे गया हुआ मान लिया जाता है: होस्ट उसे मैच से निकाल देता है और जो जुड़ा था उसके लिए `redEstado()` `"error"` देता है। |
| `redEnviar(valor [, para [, confiable]]) → bool` | Lua का एक मान (नंबर, टेक्स्ट, बूलियन या टेबल, अंदर टेबल समेत) किसी एक खिलाड़ी को (`para` = उसका id) या सबको (`nil`) भेजता है। **भरोसेमंद** (डिफ़ॉल्ट): पक्का और क्रम में पहुँचता है। `false` के साथ, खो जाने पर दोबारा नहीं भेजा जाता: उसके लिए जो आप हर फ़्रेम भेजते हैं (पोज़िशन, कंट्रोलर), जहाँ अगला उसकी जगह ले लेता है। |
| `redRecibir() → { {de, datos}, … }` | पिछली बार से जो कुछ आया, क्रम में। |
| `redCerrar()` | मैच से निकलता है (होस्ट के लिए: सबके लिए मैच बंद कर देता है)। एडिटर का Stop भी इसे बंद कर देता है। |

## अनुमति

जो प्रोजेक्ट मैच बनाता है, खोजता है या उनमें जुड़ता है, वह तब तक नेटवर्क पर नहीं जाता जब तक यूज़र अनुमति न दे। उसे खोलते समय (या
Play दबाते समय, अगर उसने बाद में नेटवर्क इस्तेमाल करना शुरू किया) एडिटर हर फ़ाइल के लिए **सिर्फ़ एक बार** पूछता है और जवाब याद रखता है। इसे
बाद में **File** कार्ड में बदला जा सकता है: *Network access*। अनुमति के बिना गेम वैसे ही चलता है और `redDisponible()`
`false, "sin permiso"` लौटाता है: नेटवर्क पर खेलने के विकल्प की जगह एक मैसेज दिखाएँ।

## एक उदाहरण: लॉबी

```lua
local JUEGO = "mi_juego"

function inicio()
  if not redDisponible() then info("sin red") return end
  if propiedad("anfitrion") then redHostear(redDispositivo(), 2, JUEGO) else redBuscar(JUEGO) end
end

function actualizar(dt)
  local estado = redEstado()
  if estado == "buscando" then
    local p = redPartidas()
    if p[1] then redUnirse(p[1].direccion) end
  end
  if teclaApretada("enter") then redEnviar({t = "listo"}) end
  for _, m in ipairs(redRecibir()) do
    if m.datos.t == "listo" then info("el jugador " .. m.de .. " esta listo") end
  end
end
```

## सुझाव

- **एक ही गणना**: सबसे सरल और अलग-अलग डिवाइस (एक PC और एक फ़ोन) के बीच सबसे अच्छा चलने वाला तरीका यह है कि
  होस्ट गेम की गणना करे और बाकियों को वह भेजे जो उन्हें दिखाना है; बाकी उसे सिर्फ़ अपना कंट्रोलर भेजते हैं। Dragon Ball
  डेमो (`dbz2w3d/lua/pelea.lua`) यही करता है।
- जो हर फ़्रेम भेजा जाता है, वह **गैर-भरोसेमंद**; जो एक बार होता है (कोई सूचना, "शुरू करो"), वह **भरोसेमंद**।
- **जब नेटवर्क अटक जाए**: अगर किसी लड़ाई में `redSilencio()` सेकंड के कुछ दसवें हिस्सों से ज़्यादा हो जाए, तो दूसरे ने भेजना
  बंद कर दिया है (वाई-फ़ाई कट गया, फ़ोन बैकग्राउंड में चला गया)। गेम पॉज़ करें और सूचना दें ("इंतज़ार हो रहा है…", साथ में `limite` तक
  बचा समय): अगर वह लौटता है, तो गेम वहीं से चलता है जहाँ था; अगर नहीं, तो `redEstado()` या `redJugadores()` यह बता देते हैं।
- उतना ही भेजें जितना ज़रूरी हो: नंबर और छोटे टेक्स्ट। एक मैसेज 60000 बाइट से ज़्यादा नहीं हो सकता।
- ब्राउज़र में अभी नेटवर्क नहीं है (उसमें UDP नहीं है)। Android `INTERNET` अनुमति माँगता है (कंपाइल किया गया गेम इसे साथ लाता है);
  Symbian, `NetworkServices` क्षमता (फ़ोन पूछता है कि किस एक्सेस पॉइंट से बाहर जाना है)।
