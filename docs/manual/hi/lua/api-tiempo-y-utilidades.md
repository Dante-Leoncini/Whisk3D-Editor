# समय, रैंडम और उपयोगी फ़ंक्शन

| फ़ंक्शन | क्या करता है |
|---|---|
| `random() → 0..1`, `random(min, max) → integer` | रैंडम संख्याएँ। |
| `clockMs() → ms` | मिलीसेकंड, यह मापने के लिए कि किसी काम में कितना समय लगता है। |
| `unixTime() → seconds, ms` | सिस्टम का समय, Unix समय के रूप में: 1/1/1970 UTC से अब तक के सेकंड, और अलग से मिलीसेकंड (0–999)। |
| `unixTimeMs() → ms`, `unixTimeSec() → seconds` | वही Unix समय एक ही संख्या में: मिलीसेकंड (पूर्णांक) में या दशमलव वाले सेकंड में। मापना बस घटाना है: `t = unixTimeSec() - start`। 64-बिट Lua के साथ सटीक (Dreamcast को छोड़कर सभी प्लेटफ़ॉर्म; वहाँ `unixTime()`)। |
| `date([seconds [, utc]]) → table` | किसी Unix समय की तारीख़ और समय (न दें तो अभी का), स्थानीय, या `utc = true` के साथ UTC में: `year`, `month`, `day`, `hour`, `min`, `sec`, `wday` (1 = रविवार), `yday`। |
| `luaProfile(frames [, label])` | मापता है कि स्क्रिप्ट के कौन-से हिस्से धीमे हैं (`luaProfile(0)` इसे बंद करता है)। |
| `createLine(name, points)`, `linePoint(id, s)` | इंजन द्वारा गणना किया गया एक स्मूद बंद कर्व (रास्तों के लिए)। |

शुरू होने से अब तक का समय: `start()` में `unixTimeSec()` सहेजें और बाद में घटाएँ (असली समय), या किसी वेरिएबल में `dt` जोड़ते रहें (गेम का समय)।
