# Armature

## Modalità Modifica dell'armatura

| Funzione | Descrizione | Scorciatoia |
|---|---|---|
| Seleziona | Sceglie un'estremità dell'osso o l'osso intero; trascinando lo si sposta subito. | Clic; <kbd>Shift</kbd> aggiunge |
| Tutto / Nessuno | Seleziona o deseleziona tutte le ossa. | <kbd>A</kbd> / <kbd>Alt+A</kbd> |
| Estrudi osso | Crea un nuovo osso da ogni estremità selezionata. | <kbd>E</kbd> |
| Sposta / Ruota / Scala | Con assi e piani come sempre. | <kbd>G</kbd> / <kbd>R</kbd> / <kbd>S</kbd> |
| Duplica | Copia le ossa e le lascia agganciate al puntatore. | <kbd>Shift+D</kbd> |
| Elimina | Elimina le ossa (i loro figli passano al nonno). | <kbd>X</kbd> o <kbd>Delete</kbd> |
| Imposta genitore | Mantieni offset o Connesso. | <kbd>Ctrl+P</kbd> |
| Disconnetti / Rimuovi genitore | Stacca l'osso dal suo genitore. | <kbd>Alt+P</kbd> |

## Modalità Posa

Solo per le armature. Serve per mettere in posa e animare.

| Funzione | Descrizione | Scorciatoia |
|---|---|---|
| Selezionare un osso | Sceglie un osso. | Clic; <kbd>Shift</kbd> aggiunge |
| Sposta / Ruota / Scala | Mette in posa le ossa selezionate. | <kbd>G</kbd> / <kbd>R</kbd> / <kbd>S</kbd> |
| Azzera posizione / rotazione / scala | Riporta l'osso alla sua posa di riposo in quel canale. | <kbd>Alt+G</kbd> / <kbd>Alt+R</kbd> / <kbd>Alt+S</kbd> |
| Inserisci keyframe | Salva la posa nel frame attuale. | <kbd>I</kbd> / <kbd>Shift+I</kbd> |
