# Editor 2D

Per costruire interfacce di gioco, HUD e giochi 2D: testi, immagini, rettangoli, contenitori, slice 9, pulsanti e video.

| Funzione | Descrizione | Scorciatoia |
|---|---|---|
| Aggiungi | Testo, Immagine, Rettangolo, Contenitore, Slice 9, Pulsante, Espandi, Video; Importa w3dui. | Menu Aggiungi |
| Seleziona | Il clic sceglie (trascinando si sposta); <kbd>Shift</kbd>+clic aggiunge; un clic nel vuoto deseleziona. | Clic; <kbd>A</kbd> / <kbd>Alt+A</kbd> / <kbd>Ctrl+I</kbd> |
| Sposta / Ruota / Scala | <kbd>X</kbd> / <kbd>Y</kbd> bloccano l'asse; si può digitare il valore. | <kbd>G</kbd> / <kbd>R</kbd> / <kbd>S</kbd> |
| Ridimensionare | Le maniglie dell'elemento attivo. | Trascinare |
| Duplica / Elimina | Copia spostata e agganciata al puntatore / elimina con conferma. | <kbd>Shift+D</kbd> / <kbd>X</kbd> |
| Imposta genitore / Rimuovi genitore | La selezione diventa figlia dell'elemento attivo, o torna a dipendere dalla UI. | Menu Oggetto |
| Cursore 2D | Si posiziona con <kbd>Shift</kbd>+clic nel vuoto. | <kbd>Shift</kbd>+clic |
| Vista gioco | La tela si vede esattamente come sul dispositivo, senza guide. | <kbd>Num0</kbd> (<kbd>Esc</kbd> esce) |
| Inquadra selezionati / Zoom 1:1…4:1 | Inquadra la selezione; zoom esatto pixel per pixel. | <kbd>Num.</kbd> / menu Vista |
