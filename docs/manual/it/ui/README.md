# Manuale di Whisk3D UI

**Whisk3D UI** è la libreria di interfaccia di Whisk3D: pulsanti, schede, menu a tendina, riquadri delle proprietà, testo e icone, disegnati sopra Whisk3D Core. L'editor è fatto con essa. Questo manuale è per chi programma in C o C++ e vuole usarla per l'interfaccia del proprio gioco o programma. Bozza da rivedere.

La pagina del progetto: **[Whisk3D UI](https://leoncini.com.ar/proyecto.php?id=whisk3d-ui&lang=it)**. Il codice è su **[Whisk3D-UI](https://github.com/Dante-Leoncini/Whisk3D-UI)**, su GitHub, con licenza MIT.
