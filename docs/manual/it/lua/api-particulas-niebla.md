# Particelle, nebbia e visibilità

| Funzione | Cosa fa |
|---|---|
| `emit(obj [, n])`, `setEmitting(obj, bool)` | Una raffica di particelle, o accendere/spegnere un emettitore. |
| `getFog(obj)`, `setFog(obj, density [, r, g, b, inicio, fin])` | Leggere e cambiare la nebbia. |
| `setSector`, `visCell`, `setVisAnchor`, `setVisCurveT`, `setBatch` | Controllo avanzato di quali parti del livello vengono disegnate. |
