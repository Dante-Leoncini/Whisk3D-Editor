# Scene e cinematiche

| Funzione | Cosa fa |
|---|---|
| `changeScene(name [, restart])` | Passa a un'altra scena (menu, livello 2…) alla fine del fotogramma. |
| `playScene(name [, "funcion"])` | Riproduce una scena 3D come cinematica con il gioco in pausa; al termine chiama quella funzione. |
| `stopScene3D()`, `scenePlaying()` | Interrompe la cinematica / dice quale si sta guardando. |
| `draw3D([on])` | Spegne o accende tutto il 3D (per esempio, dietro un menu opaco). |
