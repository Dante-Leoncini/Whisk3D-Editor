# Manuale di Whisk3D Core

**Whisk3D Core** è lo strato di astrazione su cui è costruito Whisk3D: un solo modo di chiedere le cose (disegnare, riprodurre suoni, leggere file, ricevere i tasti) e un'implementazione diversa per ogni sistema. Questo manuale è per chi programma in C o C++ e vuole fare un gioco direttamente sul Core. Bozza da rivedere.

La pagina del progetto, con esempi che girano nel browser: **[Whisk3D Core](https://leoncini.com.ar/proyecto.php?id=whisk3d-core&lang=it)**. Il codice è su **[Whisk3D-Core](https://github.com/Dante-Leoncini/Whisk3D-Core)**, su GitHub, con licenza MIT.
